旺季菠萝用量突增，和供应商临时补货的核心是：**不要只口头说“帮我多送点”，要把增量、时间、价格、验收和违约写清楚，且提前锁定替代方案。** 可执行做法如下：

1. **先内部算清需求再谈**
   - 按未来7天/14天预估用量，扣掉现有库存和在途量，得出“临时缺口”。
   - 明确每天需要多少箱/公斤、规格（品种、单果重量、成熟度、去皮/带皮）、到货时间。
   - 给供应商一个区间而不是固定数，例如“未来两周每天增加20–30箱，提前一天确认次日数量”。

2. **签一份简单的临时补货确认单**
   至少写清：
   - 补货周期和每日/每批数量；
   - 单价及是否随行就市，涨价需提前多久通知；
   - 规格、成熟度、破损率上限；
   - 到货时间和卸货地点；
   - 验收标准与不合格处理（拒收、换货、扣款）；
   - 缺货违约责任或补偿方式；
   - 付款账期是否因临时补货改变。

3. **价格条款要防旺季坐地起价**
   - 优先谈“锁价+浮动上限”，例如以当前价为基准，旺季上浮不超过X%；
   - 或约定“随行就市但需提前24小时书面确认，未确认按原价”；
   - 避免只写“按市场价”，否则旺季容易扯皮。

4. **约定优先级和最低保障量**
   - 写明在同等条件下，供应商应优先保障你的补货量；
   - 设定每日最低保障量，例如“每天不低于20箱”；
   - 若供应商断供，需提前通知并协助调货，或承担差价补偿。

5. **验收和损耗提前说死**
   - 明确成熟度标准，避免旺季给你发过熟果导致损耗；
   - 约定破损率上限（如3%），超出部分扣重或换货；
   - 到货当场抽检并拍照留证，异常当批可拒收。

6. **准备备选供应商**
   - 临时补货不要只押一家，至少提前联系1–2家备选，谈好“随时可调货”的意向价；
   - 主供应商断供时能快速切换，避免门店断料。

7. **用书面方式留痕**
   - 微信、邮件确认也可以，但要把数量、价格、时间、验收标准写清楚；
   - 每次临时增量单独确认，避免月底对账争议。

一句话：**先算缺口，再谈锁量锁价，写清验收和违约，同时备好第二供应商。** 这样旺季临时补货既有保障，也不容易被供应商拿捏。
