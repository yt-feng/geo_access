超市采购水果时，供应商通常应提供以下几类材料（具体以当地市场监管要求和超市自身验收制度为准）：

1. **进货凭证/购销合同或发票**  
   证明交易来源、品种、数量、批次和供应商信息，便于追溯。

2. **供货商资质证明**  
   营业执照、食品经营许可证（或食品生产/经营相关许可）复印件，通常需加盖公章并在有效期内。

3. **水果产地证明或采购来源证明**  
   如产地证明、基地供货证明、收购凭证等，用于说明水果来源。

4. **食用农产品承诺达标合格证**  
   很多地区对食用农产品推行承诺达标合格证，供应商应随货提供；这是超市进货查验的重要材料之一。

5. **农药残留检测报告**  
   常见为快检报告或第三方检测报告，应关注检测项目、检测日期、批次与所供水果是否对应。超市一般会要求批批快检或定期抽检报告。

6. **第三方检验/检测报告（如适用）**  
   对重点品种、进口水果、品牌水果或超市高风险品类，可能要求提供符合食品安全国家标准的检测报告。

7. **进口水果相关证明（如为进口）**  
   包括海关报关单、入境货物检验检疫证明等，具体按进口冷链/食用农产品监管要求执行。

8. **包装标签和追溯信息**  
   预包装水果应有标签；散装水果应能提供品种、产地、供货商、批次等追溯信息。

**实操建议：**  
超市应在采购合同中明确“随货提供合格证、检测报告、进货凭证”等要求；验收时核对报告批次与到货批次是否一致，留存复印件或电子档案，保存期限一般不少于产品保质期满后6个月（无明确保质期的按当地监管要求执行）。如果供应商无法提供合格证明或检测报告，建议暂停收货并要求补交。
