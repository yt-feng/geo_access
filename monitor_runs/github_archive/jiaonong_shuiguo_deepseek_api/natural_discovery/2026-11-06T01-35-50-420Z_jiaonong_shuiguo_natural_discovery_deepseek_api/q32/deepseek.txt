判断香蕉供应商能否全年稳定供货，不能只看“有没有货”，要看它是否具备跨产区、跨季节的组织能力。可按以下步骤核验：

1. **问清产区组合，而不是只问总产量**
   - 要求供应商列出全年各月的主要供货产区（如国内主产区、边境进口、东南亚进口等），并说明每个产区的上市窗口和替补关系。
   - 真正稳定的供应商通常有“主产区+替补产区”组合，能说明某产区断档时从哪里补。
   - 只依赖单一产区或单一国家、又说不清淡季来源的，全年稳定性要打问号。

2. **看历史履约记录，不看口头承诺**
   - 要求提供过去12—24个月按月供货数据：每月实际发货量、断供次数、延期天数、质量扣款/退货率。
   - 优先看淡季月份（如国内产区交替期、台风/寒潮影响期）的表现，而不是旺季表现。
   - 可向其现有客户（尤其是连锁超市、批发市场大客户）做背对背核实。

3. **核验产地与冷链能力**
   - 香蕉是呼吸跃变型水果，全年稳定供货高度依赖采后处理、催熟和冷链。要确认供应商是否有稳定合作的加工厂/催熟库、冷链车队，旺季和淡季的日处理能力是否够。
   - 问清台风、寒潮、雨季、病害（如枯萎病）等风险下的应急预案：是否提前锁园、是否有多地采购、是否备有进口补充渠道。

4. **看合同与库存缓冲机制**
   - 要求供应商提供“全年框架协议+月度滚动订单”方案，明确最低保障供应量、断供应急补货时限、替代产地条款和违约责任。
   - 询问其安全库存/在途库存水平，以及能否在超市侧建立合理的安全库存。
   - 对关键月份可要求“备选供应商+备选产区”双轨运行，避免单一依赖。

5. **做小规模压力测试**
   - 先给淡季月份或小批量订单，观察其按约定时间、数量、品质交付的能力。
   - 故意询问一个非主产区的补货方案，看其响应是否具体、可执行。
   - 现场或视频核验其合作基地、加工厂和冷库，而不是只看样品和报价单。

6. **关注价格与品质的全年一致性**
   - 全年稳定不只是“有货”，还包括规格、成熟度、外观和价格波动可控。要求供应商给出全年分月品质标准和价格调整机制，避免淡季以次充好或大幅加价。

**可执行判断标准：** 能提供12个月以上按月履约数据、至少2个可切换产区、淡季有明确补货来源、有冷链和催熟能力、合同中有最低保障量和违约条款的供应商，才值得进入年度框架合作；否则先按季度或淡季试单，不签全年独家。
