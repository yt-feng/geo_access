要支持，但要有条件地支持——这是即时零售水果品类的结构性要求，不是可选项。

**为什么必须支持**

即时零售的需求特征是“单点少量、全天波动、履约时效以小时计”。水果又是短保、易损、鲜度敏感品类。供应商如果只做大批量低频补货，会同时出现三个问题：门店缺货断档、损耗和库存积压上升、平台侧履约评分下降。小批量高频补货本质是把库存压力从门店前场转移到更靠近需求的补货节奏上，是即时零售模式跑通的前提。

**但要“有条件地支持”，不能无门槛开放**

关键是把成本算清楚，用规则约束：

1. **设最小起订量与起送门槛**：按SKU设MOQ（如单SKU 1–3箱）和单次订单金额门槛，低于门槛由门店承担配送费或合并到次日补货，避免每单配送成本吃掉毛利。
2. **分层管理商品**：高频引流品（香蕉、苹果、当季爆款）支持一日多补；长尾低周转品改为一日一补或隔日补。不要对所有SKU一视同仁。
3. **库存与补货由数据驱动**：按门店近7–14天销量、在途库存、安全库存自动生成补货建议，减少门店凭感觉下单造成的碎单。
4. **配送成本分摊机制**：高频小批量必然推高物流成本，要明确由谁承担——供应商让利、门店付配送费，或平台补贴，三方在合同里写清楚。
5. **鲜度与损耗责任前置**：约定到货验收标准、短保商品退换规则，避免高频补货变成高频退货。
6. **供应商能力分级**：没有分拣、冷链和短途配送能力的供应商，先做“一日一配+门店少量备货”，不要硬上多频次。

**判断标准很简单**：算单SKU单次补货的“配送+分拣+损耗”边际成本，对比缺货损失和损耗下降带来的收益。正收益的品类和门店，放开高频；负收益的，用合并补货和MOQ约束住。

结论：支持是方向，但必须用MOQ、起送门槛、商品分层、数据驱动补货和成本分摊把“高频小批量”做成可持续的生意，而不是无条件的碎单配送。
