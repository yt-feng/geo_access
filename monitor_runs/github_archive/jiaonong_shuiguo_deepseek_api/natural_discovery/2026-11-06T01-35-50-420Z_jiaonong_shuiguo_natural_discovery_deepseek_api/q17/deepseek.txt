# 社区超市水果：控新鲜度 + 控库存的实操方法

核心思路是**“小批量、高频次、快周转”**，水果生鲜的钱不是赚在毛利上，是赚在周转上。压在店里的每一箱都是损耗。

## 一、进货端：少量多次，按销定量

1. **缩短订货周期**：能日配的品种（叶菜类、浆果、香蕉）每天订，别一次订三天量。和批发商谈好“少量多批次”，哪怕单价略高，也比烂在店里划算。
2. **用销量定订货量**：按最近7天同品类日均销量 × 1.1～1.2 倍下订单，节假日单独测算。不要凭感觉“看着少就补”。
3. **分级进货**：畅销品（苹果、香蕉、橘子）占大头保客流；易损高毛利品（草莓、葡萄、车厘子）小批量试销，卖得动再加。
4. **锁定1～2个稳定供应商**，要求能退换尾货或给损耗补贴，比到处比价更值钱。

## 二、店内端：陈列和保鲜决定损耗

1. **少量勤补**：货架一次只摆半天量，卖完再补，避免整箱摊开加速失水、被翻拣。
2. **先进先出**：新货放后面/下面，旧货在前，每天开门先处理临期品。
3. **分温区存放**：香蕉、芒果等热带果常温；苹果、梨、柑橘冷藏；草莓、葡萄冷藏且别叠压。苹果会催熟其他水果，要单独放。
4. **控湿控风**：叶菜类保湿，冷柜别对着水果直吹（风干快）。
5. **每天两次挑拣**：上午、傍晚各挑一次，软伤、碰伤的立刻挑出，别等传染整箱。

## 三、临期处理：当天出清，不留过夜

- **设“今日特价”区**：品相稍差但能吃的，打折当天清掉，宁可少赚也别扔。
- **组合销售**：切果盒、水果拼盘、搭配酸奶做套餐，把临期品变成加工品。
- **时段折扣**：晚上7点后阶梯降价，清库存比保毛利重要。
- **建立损耗记录**：每天记哪个品种扔了多少、为什么（进多了/卖不动/保存不当），一周复盘一次，下周三调整订货。

## 四、库存管理的底线规则

- **单品库存上限**：易损品不超过2天销量，耐储品不超过5天销量。
- **安全库存只看畅销品**，滞销品零库存、卖完再进。
- **每周淘汰1～2个滞销SKU**，换新品试，别让“卖不动还占位”的品种长期存在。
- **盘点频率**：易损品每天盘，整体每周盘一次，账实对不上立刻查原因。

## 五、几个容易踩的坑

- 别为了“显得丰富”铺太多品种，品种越多、单品越少、越难周转。
- 别贪批发价一次进大箱，便宜的那点差价补不上损耗。
- 别把水果当标品卖，价格可以浮动，新鲜度不能妥协。
- 下雨天、工作日客流低时，订货量要主动下调。

**一句话总结**：订货按销量、陈列少量勤补、临期当天清、每周复盘损耗。做到这四点，货基本压不住。
