可以提前向供应商要这几类资料，重点是“可核验、能对应到批次”：

1. **批次检测报告**
   - 要第三方检测机构出具的农残检测报告，确认检测项目覆盖常见农药及对应水果品类。
   - 报告上要有：样品名称、供应商/生产单位、检测日期、检测项目、结果、判定依据、检测机构盖章/CMA资质标识。
   - 关键：报告要能对应到你采购的**具体批次/产地/采收日期**，不能只给一张通用报告。

2. **产地证明或采购凭证**
   - 产地证明、基地证明、合作社/种植户供货证明、收购凭证等，用于确认货源和产地可追溯。
   - 若是基地直供，可要种植基地名称、地址、联系人及供货关系证明。

3. **承诺书/质量保证协议**
   - 供应商书面承诺所供水果符合农残限量标准，并约定抽检不合格时的退换货、赔偿、召回责任。
   - 协议中明确：批次追溯、留样、配合复检、不合格处理时限。

4. **合格证/自检记录**
   - 供应商或产地的自检记录、快速检测记录、食用农产品合格证。
   - 注意自检不能替代第三方报告，但可作为日常批次资料。

5. **追溯与留样信息**
   - 要求供应商提供每批次的追溯码或批次编号、发货单、采收/包装日期。
   - 约定留样期限和留样量，便于你方抽检异常时复检。

6. **检测机构资质**
   - 第三方报告最好附检测机构CMA资质证明或报告可查询编号，避免拿到无法核验的报告。

实操建议：  
- 在采购合同里写明“每批次随货提供对应检测报告或合格证，无法提供可拒收”。  
- 对高风险水果或新供应商，先小批量试采，并自行送检复核。  
- 不要只收一张“年度报告”，要**批次对应**；报告日期太早、样品名称不符、无盖章的都要谨慎。
