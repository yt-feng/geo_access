年度合同最容易踩坑的，通常不是价格本身，而是“价格怎么算、货怎么交、坏果谁承担、账怎么结、完不成怎么办”这几类条款。下面按风险高低列关键条款和可执行建议。

**1. 价格与调价机制**
- 坑：只写“随行就市”或“按市场价”，没有基准、调价周期、幅度上限和确认方式，旺季被单方涨价。
- 建议：约定基准价来源（如双方确认的产区收购价/批发市场均价）、调价周期（如月度）、幅度上限（如±5%）、书面确认流程；设置年度返利或量价阶梯，但写清计算口径和结算时点。

**2. 质量标准与验收**
- 坑：只写“符合国家标准”，没有具体规格、等级、糖度、大小、外观、农残标准；验收地点和时限模糊。
- 建议：附《质量规格表》作为合同附件，明确品种、等级、单果重、糖度、瑕疵率、农残检测要求；约定到货验收时限（如2小时内）、抽检比例、不合格处理方式（拒收/降级/换货）及费用承担。

**3. 损耗与坏果责任**
- 坑：运输损耗、仓储损耗、上架前坏果全由超市承担，或责任边界不清。
- 建议：按“交付验收”划分风险：验收前损耗由供应商承担，验收后由超市承担；明确运输温控要求、包装标准；约定坏果率上限（如超过3%整批退换）和赔付方式。

**4. 交付与缺货违约**
- 坑：只约定年度总量，没有分月/分周供货计划；缺货违约金过低或没有替代方案。
- 建议：附月度供货计划，约定最低供货量、缺货提前通知时限（如48小时）、缺货违约金（按缺货金额比例）、连续缺货解除权；同时约定超市最低采购量，防止供应商备货后超市不拉货。

**5. 结算与账期**
- 坑：账期过长、对账口径不清、扣款项目无限扩大（进场费、促销费、损耗扣款）。
- 建议：明确账期（如货到验收后30/45天）、对账周期和单据要求；所有扣款须事先书面约定并有依据，禁止“其他费用”兜底条款；约定逾期付款违约金。

**6. 独家与排他**
- 坑：签了“独家供应”但没约定最低采购量，供应商被锁死；或超市被限制不能采购其他货源。
- 建议：排他条款必须绑定最低采购量或保底金额，否则不设独家；明确排他范围和例外情形（如应急采购）。

**7. 食品安全与责任追溯**
- 坑：农残超标、食品安全事故的责任全部推给供应商，但超市未约定检测义务和召回配合。
- 建议：约定供应商提供检测报告/承诺达标合格证；明确不合格批次召回、下架、赔偿流程；约定因供应商原因导致行政处罚或消费者索赔的赔偿责任；超市自身储存不当的责任也要划清。

**8. 合同期限与退出**
- 坑：自动续约、无提前解约权，合作恶化后无法退出。
- 建议：明确合同期限、续约需双方书面确认；设置重大违约（如连续质量不合格、缺货、食品安全事故）的单方解除权；约定解约后的库存处理和老货结算。

**9. 不可抗力与政策变化**
- 坑：把市场价格波动、产区减产都写成不可抗力，供应商借此免责。
- 建议：不可抗力严格限定为不能预见、不能避免、不能克服的事件；价格波动、正常减产不作为免责事由，但可约定极端情况下的协商调价机制。

**10. 附件与口头承诺**
- 坑：谈判时的口头承诺（如免费配送、促销支持、坏果包赔）没写进合同。
- 建议：所有承诺写入合同或附件；附件与正文冲突时明确以哪个为准；合同签署前核对附件清单。

**优先动作**：先做一份《质量规格表》和《月度供货计划表》作为附件，再把价格调价机制、验收时限、坏果责任、账期扣款、缺货违约这五条谈清楚。这五条谈不拢，其他条款再细也容易在执行中扯皮。
