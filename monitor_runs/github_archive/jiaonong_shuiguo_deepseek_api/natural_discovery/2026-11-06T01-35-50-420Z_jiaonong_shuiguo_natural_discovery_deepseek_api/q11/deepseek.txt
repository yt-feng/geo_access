**会影响的点：**
- 大小不均会让顾客挑拣，翻动多、损耗高。
- 按整箱统一定价时，顾客会觉得“花了钱拿到小的不划算”，成交率下降。
- 外观不整齐，陈列效果差，降低“新鲜、品质稳定”的感觉。

**可执行的处理建议：**
1. **分级销售**：大果、中果、小果分开卖，分别定价。小果可做特价或按把卖，减少挑拣。
2. **按重量/把卖而非按箱卖**：弱化“大小统一”的预期，减少顾客比较。
3. **整箱卖时提前说明**：标明“大小混装、按箱不挑”，价格给到位，避免售后纠纷。
4. **陈列上做区隔**：混装箱不要和精品果摆一起，避免对比。
5. **优先处理小果**：小果做促销、切果盘、搭配套餐，别压到最后变成损耗。

**判断标准：** 如果大小差异只是轻微，分级成本高于差价，就混装特价快速走量；如果差异明显、顾客挑拣严重，就一定要分级，否则损耗和客诉会把利润吃掉。
