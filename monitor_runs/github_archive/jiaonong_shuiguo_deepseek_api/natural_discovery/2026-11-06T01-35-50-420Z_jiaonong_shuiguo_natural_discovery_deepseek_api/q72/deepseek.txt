先把目标说清楚：你要的不是“账期越长越好”，而是用可承受的账期和额度，换取大客户的稳定采购和你的资金安全。建议按下面顺序谈。

**1. 先定自己的底线**
- 算清你每月的现金流：可被占用的资金上限=自有流动资金－安全备用金（建议至少覆盖1个月采购和运营）。
- 给单个客户设“最大敞口”：不要超过你可占用资金的30%—50%，避免一家客户拖垮你。
- 设好止损线：一旦客户逾期超过约定天数，立即停供并转现款，不因“大客户”破例。

**2. 账期和额度分开谈，不要一步给满**
推荐阶梯式方案：
- 首期合作1—3个月：现款或7天账期，额度控制在单周采购额的1—2倍。
- 稳定采购3个月、无逾期后：账期放到15天，额度提到单月采购额的50%左右。
- 持续稳定6个月以上：再谈30天账期，额度不超过单月采购额的70%—100%，且设硬上限。
- 超过上限部分：现款结算或预付。

**3. 用“额度”换“承诺”**
账期不是白给的，要换对等条件：
- 最低月采购量或最低采购额承诺；
- 固定采购频次和提前下单时间；
- 大客户承担部分物流或损耗；
- 价格上给稳定客户小幅优惠，但账期严格按合同执行。

**4. 合同里必须写清**
- 账期起算日（建议按对账单确认日起算，不按发货日）；
- 对账周期和付款日；
- 逾期违约金（如日万分之几）和停供权；
- 额度上限及超额处理方式；
- 质量异议期限，避免客户用质量问题无限拖款。

**5. 风控动作**
- 要求客户提供营业执照、经营流水或过往供应商证明；
- 前几单小额试单，观察付款是否准时；
- 每月对账，书面确认欠款余额；
- 大客户集中度过高时，主动控制额度，不因“稳定”放松监控。

**谈判话术参考**
“我们可以给稳定客户账期，但需要分阶段建立信任。前三个月现款或7天，稳定后我们给15天账期、额度为月采购额一半；半年无逾期再谈到30天。超过额度的部分现款。这样既能保证您供货稳定，也能让我们持续给您供好货。”

核心原则：**账期跟着履约记录走，额度跟着回款能力走，任何大客户都不突破你的现金流底线。**
