# 水果到货不合格：补货条款怎么约定才不断货

核心思路：**把“验收—补货—替代—责任”四件事写进合同和到货单，让不合格当批直接换成可用货，而不是等供应商慢慢赔。**

---

## 一、合同里必须写死的5个条款

**1. 验收标准要具体到可判定**

不要只写“新鲜、无腐烂”，要写明：
- 品类、等级、规格（单果克重/果径、糖度范围，如百香果糖度≥X）
- 允许损耗率（如坏果率≤3%，超过整批拒收或按比例扣款）
- 包装要求（箱重、内衬、冷链温度记录）
- 参考图片或封样，作为附件

**2. 补货时限分档约定**

| 情形 | 补货时限 | 说明 |
|---|---|---|
| 整批拒收（腐烂、异味、农残） | 当日或次日上午营业前 | 必须赶在开店前 |
| 部分不合格（坏果率超标） | 24小时内补齐合格量 | 差额补，不整批换 |
| 轻微不符（规格偏小但可用） | 下次送货时冲抵 | 折价使用，避免断货 |

时限要写“送达门店”而不是“发出”，并明确起算时间（如验收签字后X小时）。

**3. 补货的替代机制（关键，防断货）**

- 供应商无法按时补货时，**门店可自行采购同品质水果应急，差价及运费由供应商承担**（凭票据结算）；
- 或约定“同品类等价替代”：某品种缺货时，供应商须提供门店认可的同价位替代品，且不影响当日菜单供应；
- 紧急补货渠道要提前留好联系方式（供应商备用仓、二级批发市场），写进合同附件。

**4. 责任与扣款**

- 不合格批次不计入当月采购量，不付款或已付的在下期货款中抵扣；
- 因断货导致门店停售某产品的，按约定标准补偿（如按该产品日均毛利×停售天数）；
- 连续X次或月度不合格率超Y%，门店有权单方解除合同。

**5. 验收流程固化**

- 到货当场开箱抽检（按比例抽，如每批抽10%且不少于2箱），拍照留证；
- 验收单双方签字，注明不合格数量和处理方式（拒收/折价/补货）；
- 补货单单独开，注明“补X月X日批次”，避免混账。

---

## 二、实操上防止影响营业的3个动作

1. **安全库存**：对高频核心水果（柠檬、芒果、百香果等）保持1.5～2天用量，补货窗口留出缓冲；
2. **错峰到货**：要求补货在上午10点前或闭店后送达，避开出品高峰；
3. **双供应商**：核心品类至少备一家备用供应商，合同里不必写，但要有询价和试单记录。

---

## 三、一句话模板（可直接抄进合同）

> 乙方所供水果经甲方按附件《验收标准》验收不合格的，整批拒收的须于当日营业结束前补送合格货品；部分不合格的须于验收后24小时内补足差额。乙方逾期未补或补货仍不合格的，甲方有权自行采购同品质替代品，差价、运费及因此产生的停售损失由乙方承担，并可从应付货款中直接扣除。

要点就一句：**补货时限要卡在营业节点上，替代采购权要握在自己手里。**
