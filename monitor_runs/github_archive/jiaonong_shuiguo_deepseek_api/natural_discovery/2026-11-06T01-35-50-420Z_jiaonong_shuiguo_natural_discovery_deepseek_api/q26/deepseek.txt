社区超市卖小包装香蕉，采购和包装要对“损耗可控、动销快、不压货”负责。建议重点抓下面几件事。

**1. 包装规格：先小份、可拆、透明**
- 单份净重建议 **400–600g**，约3–4根，适合1–2人当天或两天内吃完；客流小的社区可先做 **2–3根/份** 试销。
- 用**透明透气袋或带孔托盘+保鲜膜**，不要完全密封；香蕉呼吸产热，闷袋易起水汽、发黑。
- 袋上打孔或选透气膜，袋口不要扎死，留排气。
- 标签写清**净重、单价、总价、包装日期**，不要只贴总价，避免顾客觉得小包装溢价高。
- 份量要稳定，采购时按“可分出多少份”核算，不只看整箱斤价。

**2. 采购成熟度：按销售节奏分批拿**
- 小包装最怕“整批同时熟”。采购时要求**青黄适中、硬身**，优先拿能放2–3天转黄的货。
- 一次采购量按 **1–2天销量** 控制；夏季或高温天再压缩，宁可少量多次补。
- 要求供应商**按成熟度分箱**，不要青黄混装；到店后青果和黄果分开存放。
- 明确验收标准：果指饱满、无大面积黑斑、无裂果、无霉点、果柄完整；轻微表皮擦伤可接受，但压伤、水烂果拒收。
- 采购单上约定**损耗补偿或换货比例**，比如到货坏果超过约定比例由供应商补换，避免损耗全由门店承担。

**3. 到店后减少二次损耗**
- 香蕉**不要冷藏**，放在阴凉通风处，避免日晒、空调直吹和挤压。
- 整箱不要堆太高，小包装不要叠压；用浅筐单层或两层摆放。
- 每天挑出黑斑重、过软的果子，**拆包转做特价份或熟蕉促销**，不要等烂在袋里。
- 包装时不要提前全部封袋，可按预估销量分时段包，减少袋内水汽。
- 保持货架先进先出，包装日期朝外。

**4. 定价和陈列配合损耗**
- 小包装会有包装和分拣成本，定价可略高于整把单价，但要和整把形成明显便利差异，避免顾客比价后不买。
- 设**临期/熟度分级**：青黄果正常价，熟蕉做“即食特价份”，黑斑明显的及时下架处理。
- 陈列量少而勤补，不要一次上满；社区店客流分散，满陈列容易剩货。

**5. 采购时可直接问供应商的几句话**
- 这批货成熟度几成？能放几天？
- 能不能按青、黄分箱？小份采购能否混拼？
- 到货坏果、压伤果怎么补换？
- 箱内是否有过度催熟或水烂情况？

优先建议：**先按400–500g/份试销一周，记录每天销量和报废份数，再定采购量和份量。** 小包装香蕉的核心不是包装好看，而是采购成熟度可控、每天能卖完、坏果能及时转特价。
