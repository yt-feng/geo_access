甜度和出汁率不是二选一，要按**用途**分优先级；但如果只选一个更重要的，通常是 **出汁率优先**。

判断逻辑：

1. **鲜果切片/装饰、果肉口感类产品**
   - 优先看**甜度稳定、纤维少、酸甜平衡**。
   - 出汁率低一些可以接受，因为主要吃果肉和卖相。

2. **菠萝汁、果茶基底、糖浆/果酱自制、冷萃/气泡饮**
   - 优先看**出汁率**。
   - 出汁率低意味着单杯原料成本高、出品效率低、风味被水稀释后不稳定；甜度可以通过糖浆、复配水果或标准化配方调整。

3. **门店通用采购**
   - 更实操的排序：**出汁率 ≥ 甜度稳定性 ＞ 香气 ＞ 酸度 ＞ 纤维感 ＞ 卖相**。
   - 原因：甜度不达标容易用糖补，出汁率低则补不了，直接推高成本、影响产能。

4. **例外**
   - 如果主打“高甜鲜果”且不做果汁，甜度权重会上升。
   - 如果菠萝只做装饰，出汁率几乎不重要，卖相和耐存放更重要。

**可执行建议：**
- 先按产品线拆需求：鲜果装饰用果、榨汁用果分开采购。
- 让供应商提供或自测：出汁率、可溶性固形物（糖度）、酸度、纤维感。
- 定一个最低门槛：例如出汁率低于某值直接不采；糖度只作为配方调整参数，不作为唯一淘汰标准。
- 小批量盲测：同配方做3杯，看出汁量、甜酸平衡、香气和成本，再定供应商。

一句话：**做果汁/基底，出汁率更重要；做鲜果口感/装饰，甜度和卖相更重要。通用门店采购，出汁率优先。**
