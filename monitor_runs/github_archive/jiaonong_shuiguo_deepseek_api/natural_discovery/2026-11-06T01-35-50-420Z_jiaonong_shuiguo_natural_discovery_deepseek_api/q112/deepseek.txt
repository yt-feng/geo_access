水果采购合同里，坏果率的赔付触发线没有统一法定标准，通常是 **合同约定优先**；没有约定时，按行业惯例和实际验收情况协商或索赔。可执行判断如下：

1. **合同有约定：按约定执行**
   - 常见写法是：坏果率超过 **3%～5%** 起扣或要求赔付；超过 **10%** 可拒收、退货或解除该批次。
   - 生鲜水果因品类差异大，浆果类、易损果可能容忍度低，耐储果可略高。

2. **合同没约定：建议按验收标准主张**
   - **坏果率 ≤3%**：一般视为合理损耗，较难单独主张赔付。
   - **3%～5%**：可要求按坏果比例扣款或补货。
   - **超过5%**：有较强理由要求赔付、折价或换货。
   - **超过10%**：可主张拒收该批次、退货、解除合同或索赔实际损失。
   - 这不是法定统一线，最终看品种、运输距离、验收时限和证据。

3. **合同里最好明确写清**
   - 坏果率计算口径：按重量还是按个数；抽样比例；抽样方法。
   - 验收时限：到货后几小时内开箱验收，逾期是否视为合格。
   - 赔付方式：按坏果比例扣款、补发、退货，还是赔偿实际损失。
   - 例外情形：运输途中非卖方原因造成的腐烂如何分担。
   - 争议处理：复检机构、复检时限、费用承担。

**建议**：如果你正在签合同，直接把“坏果率超过5%按超出部分扣款，超过10%可拒收并索赔”写成明确条款；如果是已经发生纠纷，先看合同约定，再固定开箱视频、称重记录、抽样照片和验收单，按约定比例主张。
