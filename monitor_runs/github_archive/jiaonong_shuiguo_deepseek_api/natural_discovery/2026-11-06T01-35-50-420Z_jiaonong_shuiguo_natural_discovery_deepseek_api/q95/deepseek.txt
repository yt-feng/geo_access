选供应商别只看报价，按“先定验收标准、再比供货能力、最后小批量试供”三步走最稳。

**1. 先定可验收的标准**
- 香蕉：按成熟度分级，食堂当天用选黄带少量青、无黑斑压伤；要求供应商按“几成熟”供货，避免一送就烂。
- 苹果：定品种、单果规格（如70–80mm）、果面损伤率上限（如≤3%）、糖度或口感不达标退换。
- 橙子：定品种和产区范围，要求无腐烂、无严重干水，单果规格和皮厚可接受范围写清。
- 通用：农残检测报告/承诺、腐烂率上限、缺斤少两处理、送货时间、退换货时限、临时加单响应时间。

**2. 比供应商的供货能力**
重点看：
- 是否有稳定产地或一级批发渠道，能否全年不断供；
- 冷链/周转筐/运输条件，水果是否混装挤压；
- 每天能否按食堂用量分批次送，而不是一次压货；
- 出现质量问题能否2–4小时内补货或退换；
- 是否愿意签框架协议并接受月度考核。

**3. 小批量试供再定**
选2–3家同时试供2–4周，按“到货合格率、损耗率、准时率、价格稳定性、售后响应”打分。食堂水果损耗敏感，合格率和准时率应优先于最低价。

**4. 合同里写死关键条款**
- 验收标准和不合格处理：当场拒收、扣款或补送；
- 价格机制：按周/月询价，设最高限价，避免临时暴涨；
- 账期和结算方式；
- 食品安全责任和检测报告随货或按月提供；
- 备选供应商机制，主供出问题能切换。

**建议采购方式**：常见水果可找本地一级批发商+产地直供各一家做对比；不要只找一家，也不要单纯最低价中标。先试供香蕉这类易损耗品，最能看出供应商水平。
