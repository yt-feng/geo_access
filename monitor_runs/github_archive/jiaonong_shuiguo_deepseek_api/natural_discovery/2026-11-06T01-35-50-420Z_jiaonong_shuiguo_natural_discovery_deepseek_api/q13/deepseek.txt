小水果店做小区团购，供应商要优先支持这6类服务：

1. **小批量、多频次配送**
- 支持每日或隔日送，能按团购单量分拣。
- 可拆零、混装，不强制整箱起订。
- 有临期/损耗补货机制。

2. **稳定品质与分级标准**
- 明确果径、甜度、成熟度、瑕疵率标准。
- 支持坏果包赔、缺斤少两补差。
- 到货时间可控，避免团购集中到货时品质波动。

3. **团购专属价格与账期**
- 给小区团购阶梯价，量小也有合理毛利。
- 支持先货后款或短账期，降低小店现金流压力。
- 价格保护：团购开团后短期内不随意涨价。

4. **售后与损耗兜底**
- 坏果、压伤、少件快速补发或退款。
- 明确售后响应时限，最好当天处理。
- 支持拍照报损，流程简单。

5. **包装与分拣支持**
- 提供适合小区自提的预包装、标签、提货单。
- 可按团长/小区分筐分袋，减少小店二次分拣。
- 包装能承受短途配送和自提搬运。

6. **信息与运营配合**
- 提前给品类、产地、到货量、建议零售价。
- 支持预售锁货、临时加单、团购爆品优先供应。
- 能配合做试吃、促销物料或简易宣传图。

**判断供应商是否合适，重点看4件事：**
- 起订量是否低、配送是否稳；
- 坏果赔付是否爽快；
- 团购价是否留得出20%以上毛利空间；
- 能否按小区订单分拣，减少店主人工。

建议先小范围试团1—2周，重点记录：到货准时率、坏果率、售后响应速度、分拣耗时。这四项稳定后再扩大团购群和品类。
