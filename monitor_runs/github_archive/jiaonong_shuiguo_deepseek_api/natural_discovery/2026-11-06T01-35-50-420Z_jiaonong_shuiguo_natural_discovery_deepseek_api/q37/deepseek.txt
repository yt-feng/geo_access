商超会员日水果活动，供应商要提前配合的重点不是“只供货”，而是围绕**备货、品质、价格、陈列物料、人力、应急**六件事做预案。可执行清单如下：

1. **确认活动机制与销量预估**
   - 明确会员日时间、促销价、限购规则、预估销量、主推单品和替补单品。
   - 按门店/区域拆分供货量，预留10%—20%安全库存，避免缺货或压货。
   - 与商超确认订单截止时间、补货频次、配送时段和到店验收标准。

2. **锁定货源与价格**
   - 提前锁定产地/批发市场货源，确认活动期采购价波动风险由谁承担。
   - 对易涨价的单品做备选供应商或替代规格，避免临时断供。
   - 促销价、毛利分担、损耗承担、返利或补贴方式提前书面确认。

3. **品质与分级标准**
   - 按商超验收标准做分级：糖度、果径、色泽、成熟度、包装规格、农残检测报告。
   - 活动前1—2天做批次抽检，避免集中到货后大批退货。
   - 明确次品、损耗、退换货规则，尤其是草莓、荔枝、榴莲等易损耗品。

4. **包装与陈列物料**
   - 提前备好活动装、家庭装、礼盒装、称重标签、价签、爆炸贴、试吃物料。
   - 确认陈列道具：堆头筐、端架、保鲜冰袋、喷雾设备、试吃台。
   - 物料到店时间要早于活动开始至少半天，避免活动当天等人等物料。

5. **配送与人力安排**
   - 活动日凌晨或前一晚配送到店，避开早高峰；明确卸货、上架、理货由谁负责。
   - 供应商安排驻店或巡店人员，重点门店活动首日必须有人。
   - 建立补货响应机制：缺货2小时内响应，紧急补货4小时内到店。

6. **试吃与促销配合**
   - 提供试吃样品、一次性餐具、手套、垃圾袋，安排试吃人员或培训门店员工。
   - 主推单品准备话术：产地、口感、甜度、适合人群、保存方法。
   - 配合商超做堆头陈列和动线引导，避免只供货不管卖。

7. **应急与售后**
   - 准备断货替代方案、天气导致到货延迟方案、品质异常召回方案。
   - 活动后24小时内完成对账、损耗确认和退换货处理。
   - 活动结束后复盘：销量、缺货率、损耗率、客诉、毛利，形成下次备货依据。

一句话：供应商要在活动前**把量、价、质、物料、人到店、应急方案全部确认到书面和具体时间点**，而不是等活动当天再补位。
