建议先用“ **小把为主、单根补充、整袋做少量试销**”的组合，而不是只选一种。

可执行判断：

1. **小把（2～3根）做主陈列**
   - 最适合便利店：客单价低、买来就能吃完，冲动购买率高。
   - 适合上班族、学生、单人家庭。
   - 建议放在收银台附近或鲜食区端头，标价清晰。

2. **单根做补充和引流**
   - 适合只想买一根、搭配早餐或临时购买的人。
   - 缺点是损耗和理货成本相对高，容易被捏、被碰伤。
   - 建议只保留少量，并用小托架或独立价签管理。

3. **整袋包装谨慎试销**
   - 适合家庭客群或周边社区型便利店，不是所有门店都适合。
   - 整袋容易因购买频次低造成熟损，建议先小批量测试7～14天。
   - 如果整袋销量低、损耗高，就撤掉或改为预订。

**推荐上架结构：**
- 小把：约60%陈列量
- 单根：约20%～30%
- 整袋：约10%～20%试销

**判断标准：**
连续观察1～2周，看三点：销量、损耗率、高峰时段补货频率。小把卖得最快就扩大占比；单根损耗高就减少；整袋如果一天卖不动且出现黑斑，就停止常规上架。

结论：**便利店优先选小把，单根辅助，整袋少量试销后再决定。**
