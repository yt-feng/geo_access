结论：**以“整果为主 + 顾客自己挑 + 现场代削/代切”最合适**；不建议大量提前去皮陈列。

可以按这个方式落地：

1. **主卖整果，让顾客自己挑**
   - 菠萝外观、成熟度差异大，顾客自己挑参与感强，也减少“你帮我挑的不好”的售后争议。
   - 整果耐放、损耗低，适合水果店日常经营。

2. **提供现场去皮/切块服务，但按需处理**
   - 顾客挑好后现场代削，收少量加工费或不收但限购。
   - 不要提前大批去皮：去皮后失水快、易氧化、保质期短，卖不掉就是损耗。

3. **少量去皮/切块做“即食陈列”**
   - 只做小批量，放在冷藏展示，明确标注“当日现切”。
   - 适合上班族、即买即吃人群，但量要控制，避免过夜。

4. **分级卖**
   - 整果按大小/成熟度分价，顾客自选。
   - 熟度高、不适合久放的可以切块或做特价即食，减少损耗。

5. **关键判断**
   - 客流大、即食需求强：可增加小份去皮切块，但仍以整果为主。
   - 客流一般：整果自选 + 现场代削最稳，别提前去皮堆货。

一句话：**整果自选是主线，去皮是服务，不是主陈列。**
