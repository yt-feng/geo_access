结论：**优先做切配（鲜切）线上卖，其次冷冻原料，整果最不适合作为主推。**

简要判断：

1. **整果菠萝：不建议作为线上主推**
   - 优点：损耗低、标准化相对容易、客单价可做促销。
   - 缺点：线上用户看不到实物，成熟度难保证；菠萝有刺、削皮麻烦，售后争议多；重量和配送成本高；生鲜整果竞争激烈、毛利低。
   - 适合：产地直发、低价引流、团购，但不适合作为核心利润品。

2. **切配鲜切菠萝：最适合线上卖**
   - 优点：即食、方便，匹配线上即时零售和家庭消费；可做小规格、高毛利；冷链短保模式成熟；用户复购和评价可控。
   - 关键条件：必须有冷藏/冷链配送能力；加工间卫生资质和短保管理要到位；切配后保质期短，适合城市仓+即时零售，不适合全国远距离发货。
   - 风险：损耗和食安要求高，需控制切配到履约的时间。

3. **冷冻菠萝原料：适合B端和特定C端场景**
   - 优点：保质期长、损耗低、适合远距离电商；标准化程度高；可做烘焙、饮品、餐饮供应链。
   - 缺点：C端家庭直接消费场景弱，需要解冻和再加工；口感和鲜切有差距；C端认知和溢价有限。
   - 适合：B端餐饮/茶饮/烘焙供货，或C端做冰沙、烘焙原料等细分品类。

**建议组合：**
- 主推：**鲜切菠萝**，走即时零售/社区团购/城市冷链，小规格、高复购。
- 辅助：**冷冻菠萝**，做B端供货和长保电商补充。
- 引流：**整果菠萝**，只做产地直发或低价团购，不作为利润核心。

如果只能选一个：**选切配鲜切菠萝**，但前提是你有冷链和短保履约能力；没有冷链就选**冷冻原料**。
