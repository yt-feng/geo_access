优先选**鲜果**，其次**冷冻果丁**；**果泥只适合做特定产品**，不建议作为茶饮店主力原料。

**直接建议**
1. **主推果茶、要有果肉感**：买**鲜果**，门店自己切丁/捣压。香气和口感最好，顾客感知强；缺点是损耗、人工、批次酸甜不稳定。
2. **追求稳定出品、降低人工**：买**冷冻菠萝果丁**。比果泥有咀嚼感，比鲜果稳定，适合连锁或高峰期门店。
3. **做冰沙、奶昔、果酱型产品、需要成本可控**：用**果泥**，但不要单独当“鲜果茶”卖点，最好与果丁/鲜果搭配。
4. **糖水菠萝罐头**：只适合临时替代或做甜感重的产品，香气和鲜感弱，不建议作为主原料。

**采购判断标准**
- 看菜单定位：强调“鲜切/手捣/真果肉”就必须用鲜果或冷冻果丁。
- 看门店人力：没人切果、损耗控制弱，选冷冻果丁。
- 看季节和成本：菠萝旺季用鲜果；淡季或价格波动大时用冷冻果丁兜底。
- 看单杯用量：果茶通常需要果肉感，果泥容易“像果汁”，复购感知弱。

**最稳妥组合**
- 中小店：**鲜果为主 + 冷冻果丁备用**。
- 连锁/标准化店：**冷冻果丁为主 + 少量鲜果做展示和高端款**。
- 果泥只用于冰沙、复合果酱、限定款，不作为菠萝果茶唯一原料。

另外，菠萝做果茶要重点控制**酶导致的苦味和口感发涩**：鲜果切后尽快用，必要时短时焯水/盐水处理，并先小批量试酸度和出汁率再定采购。
