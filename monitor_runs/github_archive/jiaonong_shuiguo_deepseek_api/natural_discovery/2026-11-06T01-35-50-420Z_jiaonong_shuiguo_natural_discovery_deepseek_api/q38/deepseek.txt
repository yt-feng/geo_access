大型超市对水果供应商的要求，通常分成“食品安全合规能力”和“物流履约能力”两条线。下面给出可执行、可判断的清单，便于你自查或筛选供应商。

## 一、食品安全能力（硬门槛）

1. **主体资质与许可**
   - 营业执照、食品经营/生产许可（按实际业态）、种植/加工环节相关许可。
   - 若为进口水果：进出口资质、海关报关与检验检疫证明、入境货物检验检疫证明。
   - 有机、绿色、地理标志等认证按超市要求提供，且证书在有效期内。

2. **源头与基地管理**
   - 自有基地或稳定合作基地清单，能追溯到具体地块/合作社/农户。
   - 农业投入品管理：农药、化肥、保鲜剂采购与使用记录，禁用农药清单执行。
   - 采收前安全间隔期管理，有农残自检或委托检测记录。

3. **检测与验收能力**
   - 每批次农残快检能力或第三方检测报告，检测项目覆盖超市抽检重点。
   - 重金属、真菌毒素等按品类风险定期检测。
   - 能配合超市验收标准：外观、成熟度、糖度、缺陷率、农残合格证明随货。

4. **加工与包装卫生**
   - 分选、清洗、打蜡、包装环节的卫生规范与人员健康证。
   - 包装材料符合食品接触材料要求，标签标识合规（品名、产地、等级、日期、贮存条件等）。
   - 保鲜剂、蜡类使用符合国家标准并有记录。

5. **仓储与冷链卫生**
   - 仓库防虫防鼠、温湿度监控、清洁消毒记录。
   - 冷链水果全程温控记录，冷藏/冷冻库温度异常报警。
   - 先进先出、批次管理，避免交叉污染。

6. **追溯与召回**
   - 批次码/追溯码体系，能从门店批次倒查到基地和检测记录。
   - 不合格品召回流程、演练记录、客诉与食品安全事件处置机制。
   - 食品安全责任险（大型超市常要求）。

7. **体系与人员**
   - HACCP、ISO22000、FSSC22000等体系认证（视超市门槛）。
   - 食品安全管理员、检验人员配置及培训记录。
   - 供应商审核配合：能接受超市或第三方飞行检查。

## 二、物流与履约能力

1. **冷链运输**
   - 冷藏车/保温车资源，车厢温度实时监控与记录可导出。
   - 按品类分温区运输，装车前预冷，运输途中温度异常处理预案。
   - 车辆清洁消毒记录，防交叉污染。

2. **仓配与分拣**
   - 产地仓/销地仓布局，具备分选、预冷、包装、暂存能力。
   - 越库（cross-docking）或直送门店能力，分拣准确率和破损率可控。
   - 先进先出与批次管理，临期/瑕疵品隔离机制。

3. **配送时效与覆盖**
   - 覆盖超市门店/DC的配送网络，明确到货时效、频次、最小起订量。
   - 高峰期（节假日、促销）运力保障方案和备用承运商。
   - 到货预约、卸货配合、回单与签收流程规范。

4. **订单与信息协同**
   - 能对接超市订单系统/EDI，提供库存、在途、批次数据。
   - 异常订单（缺货、短装、质量问题）响应时限和补货机制。
   - 可提供温控记录、检测报告随货或系统上传。

5. **损耗与质量管理**
   - 明确运输损耗率、到货合格率、客诉率等KPI。
   - 到货验收不合格的处理：拒收、换货、折价、赔偿规则。
   - 对易腐水果的预冷、包装、堆码、通风等操作规范。

6. **应急与召回物流**
   - 食品安全事件时的下架、召回、隔离运输能力。
   - 突发事件（天气、交通、疫情）保供预案。

## 三、快速判断供应商是否达标

- **证照与检测**：能否随货提供批次检测合格证明和追溯信息？
- **冷链证据**：能否导出运输全程温度记录，异常有无处置记录？
- **追溯闭环**：任选一个门店批次，能否在约定时间内倒查到基地和投入品记录？
- **履约数据**：近3—6个月到货合格率、准时率、损耗率、客诉率是否可提供？
- **审核配合**：是否接受飞行检查、第三方审核和召回演练？

大型超市通常还会要求供应商签署质量保证协议、食品安全承诺书，并购买产品责任险。以上清单可作为供应商准入审核表逐项打分。
