建议优先“整果为主、切果为辅”，而不是二选一。更可执行的判断如下：

**1. 先看门店客群**
- 社区店、中老年占比高、家庭采购多：**整果更适合**，耐放、损耗低、客单价高、毛利更可控。
- 商圈店、年轻客群、白领/学生多、即食需求强：**切果更适合做增量**，但必须小份、勤切、冷藏陈列。
- 混合客群：**整果占主陈列，切果做小份试吃/即食补充**。

**2. 看菠萝本身的经营难点**
菠萝整果的问题是：顾客嫌削皮麻烦、回家处理成本高；切果的问题是：**损耗和食品安全风险明显更高**，暴露时间长会影响卖相和口感。
所以：
- 整果适合做**低价引流、家庭装、堆头陈列**；
- 切果适合做**即食小份、试吃转化、下午/晚间补位**，不适合大量提前切好压库存。

**3. 建议的采购和陈列策略**
- 采购端：整果按日常销量备货，切果用**同批次整果现切**，不要单独大量采购切果。
- 陈列端：整果堆头+切果小盒并排，切果盒标注“现切/当日售完”。
- 定价端：整果走性价比，切果允许略高单价，但分量要小，降低顾客尝试门槛。
- 时段端：切果集中在**上午补切、下午高峰和晚间少量补切**，闭店前打折清货。
- 损耗端：切果当天未售完不建议次日继续原价卖；整果可做次日的特价或加工成果切/果汁。

**4. 什么情况下更适合主推切果**
只有同时满足以下条件才建议切果占比提高：
- 门店有冷藏陈列和相对稳定的客流；
- 有专人能频繁现切、换盒、控温；
- 即食消费占比高；
- 能接受较高损耗并做好当日清货。

**结论：**
大多数商超更适合**整果做主销、切果做补充和增量**。整果负责销量、毛利和耐储；切果负责便利性、试吃转化和年轻客群。不要把切果当主力大量备货，除非门店客流、冷藏条件和现切管理都跟得上。
