选规格的核心是**按出成率和损耗算，不要只看单价**。水果拼盘主要追求：切块整齐、色泽好看、损耗低、当天能用完。

**苹果**
- 优先选**单果 200–250g 的中大果**：出成率高，切块规整，摆盘好看。
- 不选过大的果：单果太大往往切后容易氧化、边角料多；也不选小果，去皮去核后净料太少。
- 划算判断：按“去皮去核后净重÷采购重量”比较，通常中果出成率更稳定。餐厅用量大可选**80–90mm 果径的箱装一级果**，比礼盒果便宜。

**橙子**
- 做拼盘优先选**果径 70–80mm 的脐橙/晚伦晚类**：皮薄、瓣形完整、好剥。
- 不选太小的果：剥皮损耗大、瓣小；也不选过大的果，瓣太厚切开不好摆。
- 划算判断：看出汁率和剥皮损耗。拼盘用橙子重在瓣完整，不建议买榨汁级小果。

**菠萝**
- 优先选**单果 1.2–1.5kg 的中果**：去皮去眼后净肉比例较稳，切块大小均匀。
- 过大的菠萝芯粗、边角多；过小的去皮损耗高。
- 划算判断：按“去皮去眼后净重”算，不按整果单价算。量大可直接用**已去皮菠萝净果**，省人工，但要算清净料单价是否低于自处理。

**统一采购建议**
1. 先称 3–5 个样品，记录**去皮去核后的净重**，算出实际净料成本。
2. 拼盘用果选**一级或二级商品果**即可，不必用礼盒果；外观要求高时选一级，控制成本选二级但剔除伤果。
3. 苹果、橙子、菠萝都按**当天用量分批采购**，水果拼盘损耗主要来自存放和氧化，库存天数比单价更影响划算程度。
4. 和供应商谈**固定果径/单果重规格**，比“统货”更利于标准化出品和成本核算。
