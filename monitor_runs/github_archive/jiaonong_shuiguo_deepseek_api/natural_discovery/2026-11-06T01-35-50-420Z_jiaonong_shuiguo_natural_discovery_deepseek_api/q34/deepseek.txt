# 价格低 vs 损耗低：哪个更影响最终毛利？

**结论先说：在商超水果品类里，损耗对最终毛利的影响通常远大于采购价格，而且价格和损耗往往是联动的——低价往往买来的是高损耗风险。**

## 为什么损耗更关键

毛利率的本质公式可以拆成：

> 毛利 = 销售额 − 销货成本 − 损耗成本
> 实际毛利率 ≈ 理论毛利率 − 损耗率 ÷（1 − 损耗率）的影响

水果是生鲜里损耗率最高的品类之一，行业常见损耗率在 **8%~20%**（叶菜/浆果类更高，苹果柑橘等耐储类偏低）。关键点在于**损耗直接吃掉毛利，且是乘法关系**：

- 假设理论毛利率 25%，损耗率 10% → 实际毛利率约 **16.7%**
- 同样理论毛利 25%，损耗率 18% → 实际毛利率约 **8.5%**

也就是说，损耗率从 10% 涨到 18%，毛利几乎腰斩。而采购价再压低 5%，对毛利率的改善通常只有 1~3 个百分点（取决于加价率）。**8 个百分点的损耗恶化，远不是几个点的进价能补回来的。**

## 但两者不是独立的，低价常是损耗的诱因

采购价特别低，通常意味着：尾货、成熟度高、品相差、产地远/冷链不足、批次不稳定。这些都会推高损耗。所以"低价"带来的账面毛利，经常被后端损耗抵消甚至倒亏。**真正该比较的不是"进价"和"损耗"，而是"进价 + 由它引来的损耗"的总成本。**

## 可执行的判断方法

用**"到手可用成本"**而不是"采购单价"来决策：

> 有效成本 = 采购单价 ÷（1 − 预计损耗率）

举例：A 货 5 元/斤、损耗 8% → 有效成本约 5.43；B 货 4.3 元/斤、损耗 20% → 有效成本约 5.38。B 看起来便宜 14%，实际成本几乎一样，还多占了货架、人工和报废风险。按这个口径比，才看得出低价是否真便宜。

## 采购动作上的优先级

1. **先控损耗结构**：分品类设损耗红线（耐储类 ≤8%，易损类 ≤15%），超线就复盘订货量、陈列、冷链、促销清货。
2. **再谈价格**：在同损耗档次内比价才有效；用有效成本口径比价。
3. **用"低价"换"周转"而非换"毛利"**：低价货要么快进快出（缩短在架时间、加大促销），要么别进。
4. **考核联动**：采购的 KPI 不能只看进价，要挂"到店损耗率/动销率"，否则采购会把损耗成本转嫁给门店。

**一句话：控损耗是保毛利的地基，压价格是锦上添花；低价如果伴随高损耗，通常是负贡献。**
