买香蕉时，想让它在你要吃的时候正好熟，关键是把“采购时成熟度”和“到家后变色速度”一起考虑。先定用途再挑颜色：

**1. 按计划吃的时间选颜色**
- **当天/第二天吃**：选**全黄、略带少量褐斑**的，甜度和软度最合适。
- **2～3天后吃**：选**黄中带绿尖**、捏起来略硬的。
- **4～5天后吃**：选**整体偏绿、棱角明显**的。
- **马上做奶昔/香蕉泥/烘焙**：可以选**有褐斑但没烂**的，更甜更软。
- **不要买**：大面积发黑、渗汁、表皮破损、根部霉变、捏起来局部软烂的。

**2. 到店快速判断**
- **看棱角**：棱角越明显越生；越圆润越熟。
- **看颜色**：绿→黄→褐斑，成熟度递增；褐斑集中在表皮、果肉不烂通常还能吃。
- **轻捏中部**：硬=生，微软=刚好，局部软塌=过熟或碰伤。
- **看果柄和根部**：发黑、发霉、有异味的不要。
- **看整串**：整串成熟度较一致更好；如果一串里已有几根过熟，别指望回家后其余几根还能放很久。

**3. 采购策略**
- 如果超市离家近、你几天内会吃完：买**黄中带绿**的，回家常温放，每天观察。
- 如果要放一周：**一部分买偏绿、一部分买微黄**，错开成熟。
- **不要一次买一整串都很黄的**，除非当天分装冷冻或做香蕉泥。
- 超市冷柜里的香蕉如果表皮发黑但果肉硬，可能是低温冻伤，口感会差，尽量别选。

**4. 回家后控制成熟速度**
- **想催熟**：和苹果/梨装纸袋，常温避光，别密封太死。
- **想慢熟**：擦干表面、根部包保鲜膜、常温阴凉通风处，**不要先放冰箱**；香蕉低温会冻伤发黑。
- **已经熟透**：剥皮切段冷冻，做奶昔/烘焙；或冷藏1～2天尽快吃。
- **别和已经过熟的水果混放**，乙烯会加速其他香蕉成熟。

一句话：**当天吃选全黄微斑，2～3天吃选黄中带绿，要放久选偏绿；捏中部微软、棱角不明显、根蒂无霉最稳。**
