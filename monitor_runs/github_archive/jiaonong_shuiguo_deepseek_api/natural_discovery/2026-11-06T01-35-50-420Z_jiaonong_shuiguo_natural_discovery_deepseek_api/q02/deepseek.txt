对社区小水果店，香蕉这个单品，建议的优先级是：**熟度（到店可售窗口）> 坏果率/损耗 > 价格 > 送货速度**，但具体排序要看你的售卖节奏和客群。更准确地说，不是四选一，而是先卡“能卖”的底线，再谈成本。

**1. 熟度排第一**
香蕉是后熟水果，到店太青要等，太黄当天卖不掉就变损耗。小水果店最怕“看起来便宜，但到店不能立刻卖或两天内集中变黑”。进货时要明确你要的是几分熟：比如计划2天内卖完，可要略黄带青；如果当天主推即食，要偏黄但无黑斑。熟度决定周转，周转决定你后面三项有没有意义。

**2. 坏果率/损耗排第二**
香蕉损耗隐蔽：碰伤、水烂、果柄发霉、箱底压伤，到店后才显现。小店的利润很薄，10%坏果就可能吃掉价格优势。谈价时要问清“坏果怎么算、能否拍照补损、箱底是否同样品质”，不要只看表面报价。

**3. 价格排第三**
价格重要，但应该比较“可售成本”，不是箱价。算法很简单：**可售成本 = 进价 ÷（1 - 坏果率 - 预计损耗率）**。比如A家便宜10%但坏果加损耗高15%，实际更贵。小水果店单次进货量不大，优先选稳定、可少量多次补的供应，而不是单纯最低价。

**4. 送货速度排第四**
香蕉不是叶菜，对“几小时送达”没那么敏感；但送货慢会影响你补货节奏和鲜度窗口。如果供应商能稳定次日达、按你要求的熟度送，速度够用即可。真正要警惕的是“承诺快但混装、挤压、熟度不可控”。

**实操建议：**
- 先定你的香蕉周转目标：当天卖完、2天卖完、还是3天，对应不同熟度。
- 每次进货留样拍照，记录坏果率和损耗，连续3次比较供应商。
- 新供应商先小批量试，不要一次压货。
- 价格谈判围绕“坏果补损”和“稳定熟度”，比单纯压价更有用。

一句话：**小水果店进香蕉，先买“能按时卖掉的熟度”和“低隐性损耗”，再谈便宜；送货速度只要稳定够用就行。**
