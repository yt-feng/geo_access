酒店采购水果盘原料时，建议把“规格和外观标准”写成可验收的条款，而不是只写“新鲜、无破损”。可按以下维度向供应商明确要求，并在到货验收时逐项抽检。

## 一、通用规格要求

1. **品种与等级**
   - 明确品种名称、产地范围、等级（如一级/特级），不接受以次充好或混级。
   - 同一批次品种、成熟度、大小应基本一致。

2. **单果规格**
   - 按品种约定单果重量或直径范围，例如：
     - 苹果/梨：单果直径或重量区间；
     - 橙/柑橘：横径区间；
     - 草莓：单果克重区间；
     - 葡萄：单穗重量、果粒大小；
     - 西瓜/哈密瓜：单果重量区间。
   - 允许偏差建议控制在±5%～10%，超出部分可拒收或折价。

3. **成熟度**
   - 到货时应达到“即切即食”或“短时后熟即可使用”的成熟度。
   - 过生、过熟、软烂、发酵味均不合格。
   - 需要后熟的水果应明确到货成熟度阶段和可存放天数。

4. **新鲜度与货架期**
   - 明确采摘/采收后至到货的最长时限。
   - 到货后酒店可接受的剩余货架期，例如不少于2～3天。
   - 叶菜类、浆果类应冷链运输，到货中心温度符合要求。

5. **安全与合规**
   - 农药残留符合国家限量标准，必要时提供检测报告或承诺书。
   - 不得使用违规催熟、保鲜或染色处理。
   - 预切水果原料还应符合即食食品微生物要求。

## 二、外观标准

1. **色泽**
   - 具有该品种成熟时应有的色泽，色泽均匀，无明显褪色、发白、褐变。

2. **形态**
   - 果形端正，无明显畸形、裂口、机械压伤、虫眼、病斑。
   - 不得有影响切配出成率的严重凹陷、腐烂点。

3. **表面与清洁**
   - 表面干净，无泥土、药斑、霉斑、异物。
   - 不得有肉眼可见的虫体、虫卵、毛发、塑料等异物。

4. **缺陷允许度**
   - 建议按抽检比例设定：单果轻微瑕疵面积不超过果面一定比例（如5%），且不影响切盘外观。
   - 腐烂、霉变、异味、流汁为“零容忍”，发现即整批退回或隔离处理。

5. **大小与整齐度**
   - 同批次大小、颜色、成熟度整齐，便于标准化切盘和控成本。
   - 混装果应分层明确，不得底层以小果、次果充数。

## 三、包装与运输标准

1. 包装牢固、清洁、无污染，标签注明品种、产地、等级、重量、采收/包装日期。
2. 易压伤水果应有分隔、衬垫；浆果类使用透气浅盒。
3. 冷链品种到货温度应符合约定，运输过程不得与生肉、化学品混装。
4. 到货数量允许短溢装比例，例如±2%～5%，超出按实际结算。

## 四、验收与不合格处理建议

- **抽检比例**：每批次按件数抽检，重点查腐烂、压伤、成熟度、大小偏差。
- **验收记录**：拍照留证，记录批次、到货时间、温度、抽检结果。
- **不合格处理**：轻微偏差可折价接收；腐烂、异味、严重混级可整批拒收；连续两次不合格可要求整改或更换供应商。
- **合同附件**：把上述规格、外观、包装、运输、验收方法写成《水果原料验收标准》作为合同附件，避免口头标准。

简言之，供应商应保证：**品种等级明确、单果规格可量化、成熟度适切、新鲜无腐烂、色泽形态正常、无病虫害和异物、包装运输合规、农残安全可追溯**。酒店则按合同附件逐批抽检并留证。
