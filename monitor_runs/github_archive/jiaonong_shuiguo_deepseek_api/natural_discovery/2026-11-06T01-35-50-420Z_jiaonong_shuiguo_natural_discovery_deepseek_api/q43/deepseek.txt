评估水果供应商的仓配覆盖，核心不是看“供应商有几个仓”，而是看**从供应商仓到每家门店的到货时效、损耗可控性、成本可承受性**是否匹配。建议按下面框架做可执行评估。

## 1. 先定评估口径

对每家门店建立“门店-供应商仓-配送线路”的最小评估单元，明确：

- **到货时效要求**：叶菜/浆果/熟度敏感品 vs 根茎/耐储品，分开定。
- **验收标准**：到店温度、破损率、成熟度、缺货补货时限。
- **配送频次**：日配、隔日配、一周多配。
- **单店最小起订量/拼车条件**。
- **仓配责任边界**：供应商送到店、送到城市中转点、还是门店自提。

没有这些口径，覆盖半径没有意义。

## 2. 用“时效圈”而不是“公里圈”评估覆盖

按品类分别划圈：

| 品类 | 关键约束 | 评估重点 |
|---|---|---|
| 叶菜、浆果、鲜切水果 | 保鲜期短、怕压 | 仓到店运输时长、冷链完整性、日配能力 |
| 常规水果 | 耐储性中等 | 配送频次、拼车效率、到店损耗 |
| 根茎、耐储水果 | 损耗低 | 成本、整车装载率、跨城干线能力 |

建议输出每家门店的：
- 最近可用仓
- 正常/高峰/恶劣天气下的到店时长
- 是否满足品类时效
- 超时后的替代仓或替代线路

## 3. 做门店级覆盖矩阵

把所有门店按城市、商圈、销量、品类结构打标，形成矩阵：

- **A类**：高频、高销量、时效敏感 → 必须有本地仓或城市前置仓支撑
- **B类**：中频、常规品 → 可接受区域仓+城市中转
- **C类**：低频、耐储品 → 可跨城干线覆盖

判断标准建议：
- 时效敏感品到店时长是否稳定达标；
- 单店配送成本是否高于品类毛利可承受线；
- 缺货/断货时是否有 2 小时内补货或替代方案；
- 同一城市门店能否拼车，装载率是否经济。

## 4. 重点评估“仓配能力”，不只看仓库数量

对每个供应商仓核查：

1. **冷链能力**：冷藏/冷冻/常温分区，温控记录，断链应急。
2. **分拣与加工能力**：是否支持按门店分拣、称重、贴标、成熟度分级。
3. **车辆与线路**：自有车/外包车比例，日配送班次，跨城干线频次。
4. **峰值能力**：节假日、促销、新店开业时能否加车加人。
5. **异常处理**：坏果、短少、延迟的补发和赔付机制。
6. **信息系统**：订单、库存、在途温度、到店签收是否可追溯。

## 5. 做覆盖测算，而不是凭感觉

每个门店算三个指标：

- **时效达标率** = 按品类时效要求到店订单数 / 总订单数
- **到店损耗率** = 报损数量或金额 / 到货数量或金额
- **单店单箱配送成本** = 线路总成本 / 门店订单箱数或重量

再按城市汇总：
- 城市覆盖率 = 满足时效门槛的门店数 / 城市总门店数
- 经济覆盖率 = 配送成本可接受的门店数 / 城市总门店数

这两个覆盖率往往不同，要分开看。

## 6. 设“覆盖不合格”的判定线

建议明确几条硬门槛，例如：

- 时效敏感品到店时长超过约定时限的门店，视为“时效不覆盖”；
- 到店损耗率连续高于品类阈值，视为“质量不覆盖”；
- 单店配送成本高于毛利承受线，视为“经济不覆盖”；
- 同城门店无法拼车、单店起送量不达标，视为“线路不覆盖”。

对不覆盖门店，给出三种方案：
1. 供应商增设城市前置仓/中转点；
2. 调整配送频次或品类结构；
3. 引入本地补充供应商或区域二供。

## 7. 落地建议

先做一张表，每行一家门店，列：城市、品类需求、最近仓、到店时长、配送频次、损耗率、单店配送成本、是否达标、替代方案。然后按城市聚合，和供应商逐城谈覆盖承诺与考核指标。

**一句话判断标准：** 如果一家门店的时效敏感水果不能在约定时长内稳定到店、损耗可控、单店配送成本可承受，就不能算被供应商仓配真正覆盖；仓的数量只是背景信息。
