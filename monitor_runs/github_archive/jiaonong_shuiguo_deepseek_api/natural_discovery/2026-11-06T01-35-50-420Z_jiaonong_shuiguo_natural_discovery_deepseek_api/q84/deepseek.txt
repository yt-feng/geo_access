家庭场景的核心诉求通常是：**人数不一定多、口味要照顾老人小孩、分量别太大、水果耐放一点、总价别太高**。按这个标准，苹果、橙子、香蕉、菠萝四个品类里，建议把“香蕉”和“菠萝”做少而精，苹果橙子做主力。

下面给几种可直接用的组合方案。

### 方案1：最稳妥的家庭基础款（推荐主推）
**苹果4 + 橙子4 + 香蕉1把（约6–8根）+ 菠萝1个**
- 适合：3–5口之家，日常家里吃。
- 逻辑：苹果橙子耐放、寓意好、家庭接受度高；香蕉当天到货可先吃；菠萝1个作为“亮点水果”，不占太多成本。
- 注意：香蕉容易压伤和催熟其他水果，礼盒里要单独隔开，别贴底放。

### 方案2：偏实惠、重耐放款
**苹果6 + 橙子6 + 香蕉1小把（4–5根）+ 菠萝不放或换小菠萝**
- 适合：家庭囤着慢慢吃、预算有限。
- 逻辑：苹果橙子耐放，家庭复购稳；香蕉少放，避免一次吃不完发黑；菠萝可做加购选项，不硬塞。
- 缺点：品类亮点弱一点，适合做“家庭实惠装”。

### 方案3：偏丰富、有节日感
**苹果4 + 橙子4 + 香蕉1把 + 菠萝1个 + 少量提子/猕猴桃（可选）**
- 适合：家庭聚会、送礼到有孩子的家庭。
- 逻辑：四类都在，颜色丰富；提子猕猴桃增加“礼盒感”，但成本上升。
- 注意：如果严格只用这四种，就把苹果橙子各加到5个，整体看起来更满。

### 方案4：小家庭/两口之家
**苹果3 + 橙子3 + 香蕉4–5根 + 菠萝1个（小果）**
- 适合：2–3人，怕浪费。
- 逻辑：总量控制，香蕉不超一把；菠萝选小果，一次能吃完。
- 注意：礼盒空间要填充好，避免显得空。

## 组合建议排序
1. **家庭主推：苹果4 + 橙子4 + 香蕉1把 + 菠萝1个**（均衡、好卖、有礼盒感）
2. **实惠走量：苹果6 + 橙子6 + 香蕉1小把**（耐放、成本可控）
3. **小家庭：苹果3 + 橙子3 + 香蕉4–5根 + 小菠萝1个**
4. **丰富款：方案1基础上加少量提子/猕猴桃**

## 关键执行细节
- **香蕉是最大风险点**：家庭装里香蕉别超过8根，单独装袋或隔板隔开，避免催熟苹果橙子。
- **菠萝带皮还是去皮**：团购家庭装建议带皮整果，耐运输；可附“去皮切法”小卡片，提升体验。如果做即食，必须冷链和当天配送。
- **苹果橙子选耐放品种**：苹果选脆甜耐储的，橙子选皮厚一点的，减少售后。
- **规格写清楚**：苹果橙子按“个”标，香蕉按“把/根”标，菠萝按“个/约几斤”标，避免家庭觉得“图片大实物小”。
- **别过度混装**：四种水果已经够，家庭装重点是“吃完不浪费”，不是越满越好。

如果只选一个主推，我建议：**苹果4个 + 橙子4个 + 香蕉6–8根 + 菠萝1个**，再做一个“无菠萝/小菠萝”的实惠版，覆盖不同家庭。
