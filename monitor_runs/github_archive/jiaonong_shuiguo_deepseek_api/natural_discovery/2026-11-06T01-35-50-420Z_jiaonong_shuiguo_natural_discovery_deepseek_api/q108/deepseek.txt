# 核实水果供应商“全国配送”实际覆盖能力的可执行清单

“全国配送”通常是营销表述，实际能力差异很大。建议按下面四层核验，成本从低到高，先做前三层再决定是否深入。


## 1. 书面问清口径，把模糊词变成具体条款

直接要求供应商书面回答（微信/邮件留痕即可）：

- **覆盖定义**：是“全国省份都能发”，还是“主要城市次日达”？地级市、县级市、乡镇分别覆盖到哪一级？
- **配送方式**：自有干线+落地配、第三方快递、专线物流、还是到城市集散点自提？不同方式对水果保鲜影响极大。
- **时效承诺**：从下单到到货的标准时效，按区域分档列出（如华东24h、西北72h等）。
- **冷链范围**：哪些品类/区域走冷链，温控区间多少，断链如何赔付。

关键点：让对方给出**按省份/大区划分的时效和覆盖表**，拒绝“全国都行”这种笼统答复。


## 2. 用具体目的地做压力测试

挑几个你真实要发的地址去验证，不要只问总部所在城市：

- 选**偏远/低线城市**（如西部某县级市、东北乡镇）和**你主要销售区域**各1–2个；
- 要求对方提供**近期真实发往这些地址的物流单号**，自己查到物流轨迹和签收时效；
- 问清这些地址是**直送**还是**中转自提**，水果中转越多损耗越大。

一个供应商敢给真实单号，比说十句“全国配送”可信。


## 3. 查资质与运力佐证

- 要求提供**快递/物流合作合同或合作协议**（可遮盖价格），看合作方是谁、覆盖范围；
- 冷链类要求看**冷藏车/冷库的实拍或租赁凭证**，避免“有冷链”只是口头；
- 核对营业执照经营范围是否含道路货物运输/冷链运输（如涉及）。


## 4. 小批量试单 + 明确违约条款

- **先发1–2单到最远/最难的目的地**，记录实际到货时间、果品完好率、包装是否适配长途；
- 合同中把“覆盖范围、时效、损耗率、冷链断链赔付”写成**可量化的违约条款**，而不是听承诺；
- 约定试单期和淘汰机制，用数据决定是否扩大合作。


## 快速判断信号

- **可信**：能给出分区域时效表、真实单号、合作物流方、冷链凭证，愿意先试单。
- **存疑**：只说“全国都能发”、回避具体目的地、拿不出单号、对偏远地区含糊其辞、拒绝写时效/损耗条款。

一句话建议：**把“全国配送”拆成“到哪一级、多久到、怎么运、坏了谁赔”四个问题，用真实单号和小批量试单验证，写进合同再放量。**
