优先看**切果损耗**，其次甜度，再看外观，大小最后。

原因是超市卖菠萝的真实利润不在“单个好看”，而在**整批可售率和损耗**：菠萝有冠芽、厚皮、眼、两端，切果出成率差异很大；一批果如果外观漂亮但出成率低、坏果多，毛利会被吃掉。

具体判断顺序：

1. **切果损耗（最优先）**
   - 看去皮去眼后的净果率、切坏率、黑心/水心/烂心比例。
   - 同一批抽切几个，记录“毛重→净果重”，算出成率。
   - 损耗高的果不适合主推，除非售价能覆盖。

2. **甜度**
   - 菠萝是典型“复购靠口感”的水果，酸涩会直接压复购。
   - 用糖度计抽测，结合成熟度；不要只看颜色。
   - 甜度稳定比单次极甜更重要。

3. **外观**
   - 外观影响首购和陈列，但不是核心利润项。
   - 看果形端正、果眼浅、无裂口、无腐烂、冠芽新鲜。
   - 外观好但切果损耗高的批次要谨慎。

4. **大小**
   - 大小影响定价和客群：太大单价高、家庭客犹豫；太小出成率低、切果麻烦。
   - 应选目标客群接受的规格，而不是一味求大。
   - 大小均匀度影响陈列和定价效率，可放在外观里一起看。

实操建议：**先小批量抽切算净果率，再测糖度，最后看外观定陈列和定价；大小按门店客群定主推规格。** 如果只能盯一个指标，就盯“每批切果净出成率+坏果率”，这是超市菠萝最直接的盈亏线。
