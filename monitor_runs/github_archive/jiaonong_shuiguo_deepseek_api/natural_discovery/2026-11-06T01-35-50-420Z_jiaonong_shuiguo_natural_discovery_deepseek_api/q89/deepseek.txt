# 阶梯价 vs 返利：给价格敏感团购客户的建议

**结论先行：优先用阶梯价（量价挂钩），返利用作补充。** 对价格敏感型团购客户，"看得见的现价折扣"比"事后返利"的心理权重高得多，成交推动力更强。

## 为什么阶梯价更合适

1. **价格敏感 = 决策时点敏感。** 团购客户在比价下单那一刻就要算出到手价。阶梯价直接体现在报价单上，客户一眼能算清"50件多少钱、100件多少钱"；返利是事后兑现，客户会打折看待（"不知道能不能拿到""拿到也是以后的事"），对首单成交作用弱。
2. **团购天然有量。** 团购客户本来就是凑量采购，阶梯价正好匹配其行为模式，还能反向刺激"再加20件就降一档"，推动凑单。
3. **规则简单、争议少。** 阶梯价在合同/报价单里写清即可，结算时没有确认、核算、对账的摩擦。返利需要统计周期、确认口径、开票处理，小单团购客户往往嫌麻烦。

## 返利的适用场景（作补充）

返利更适合以下情况，不宜作为主机制：

- **长期稳定、多品类采购的团购客户**：返利可以绑定年度总量，鼓励持续采购而非单次冲量。
- **价格体系需要保护**：直接降价会被其他客户比价、破坏价盘时，用返利（私下结算）维持表面统一价。
- **想考核回款/复购等非量的指标**：返利可以挂"全年回款达标""复购次数"等条件。

## 落地建议

- **主机制用阶梯价**：设 3 档左右（如 50/100/300 件），档差要明显到能推动凑单（相邻档降幅建议不低于 3–5%），最高档给到成本能承受的底线。
- **叠加一个小额返利做钩子**：例如年度累计满额返 1–2%，或复购返，成本低但能锁定长期关系。
- **算清毛利底线**：阶梯最低档的价格必须覆盖变动成本+目标毛利，避免团购量越大越亏。
- **注意价盘**：阶梯价若面向多个团购客户，档位和折扣要统一，避免客户互相比价引发矛盾。

一句话：**用阶梯价解决"这一单怎么成交"，用返利解决"这个客户怎么留住"。**
