针对连锁超市降低门店坏果率的需求，合同中的赔付条款需要**明确、量化、可执行**，避免模糊表述导致扯皮。以下是合同条款的具体建议，您可以根据实际情况调整：

### 一、核心条款设计（建议直接写入合同）

**第X条 鲜果质量标准与验收**

1.  **验收标准：** 乙方（供应商）供应的水果应达到《XX商品质量标准》（附件一）中约定的**一级品**标准，即无腐烂、无明显机械损伤、无病虫害、色泽正常、新鲜度符合批次要求（可用硬度、糖度等量化指标辅助验证）。
2.  **到货验收：** 甲方（超市）在收货时进行**开箱抽检**，抽检比例不低于总量的5%。如发现单批次坏果率（**坏果率 = 腐烂/变质果数 ÷ 抽检总数 × 100%**）超过 **【建议填：2%】**，甲方有权**拒收该批次全部货品**，并要求乙方在 **【24小时】** 内补足合格货品，由此产生的物流、人工费用由乙方承担。
3.  **上架后短保质期责任（关键条款）：** 针对易腐水果（如草莓、荔枝、香蕉），双方约定：若水果在**到货后【48小时】内**（指从门店验收合格入库开始计算），因**水果自身品质原因**（非门店存储不当）出现大面积腐坏，且单店该品类坏果率超过**【建议填：5%】**，乙方需按以下方式赔付：
    *   **第一种（现金赔付）：** 对超出5%部分的腐坏果，按**该批次该门店当日销售价的【1.5倍】** 向甲方支付赔偿金（用于覆盖损耗、人工清理及潜在客诉成本）。
    *   **第二种（货品补偿）：** 按超出部分货值的 **【1.2倍】** 无条件向甲方补发等值新鲜水果（次日达）。
    *   （建议：二选一，否则需明确计算方式）

### 二、赔付触发机制与举证（防止争议）

*   **证据固定：** 甲方发现坏果应立即**拍照/录像留证**（含柜内温度计、日期时间），并于**发现后【12小时】内**通过系统或邮件通知乙方客服。乙方需在【24小时】内回复处理意见，否则视同认可甲方提出的赔付诉求。
*   **争议处理：** 若双方对坏果率有异议，可共同委托**有资质的第三方质检机构**（如SGS、华测检测）进行鉴定，鉴定费用由过错方承担。

### 三、月度综合考核与阶梯赔付（长效约束）

为避免单次赔付难覆盖整体损耗，建议设置**月度损耗率考核**：

| 月度综合坏果率（全部门店加权平均） | 处理方式 |
| :--- | :--- |
| **低于【2%】** | 甲方给予乙方当季采购金额的 **【0.5%】** 作为品质奖励（或优先续约权） |
| **【2% - 3.5%】** | 双方正常结算，但乙方需提供下周促销方案支持 |
| **高于【3.5%】且低于【5%】** | 乙方按当月该品类采购总金额的 **【2%】** 向甲方支付品质违约金 |
| **高于【5%】** | 甲方有权**单方解除合同**，且乙方需支付当月该品类采购总金额的 **【5%】** 作为根本违约赔偿，并赔偿甲方因下架、促销取消造成的直接损失 |

### 四、特别注意事项（避坑指南）

1.  **必须排除“自然损耗”：** 在合同中明确约定，以下情况不计入坏果率：
    *   门店冷藏柜温度超标（如高于标准5℃）导致的加速腐坏。
    *   顾客挑拣造成的物理挤压损伤（可约定操作规范）。
    *   水果在陈列超过【3天】后的正常失水萎蔫。
    *   （这一点非常重要，否则供应商会以“你们自己没放好”为由拒赔）

2.  **赔付上限与保底条款：** 建议约定乙方单月累计赔付总额**不超过当月该品类采购金额的【10%】**，避免供应商因赔付过高而直接断供，但需同时约定断供的违约责任（如按日5%违约金）。

3.  **与“账期”挂钩：** 这是最有效的控制手段。在付款条件中写明：*“甲方有权从应付乙方货款中直接抵扣根据本合同约定应由乙方承担的赔付金额及违约金，无需另行通知。”*

### 五、法律效力提示

*   确保合同中的**“验收标准”和“计算公式”**写在主合同正文或附件中，并由双方签字盖章。
*   如果涉及大量现金赔付，建议在合同中明确**赔付账期**（如“赔付金额可抵扣下期货款”），避免税务上被认定为“价格折让”而产生争议。
