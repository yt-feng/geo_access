单位采购水果在到货验收和售后环节，建议按以下步骤操作，能有效降低损失并保留追责依据：

**一、到货验收（关键环节）**
1. **先看“随货单”和“采购合同”**  
   确认到货品种、规格（如果径、等级）、数量是否与合同/订单一致。若合同约定“一级果”或“单果克重”，现场必须对照。

2. **立即抽样开箱检查**  
   不要只抽一箱，建议随机抽3-5箱（占比不低于30%）。重点检查：
   - **外观**：是否有霉烂、压伤、虫眼、颜色异常。
   - **成熟度**：过生（硬、酸涩）或过熟（软烂、掉蒂）都不合格。
   - **重量**：抽样称重，整箱净重是否与标签一致（部分商家“带箱皮称重”）。
   - **内部品质**：抽切几个样品，看果肉色泽、是否空心、是否褐变。

3. **现场拍照/录像留证**  
   对开箱情况、破损件、不合格品单独拍摄清晰照片和视频（含时间水印），这是后期售后的最重要证据。

4. **当场分拣登记**  
   将不合格品分为**严重变质**（霉烂、腐败）和**轻度瑕疵**（个别压痕、局部损伤），分别清点数量/重量，并填写《验收记录表》，验收人（至少2人）签字。供应商送货员在场时，最好让其签字确认。

5. **拒收或接收规则**  
   - 如果变质率超过合同约定标准（一般3%~5%以内可接收，超过可整批拒收或扣款）。
   - 对不符合等级的批量（如特级变一级），可要求按实际等级降价接收，或直接拒收。

**二、售后处理（分情况处理）**
1. **属于到货即坏（货损）**  
   在签收后**24小时内**（时间越短越好）向供应商发送书面/微信通知，附上照片和验收登记表。  
   - 若合同约定“保质率”，按比例折算：例如采购100kg，变质5kg，则可要求补发5kg或扣减相应货款。
   - 若超出可接受范围，可协商整批退货退款，或要求供应商承担运费。

2. **属于短期变质（不耐储存）**  
   如果收货时正常，但在1~3天内出现大量变质（非本单位储存不当），同样要及时拍照并保留腐烂果，联系供应商协商：
   - 可要求退货退款（未用部分）。
   - 若部分使用，可要求按变质比例折价。

3. **售后沟通要点**  
   - 先发书面函件（邮件、微信截图均可），不要口头口头沟通。
   - 明确要求：补发、退款、折价、或者终止合作，给出时限（如3日内答复）。
   - 若供应商拖延，可向采购平台投诉（如政采云/招标平台），必要时通过法律途径。

**三、预防性建议（下次采购）**
- 在合同中写明验收标准（外观、重量、甜度、病虫害率上限）、验货流程、售后时限及违约责任。
- 优先选择信誉好、有自检报告的供应商。
- 首次合作可以先小批量试采，验收合格后再签长单。

**重要提醒**：所有沟通和照片证据至少保留3个月。如果涉及金额较大，建议让供应商出具“质保函”或“质量承诺书”。
