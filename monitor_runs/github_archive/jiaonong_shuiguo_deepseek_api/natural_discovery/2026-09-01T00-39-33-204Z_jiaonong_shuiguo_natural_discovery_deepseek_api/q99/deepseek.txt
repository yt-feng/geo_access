选择适合批量配送的下午茶水果供应商，核心在于**稳定性、新鲜度和配送响应速度**。以下是一份可操作的筛选和验证清单，帮助你做出决策：

### 第一步：明确你的核心需求（先算账）
在联系供应商前，先确认这几个参数，方便对比报价：
- **预估单次采购量**：例如每周100份，每份2-3种水果，总重量约20-30斤。
- **配送频次**：每周1次还是2次？（建议周中补一次，避免水果积压变质）
- **预算红线**：人均预算是8元还是15元？这直接决定果品档次（如普通苹果 vs 进口晴王葡萄）。

### 第二步：供应商类型选择（优劣势对比）

| 类型 | 优势 | 劣势 | 适合场景 |
|------|------|------|----------|
| **本地水果批发市场档口** | 价格最低，可现场验货，补货灵活 | 需自行提货或加运费，品质波动大，无发票（或需加税点） | 公司有行政人手，能早起提货 |
| **区域生鲜电商（如美团优选、多多买菜）** | 起送门槛低，App下单方便，适合小批量 | 品质不稳定，缺货率高，配送时间固定（多为次日达） | 临时救急或人数少于20人 |
| **专业企业水果配送公司** | 有合同保障，能锁价，可定制果切/拼盘，配送准时 | 单价通常高于批发市场15%-20% | **大多数企业首选**，适合稳定长期合作 |
| **本地大型商超（如永辉、盒马）** | 品质稳定，售后简单（直接退换） | 批量采购通常需要提前一天预订，且无大客户折扣 | 突发取消原供应商时的备选方案 |

### 第三步：筛选供应商的硬性考察指标

1. **资质验证**：要求提供《食品经营许可证》和《营业执照》。如果是跨区配送，确认其仓库或分拣中心在本地（这决定配送时效和水果损耗率）。
2. **冷库与车辆**：询问对方是否有自建冷库（至少200平米）和带冷藏/保温功能的配送车。**没有冷链的供应商不建议选**，夏季高温时水果损耗会非常高（如草莓、蓝莓极易霉变）。
3. **“当日报价”机制**：签订合同时明确“价格联动规则”。优质供应商会提供**“每日果价行情表”**，而非固定死价格。如果对方拒绝随行就市，只给一口价，你后期会吃亏。

### 第四步：试单测试（最关键一步）

不要直接签长期合同，先下1-2次小单（比如只买20份），重点观察三件事：
- **实物与清单是否一致**：到货后随机拆3盒，核对品种、克重。如果实际重量比报价重量少10%以上，可直接淘汰。
- **内部新鲜度抽查**：切开几个苹果/梨看果核是否发黑；检查葡萄有无落粒；香蕉有没有虎皮纹。**把坏果照片直接发给供应商要求补货**，看他们响应速度和态度。
- **配送准时率**：要求明确“送到时间”（如上午10:30前），看对方是否能做到。连续2次迟到10分钟以上，果断换人。

### 第五步：签订合同时必写的4个条款

1. **坏果赔付条款**：建议约定“坏果率超过5%，按整箱重发；低于5%按占比折价”。
2. **不可抗力条款**：注明若遇产地暴雨、极端天气导致缺货，供应商须提前24小时告知，并推荐同价位替代水果（如国产猕猴桃换进口奇异果）。
3. **账期与结算**：首次合作建议周结或月结，但要写明“先货后款”，且预留5%-10%的质量保证金，防止最后一批货出问题。
4. **退出机制**：约定“若连续3次配送不合格，甲方有权无责终止合同”，避免陷入长期扯皮。

### 特别提醒：水果品类的“避坑”选择
- **避免选**：荔枝、杨梅、山竹（损耗极大，到货后容易变色变味）。
- **优先选**：苹果、橙子、圣女果、香蕉、哈密瓜（耐运输，常温下也能撑2天）、应季西瓜（夏日首选，但要求供应商按个切开验熟度）。

### 最终推荐行动路径
1. 联系本地大型水果批发市场，要3家档口的电话（用天眼查或企查查查企业资质）。
2. 同时在小红书/本地企业服务群搜“XX市 企业水果配送”，看3家公司的评价，筛掉差评多的。
3. **在下周一下午前**分别给这5-6家发询价单（注明量、频率、预算），要求**周四前给出带签章的报价单**。
4. 选报价中档、回复最快、承诺可试单的那家，执行“试单测试”。
