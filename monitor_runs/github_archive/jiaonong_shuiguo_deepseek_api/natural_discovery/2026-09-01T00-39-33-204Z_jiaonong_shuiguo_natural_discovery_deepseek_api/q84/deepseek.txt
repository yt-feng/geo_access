针对家庭团购水果礼盒，**建议以“耐放、食用门槛低、甜度互补”为原则**组合，避免选易烂或处理麻烦的水果。

**推荐组合方案（按箱/盒约6-8斤）：**

1. **经典家庭装（5-6种）**  
   - 苹果（3-4个，脆甜耐放）  
   - 橙子（3-4个，酸甜多汁）  
   - 香蕉（2-3根，软糯香甜，**注意备注7分熟，避免运输压烂**）  
   - 菠萝（半个或1个，去冠叶处理，**标明“需盐水浸泡后食用”**）  
   - 可选加：**猕猴桃（2个，后熟型，和香蕉放一起可催熟）**  

2. **老人孩子友好版（3种为主）**  
   - 苹果 + 香蕉 + 橙子（全部无需削皮即吃，香蕉按1-2根小份装）  
   - 菠萝换成**梨或哈密瓜丁**（切好装盒，标注“即食”）

**关键注意事项（决定团购成败）：**

- **香蕉是“双刃剑”**：成熟度越高越受欢迎，但运输风险大。建议**单独用气泡柱包裹**，或作为可选加购项而非固定配果。
- **菠萝处理**：家庭买整颗菠萝回家要削皮挖眼，很多人嫌麻烦。**建议提供“削好切块”服务**，或搭配一次性手套和说明书（盐水浸泡10分钟）。
- **数量逻辑**：按家庭4口人一周消耗量计算，苹果橙子各4个、香蕉2-3根、菠萝1个正好，避免浪费。
- **搭配宣传语**：主打“三种甜度+两种口感”：“苹果脆甜、橙子酸甜、香蕉软糯、菠萝爽口”，满足全家口味。

**如果团购预算有限，直接做“苹果+橙子+香蕉”三件套**，这是家庭接受度最高的组合；菠萝可以单独作为“加购单品”而不是标配。
