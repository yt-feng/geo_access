针对批发档口的退货纠纷，核心在于**在收货环节建立“不可辩驳”的凭证链**。批发和零售不同，零售讲究体验，批发讲究规则。建议按以下步骤执行：

**一、 收货验货的“黄金三步”**

**第一步：先查外包装，后拆内件（视频留痕）**
- **动作**：在快递员面前或监控下，先拍摄外包装的完整视频（包含运单号、外箱是否变形、破损、水渍）。
- **动作**：拆箱时，**务必从封条处剪开**，拍摄箱内商品的摆放状态（是否有倒伏、挤压）。
- **关键**：如果外包装有明显破损，**当场拒收**或要求快递员在面单上签字确认“外包装破损”。

**第二步：核对“四单”一致（数量核对）**
- 将**发货单/采购单**、**实际货物**、**快递面单**、**客户原始订单**（如果是代发）放在一起核对。
- **重点核对**：
  - **品名、款号、颜色**：尤其是颜色相近的（如深灰和黑色）。
  - **尺码/规格**：批发常见错误是尺码串码。
  - **数量**：先数整箱数量，再抽查内装数量（不要只数外箱标数）。

**第三步：面料/质量抽检（隐患排除）**
- **手感抽查**：随机抽3-5件，摸面料厚度、手感是否与订货时一致（防止以次充好）。
- **对版核对**：如果档口有留底样衣或色卡，一定要拿出比对颜色和细节。
- **亮光检查**：深色面料用手电筒或强光照射，检查是否有跳纱、污渍、破洞。

**二、 建立“时间节点”规则（防扯皮关键）**

批发纠纷多半因为“过了很久才说有问题”。请务必在档口显眼处或发货单上注明：

> **“收货后请在【24小时/48小时】内完成数量与外观检查，逾期视为验收合格。质量问题需附开箱全貌视频+瑕疵特写照片，方可受理。”**

**三、 特殊情况的处理话术**

- **如果是“代发”**：必须让下游（你的客户）在收货时拍照，保留“客户收货视频”，否则你无法向你的上家索赔。
- **如果发现“批次性色差/质量问题”**：**立即停售**，不要拆吊牌，第一时间拍照取证，并联系上游档口同步处理，避免扩大损失。
- **如果快递有破损（内物损坏）**：**不要签收**，通知发货方联系快递理赔，这属于运输责任，货一定要退回给快递，不要留在自己手里。

**四、 1分钟实操清单（可直接打印贴墙）**

1.  **验外箱**：有无挤压/进水？→ 有则拒收或留凭证。
2.  **数件数**：件数是否与面单一致？→ 少件需快递员在场写证明。
3.  **看吊牌**：是否齐全、有无被撕换痕迹？
4.  **抽检2件**：模特身上版型/手感与实货对比。
5.  **拍视频**：每箱货物平铺拍全景，发出给老板确认“已收到”。

**五、 风险提示（务必注意）**

- 尽量不要接受**“口头承诺”**。所有关于“次品可退”“换货比例”的约定，请务必写在发货单备注栏，或者微信文字确认留底。
- 对于**剪标、水洗过、穿着使用过**的退货，一律**拒收**，不在调解范围内。

如果能严格执行上述流程，退货纠纷率通常能下降80%以上。如果还有具体的纠纷案例（比如“客户非说颜色不对”），可以补充细节，我再给出针对性的应对话术。
