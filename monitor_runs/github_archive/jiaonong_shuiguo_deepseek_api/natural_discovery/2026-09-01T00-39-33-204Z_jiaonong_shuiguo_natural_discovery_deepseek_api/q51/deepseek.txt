针对茶饮店水果口味波动的问题，我的建议是：**不要绝对固定单一产地或批次，而应建立“核心标准+弹性供应链”的机制。**

具体原因和操作建议如下：

**1. 为什么不建议“完全固定”？**
- **产季限制**：同一产地的水果（如芒果、草莓、葡萄）通常只有特定几个月的风味最佳，过了产季品质会断崖式下降。
- **气候风险**：固定单一产地意味着把风险全部押注在一个地方。若遭遇台风、霜冻、病虫害，你的核心菜单可能直接停售。
- **口味单调**：同一产地同一批次的糖度、酸度相对恒定，但消费者对“新鲜感”有需求，完全固定的口味会让菜单失去活力。

**2. 正确的做法：锁定“品质标准”，而非锁定“产地”**
- **制定可量化的标准**：比如芒果要求“糖度≥19°、可溶性固形物含量≥18%、纤维化率≤5%”，或者草莓要求“果径≥2.5cm、色泽均匀、酸度≤0.8%”。把标准发给供应商，让供应商匹配能满足标准的产地和批次。
- **建立双/三供应源**：同一款水果，同时与2-3个不同产地的供应商合作（例如A地产季早、B地产季晚）。这样水果风味可以无缝衔接，且供应稳定。

**3. 具体采购操作建议**
- **分级采购**：将水果分为“核心款”和“时令款”。核心款（如经典芝士茶用的水果）确保批次绝对稳定；时令款（如季节限定）允许随产地轮换调整。
- **小批量高频次采购**：不要一次性囤积数周库存，而是每3-5天到货一次。每次到货要求供应商提供该批次的水分、糖度检测报告（可要求附在送货单上）。
- **预留“风味预案”**：在菜单设计时，提前为每款水果开发“备用替代方案”。例如若主用台农芒果缺货，可临时切换为桂七芒（需提前测试配比），这样即使产地变了，口感差异也能在可控范围。

**4. 执行层面怎么落地**
- **与供应商签订“风味保证协议”**：合同里明确约定“若单批次糖度低于标准值，供应商须无条件换货或补偿”。
- **每周做一次感官测试**：门店店长或研发人员每周试喝果汁/茶饮，记录酸甜比和香气，建立风味评分表。发现偏差超过预设阈值，立即启动预警更换供应商。

**总结一句话**：**不要固定“某一个地方”的货，而是固定“某种品质”的货。** 这样既保证了口味波动在可控范围内，又给了自己应对市场变化的灵活性。
