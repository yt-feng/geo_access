社区团购旺季爆单，提前与水果供应商锁定库存，核心在于**建立利益绑定**。水果是易损耗、价格波动大的品类，单纯靠“口头预定”或“交定金”远远不够。

以下是分步骤、可执行的锁库存实操方案，按优先级排序：

### 第一步：签对合同，锁住“量”和“价”

这不仅是锁库存，更是锁风险。如果只是口头说“给我留1000箱”，供应商旺季根本不敢全押给你。

1.  **签订“框架采购协议”**：
    -   **锁定阶梯价**：明确不同采购量（比如500箱、1000箱、2000箱）对应的结算单价，并约定**价格浮动上限**（例如：市场价涨跌超过20%时，双方协商调价，避免供应商因涨价毁约）。
    -   **写清楚“坏损率”**：水果在运输和存放中的自然损耗（一般约定3%-5%以内）由谁承担。签了合同，才能在旺季扯皮时有据可依。

2.  **支付“预售定金”或“包园定金”**：
    -   旺季供应商资金压力也大。支付总货款20%-30%的定金，不仅能优先排产（采摘），还能让供应商有动力把最好的货留给你，因为你已经是“股东”了。
    -   **注意**：定金要写明是“担保性质”，如果供应商未能履约，需双倍返还（《民法典》定金罚则），以此增加他的违约成本。

### 第二步：反向定制，把库存“压在树上”

与其去抢冷库里的现货，不如直接锁定源头产地。

1.  **提前2-3周“锁树”**：
    -   直接联系产地代办或果园主，锁定某片果园的采摘权。比如你们预测要卖1万单（约10吨），直接包下这片果园。
    -   **操作细节**：跟果农约定“糖度达标才采”（标准定在12度以上），这样锁的不只是数量，更是品质，避免旺季为了凑货把生瓜蛋子采下来。

2.  **让供应商“代加工”**：
    -   旺季大家都缺分级和打包人手。如果你能**主动承包果子的分拣、打包、贴标环节**（提供包装箱和人工），供应商只需要出裸果。这能极大提高供应商对你的优先级，因为你去掉了他最头疼的打包压力，他更愿意优先给你留库存。

### 第三步：动态调整，避免“锁死”或“断供”

旺季销量是波动的，锁库存不能让仓库压死，也不能让货断供。

1.  **设置“每日滚动预测”**：
    -   不要一次性报死数量。建议采用 **“周预测+日微调”** 模式。
    -   每周日统计下周团购报名量，以80%的量作为“硬库存”（锁死），留20%作为“机动量”（随市场行情现采）。
    -   如果某天爆单远超预期，立即启动**供应商备选名单**（至少准备2家同产区的替补），提前跟他们打好招呼：“我有固定主供，但我需要你作为应急备份，如果我调用你，每斤加0.2元”，这样应急也有保障。

2.  **等价换量**：
    -   如果担心锁定量卖不完，可以跟供应商谈：“这次我锁你1000箱，同时我愿意把另一款滞销的苹果（或利润较低的水果）也放在我这里主推帮你清货。”
    -   用你的推广资源去换供应商的库存保障，这种“非货币”的筹码在旺季往往比加钱更有效。

### 第四步：建立“排他性”防反悔机制

旺季最怕的就是供应商看别人出价高，把你的货给截胡。

1.  **物流押金池**：
    -   跟供应商约定，你支付定金的账期稍微拉长（比如货到验收后2天内结款，而非现款现货），并且明确告诉供应商：“只要你不给我断供，今年一直到年底的采购都走你这，且结款时间最快。”
    -   **关键点**：一定要跟供应商老板当面沟通，**让他觉得你在所有团长中“链路最短、最省心”**，且能帮他把货卖到终端消费者手里，而不是倒卖去批发市场。

### 给一个具体的“锁库行动清单”（建议今天就能做）：

1.  **今日**：整理你预测的爆品（前3款），列出你希望锁定的总吨数。
2.  **本周内**：约现有主要供应商面谈，拿出协议模板，直接落定“预付款+最低采购量”条款。
3.  **下周起**：每日早8点发采购预测表给供应商（基于昨日销量），并告知他你为他准备的应急包材和人工，展示你的操作能力。

**特别注意**：如果供应商对你提供的高价格和定金打动，但他提出“市场价跌了你要补差价”这类要求，**不要答应**。旺季锁库存的本质是锁“确定性”，如果你接受价格随行就市，就失去了锁库存的意义。建议锁定价格时，反而可以适当高于市场均价0.1-0.2元/斤，换取绝对供应的优先权——旺季节省下来的“找货时间”和“取消退单损失”，远大于这点采购差价。
