茶饮店遇到水果到货不合格，处理不当很容易直接导致断货或营业危机。为了避免影响营业，建议你从**合同约定**和**紧急预案**两个层面来操作。

### 一、把“补救措施”写进采购合同（核心方案）

在采购合同中，不要只约定“不合格退货”，要**明确约定“补货的时效性和数量补偿”**，这样才能约束供应商。

**1. 明确“不合格”的判定标准与验收时效**
-   标准细化：不要只写“新鲜”，要写清楚具体指标。例如：芒果“表皮无黑斑、切开无黑心、糖度不低于XX度”；柠檬“直径不小于XX厘米”等。
-   验收时效：约定收货后**2小时内**为验收期，发现问题需拍照并书面通知供应商，逾期视为默认合格。这能防止对方拖延。

**2. 约定“同批次补货”及“优先补货权”**
-   条款示例：“若因水果不合格导致本店缺货，供应商需在收到通知后**4小时内**安排同规格、同品质的新鲜水果补货送达。若无法按约定时效补货，本店有权从其他渠道采购，产生的差价及运费由供应商承担。”
-   关键点：补货时效要**短于**你的营业周期。如果晚上7点是营业高峰，一般要求上午11点前送达或4小时内必达。

**3. 约定“质量保证金”或“扣款机制”**
-   为了有约束力，在合同里约定：如果单月出现**2次**因水果不合格造成的断货，本店有权扣除当月货款的5%-10%作为违约金，或直接从质量保证金中扣除。

---

### 二、建立“店内应急补货流程”（运营层面）

有了合同条款，日常还要有具体操作动作，否则合同也难落地。

**1. 指定“一手备用供应商”**
-   不要把所有水果都押在一家供应商上。提前联系1-2家本地批发市场或线上生鲜平台作为**备用供应商**（B计划）。
-   关键动作：在采购台账里，记录好备用供应商的联系人和当日价格。一旦主供应商无法及时补货，**当场电话联系备用供应商单独送一趟**，哪怕量小，也要确保不断货。

**2. 拆分“原物料”紧急预案**
-   比如柠檬不合格，可以改为**用浓缩柠檬汁（需提前备好）**暂时替代鲜柠檬，或者暂时调整菜单（下架全用鲜果的饮品，主推使用库存充足的水果）。在吧台备一点**冷冻水果果粒**或**果酱**作为应急物料。

**3. 内部执行标准（给店长的SOP）**
-   到货后**先验货再签收**。如果当场发现明显不合格，拍照拒收并让送货司机签“拒收单”，当场要求物流或业务员联系补货。
-   如果签收后发现不合格，立刻走“店内异常处理单”，写明时间、数量、问题并抄送老板，同步在供应商微信群里@对方负责人。

---

### 三、如果你现在正在处理当下问题（短平快操作）

如果现在水果已经到货且不合格，且供应商还没补，建议你按这个顺序操作（按优先级）：

1.  **立刻打电话给供应商老板**（注意是老板，不是业务员），提出明确诉求：“这批柠檬坏了不能用，我们现在要出单，请您今天下午4点前必须补一箱同等规格的过来，到时候运费我出，但这次的坏果必须按合同扣款处理。”
2.  **同时联系备用供应商**报需补货的品类和数量，让TA先送过来应急（哪怕价格高一点），保证今晚高峰有货可卖。
3.  **销售端调整**：如果柠檬实在补不上，吧台紧急切换“柠檬薄荷气泡水”为“青桔气泡水”或“茉莉花茶”，提前在点单牌上写好“本日推荐”，避免顾客因点单缺货而流失。
4.  **记录在案**：当天晚上下班时，把这次不合格的情况记录到供应商档案里，下个月结款时直接引用合同条款扣款或要求对方给予折扣补偿。

**核心原则：合同条款是“武器”，平时有备用货源是“保命符”，高峰期切配方是“缓兵之计”。** 三管齐下，即便偶尔遇到坏果，也能把对营业的影响降到最低。
