与酒店早餐水果供应商谈合作，核心目标是**稳定、新鲜、成本可控、可追溯**。以下是几个关键注意点，供你参考：

**1. 明确“稳定”的具体标准（这是首要条款）**
- **最低日供应量**：写清楚酒店每天/每周的保底采购量，以及节假日的预估增量（如春节、展会期间）。
- **供货时间窗**：规定几点前必须送达（如早餐高峰前1小时），迟到如何扣款。
- **替代方案**：如果某天某水果缺货或品质不合格，供应商必须在多长时间内补货或用同等价格的替代品。

**2. 品质标准与验收流程**
- **制定书面规格**：不要只说“新鲜”，要写明具体等级。例如：苹果直径≥8cm、无碰伤虫眼；香蕉全黄且无黑斑；切片水果（如西瓜）糖度≥10度等。
- **验收权**：酒店有权开箱随机抽检，不合格品按比例拒收或折价。建议试合作期（如2周）内，供应商负责全部风险。

**3. 价格机制与成本控制**
- **锁价周期**：水果价格波动大，建议按月或季度锁价，并约定调价公式（如参考批发市场旬均价涨跌幅超过10%时可协商调整）。
- **隐性费用**：明确是否含配送费、冷藏费、损耗费（如切好的水果是否按净重计费）。
- **付款账期**：商定如月结30天，但可要求供应商提供质量保证金（如押1-2万元，用于违约扣款）。

**4. 食品安全与合规**
- **资质审查**：要求供应商提供营业执照、食品经营许可证、水果产地证明/检疫合格证（如进口水果需报关单和入境检疫证明）。
- **农残检测**：要求每月或每批随机提供第三方农残检测报告，费用分担需在合同中写明。
- **冷链链承诺**：明确供应商从产地到酒店的全程冷链温度记录，防止“断链”导致的变质。

**5. 应急预案与退出机制**
- **不可抗力**：如遇台风、疫情等导致断供，供应商需提前48小时通知，并协助调货（可约定从周边市场调货的额外费用分摊）。
- **违约金/解除权**：若连续2次或累计3次出现延误/品质不达标，酒店有权单方解除合同，且供应商需赔偿当日采购价差损失。

**6. 细节谈判建议**
- **试供期**：先签1个月试供合同，观察稳定性后再给长约。
- **多供应商备份**：即使谈好主供应商，也要保留1-2家备选供应商的报价，用于议价和应急。
- **定期复盘**：约定每月开一次供应商会议，核对损耗率、客户投诉率和补货及时率。

**一句话提醒：** 把上述所有点都**写进合同**，不要只靠口头承诺。尤其是“稳定”一词，一定要量化为数字（如“98%的月份达到日供应量”），并配套明确的奖惩条款。
