判断茶饮连锁的菠萝供应商能否**稳定按规格送货**，核心要看**供应链的“确定性”**，而非口头承诺。建议从以下五个可执行维度进行供应商背调与测试：

### 一、 硬性资质与合同条款（法律保障）
1. **索要规格书（Spec Sheet）**：明确要求供应商提供《产品规格书》，内容必须包含：菠萝的**单果重量区间**（如1.2-1.5kg）、**糖度下限**（如12°Brix）、**成熟度**（如8成熟）、**切口/去皮标准**、**包装方式**（如隔板纸箱、每箱数量）。
2. **合同违约责任条款**：在采购合同中明确约定——“如连续两次到货规格不符，供应商需承担返工费用及违约金”，并要求供应商书面确认该条款。

### 二、 产地与采收节奏（稳定性基础）
- **询问期货或包园机制**：直接问“你们在海南/广东/云南的种植基地是自建、合作还是市场收购？”自建基地或签订“包园收购”的供应商，抗市场波动能力强，规格更统一。
- **核查采收日历**：要求对方提供**未来6个月的预计采收计划表**（分周列出可供应量）。如果对方含糊其辞，说明其无法锁定货源，只能临期拼凑。

### 三、 分级与分选能力（规格一致性）
- **现场看分选线**：如果方便，参观其加工厂。重点看是否有**自动重量分级机**和**视觉选别机（测糖度）**。只有机器分级才能保证规格统一，纯人工挑拣的合格率极不稳定。
- **索要历史抽检记录**：要求对方提供**最近10批次的发货检验报告**（COA），查看每批的规格合格率（应≥95%）及标准差。

### 四、 试单测试（最有效的检验）
**不要先谈大合同，先下3-5次小试单**（每次几百公斤）：
1. **错峰下单**：分不同周下单，检验其补货速度和规格一致性。
2. **入库全检**：每次到货后，随机抽10箱，逐一称重、测糖度、查瑕疵。
3. **记录偏差率**：如果试单期间，单果重量偏差超过±5%或糖度不达标，可直接淘汰该供应商。

### 五、 应对断货/补货的应急能力（长期稳定的关键）
- **替补渠道测试**：问“如果主产区下雨采收不了，你们怎么保证供货？”看其是否能提供**第二产区（如中转冷库）的备货方案**。
- **冷库库存透明度**：要求供应商每日提供**实时库存可视化报表**（或至少每两日一次），确认其是否有锁定的应急库存池。

---

**最终行动建议**：
将上述测试结果量化为**供应商评分卡**（权重：规格一致性40%、准时率30%、应急能力20%、价格10%），**连续3个月试运营**后再签长期框架协议。如果对方在试单期间迟到1次或规格不符1次，就直接降级为后备供应商。

**特别注意**：菠萝是季节性水果，如果对方是单一产地供应商，在非主产季（如夏季）几乎**必然**会混入不同产地果源，导致规格漂移。务必要求对方在合同中注明“供应期内的产地切换需提前15天书面通知并送样确认”。
