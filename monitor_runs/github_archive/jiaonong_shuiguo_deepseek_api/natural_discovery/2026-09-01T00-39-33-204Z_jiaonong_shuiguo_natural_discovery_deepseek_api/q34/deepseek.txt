在商超做水果采购时，**损耗率对最终毛利的影响几乎总是大于进货价格**。原因如下：

**1. 损耗是“乘法”损失，价格是“加法”影响**
- **价格影响**：采购价降低10%，对毛利率的影响通常是几个百分点的提升，属于一次性成本变动。
- **损耗影响**：如果损耗率是10%（果品腐烂、碰伤、超期丢弃），意味着你购买10斤水果，只有9斤能销售。**损耗是直接减少可销售数量，相当于你的商品成本被无形提高了10%以上**。损耗率每上升1%，对毛利的侵蚀力度可能远超价格降低1%带来的收益。

**2. 亏损是“全额亏损”，降价是“打折”**
- 损耗不能卖的那部分，其购入成本、运输、冷链、人工费用全部沉没，**100%打水漂**。
- 即使采购价低，但如果低质量水果易损耗，最终可能“省了1毛，赔了5毛”。低价的坏果可能一开始便宜，但卖出前就要剔除，实际卖价被摊高。

**3. 损耗还会带来隐性成本**
- 损耗果品若没挑干净，会影响顾客体验，导致差评、退货、客流下降，这比直接损耗更伤毛利。
- 损耗带来的垃圾处理、人工分拣、二次上架时间，也是额外成本。

**4. 实际案例对比**
- 假设你采购10箱西瓜，单价100元/箱，毛利目标30%。
  - **压低价格10%**：成本降至90元，利润可能从300元升至390元（+30%）。
  - **损耗10%**：直接损失1箱的成本100元，同时少卖那箱的潜在毛利30元，总影响约130元，远大于降低价格带来的90元收益。

**5. 但两者需要平衡（不能极端）**
- 如果**价格低到明显影响品质**，损耗率会飙升，即使价格压到极低，也可能亏本。
- 合理的做法是：**在保证基本品质、控制损耗的前提下，再通过规模采购、供应链优化压低价格**。尤其是生鲜水果，**质量是生命线**。

**最终结论（可执行建议）：**
- **优先关注损耗率**，将其控制在5%以内（精品水果）或8%以内（大众水果）。
- 采购时要算“**实际可售成本**”而不是进货价：`实际成本 = 采购价 ÷ (1 - 预期损耗率)`。
- 对易损耗的高价值水果（如草莓、车厘子、芒果），**宁愿单价贵10%进货，也不选次品**；对耐储水果（如苹果、橙子），可以适当压低价格，但也要控制周转天数。

**一句话总结**：损耗是毛利的第一杀手，价格是第二因素。管好损耗，价格才有意义。
