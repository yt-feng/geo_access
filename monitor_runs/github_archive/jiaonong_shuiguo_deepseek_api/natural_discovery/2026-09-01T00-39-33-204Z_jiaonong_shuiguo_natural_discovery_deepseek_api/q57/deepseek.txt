对于餐饮连锁采购水果，**中央厨房统一收货通常更好**，但需要根据门店规模、品类和物流条件，结合具体场景来定。以下是核心判断和建议：

**一、中央厨房统一收货的明显优势（大多数连锁的首选）**
1. **品质和标准统一**：水果易损耗、成熟度不均。中央厨房可以统一验收标准（甜度、新鲜度、大小），剔除残次品，避免门店各自验收标准不一。
2. **成本更低**：大批量集中采购，进价更低；统一验收可减少门店单独送货的物流次数，降低运输费用。
3. **减少门店工作量**：门店无需处理供应商对接、收货、退换货，专注出品。
4. **便于库存和损耗控制**：中央厨房可集中冷藏/保鲜，按日配货，减少门店存放腐烂损耗。

**二、中央厨房统一收货的潜在问题（需规避）**
- **二次运输损耗**：水果在配送途中可能磕碰。需使用定制果蔬周转筐，并计划“当日达”或短时冷链。
- **门店需求差异**：若不同门店销量差异大，容易在中央库积压。可让门店按周预估，动态调整。
- **对中央厨房设施要求高**：需配备冷藏库、分拣区，否则反而加快腐烂。

**三、什么时候更适合门店分开收货？**
- **门店数量少（少于10家）且离供应商近**，且水果为高档鲜果（如山竹、杨梅）时，门店自己收货可减少中转。
- **水果为“短保易损”且当季**，如荔枝、草莓，如中央配送超过2小时，建议部分门店直送。

**四、最实用的折中方案（混合模式）**
1. **基础大宗水果**（苹果、柑橘、香蕉等）：中央厨房统一收货、净洗分切，按日配送到门店。
2. **高损耗精品或本地特产**：允许门店从当地供应商直采，但总部规定购销价和标准，月底统一报账。
3. **引入数字订货系统**：门店每日在系统报单，中央厨房按单分拣，避免库存积压。

**最终建议**：如果连锁规模在10家以上，强烈建议采用**中央厨房统一收货**，但前提是：
- 必须建立**水果验收SOP**（糖度测试、目测法、称重扣损）；
- 建**冷却库**（0-4℃），分品类存放；
- 选择**有快速反应能力的第三方物流**或在当地设分仓。

如果目前门店少、物流弱，可先用门店直收，但由总部统一定价和供应商，每季度复盘更换供应商。
