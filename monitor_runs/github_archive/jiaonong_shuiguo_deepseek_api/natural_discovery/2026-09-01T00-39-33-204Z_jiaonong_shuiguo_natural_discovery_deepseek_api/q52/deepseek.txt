甜品店采购香蕉时，要避免到店后很快变黑，核心思路是**从源头选对成熟度、运输中保护、到店后科学存储**。以下是具体可操作的建议：

### 一、采购环节（关键源头）
1. **选“七分熟”的货**  
   采购时不要买外表全黄甚至带斑点的香蕉。**标准是：果皮青黄相间（约六到七分熟），捏起来稍硬但能压动**，这种香蕉到店后常温可放2-3天，完全适合甜品制作。如果店里甜品用到的是果肉（如香蕉奶昔、布丁），这个成熟度正好，甜度足够且不易黑。

2. **避开已催熟的“催熟果”**  
   问清产地和催熟方式。市场上很多香蕉是乙烯利催熟的，全黄但内部已“过熟”。**采购时捏一下果肉，如果软塌带水感，直接放弃**。优先选“自然熟”或“半熟”的生蕉，自己控制成熟度。

3. **看果柄和表皮**  
   果柄新鲜不发黑、表皮无机械损伤（碰伤、压痕）的香蕉，黑斑出现概率低。**有磕碰的香蕉到店后先消耗，不能久存**。

### 二、运输环节（减少损伤）
1. **平放，不能堆叠**  
   香蕉怕压，运输时**必须单层平放或侧放**（果柄朝上），不能竖放或堆叠，否则压痕处最先变黑。

2. **避免高温和阳光直射**  
   运输车里尽量放阴凉处，香蕉在超过25℃环境下会加速呼吸作用，产生乙烯气体，催熟并变黑。如果夏天采购，建议用保温袋或泡沫箱隔温。

### 三、到店后的存储（延长寿命）
1. **分批次上市**  
   如果当天用不完，**不要全部放常温**。把青黄的放阴凉通风处（18-22℃最佳），把已经偏黄的放冷藏室（但**注意：冷藏让香蕉表皮变黑更快，但果肉不变质**，如果甜品用果肉，冷藏没问题；如果卖整根香蕉，则不能冷藏）。

2. **用保鲜膜包住果柄**  
   香蕉的乙烯气体主要从果柄释放，**用保鲜膜或锡纸包住果柄根部，能大幅延缓成熟变黑**。这是最有效且成本最低的方法。

3. **单独存放，远离苹果/梨**  
   甜品店通常有苹果、梨等水果，这些会释放乙烯，**不要把香蕉和它们放同一个篮子或保鲜袋里**，否则香蕉一夜变黑。

4. **如果已经有少量黑斑**  
   别全扔掉。黑斑如果只在表皮，果肉没软烂，**立即剥皮取肉，冷冻或冷藏备用**（做冰沙、蛋糕夹心、冰淇淋），变废为宝，不影响甜品口感。

### 四、额外提醒（针对甜品店场景）
- 甜品店如果要长期保持香蕉外观（比如做摆盘装饰），**可以采购青香蕉，自己用乙烯利滴液催熟**（按说明稀释，喷在果柄处），这样能精确控制到货后的成熟时间，到店后当天熟，当天用完，绝不会提前变黑。
- 如果采购量较大，建议和供应商约定“次日达”或“当日达”，减少在途时间，这是最根本的方式。

总结一句话：**买青黄相间的半熟果、运输防压、到店包果柄、远离苹果分开放**，这样香蕉到店后至少能保持3天卖相良好。
