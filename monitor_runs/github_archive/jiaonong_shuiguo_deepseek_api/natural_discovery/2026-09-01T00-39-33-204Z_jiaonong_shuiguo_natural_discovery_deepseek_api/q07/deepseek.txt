针对水果礼盒，苹果、橙子、香蕉、菠萝这四种水果，建议以**“色彩、口感、耐放度”**三个维度进行搭配。以下是比较实用的方案，直接按利润和畅销度排序：

**最推荐（颜值+性价比）：苹果 + 橙子 + 香蕉**
- **原因**：红（苹果）、黄（香蕉）、橙（橙子）撞色，视觉冲击强。苹果耐存放，橙子香气足，香蕉是大众甜度最高的，老人小孩都爱吃。
- **操作**：苹果选红富士（大果），橙子选脐橙，香蕉选进口蕉（不要选有黑斑的）。数量比例：苹果5个 + 橙子4个 + 香蕉1把（6-8根），整体看起来饱满。
- **注意**：香蕉要放在最上层，用纸或泡沫隔垫，防止压伤。

**高端选项（送礼）：苹果 + 橙子 + 菠萝**
- **原因**：菠萝是这四种里单价最高的，能抬高礼盒档次。金黄的菠萝配红苹果和绿橙，显得很“贵”。
- **操作**：菠萝建议选去皮切好，用保鲜膜包好放入礼盒，并附赠一根牙签和切菠萝小卡。苹果选冰糖心，橙子选进口甜橙（如新奇士）。
- **注意**：菠萝不耐压，必须单独放在硬纸托里，且不要和苹果贴在一起（苹果释放乙烯催熟菠萝）。

**低配大众款（走量）：苹果 + 橙子**
- **原因**：最稳妥，成本最低，不易损耗。适合门店日常主推，或客户预算在30元以内。
- **操作**：苹果5个 + 橙子4个，中间空隙用拉菲草填充，套一个透明手提袋，贴上手写祝福卡，成本极低但效果不差。

**不推荐的组合（避雷）**：
- **香蕉 + 菠萝**：两者都是热带水果，且香蕉释放乙烯会加速菠萝变软，同时两者都不耐压，容易在运输中坏掉，不建议放在同一个盒子里。

**额外提升销量的3个细节**：
1. **配色心机**：四种里香蕉是“拉低颜值”的，如果要拍照好看，尽量用绿香蕉（放两天变黄）或干脆不放香蕉，换成小番茄/青提点缀，成本更低。
2. **尺寸盒子**：选三角形的或方形硬纸盒，底部放泡沫垫，中间放苹果和橙子，顶层放香蕉，侧面塞菠萝（菠萝可以竖插）。
3. **搭配增值品**：附赠一包湿巾、一张祝福卡、或一小瓶蜂蜜，成本不到1元，客单价能提高5-10元。

**总结**：
- **最好卖且能走量**：苹果+橙子（基础款）
- **最能卖高价**：苹果+橙子+菠萝（高端款）
- **短期促销**：苹果+橙子+香蕉（节日款）

建议你先做20盒“苹果+橙子+香蕉”试水，看顾客反馈再加菠萝，因为菠萝切皮会增加人工和损耗，除非你能保证当天卖完。
