针对便利店这类**小面积、高周转、毛利适中**的业态，水果采购的核心逻辑不是“多而全”，而是**“精而快”**。以下是控制品类和损耗的具体操作策略：

### 一、品类控制：从“全品类”转向“爆款+刚需”

小门店没有空间和资本去做“水果超市”，必须遵循**“3+2+1”**选品法则：

1.  **3个必做引流款（高流转、大众化）**
    -   **香蕉**：永远的第一走量水果，几乎人人买，且损耗可肉眼预判（熟度变化明显）。
    -   **苹果（红富士/嘎啦）**：价格稳定，耐储存，是家庭刚需。
    -   **梨（秋月梨/皇冠梨）**：清甜解腻，与苹果搭配销售。
    -   *操作要点*：这3种建议**整箱散卖**，摆在门口最显眼处，不做礼盒。

2.  **2个毛利款（应季限定、高客单）**
    -   **当季热门水果（如夏天的西瓜/秋天的阳光玫瑰）**：应季水果信息透明，价格竞争激烈，但客流大。只需备**1个单品**做爆。
    -   **精选高价单品（如进口西梅/当季草莓）**：只选1种，用小托盘装好，按“份”卖，不按斤称，减少顾客挑拣造成的损耗。

3.  **1个补充款（非标品、按需进）**
    -   **便携类（如圣女果/蓝莓/切好的水果杯）**：适合上班族和应急场景，这是便利店区别于菜市场的核心。注意，**尽量采购预包装好的，不要自己在店内切**，否则人工和损耗极高。

**坚决砍掉的品类**：杨梅、无花果、山竹等极易腐坏、且需要低温精细养护的品类，小店不建议碰。

---

### 二、损耗控制：利用“物理限制”反推采购策略

#### 1. 采购源头定零头
-   **“够卖半天”原则**：早上进货，**绝不按天备货，按“半日”备货**。例如：预估今天能卖10斤香蕉，只进5斤，卖完中午再补。
-   **挑选“欠熟”果**：批发市场进货时，苹果和梨要选硬度的，香蕉选皮绿、棱角分明的（在店内常温放一天刚好熟）。

#### 2. 店内陈列与操作减法
-   **少摆多存**：台面上只放**一层**，不留堆头。底层铺上碎纸条或软垫，避免磕碰伤。
-   **放大颗粒**：像草莓、蓝莓这种易压坏的，**禁止散装倒在筐里**，必须带原包装盒卖，或者装成小盒（每盒6-8两）卖。
-   **剪枝减重**：批发的葡萄、提子带很长的梗，**进货后先在后台剪掉大梗**，只留一小截（这能减少5%的称重损耗，但看起来更干爽）。

#### 3. 降价促销的“三步走”
这是控制损耗最有效的手段，要有**极强的时间观念**：

-   **第一步（上午10点）**：发现表皮微皱的，立刻挑出来，**打折（8折）**，放在收银台旁边。
-   **第二步（下午3点）**：已经软化、有轻微碰伤但没烂的，**做特价（5折）**，并贴上“今日特价”标签。
-   **第三步（晚上8点后）**：还没卖完的，直接**打包成一袋3-5元**，随顾客买烟或买水时**顺带推销**，主打“今日清仓，不吃亏”。

#### 4. 核心损耗指标：先进先出
哪怕货再少，也要严格执行**“旧货必须摆在上面/前面，新货垫底”**。如果新货压旧货，旧货烂了直接全损，这是很多小便利店最大的隐性损耗。

### 三、附赠：“碎片化”操作的实战小技巧

1.  **买“小”不买“大”**：进货时尽量选单果重量在100-150g的中小果。因为便利店顾客多为单人购买，买小果容易一次吃完，不会因为太大吃不完而浪费，也便于按“个”定价，比如“2元1个苹果”，比称重结账更快，损耗更低。
2.  **建立“黑名单”制度**：记录下每一批进货的供应商，如果某一家的某类水果连续两次到货品质差（成熟度过高或磕碰多），**立刻换供应商**，不要因为价格便宜而保留，这通常是损耗的大头。
3.  **理货时“下手要狠”**：每天至少翻检2次（早、晚），**只要发现有霉变/出水的，立刻连根扔进垃圾桶**。不要用手去擦掉烂斑继续卖，霉菌会传染给旁边的水果，且会影响整个柜台形象。

**最终提醒**：便利店水果利润很薄，**止损比盈利更重要**。如果连续一周某品类的日损耗率（报损金额/进货金额）**超过5%**，果断砍掉该品类的进货，或者将进货量减半测试。
