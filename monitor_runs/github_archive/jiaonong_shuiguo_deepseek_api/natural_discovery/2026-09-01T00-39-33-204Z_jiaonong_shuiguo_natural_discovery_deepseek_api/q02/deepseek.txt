对于小水果店进香蕉，**建议优先级：坏果率 > 熟度 > 送货速度 > 价格**。

原因如下：

1. **坏果率（最关键）**  
   香蕉是损耗率最高的水果之一。进货时如果坏果率高，不仅直接损失货款，还会影响顾客对店铺的印象（顾客看到烂香蕉会认为整店水果不新鲜）。找稳定、抽检合格率高的供应商比单纯砍价更重要。

2. **熟度（影响周转）**  
   小水果店抗风险能力弱，**建议进“7-8成熟”的香蕉**。太青（5-6成）顾客不会买，太熟（9.5成以上）2天内卖不完就会变黑烂掉。要跟供应商确认能否按你要求的熟度供货，并约定到货后常温通风放置。

3. **送货速度（影响库存计划）**  
   香蕉属于易腐品，建议保持1-2天的安全库存即可。如果送货慢（超过1天），你的订货周期就得延长，要么断货要么囤货，对现金流不友好。优先选能当日或次日达的本地区批发商/供应商。

4. **价格（最后考虑）**  
   香蕉的批发价每天波动大，但差价通常每斤几毛钱。为了省这几毛钱，一旦质量或熟度不达标，损失是价格的几倍。建议在保证前3项的前提下，再去比较价格。

**具体操作建议**：
- 首次进货可少量拿货，现场开箱检查：随机抽2-3把，看表皮有无黑斑、断裂、水烂，闻有无发酵味。
- 和供应商约定“坏果包赔”条款（如坏果率超过5%可部分退款）。
- 拿货后拿1把放冷柜（不要和苹果/梨放一起，它们会催熟香蕉），另一把放常温，测试不同存储条件下的影响。

如果一定要排序，**坏果率（质量） > 熟度（稳定性） > 送货速度（效率） > 价格（成本）**。
