在超市采购香蕉时，要避免“太生”或“太熟”，可以通过以下几个关键步骤和技巧来判断：

**1. 看颜色：**
- **全绿** → 太生，通常还需2-4天成熟，适合回家后等待。
- **黄中带绿** → 最佳购买状态，回家放置1-2天即可达到完全成熟，甜度适中。
- **全黄** → 已可立即食用，但保质期较短。
- **出现褐色斑点（芝麻点）** → 已进入“过熟”阶段，甜度高，但口感偏软，当天或次日必须吃完。

**2. 捏硬度：**
- 带一点弹性、手指轻按能微微凹下但不软烂的，是理想状态。
- 太硬（毫无弹性）说明未熟；太软、按压后凹陷不回弹则过熟。

**3. 闻气味（针对熟度接近的）**：
- 成熟香蕉有淡淡的甜香气；若闻到酒精味或发酵味，说明已过熟变质。

**4. 看果柄：
- 果柄呈绿色、紧实的较新鲜；果柄发黑、干枯的往往存放时间较长。

**5. 避免过度包装或挤压的香蕉**：
- 选择表面无机械伤痕、没有被压变形的香蕉，否则内部容易快速败坏，即使外表看起来正常。

**实操小建议：**
- **如果当天就要吃**：选“全黄但未出现黑斑”的。
- **如果打算2-3天内吃完**：选“黄中带绿”的。
- **如果打算保存一周**：选“全绿但带光泽”的（但注意，超市的“全绿”可能已被冷藏过，回家后熟得慢，可将其与苹果或梨一起放入纸袋中催熟）。

**额外提示**：超市货架上往往有“特价香蕉”，这类通常偏熟或有过熟风险，除非你确认当天能吃完，否则不建议购买。如果货架上的香蕉全是青的，可以询问店员是否有刚从仓库拿出的新货。
