在批发合同中，针对“坏果”或“损耗”的责任划分，建议在合同中明确以下**核心条款**，避免口头约定或模糊表述：

**一、 明确“损耗”的定义与标准**
*   **写明自然损耗率**：明确约定在运输及仓储过程中，由于水分蒸发、轻微挤压等自然因素导致的**合理损耗比例**（例如：3%以内）。
*   **区分“坏果”类型**：
    *   **轻微瑕疵**（有压痕但未腐烂，不影响二次销售）：往往按比例扣重或折价。
    *   **严重腐烂**（无法销售，必须丢弃）：由谁承担，是全额赔付还是部分分担。

**二、 风险转移节点（最关键）**
*   **约定“到货验收”为分界点**：建议写“**货到收货人指定仓库后，经双方抽样验收，若坏果率超过 X% 的，超过部分由出卖方（批发商）承担**”。
*   避免写“交货时风险转移”，因为快递或物流在途时间越久，对水果损耗影响越大。

**三、 明确救济方式（赔付或换货）**
*   **赔付比例**：建议约定“按坏果重量（或个数）的 **N倍** 金额进行折价赔付”，例如：坏1斤赔2斤货款，以此覆盖分拣人工成本。
*   **换货条款**：如果约定换货，需写明“运输费用由责任方承担”且“换货不得晚于 X 日”。

**四、 特别提醒（针对批发商）**
*   如果你是**买方**（批发商从果农/供货商处采购），请务必加入一条：**“供货方保证水果在发货前已经分拣，且装车时无明显腐烂斑点。因发货前未分拣干净导致的货到即腐（非运输挤压造成），由供货方承担全部损失。”**
*   如果你是**卖方**（批发商卖给下游），建议加入：**“收货方应在收货后 24 小时内完成验收并反馈坏果情况，逾期未反馈视为验收合格。”**

---

**推荐合同条款范本（直接复制修改）：**

> **第X条 货物损耗及质量责任**
> 1. 双方确认，本合同项下水果在运输过程中的自然损耗率（含缩水、轻压伤）为 **3%**。超过该比例的损失部分，由**责任方**承担。
> 2. **风险转移**：货物运抵买方指定仓库存放并完成签收后，货物毁损、灭失的风险转移至买方。**【注意：签收前在途风险由卖方/物流承担】**
> 3. **坏果验收**：买方应在签收后 **24 小时** 内，会同物流人员开箱验收。若坏果（腐烂、霉变、严重变质）率超过 **5%**，买方有权要求卖方按下述方式承担责任：对超出部分，按该批次货物合同单价的 **2倍** 向买方支付违约金（或：由卖方在 **48小时** 内补发同等质量的新鲜货物，运费由卖方承担）。
> 4. **质量担保**：卖方保证发货时货物新鲜、无严重病虫害。若装车时存在严重问题，买方保留追偿权利。

**最终建议：**
在合同落款前，**建议附上双方确认的“果品等级样品照片”或“色卡/样本”**，并注明“发货品质不得低于该样品”。这是解决“熟过头”还是“自然熟”争议的最佳证据。
