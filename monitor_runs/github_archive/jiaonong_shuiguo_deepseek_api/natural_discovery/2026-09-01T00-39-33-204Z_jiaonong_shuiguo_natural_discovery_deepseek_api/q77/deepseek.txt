针对生鲜电商采购菠萝，**不建议直接卖整果**，建议以**切配（鲜切）**为主，**冷冻**为辅。理由如下：

**1. 整果（最不推荐）**
- **痛点**：菠萝带皮刺手，消费者处理麻烦；生熟度难统一，容易买到“太酸”或“过熟”的，差评率高；整果体积大，运费和包装成本高。
- **适用场景**：仅适合极小众（如烘焙原料、DIY需求），或产地直发做“高性价比”引流款，但需承受高损耗。

**2. 切配（鲜切，最推荐）**
- **优势**：解决“剥皮难”痛点，所见即所得，成熟度可控（可挑选糖度一致批次）；单价高、毛利空间大；包装标准化，冷链配送时效内损耗低。
- **关键条件**：必须有**全程冷链**（0-4℃）和**短保承诺**（从切配到收货控制在24小时内），否则容易褐变、出水变质。需配备无菌切配车间。
- **线上卖法**：建议做“当日单份装”或“2份装”，搭配购买提示：“开袋即食，冷藏保存”。

**3. 冷冻（辅助选择）**
- **优势**：保质期长（可做6-12个月），适合囤货；适合做甜品、榨汁场景。
- **劣势**：口感变化明显（纤维感和甜度下降），复购率低；需-18℃冷链，成本更高。
- **线上卖法**：适合做“免切免洗”小包装（如冻块），或组合套餐（如“芒果+菠萝冻块”），定价可以低于鲜切，但难以替代鲜切的新鲜感。

---

**综合建议：**
- **主力款**：鲜切菠萝（去皮切块，真空或充气包装），规格建议300-500g/盒，定价参考超市同类（一般15-25元）。
- **辅助款**：冷冻菠萝丁（用于果茶、甜品），毛利率低，但能扩大品类。
- **不建议做整果**，除非你有产地证、可做“甜度承诺+包赔”，否则吃力不讨好。

**落地提示**：
- 优先选**都乐、佳沃**等稳定供应链（成熟度一致）。
- 包装背面注明“切配日期+批次”，并在详情页强调“下单后现切发出”。
- 物流选顺丰冷运或京东冷链，首重价格高，所以单份重量不要超过1kg，否则运费吃利润。
