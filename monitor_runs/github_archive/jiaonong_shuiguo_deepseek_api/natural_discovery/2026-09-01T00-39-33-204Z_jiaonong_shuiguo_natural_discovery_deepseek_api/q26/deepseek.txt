社区超市销售小包装香蕉，核心目标是**控制损耗**和**提升周转**。采购和陈列时，建议重点注意以下几个环节：

**一、 采购源头与规格选择**

1.  **成熟度把控（最关键）**：不要采购全熟或过黄的香蕉。建议采购**7-8成熟**（果皮黄中带绿，果体硬实）的香蕉。到店后常温放置1-2天即可自然熟成，给门店留出销售窗口期。
2.  **小包装规格**：社区家庭日常消费量小，建议单包重量控制在**500克-750克**（约3-5根）。包装袋上最好标注重量和食用建议（如“当天食用”或“催熟后食用”）。
3.  **箱内检查**：开箱时务必检查有无“头蕉”（果柄受伤）或“水烂”（果皮发黑）情况。如有，应要求供应商承担损耗或调换。

**二、 包装方式选择**

| 包装形式 | 优点 | 注意损耗风险 |
| :--- | :--- | :--- |
| **保鲜膜/密封袋** | 减缓水分流失，卖相干净 | 密封过紧易产生冷凝水加速霉变，建议袋上打2-3个透气孔 |
| **网套+托盘** | 保护果尖，避免磕碰产生黑斑 | 托盘成本略高，需定时清理顾客翻动后的散果 |
| **裸卖+称重贴标**（适用于极快速周转店） | 损耗最低，但卖相一般 | 仅建议在日客流大的社区店尝试 |

**三、 门店陈列与损耗控制实操**

1.  **先进先出**：将早收货、熟度高的放在货架最外层，新到的放在内侧。严禁将新货叠在旧货上面。
2.  **避压与通风**：摆放时**果柄朝上**（模仿自然生长方向），避免被重物压伤。不要放在阳光直射或冷藏柜风口下方，否则会迅速变黑。
3.  **每日翻包**：每天至少早晚各抽查一次包装袋，发现袋内有水汽或个别熟透发软的，立即挑出做**特价处理**或试吃。建议设置“今日特价香蕉”档口，在熟透前卖出。
4.  **损耗预估公式**：社区店小包装香蕉的正常**自然损耗率**（挤压、轻微黑斑）应控制在3%-5%。如果超过8%，说明采购成熟度过高或包装通气不足。

**四、 给供应商的采购话术建议**

- 要求供应商提供**“二次成熟”**服务，即供应商发货时就按7-8成熟分拣，避免在产地放至全熟。
- 明确要求**“原箱重量”**与“净重”差异，防止供应商在包装箱或吸水纸重量上做文章。

**总结建议**：优先采购7-8成熟、带透气孔包装、约500g/包的小规格产品。门店坚持**少进勤补**（每日或隔日进货），比一次性囤货更能有效控制损耗。
