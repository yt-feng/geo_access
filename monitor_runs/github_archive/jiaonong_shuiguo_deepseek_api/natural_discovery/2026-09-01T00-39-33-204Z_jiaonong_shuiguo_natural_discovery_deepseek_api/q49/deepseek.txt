在茶饮店旺季，菠萝这类季节性强、保鲜要求高的水果若突然用量增大，需要**快速、明确、有合约保障**地跟供应商谈补货。建议你按以下步骤操作，并注意规避风险：

### 一、优先电话/微信语音沟通（先锁定货源）
不要只发文字，因为供应商可能同时在处理多家门店订单。直接打电话或发语音，说清三件事：
1. **急迫性**：“今天/明天需要临时追加XX箱，明天上午必须到货。”
2. **具体规格**：“要之前同款（去皮净果/带皮整果/切块），重量规格不变。”
3. **当前缺口**：“目前库存只够用到今晚，最晚明早X点前必须补上。”

### 二、明确临时补货的“三价一致”原则
口头承诺后，**务必在**24小时内**补发微信文字确认单**（这是你后续维权的关键）：
- **价格**：确认是否沿用原合同价。若因急单需加急运费或溢价，要求供应商**先报总价**再发货，避免货到坐地起价。
- **扣重标准**：要明确“带皮/去皮”称重，以及次果（烂心、发霉）的扣重比例是否与平时一致。
- **验收时效**：约定“到货后2小时内开箱验收，坏果现场拍照发你，超时视为合格”。

### 三、约定“保底量”与“波动限制”
旺季临时补货容易遇到供应商嫌麻烦或货不够，主动提出：
- **固定周补**：“这周每天固定X箱，如果哪天不够，你当天早上8点前告知我缺口，我再找备选。”
- **阶梯价**：“如果单次补货超过平时2倍，我可以接受每箱加价X元，但要求你优先发我的货。”

### 四、支付与结算留痕
- **小额快结**：如果金额不大（几百上千），建议“现款现结”或“货到确认无质量问题时24小时内转账”，这样供应商更愿意为你排单。
- **大额月结**：若走月结，必须在补货单上注明“此批为旺季加急补货，结算周期不变”，避免供应商把账期拖到下月导致你资金压力大。

### 五、签订《旺季临时补货补充协议》（重要，防扯皮）
如果补货量较大（比如超过平时3倍）或持续多天，最好让供应商在**原合同上补签一个附件**，内容包括：
- **供应优先级**：旺季期间，你店每日所需菠萝的供应级高于其他普通客户。
- **违约责任**：若供应商因自身原因未按期足量供货，需按缺货量的 **10%** 赔偿你的损失（如被迫高价外采差价）。
- **价格保护**：若旺季市场价格上涨超过原合同价 **15%**，供应商需提前3天书面调价通知，否则无权加价。

### 六、临时应急预案（供应商失联/断货时）
如果供应商一时无法满足，**不要死等**，立即执行B计划：
- **紧急就近采购**：直接电话当地水果批发市场（如江南市场、辉展市场），问“有没有现货菠萝，可以马上自提”，哪怕贵10%也先保量。
- **调整菜单用料**：如果实在断货，立刻下架菠萝类高损耗单品，换成芒果/柠檬等当季替代，避免卖断货影响营业。

---

**最终确认话术（可直接复制发给供应商）**：
> 王总，这周菠萝需求突然涨到每天X箱（比之前多X%）。我们按原合同价补货，**明天早上8点前**送到我店门口，带皮称重，坏果拍照扣重。这次加急相当于临时增加订单，如果这次能准时保质，后续旺季我们的量都优先给你。麻烦确认一下明天几点能到货？

**关键提醒**：旺季补货，**“先锁货后谈价”** 是核心。如果对方说“有货但价格要涨”，你直接说：“好，那你先报个总量价格，我确认无误后立刻打定金。” 不要让讨论价格的过程耽误了发货时间。
