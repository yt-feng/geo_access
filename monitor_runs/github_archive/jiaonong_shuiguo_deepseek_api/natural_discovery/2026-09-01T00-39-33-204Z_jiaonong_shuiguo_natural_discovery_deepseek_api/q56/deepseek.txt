茶饮店在采购水果供应商的产品时，为控制食品安全风险，建议要求供应商提供以下证明文件（根据实际情况选择或组合，并确保证明在有效期内）：

1. **营业执照**（复印件加盖公章）—— 确认供应商是合法经营主体。
2. **食品经营许可证**（或食品生产许可证）—— 证明其具备食品销售或生产资质。
3. **水果的合格证明或出厂检验报告**—— 每批次或定期提供，包含农残、重金属等指标。
4. **农产品产地证明或食用农产品合格证**—— 证明水果来源合法、产地信息明确。
5. **农药残留检测报告**（第三方检测或政府抽检报告）—— 至少提供近3个月内的有效报告，重点检测有机磷、菊酯类等常用农药。
6. **冷链运输或配送记录**（如适用）—— 证明运输过程中温度控制符合要求。
7. **进货查验记录**（供应商需提供其上游的具体来源和单据）—— 保证可追溯性。
8. **合格供应商评定表**（如已建立供应商准入制度，应让供应商配合填写）—— 证明其通过你的内部审核。

**特别提醒：**
- 所有文件应加盖供应商公章或提供电子版原件截图，并定期更新（建议半年或一年一次）。
- 对于高风险水果（如草莓、葡萄、樱桃等易残留农残的品类），务必索取农残检测报告。
- 保留所有单据至少6个月以上，以备监管部门查验或追溯。
- 如果供应商无法提供上述核心文件，应视为高风险供应商，建议启用替代供应商或停止合作。
