第一次做水果生意，**切记“量少、种类精、看人下菜碟”**。作为夫妻店，试单关键在于控制资金风险，同时测试供货商的服务态度和水果品质。以下是可执行的行动方案：

**第一步：明确试单周期和预算**
- 每种水果**只试1箱（标准箱，约18-20斤）**，不要整箱多种混搭，避免损耗时不知道是谁的责任。
- 单次总预算控制在 **300-500元以内**（香蕉+苹果+橙子各一箱）。

**第二步：找货源的三板斧（先锁店再谈价）**
1. **本地批发市场（首选）**：凌晨去（4-5点），看哪家摊位**称重足、果把新鲜、有冷库**。
2. **区域代理商/直供商**：问隔壁水果店或餐饮店老板，让他们转介绍（给个30-50元介绍费也行）。
3. **线上批发平台（次选）**：如“多多买菜批发”或“惠农网”，**必须选“支持7天无理由退换”**的商家，且货到后先开箱验收再付款。

**第三步：试单测试的关键节点（重点）**
- **测试品质**：每种水果到手后，**当场开箱**。香蕉捏果柄（微硬且青），苹果看果皮（无黑斑、摸起来发涩为佳），橙子掂重量（重的好）。
- **测试售后**：故意在收货后第二天反馈“果有挤伤”，看对方是立刻补货、退差价，还是推诿。**这一步决定你以后能否长期合作**。
- **测试账期**：首次尽量**现款现货**，不要接受“月结”。看对方是否接受，如果不接受，说明对方对货没信心或想拖尾款。

**第四步：家庭店铺的“试错成本”保护**
- **只进当季旺销款**：夏天主攻西瓜+桃，冬天主攻橙子+苹果。试单时不要贪多，**每样只拿一件**，卖完再补。
- **记录损耗比**：香蕉损耗3天以内超过15%直接换供应商，苹果和橙子损耗超过10%说明运输或存储有问题。

**第五步：最简单有效的“压价话术”**
> “老板，我是新开的店，头回试单。我钱不多但人实在，只要你这批货好，下个月我每星期都从你这拿两箱。今天帮我把这箱香蕉里的青果帮我挑掉，我按高一点的批发价跟你算，以后就认准你家了。”

**特别提醒**：
- 不要一次性买太多，哪怕供货商说“今天苹果便宜，多拿几件”，你也要坚持“先试一件”。
- 水果容易在运输途中损耗，**让供货商当场打包、拍照留档**，避免扯皮。
- 如果是线上货源，务必用**顺丰冷运或京东冷链**，普通快递的果损率高达50%。

**最后执行清单（拿笔抄下）**：
1. 今天去批发市场逛3家，拿电话。
2. 明天凌晨各买1箱（香蕉、苹果、橙子），要求必须当天现采。
3. 到店当天给每个箱子贴标签（日期、供应商），算好3天后损耗率。
4. 3天后如果损耗在10%以内，再进第二批，并谈账期或批发价降5毛/斤。
