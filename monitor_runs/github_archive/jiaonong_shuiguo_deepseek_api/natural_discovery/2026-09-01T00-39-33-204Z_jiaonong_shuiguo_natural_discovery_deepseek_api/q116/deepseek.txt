对于小商家采购水果，**现金结算**和**月结账期**各有不同的风险，具体如下：

---

### 一、现金结算的风险
**优点**：资金即时到账，供应商无欠款风险，采购价格通常有优惠（因为现金周转快）。
**风险**：
1. **资金压力大**：小商家需要一次性支付全部货款，如果现金流不充裕，可能影响日常经营周转。
2. **质量风险难追溯**：现金交易通常无正式合同或发票，若水果出现腐烂、缺斤短两、品种不符等问题，后续维权和索赔困难（尤其是不熟悉的小供应商）。
3. **采购量受限**：由于需要即时付款，小商家可能无法一次性购买大量货物，导致错过批发价优惠或备货不足。
4. **供应商稳定性差**：现金交易多为临时或小规模供应商，其供货能力、品质稳定性、诚信度参差不齐，可能存在“一锤子买卖”风险。

---

### 二、月结账期的风险
**优点**：缓解小商家短期资金压力，便于灵活备货；对长期合作供应商，可能获得更稳定的价格和货源。
**风险**：
1. **欠款信用风险**：若商家经营不善或资金链断裂，无法按时付款，会影响与供应商的合作关系，甚至被停止供货。
2. **价格或品质被动**：月结模式下，供应商可能在账期内调整价格或降低供货品质（尤其是水果价格波动大时），商家缺乏约束力。
3. **账期管理成本**：需要记录每一笔采购明细、对账、催票等，增加人力时间成本；若忘记记账，易产生纠纷。
4. **被压货款风险**：有些供应商可能会要求“预付款+月结”或“下单即付定金”，若订单取消，定金可能不退。
5. **法律纠纷风险**：若双方对账不清或合同条款模糊（如账期起算日、滞纳金等），容易引发货款纠纷。

---

### 三、针对性建议
- **水果易腐、价格波动大**，建议小商家：
  - **对陌生供应商**：优先现金成交，但要求开具收据或简易购销单，最好现场验货（重量、品相、新鲜度）。
  - **对长期合作、信誉良好的供应商**：可协商“短期账期”（如7天或15天），并签订简易合同，明确账期、质量标准和违约责任。
  - **混合模式**：大宗采购付部分现金，小额高频用月结，降低整体风险。
  - **留痕管理**：无论何种方式，保留微信聊天记录、转账凭证、收据，便于纠纷时举证。
