这是一个很实际的经营决策问题。**没有绝对答案，核心取决于门店定位、客群和损耗控制能力。** 但一般来说，**“整果为主，切果为辅”** 是比较稳妥的策略。

给你几个可执行的具体建议：

**1. 判断你的客流类型（最优先）**

- **社区型/家庭客群店**：应以**卖整果为主**。家庭采购通常需要做菜、饭后水果，整果易保存，顾客习惯自己回家处理，且毛利高。
- **写字楼/商圈/景区/地铁门店**：应以**切好的为主**。这类客群是即时性消费，追求方便，买完就吃，单次消费额低但复购率高。
- **混合型门店**：建议按照 **6:4（整果：切果）** 的陈列比例来备货。

**2. 看品种和成熟度（关键抓手）**

- **菠萝/凤梨**属于“后熟容易过熟”的水果。
- **较青、较生的货**：建议卖整果，让顾客拿回家放几天。
- **已熟、甚至有点过熟（表皮透香）的货**：**必须全部切好卖**，这是避免损耗的唯一途径，否则整果会烂在货架。

**3. 卖切好的核心是“快”**

如果你决定卖切好的，这三点必须做到，否则顾客不会买：

- **保鲜展示**：必须用保鲜膜包裹，下面垫吸水纸，冷藏柜温度保持在5℃以下。
- **当日清货**：切开的水果氧化快，超过4小时口感骤降，贴“当日鲜”标签，明确写“请于当日内食用”。
- **定量小份**：卖小盒装（300g-500g），别卖大盒。顾客买切好的，通常是想随手吃完，太大盒反而滞销。

**4. 毛利测算上的差异（给你算笔账）**

- **整果**：毛利一般在20%-30%，但损耗极低（只要不分拣坏果）。适合走量。
- **切果**：毛利能到50%-60%（因为加工溢价），但损耗极高（切口氧化、顾客挑拣）。适合赚净利。

**决策结论：**
如果你门店面积小、人手不够、追求快速周转，**只卖整果**更安全；如果你能接受理货员频繁处理废弃果肉，且客单价高（如城市白领密集区），则**加大切果比例**。

**一个稳妥的实操方案**：早上卖整果（挑外观漂亮的），下午太阳下山后，将所有**表皮出现褐斑或软化的整果**全部转为切盒销售，并配合试吃。这样既保证顾客买到新鲜整果，又最大限度把临期水果变现。
