选择公司下午茶水果供应商，核心看四点：**能否稳定批量供货、配送是否准时、损耗谁承担、结算是否方便**。按这个顺序筛选，基本不会踩大坑。

**一、先明确自己的需求**
- 人数和预算：比如 50 人、人均 10 元，就是 500 元总额。
- 配送频率：每周一次还是每天一次。
- 配送时间：必须卡在下午茶前送到，比如 14:30 前。
- 水果形式：整果、切果拼盘、还是小份分装。切果方便但损耗和食品安全风险高，整果便宜耐放。

**二、优先考虑这几类供应商**
1. **本地水果批发市场商户**：价格最低，适合大批量整果，但配送和售后一般，需要自己谈。
2. **生鲜 B2B 平台**：如美菜、快驴等，批量配送成熟，有发票，适合企业采购，价格中等。
3. **连锁水果店/区域水果连锁**：如百果园等，品质稳定、可开发票，但批量折扣有限。
4. **专业企业下午茶/团餐供应商**：一站式配送到工位，省心，但单价最高。
5. **产地直发/社区团购团长**：便宜，但时效和品质波动大，不适合对时间要求严格的场景。

**三、筛选供应商的关键问题**
问清楚这几点，能过滤掉大部分不靠谱的：
- 起送量和最小起订金额是多少？
- 配送费怎么算？超出范围加钱吗？
- 能不能固定时间送达？迟到怎么处理？
- 水果有坏果、压伤，是补送还是退款？多久内反馈有效？
- 能不能开增值税发票？支持月结还是现结？
- 临时加量或改单，提前多久通知有效？

**四、建议的做法**
1. 先选 2–3 家试单，同一预算下对比品质、准时率、损耗率。
2. 试单时故意观察：实际到货和图片是否一致、坏果比例、配送是否准时。
3. 稳定后签简单协议，写明配送时间、验收标准、坏果赔付、结算周期。
4. 不要只盯单价，算“实际可食用成本”：便宜但坏一半，反而更贵。

**五、避坑提醒**
- 切果拼盘要看是否有冷链和分装资质，夏天容易出食品安全问题。
- 不要长期只依赖一家，保留一个备选供应商。
- 大批量采购前先确认公司能否报销、需要什么发票类型。
