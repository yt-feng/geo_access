单位采购水果，到货品质不一致是很常见的问题。要减少扯皮，核心是：**验收标准提前写进合同/订单，到货当场按标准验，异常当场记录并约定售后时限**。下面按可执行流程说明。

## 一、采购前先把标准定清楚

不要只写“新鲜、优质”这种模糊词，要写可判断的指标：

1. **品种、规格、等级**：如红富士苹果，直径80mm以上，单果重200g以上。
2. **成熟度**：如香蕉到货青黄比例、芒果硬熟度。
3. **外观**：允许的斑点、碰伤、裂口、腐烂比例。
4. **糖度/口感**：如有条件，约定可抽检糖度。
5. **包装和温度**：箱装、净重、冷链要求。
6. **验收合格率**：如抽检合格率≥95%视为整批合格；低于则按比例扣款或退换。
7. **售后时限**：如到货24小时内提出异议有效，腐烂类可延长至48小时。

## 二、到货验收怎么操作

建议至少两人在场，一人清点，一人记录，最好拍照/录像。

### 1. 先核对单据和数量
- 送货单、订单、合同是否一致；
- 品种、规格、数量、重量是否相符；
- 称重建议抽箱称，避免只点箱数。

### 2. 抽检而不是全检
- 大批量按比例抽检，如每批抽5%-10%；
- 小批量可全检；
- 抽检要覆盖不同位置、不同箱，避免只查表面。

### 3. 按标准逐项判断
重点看：
- 腐烂、霉变、虫蛀；
- 碰伤、压伤、裂口；
- 大小、颜色、成熟度是否一致；
- 是否有异味、冻伤、失水。

### 4. 当场记录
记录内容包括：
- 到货时间、批次、数量；
- 抽检数量、不合格数量；
- 不合格类型和照片；
- 双方签字确认。

如果送货方不签字，也要在送货单上注明“当场抽检发现XX问题，待处理”，并拍照留证。

## 三、品质不一致时怎么判定

可以按比例处理，避免整批退或整批收：

| 情况 | 处理建议 |
|---|---|
| 少量碰伤、成熟度略差 | 按比例扣款或折价接收 |
| 腐烂、霉变、虫害 | 单独挑出，退货或换货 |
| 规格严重不符 | 拒收或要求重新发货 |
| 整批品质明显低于约定 | 整批拒收，费用由供应商承担 |
| 部分合格部分不合格 | 合格部分收，不合格部分退换 |

关键：**不要先签收再慢慢扯**。一旦签“数量无误、质量合格”，后面维权会很难。

## 四、售后怎么谈

### 1. 当场提出，书面确认
- 到货当天发微信/邮件/函件给供应商；
- 写明批次、问题、数量、照片、诉求；
- 要求对方在约定时间内回复。

### 2. 售后方式
常见有：
- 补发合格品；
- 退货退款；
- 按不合格比例扣款；
- 折价接收；
- 换货并承担因此产生的费用。

### 3. 约定时限
- 24小时内反馈；
- 48小时内给出处理方案；
- 腐烂类商品当天处理，避免扩大损失。

### 4. 保留证据
- 合同、订单、送货单；
- 验收记录、照片、视频；
- 聊天记录、邮件、通话录音；
- 付款凭证。

## 五、建议写进合同/订单的条款

可以直接用这几条：

1. 到货品质以双方确认的规格书为准。
2. 采购方有权按不低于5%比例抽检。
3. 抽检不合格率超过5%，供应商应按不合格比例扣款；超过20%，采购方有权拒收。
4. 腐烂、霉变、虫害等严重问题，供应商应无条件退换，并承担运输费用。
5. 采购方应在到货后24小时内提出质量异议，供应商应在48小时内处理。
6. 因质量问题导致的退货、换货、延误，供应商应承担相应责任。

## 六、简单执行清单

到货时按这个顺序做：

1. 核对订单和送货单；
2. 抽检数量、重量、规格；
3. 检查腐烂、碰伤、成熟度；
4. 拍照记录不合格品；
5. 双方签字确认验收结果；
6. 当场提出售后诉求；
7. 保留所有证据；
8. 按合同扣款、退换或折价。

一句话：**验收要当场、标准要量化、异常要留证、售后要限时。** 这样既能把品质问题控制住，也能避免后面反复扯皮。
