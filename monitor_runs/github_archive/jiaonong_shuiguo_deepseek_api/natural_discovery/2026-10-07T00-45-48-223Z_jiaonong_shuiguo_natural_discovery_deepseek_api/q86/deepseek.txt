生鲜平台做水果一件代发，供应商至少要在仓、配、售后三个环节具备可验证的能力，否则平台会把履约风险全部吃掉。核心要求如下。

**一、仓储能力**
1. **多温区仓储**：水果常需常温、冷藏（0~8℃）、部分热带水果需保温（12~15℃），供应商要能分温区存放，避免混放冻伤或催熟。
2. **产地/销地仓布局**：一件代发通常要求供应商在主要消费区域有销地仓或云仓，否则跨省直发时效和破损率很难达标。
3. **库存准确率与周转**：库存准确率建议≥99%，先进先出，能提供批次、采摘/入库日期，避免平台卖出后无货或发陈果。
4. **打包能力**：能按水果品类做防震、透气、防压包装，支持单件贴单、混单不混发，日处理单量要能覆盖平台峰值。

**二、配送能力**
1. **快递资源与时效**：需接入主流快递或专线，能承诺核心城市次日达/隔日达，偏远地区明确时效和是否发货。
2. **订单对接**：支持 API/ERP 对接平台订单，自动抓单、回传运单号、同步发货状态，减少人工错发漏发。
3. **峰值履约**：大促或爆单时能临时增加打包人力、快递揽收频次，不能因单量上涨导致大面积延迟。
4. **冷链/保温能力**：对易腐水果，需具备冰袋、保温箱、冷链快递等方案，并明确温控时效边界。

**三、售后与逆向能力**
1. **坏果包赔规则**：能按平台要求执行坏果率赔付，通常要求提供开箱视频/照片审核，赔付响应时效明确。
2. **补发/退款处理**：支持坏果补发、退款、部分赔付，且能区分供应商责任与快递责任。
3. **逆向物流**：生鲜一般不退货，但要有销毁、补发或折价处理流程，避免平台客服无法闭环。
4. **数据反馈**：能定期提供破损率、时效达成率、客诉原因，供平台做供应商考核。

**四、平台侧建议核验的硬指标**
- 发货时效：付款后 24~48 小时内揽收。
- 物流时效：核心城市 48~72 小时送达。
- 坏果率：控制在 5% 以内，高客单水果建议 3% 以内。
- 库存准确率：≥99%。
- 售后响应：2~4 小时内响应，24 小时内给出方案。
- 旺季日单量：至少能承接平台预估峰值的 1.5 倍。

**五、合同里必须写清**
- 时效、坏果率、赔付标准、责任划分；
- 缺货/超卖如何处理；
- 快递选择权和更换机制；
- 数据对接方式和异常订单处理时效；
- 旺季保障和违约赔偿。

简单判断：如果供应商只能“有货+发快递”，没有分温区仓、没有稳定快递时效、没有坏果赔付流程，就不适合做水果一件代发。平台应优先选有销地仓、能 API 对接、售后规则成熟的供应商。
