水果店采购菠萝，核心是**按“预计卖完的时间”来倒推采购熟度**，而不是一律挑最熟或最生。菠萝是后熟型水果，采购时判断熟度可以看这几个可执行指标：

1. **看果皮颜色**
   - **全青**：适合还要放 3～5 天再卖，但太生会酸、涩，顾客当场买回去可能觉得不好吃。
   - **青转黄、底部开始泛黄**：最适合采购，通常 1～3 天进入适售期。
   - **半黄到金黄**：适合 1～2 天内卖完，香气足、甜度高，但再放容易过熟。
   - **全黄、果眼发暗**：已偏熟，最好当天促销或做果切，不适合再囤。

2. **看底部和果眼**
   - 菠萝底部开始变黄、果眼由尖凸变得较平、颜色从青绿转黄褐，说明在转熟。
   - 如果底部发黑、发软、有酒味，说明过熟或开始腐烂，不要采购。
   - 果眼周围如果出现明显黑斑、水渍状，也不要拿。

3. **闻香气**
   - 靠近底部闻：
     - 几乎无味：偏生，可放。
     - 有清甜菠萝香：正好，适合近期卖。
     - 香气很浓甚至带酒味：过熟，必须快卖。
   - 香气是最直接判断“还能放多久”的指标之一。

4. **掂重量、按硬度**
   - 同样大小，**越重越好**，说明水分足。
   - 轻飘飘的可能失水或内部空心。
   - 用手指轻按底部，微软有弹性是适熟；明显软陷就是过熟。
   - 硬得像石头则偏生。

5. **看叶片和果柄**
   - 叶片青绿、有光泽，说明较新鲜。
   - 叶片枯黄、果柄干缩，说明存放时间长，熟度可能不好控。
   - 但叶片状态只能辅助，不能单独判断果肉熟度。

6. **按销售节奏定采购比例**
   比较实用的做法：
   - **当天卖**：采购半黄到金黄、香味明显的。
   - **2～3 天卖**：采购青转黄、底部微黄、香气淡的。
   - **3～5 天卖**：采购全青或刚转黄的，但量不要大，因为菠萝后熟速度受温度影响大。
   - 夏天温度高，后熟快，采购熟度要偏低；冬天温度低，可以适当采熟一点。

7. **控制损耗的采购原则**
   - 不要一次全采同一熟度，按“今天卖、明天卖、后天卖”分三档采购。
   - 熟度高的放前排、做试吃或果切；熟度低的放后面。
   - 菠萝怕冷害，未熟果不要直接放冷库低温太久，通常适合放在阴凉通风处或适温区。
   - 每天检查底部，有酒味、发软、黑斑的立刻挑出，避免传染和继续损耗。

简单记：**底部微黄、有淡香、手感沉、按底部微软，是最适合采购的熟度；全青可放但风险是口感差，全黄则必须快卖。** 采购时最好按你预计的销售天数，把生熟搭配着拿。
