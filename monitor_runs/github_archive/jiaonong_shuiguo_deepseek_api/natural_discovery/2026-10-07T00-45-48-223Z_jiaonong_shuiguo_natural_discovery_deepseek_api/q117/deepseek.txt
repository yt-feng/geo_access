先试卖多少，没有一个放之四海皆准的固定数字，但可以按“先小批量验证、再按数据放量”的思路来定。比较稳的做法是：

**1. 先定试卖量级**
- **单店/单渠道首次试卖**：建议从 **3～7 天销量** 或 **1～2 个最小起订量（MOQ）** 起步，取两者中更小的那个。
- 如果是社区店、水果摊、小超市：首次通常 **10～30 公斤/件** 比较常见，具体看单品和包装规格。
- 如果是连锁采购或批发渠道：可以先在 **1～2 家门店或 1 个区域** 试卖，量控制在 **正常单品周销量的 20%～30%**。

**2. 比“多少斤”更重要的是试卖周期**
- 水果有保鲜期，试卖周期建议 **3～7 天**，最多不要超过一个订货周期。
- 易损、易熟、保质期短的水果：**2～3 天**就要看数据。
- 耐储存水果：可以拉到 **5～7 天**。

**3. 判断能不能放量的核心指标**
- **动销率**：试卖期内卖出比例达到 **70% 以上**，可以考虑补货。
- **损耗率**：超过 **5%～8%** 就要谨慎，超过 10% 基本不建议直接放量。
- **毛利率**：扣掉损耗后仍能覆盖成本并有合理利润。
- **复购/反馈**：有顾客主动问、回头买，比单纯“卖完了”更有参考价值。
- **售后投诉**：口感、成熟度、外观投诉多，先别放量。

**4. 比较稳的操作节奏**
- 第一批：小批量试卖，选 1～2 个有代表性的门店或渠道。
- 第二批：如果动销好、损耗低，按试卖量的 **2～3 倍**补货。
- 第三批：连续两轮数据稳定，再扩大到更多门店或正常采购量。
- 全程记录：到货时间、售价、销量、损耗、顾客反馈、天气影响。

**5. 可以直接套用的建议**
如果你是普通采购方，第一次试卖一个新水果单品，可以这样定：

> **首次试卖量 = 单店 3 天预估销量，且不超过供应商最小起订量的 1～2 倍；先放 1～2 个门店，卖 3～7 天看动销和损耗，再决定是否放大。**

如果供应商要求起订量很大，而你对新品没把握，更稳的做法是：**先谈小包装、拼柜或联合其他采购方分摊首单**，不要一上来就压大货。
