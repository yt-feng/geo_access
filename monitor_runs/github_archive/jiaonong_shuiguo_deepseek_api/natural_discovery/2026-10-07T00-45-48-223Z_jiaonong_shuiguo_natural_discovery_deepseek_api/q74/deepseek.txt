拓展餐饮客户，菠萝和香蕉的规格核心看**用途**——餐饮端不是买来直接吃，而是做菜、做饮品、做甜品、做拼盘，所以规格要按**加工场景**来分，而不是按零售的"大小好看"来分。

## 菠萝

餐饮端主要三个流向：热菜（菠萝咕咾肉、菠萝炒饭）、饮品/甜品（菠萝汁、菠萝冰、糖水）、果盘。

**建议备的规格：**

| 规格方向 | 具体标准 | 对应客户 |
|---|---|---|
| 大果 | 单果1.2–1.8kg，果眼浅、易削 | 果盘、酒店、宴席 |
| 中果 | 单果0.8–1.2kg | 炒菜、炒饭、批量加工 |
| 小果/迷你 | 单果0.5–0.8kg | 一人份甜品、网红饮品 |
| 去皮菠萝块/整只去皮 | 真空或鲜切，按kg计 | 饮品店、快餐、后厨省人工的店 |

**关键点：**
- 餐饮客户最在意**出肉率和削皮人工**。能提供"去皮整只"或"切块"的档口，对饮品店和快餐店吸引力大。
- 菠萝品种上，**金钻/台农**甜度高、果眼浅，适合直接出品；**普通品种**酸度高，适合做菜和糖水。
- 成熟度要能控：饮品店要7–8成熟，热菜可以用8–9成熟。

## 香蕉

餐饮端主要流向：果盘、甜品（香蕉船、炸香蕉）、饮品（香蕉奶昔）、烘焙（香蕉面包/蛋糕）。餐饮客户对香蕉的核心诉求是**成熟度可控**和**批次稳定**。

**建议备的规格：**

| 规格方向 | 具体标准 | 对应客户 |
|---|---|---|
| 大果（标准蕉） | 单根150–200g，长度18–22cm | 果盘、酒店、自助餐 |
| 中果 | 单根100–150g | 甜品、饮品、烘焙 |
| 小果/小米蕉 | 单根50–80g | 特色甜品、拼盘、网红饮品 |
| 青蕉（未熟） | 按成熟度分级 | 需要自己催熟的连锁客户 |
| 熟蕉（即用） | 黄皮带少量糖斑 | 当天出品的餐饮店 |

**关键点：**
- 香蕉最大的痛点是**成熟度**。餐饮客户要么要"能放几天慢慢熟"的青蕉，要么要"今天就能用"的熟蕉，档口最好能按成熟度分批供。
- 烘焙和奶昔客户往往要**过熟蕉**（带糖斑甚至发黑），这种零售卖不掉，但餐饮是刚需，是很好的差异化切入点。
- 规格上按**根重**分级比按"把"更受餐饮欢迎，因为后厨按份量算成本。

## 给你的实操建议

1. **先分客户类型再定规格**：饮品店要切块/去皮、要稳定甜度；热菜店要大中果、耐存放；酒店自助要外观整齐的大果。
2. **菠萝主打"省人工"**，香蕉主打"成熟度可控"，这是餐饮客户最愿意付溢价的两个点。
3. **首批别铺太全**：先备2–3个主力规格（比如菠萝中果+去皮块、香蕉中果+过熟蕉），跑通一两家客户再扩。
4. **报价按kg或按份**，别按"个"报，餐饮后厨是算成本的。
