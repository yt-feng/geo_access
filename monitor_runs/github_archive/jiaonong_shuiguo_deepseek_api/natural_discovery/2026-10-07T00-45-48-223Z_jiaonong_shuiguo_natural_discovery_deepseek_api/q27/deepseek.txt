判断苹果和橙子的规格是否适合门店销售，核心是看**目标客群、陈列方式、损耗控制和定价带**，而不是单纯看“大不大”。可以按下面几个维度直接判断。

## 一、先明确门店定位和客群

| 门店类型 | 更适合的规格方向 |
|---|---|
| 社区生鲜店/便利店 | 中等偏小，单次购买量小，单价敏感 |
| 精品水果店 | 中大果，外观整齐，礼盒/散卖都好卖 |
| 商超大卖场 | 规格分层，大中小都要有，满足不同家庭 |
| 线上到家/团购 | 中等规格，标准化强，耐运输 |
| 高端礼赠 | 大果、均匀、色泽好，包装后溢价 |

所以先问一句：**你的顾客是“按个买”“按斤买”还是“按箱买”？**

## 二、苹果怎么判断规格

苹果常用“果径”判断，单位是毫米。

常见参考：

- 小果：60–65mm，适合低价引流、儿童果、切果
- 中果：70–75mm，社区店、便利店最好卖
- 大果：80–85mm，精品店、商超主推
- 特大果：90mm以上，礼盒、高端客群

判断是否适合门店：

1. **看陈列稳定性**  
   太小显得散、不饱满；太大堆头容易滚落、占空间。

2. **看单果重量和手感**  
   一般中大果拿在手里有分量，顾客觉得“划算”。

3. **看表皮和果形**  
   规格再合适，如果有明显畸形、锈斑、碰伤，也不适合正常货架销售。

4. **看价格带**  
   如果同品类中果卖 5.99 元/斤，大果卖 9.9 元/斤，要确认顾客是否愿意为大果多付钱。

5. **看包装方式**  
   托盘装、礼盒装适合 80mm 以上；散装适合 70–80mm。

## 三、橙子怎么判断规格

橙子通常也看果径，但更要看**品种和单果重量**。

常见参考：

- 小果：55–60mm，适合榨汁、促销
- 中果：60–70mm，日常散卖主力
- 大果：70–80mm，精品陈列、礼盒
- 特大果：80mm以上，部分脐橙、血橙可做高端

判断是否适合门店：

1. **看皮厚和出汁率**  
   有些大果皮厚、空壳，反而不如中果好卖。

2. **看大小 uniformity**  
   同一陈列面里，大小差异太大，顾客会挑拣，增加损耗。

3. **看耐储运性**  
   太熟的橙子不适合长时间货架期；太青的酸度高，复购差。

4. **看消费场景**  
   - 家庭日常吃：中果最稳  
   - 榨汁：中小果更划算  
   - 送礼：大果、均匀、表皮亮

5. **看称重还是按个卖**  
   按个卖时，规格要更统一；按斤卖时，可以接受一定大小差异。

## 四、直接可用的采购判断标准

采购时建议按这 5 条快速判断：

1. **目标售价能否覆盖损耗**  
   例如进价 3 元/斤，售价 5.99 元/斤，损耗 15%，还有没有毛利？

2. **同批货大小是否均匀**  
   均匀度差，顾客挑拣多，实际损耗会高于预期。

3. **是否匹配门店主力消费场景**  
   社区店别大量进 90mm 苹果；精品店别只进 65mm 小果。

4. **货架和包装是否适配**  
   层板高度、托盘孔径、礼盒格数，都会限制规格。

5. **试销数据是否支持**  
   先小批量试 2–3 个规格，看 3 天动销率、挑拣率、损耗率，再决定主推规格。

## 五、最实用的试销方法

新规格不要凭感觉大批量采购，直接做小测试：

- 同一品类进 2–3 个规格
- 分开陈列，标清价格
- 记录 3 天数据：
  - 销量
  - 剩余量
  - 挑拣后损耗
  - 顾客询价和复购
- 留下动销最好、损耗最低、毛利达标的规格作为主采

## 六、结论

**苹果**：社区/便利店优先 70–80mm，精品/礼盒优先 80–90mm。  
**橙子**：日常散卖优先 60–70mm，榨汁可接受 55–65mm，礼盒优先 70–80mm 且均匀度要高。

最终判断标准不是“越大越好”，而是：**好陈列、好动销、低损耗、有毛利、匹配客群**。
