**1. 开发票**
- 企业采购一般必须取得合规发票才能入账、报销和税前扣除。
- 应明确要求：能开**增值税专用发票**或**普通发票**，并确认税率、开票项目（如“水果”“食品礼盒”）、开票时间。
- 若是员工福利发放，部分企业还涉及个人所得税代扣代缴，财务通常更看重发票和采购凭证的完整性。

**2. 定制包装**
- 企业福利礼盒通常需要体现企业标识、节日主题、祝福语、员工关怀信息等，所以定制包装往往是实际需求。
- 应确认供应商能否支持：LOGO印刷、外盒/手提袋定制、贺卡、分装标签、不同预算档位包装。
- 还要问清定制起订量、打样费、打样周期、是否另收费、能否混搭水果品类。

**建议采购时直接列为供应商筛选条件：**
1. 具备合法经营资质和食品经营许可；
2. 能开具合规发票；
3. 支持定制包装并可打样确认；
4. 能按约定时间配送到指定地点；
5. 有售后处理机制，如果品控或破损问题能退换补发。

如果供应商只能满足其中一项，通常不建议作为企业福利采购的主供应商，除非是临时补充且财务和发放要求都能接受。
