判断一批香蕉，核心看 **颜色、硬度、棱角、果柄、气味、伤口和温度**，再结合你要卖几天来决定能不能拿。

**一、先判断熟度**

1. **颜色**
   - **全绿**：生，适合长途、囤货，但需要催熟。
   - **绿中带黄**：开始转熟，批发最常用，适合几天内出货。
   - **黄多绿少**：接近可售，适合快批快走。
   - **全黄**：熟，适合马上卖，不耐放。
   - **黄带黑斑**：糖化高，零售好吃，但坏果风险明显上升。
   - **大面积黑斑、发黑发暗**：过熟或已经开始腐坏，谨慎拿。

2. **硬度**
   - 轻按果身，**硬**说明生，**稍软有弹性**说明熟度合适。
   - **一按一个坑、软塌**：过熟，运输和摆放损耗大。
   - **局部特别软**：可能是内伤或腐坏起点。

3. **棱角**
   - 香蕉越生，棱角越明显，截面接近五边形。
   - 越熟，棱角越圆润，果身越饱满。
   - **棱角很尖**：偏生。
   - **果身圆鼓但没软塌**：熟度较好。

4. **果柄和果轴**
   - 果柄青绿、切口新鲜：通常较新。
   - 果柄发黑、干缩、霉点：存放久或伤过水。
   - 果轴有白色霉、黑霉、酸味：整批风险高。

5. **气味**
   - 清香正常。
   - **酒味、酸味、发酵味**：说明过熟或内部开始坏。
   - **霉味**：可能已有腐烂，别只看表面。

**二、判断坏果风险**

重点查这些地方：

1. **果皮伤口**
   - 擦伤、压伤、裂口、虫眼。
   - 小伤在高温下很快变黑腐烂，会传染旁边香蕉。

2. **果柄和果冠**
   - 发黑、发霉、流汁。
   - 这是香蕉批次腐烂的常见入口。

3. **果身黑斑类型**
   - 零星芝麻斑：熟度表现，不一定坏。
   - 大块黑斑、边缘水渍状：腐坏风险高。
   - 黑斑处按下去软烂：直接算坏果。

4. **箱内温度和湿度**
   - 摸箱内是否发热。发热说明呼吸作用强，熟得快、坏得快。
   - 有水珠、纸箱湿软：容易长霉。
   - 受冷害的香蕉皮会发暗、发灰，熟后发黑但不一定马上软，卖相差。

5. **整批均匀度**
   - 如果一箱里熟度差很多，说明混装或存放不均，后面很难统一出货。
   - 如果底层、中间已经软烂，上层再好也要压价或拒收。

6. **抽检方法**
   - 不要只看最上面一层。
   - 随机抽 **3—5箱**，每箱看 **上中下三层**。
   - 每箱抽 **5—10根**，重点捏果柄、看果冠、闻气味。
   - 发现一箱有霉柄、酸味、大面积软烂，要查同批次其他箱。

**三、按用途给建议**

- **要囤 5—10 天再卖**：拿绿中带黄、硬、棱角明显、无伤、无霉的货。
- **2—3 天出货**：拿黄多绿少、稍软、少量芝麻斑的货。
- **当天或第二天卖**：可以拿全黄、少量黑斑的货，但必须便宜且快走。
- **做零售/水果店**：熟度可以稍高，但坏果率要低，卖相要好。
- **做批发转手**：优先耐运输，别拿过熟货。

**四、简单拿货口诀**

**看色定熟度，捏硬定老嫩，看柄定新鲜，闻味定坏果，抽底定整批。**

**五、最容易踩的坑**

1. 只看表面黄，不看底层软烂。
2. 把芝麻斑当坏果，压价过度；或把大黑斑当熟斑，拿回就烂。
3. 忽略果柄霉变，后面整箱传染。
4. 夏天拿全黄货，路上就熟过头。
5. 冬天拿受冷害的货，表面还行，回温后发黑。
