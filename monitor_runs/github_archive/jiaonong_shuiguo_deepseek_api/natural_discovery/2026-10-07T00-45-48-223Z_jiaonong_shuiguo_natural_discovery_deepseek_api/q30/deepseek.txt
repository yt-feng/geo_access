超市水果到货后发现品相不好，售后流程建议按下面这种方式约定，核心是把“验收标准、反馈时限、处理方式、责任划分、留证要求”写清楚。

**1. 先约定验收标准和验收时间**
- 到货后应在约定时间内验收，比如“卸货后2小时内完成初验，24小时内完成终验”。
- 明确品相标准：大小、色泽、成熟度、机械伤、腐烂率、冻伤、虫眼、压伤、霉变等。
- 最好写量化指标，例如：
  - 腐烂果比例不超过2%；
  - 机械伤果比例不超过5%；
  - 不符合规格果比例不超过3%；
  - 成熟度按约定糖度、硬度或颜色标准执行。
- 避免只写“品相良好”这种模糊表述。

**2. 约定反馈时限和反馈方式**
- 发现问题后应在约定时间内提出，例如“收货后24小时内书面反馈，逾期视为验收合格”。
- 反馈方式要固定：微信、邮件、系统工单、电话加书面确认都可以，但必须可留痕。
- 反馈内容要包括：批次、品种、数量、问题类型、照片/视频、抽检比例、要求处理方式。

**3. 约定处理方式**
常见处理方式可以分档写：
- **轻微问题**：折价接收，按不合格比例扣款。
- **中等问题**：部分退货、换货，或补发合格货。
- **严重问题**：整批拒收，供应商承担退货运费、装卸费及因此产生的损失。
- **已上架后才发现**：能下架的下架，能退货的退货；已售出部分一般不再追溯，但可要求供应商按比例补偿。
- 对生鲜水果，通常不适合“无条件全退”，因为存在自然损耗和存放责任，所以要约定抽检和比例。

**4. 约定责任划分**
- 到货前责任在供应商：采摘、包装、运输、冷链不当导致的品相问题，由供应商负责。
- 到货后责任在采购方：验收后因存放、温湿度、挤压、超期销售导致的问题，由采购方负责。
- 若双方都有责任，按过错比例分担。
- 最好写明：因品相问题引发的客诉、罚款、下架损失，按责任归属承担。

**5. 约定留证和抽检规则**
- 到货现场拍照、拍视频，保留外包装、批次号、车牌、温度记录。
- 抽检要有代表性，比如按箱数或件数随机抽检，写明抽检比例和判定规则。
- 双方可共同封存样品，必要时送第三方检测。
- 检测费用先由提出方垫付，最终由责任方承担。

**6. 约定结算和赔付**
- 明确扣款计算方式：按不合格数量×单价，或按整批比例折价。
- 明确补货、换货、退货的时限。
- 明确运费、装卸费、冷链费、销毁费由谁承担。
- 可约定质量保证金，出现问题时直接从保证金中扣除。

**7. 建议写进合同或订单的条款示例**
> 乙方应在到货后24小时内完成验收并书面反馈品相问题，逾期视为验收合格。经双方确认存在腐烂、机械伤、规格不符等问题的，按不合格数量占抽检数量的比例折价结算；腐烂率超过5%的，甲方有权拒收该批次，乙方应在3日内补发合格货物，并承担往返运费及装卸费。因乙方包装、运输或冷链原因导致的品相问题，由乙方承担全部责任；因甲方存放或销售超期导致的问题，由甲方自行承担。

**8. 实操建议**
- 生鲜水果最好“一车一验、一批一单”，不要月底统算。
- 问题反馈要快，生鲜拖久了很难分清责任。
- 能用照片、视频、温度记录解决的，尽量不要只靠口头。
- 对新供应商先小批量试单，再约定稳定售后条款。
- 如果是在超市门店端发现，门店应第一时间下架、隔离、拍照，并通知采购和供应商。

简单说，售后流程要围绕一句话约定：**到货多久内验、按什么标准验、怎么反馈、怎么赔、谁负责、留什么证。** 这几项写清楚，后面扯皮会少很多。
