香蕉损耗主要来自“到货时已经过熟”和“到货后集中后熟”。采购时要把熟度、到货时间、运输温度和后熟状态写清楚，按以下方式要求供应商：

**1. 熟度要求：按销售速度定，不按颜色口头说**
- 如果门店2～3天内能卖完：要求到货熟度 **3～4级**，即果身基本饱满、棱角还明显、整体偏绿或微黄，只有少量转黄。
- 如果门店1～2天内能卖完：可接受 **4～5级**，即黄绿相间、开始转黄但果肉还硬。
- 如果当天就要大量促销：才要求 **5～6级**，即大面积黄色、少量青边。
- 不要只说“要熟一点/生一点”，要写成：**到货时青果比例不低于X%，黄熟果不超过X%，无黑斑、无软塌、无裂果。**
- 要求供应商提供 **采收成熟度**，通常香蕉采收成熟度在7～8成饱满即可，不要采太饱满；采得太晚，后熟快、货架期短。

**2. 到货时间：要求“冷链到店、避开高温时段”**
- 最好要求 **清晨或上午到货**，避开中午高温和下午晚高峰。到店后能尽快入冷库或阴凉库。
- 从产地/催熟库到门店的时间要明确：**运输时间越短越好，最好控制在24～48小时内**。
- 如果是已经催熟过的香蕉，要求 **催熟完成后尽快发运，运输温度13～15℃**，不要低于12℃以免冻伤，也不要高于18℃以免继续快速后熟。
- 到货时果心温度最好在 **13～15℃**。如果夏天到货果温超过20℃，损耗会明显增加。

**3. 采购合同/订单里要写清的条件**
- 品种、等级、每箱净重、每把/每根大致规格。
- 到货熟度：颜色、硬度、青黄比例、有无催熟。
- 采收成熟度：约7～8成饱满。
- 运输温度：13～15℃，全程冷链或控温运输。
- 到货时间：具体日期和时段，例如“每周二、五上午9点前到店”。
- 验收标准：黑斑、软果、裂果、冻伤、机械伤比例超过约定即拒收或扣重。
- 后熟管理：供应商是否提供催熟服务；若已催熟，要标注催熟日期和预期货架期。

**4. 到店后的简单判断**
- 手指轻按果身：能轻微下陷但迅速回弹，适合1～2天内卖。
- 果身硬、棱角明显：适合放2～4天，可继续后熟。
- 果身软、棱角消失、有酒味：已经过熟，应尽快处理。
- 表皮有黑斑但果肉还硬：通常是后熟或运输损伤，货架期短。

**5. 最实用的采购说法**
可以直接这样要求供应商：
“我们要到货熟度3～4级，青黄比例约7:3，果身硬、无黑斑无软果；采收成熟度7～8成；催熟后尽快发运，运输温度13～15℃；每周二、五上午9点前到店。到货软果、黑斑、冻伤超过5%就拒收或扣重。”

如果门店销量不稳定，建议 **少量多次采购**，每次到货熟度偏生一点，店里再自然后熟或分区催熟，比一次进大量熟香蕉更安全。
