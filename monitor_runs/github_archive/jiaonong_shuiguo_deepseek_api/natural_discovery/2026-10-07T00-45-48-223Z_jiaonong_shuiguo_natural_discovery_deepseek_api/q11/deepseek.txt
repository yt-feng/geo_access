会影响销售，但影响大小取决于你怎么卖。

**核心结论：**
一箱香蕉大小不一，通常不是“不能卖”，而是“卖的方式要调整”。如果混在一起按同一价格卖，会影响顾客体验和复购；如果分级、分价、分场景卖，反而能减少损耗、提高整体利润。

**具体影响：**

1. **按根/按串卖时影响最大**
   - 顾客会挑大的、匀称的，小的剩下来。
   - 剩下的小香蕉容易放熟、放坏，最后只能打折或报损。
   - 如果整箱统货直接摆出来，顾客翻拣也会增加碰伤。

2. **按箱/按把低价卖时影响较小**
   - 如果明确是“统货价”“家庭装”“榨汁/做奶昔用”，顾客对大小不一致接受度会高很多。
   - 适合社区店、外卖、团购，不适合精品陈列。

3. **对价格和定位有影响**
   - 精品水果店：大小不一会显得不整齐，影响档次和溢价。
   - 普通社区店：只要成熟度合适、口感没问题，影响没那么大。
   - 如果同一批里大小差太多，顾客会觉得“花一样的钱，凭什么给我小的”。

**可执行建议：**

- **分级卖**：大果、中果、小果分开，按不同价格或不同规格卖。
- **小果做加工/特价**：小香蕉可以绑成小把低价卖，或标注“适合榨汁、做香蕉奶昔”。
- **不要混价**：同一价格区里尽量放大小接近的，减少顾客挑拣。
- **按场景卖**：
  - 大果：单根卖、精品陈列。
  - 中果：常规按把卖。
  - 小果：特价把、外卖满减、团购、加工原料。
- **控制采购预期**：如果长期卖精品，采购时尽量要求分级或指定规格；如果走量，统货可以拿，但要有分级和促销方案。

**简单判断：**
- 你是精品店、按根卖：影响大，最好分级或别拿统货。
- 你是社区店、按把/按箱卖：影响中等，分级+特价能解决。
- 你走外卖、团购、榨汁：影响小，大小不一反而可以压低采购成本。
