酒店采购水果盘原料时，建议对供应商明确以下规格和外观标准，并写进采购合同或验收标准中。

**一、基本规格标准**
1. **品种与等级**
   - 明确具体品种，如红富士苹果、皇冠梨、巨峰葡萄等，不接受替代品种。
   - 明确等级，如一级果、特级果，或按果径/单果重分级。
2. **单果重量/果径**
   - 苹果、橙、梨等：规定单果重区间，如苹果180–220g，或果径75–80mm。
   - 西瓜、哈密瓜等：规定单果重量范围。
   - 葡萄、草莓、蓝莓等：规定每串/每盒重量或果粒大小。
3. **成熟度**
   - 要求成熟度适中，适合当天切配、摆盘，不能过生或过熟。
   - 香蕉、芒果、牛油果等后熟型水果，应约定到货成熟度。
4. **新鲜度**
   - 要求采摘后运输时间、到货日期明确。
   - 叶菜类、浆果类应冷链运输。

**二、外观标准**
1. **形状**
   - 果形端正、匀称，无明显畸形、偏斜、凹凸。
2. **色泽**
   - 具有该品种成熟时应有的色泽，颜色均匀。
   - 不允许明显青红不均、褪色、暗沉。
3. **表面**
   - 果面洁净，无泥土、药斑、虫粪、霉斑、污渍。
   - 无裂口、破损、压伤、冻伤、烫伤。
4. **瑕疵控制**
   - 允许轻微自然瑕疵，但不能影响切配和摆盘。
   - 腐烂、霉变、虫蛀、异味为零容忍。
5. **大小一致性**
   - 同一批次水果大小、颜色、成熟度应基本一致，便于摆盘统一。

**三、安全与合规标准**
1. **农残与重金属**
   - 符合国家食品安全标准，如GB 2763等。
   - 供应商应提供检测报告或承诺符合标准。
2. **新鲜无污染**
   - 无非法保鲜剂、染色剂、打蜡超标等问题。
   - 需要时提供可食用蜡证明。
3. **包装与运输**
   - 包装清洁、无破损、无污染。
   - 冷链水果全程冷链，到货温度符合要求。
4. **证照与追溯**
   - 供应商具备营业执照、食品经营许可证等。
   - 可提供批次、产地、采摘日期等追溯信息。

**四、验收建议**
- 到货后按批次抽检，记录品种、数量、重量、外观、成熟度、温度。
- 不合格处理方式写清楚：拒收、换货、扣款或退货。
- 对易损水果，如草莓、蓝莓、葡萄，规定破损率上限，如不超过3%–5%。

**五、合同里建议写明的关键条款**
- 品种、等级、单果重/果径、成熟度、产地。
- 外观要求：无腐烂、无霉变、无虫害、无明显压伤。
- 安全要求：符合国家农残和食品标准。
- 包装、冷链、到货时间。
- 抽检比例、不合格判定、退换货和赔偿方式。

简单说，酒店水果盘原料的核心标准是：**品种对、大小匀、颜色正、成熟适中、新鲜无损、安全合规、冷链到位**。供应商不仅要保证“能吃”，还要保证“好看、好切、摆盘统一”。
