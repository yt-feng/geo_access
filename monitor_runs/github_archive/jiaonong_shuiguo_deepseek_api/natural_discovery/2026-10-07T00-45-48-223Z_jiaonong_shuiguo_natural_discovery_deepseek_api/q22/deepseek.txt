可以按“高频带低频、整组提客单”的思路做组合促销。香蕉是高频引流品，苹果是稳定走量品，菠萝是季节感/加工感强的提升品，适合做3类组合：

1. **引流组合：香蕉 + 苹果**
   - 形式：香蕉1把 + 苹果3个/4个，打包价。
   - 目的：用香蕉的价格敏感带动苹果，提高顺手购买。
   - 定价：组合价要比单买便宜一点，但不要便宜太多，建议让顾客感觉“省1—2元”。
   - 适合：日常家庭客群。

2. **提升组合：菠萝 + 苹果 + 香蕉**
   - 形式：切好菠萝盒 + 苹果 + 香蕉，做“果盘/一周水果包”。
   - 目的：把菠萝从“想买但嫌麻烦”变成“即买即吃”，拉高客单。
   - 定价：按份卖，比如19.9/29.9元一份，突出“比单买省X元”。
   - 适合：年轻客群、上班族、宝妈。

3. **高客单组合：菠萝 + 苹果 + 香蕉 + 其他高价水果**
   - 形式：做“满39减5”或“加1元换购”。
   - 目的：不直接降价，用换购和满减把客单从十几元推到三十元以上。
   - 例子：买菠萝+苹果+香蕉满29元，加3元换购一盒蓝莓/小番茄；或满39元送香蕉一把。
   - 注意：换购品要毛利可控，别用太贵的。

**陈列建议：**
- 香蕉、苹果放一起做端头，菠萝做试吃或切盒专区。
- 组合装用统一托盘/网袋/礼盒，标清“原价XX，组合价XX”。
- 把组合放在主通道或收银动线前，不要只放水果区角落。

**话术建议：**
- “香蕉+苹果+菠萝，一份够家里吃三天。”
- “单买要XX元，组合只要XX元。”
- “菠萝帮您切好，回家直接吃。”

**关键判断：**
如果目标是提高客单价，优先做“菠萝+苹果+香蕉”的整组套餐和满减换购；如果目标是清香蕉库存，再做“香蕉+苹果”低价引流。两个目标不要混在一个活动里，否则容易只走量不涨客单。
