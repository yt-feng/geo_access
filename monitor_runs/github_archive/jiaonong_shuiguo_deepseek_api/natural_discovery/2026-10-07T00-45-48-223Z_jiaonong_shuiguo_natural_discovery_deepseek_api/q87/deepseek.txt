社区团购旺季爆单时，水果供应商的库存和物流都会被抢，**临时下单基本拿不到货，或者价格被抬高**。要把库存锁住，核心是做到四件事：**提前锁量、付定金、签协议、建备选**。具体可按下面操作：

**1. 提前 2–4 周下“预估量 + 阶梯量”**
不要只给一个模糊数字。给供应商一个可执行的区间，例如：
- 保底量：XX 箱（必须供）
- 预估量：XX 箱（优先供）
- 爆单追加量：XX 箱（按日确认）
这样供应商敢给你备货，你也不会一次性压太多库存。

**2. 用定金/预付款锁货**
口头承诺在旺季没有约束力。付 10%–30% 定金，约定：
- 锁定的品类、规格、单价
- 最晚到货时间
- 违约赔偿方式
- 若市场价格下跌，是否按锁定价结算
定金的作用是让供应商优先排产、优先发货。

**3. 签短期供货协议，写清关键条款**
重点写：
- 锁量：保底多少、上限多少
- 锁价：旺季是否涨价、涨多少
- 锁时：哪天到仓、分几批到
- 品质标准：糖度、个头、损耗率、坏果赔付
- 违约：缺货怎么赔、晚到怎么赔
- 结算：现结还是账期，避免旺季拖款导致断供

**4. 分批次到货，降低压货风险**
水果损耗高，不要一次性全到。可以约定：
- 第 1 批：开团前 1–2 天到
- 第 2 批：爆单后 24 小时内补
- 第 3 批：根据实时销量追加
这样既锁了库存，又不会因为卖不动而烂在仓库。

**5. 同时锁定 2–3 家供应商**
主供应商给 60%–70% 量，备选供应商给 30%–40%。主供缺货时，备选能立刻补位。备选也要提前付小额定金或签意向协议，否则旺季一样抢不到。

**6. 用“包园/包车”方式锁源头**
如果单量够大，可以直接和产地果园或一级批发商谈：
- 包园：整片果园按约定标准包下
- 包车：整車发运，锁定物流和价格
这种方式适合爆款单品，能拿到更低价格和更稳供应。

**7. 提前确认物流和仓储**
旺季不仅缺货，还缺车、缺冷库。要提前确认：
- 供应商发什么物流、几天到
- 你这边有没有冷库/保鲜条件
- 爆单时谁负责装卸、分拣
物流没锁住，货到了也可能压在路上。

**8. 建立每日对账和预警机制**
旺季每天跟供应商对一次：
- 已发多少、在途多少、库存多少
- 明日可发多少
- 哪些品项可能断
一旦发现缺口，立刻启动备选供应商。

**一句话总结：**
旺季锁库存 = **提前给量 + 付定金 + 签协议 + 分批到货 + 多家备选**。只靠“关系好”或临时打电话，基本锁不住。
