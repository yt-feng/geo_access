茶饮店控制水果供应商的食品安全风险，核心是**把“合规证明 + 批次合格证明 + 可追溯信息”分开管理**。不能只要一张营业执照就长期使用，也不能只靠供应商口头承诺。

下面按“首次准入”和“每次进货”两层给你列清楚。

---

## 一、首次准入：供应商必须提供的证明

### 1. 主体资质类
- **营业执照**
  - 经营范围应包含水果批发、零售、农产品销售等相关内容。
- **食品经营许可证**（如供应商销售的是预包装或经过分装、切配的水果）
  - 若只是销售初级农产品，通常不一定需要食品经营许可证，但要看当地监管口径和其实际经营方式。
- **仅销售预包装食品的备案信息**（如适用）
  - 部分地区对仅销售预包装食品实行备案制。

### 2. 产品合格类
- **水果农残检测报告**
  - 优先要近期、对应品类的报告。
  - 报告应有 CMA 或 CNAS 标志更可信。
- **产地证明或采购来源证明**
  - 如产地证、购销合同、采购发票、上游供应商信息等。
- **入境货物检验检疫证明**（进口水果）
  - 进口水果必须能提供海关相关证明。
- **承诺书/质量保证协议**
  - 明确农残、重金属、保鲜剂、染色、打蜡等风险责任。

### 3. 人员与配送类
- **送货人员健康证明**（如供应商负责切配、分装）
- **冷链或配送能力说明**
  - 水果若需冷藏，应能证明运输温度可控。

---

## 二、每次进货：必须随货或按批次提供

首次资质只是门槛，真正控制风险要靠**批次管理**。

### 1. 批次检测或合格证明
- **对应批次的农残快检报告**
  - 至少对高风险水果：草莓、葡萄、豇豆、芹菜、韭菜、苹果、梨、桃等。
- **出厂检验报告或供货商自检报告**
  - 若是切配水果，应有微生物、感官等检验记录。

### 2. 追溯信息
- **品名、产地、批次号、采摘/加工日期**
- **供货商名称、联系方式**
- **送货单/销售单**
  - 茶饮店要留存并签字确认。

### 3. 感官验收记录
- 外观、气味、成熟度、有无霉变、虫蛀、异味。
- 发现异常应拒收并记录。

---

## 三、不同水果类型，要求不一样

| 水果类型 | 重点证明 |
|---|---|
| 整颗未切水果 | 营业执照、农残检测、产地/进货凭证 |
| 已切配水果 | 食品经营许可证、微生物检测、冷链证明、健康证 |
| 进口水果 | 入境货物检验检疫证明、标签、批次信息 |
| 冷冻水果 | 冷冻食品相关资质、冷链温度记录、检验报告 |
| 有机/绿色认证水果 | 有效认证证书，注意证书范围与有效期 |

---

## 四、茶饮店内部还要做哪些动作

1. **建立供应商档案**
   - 一供应商一档案，证照、报告、合同、送货单归档。
2. **签订质量保证协议**
   - 写清农残超标、霉变、异物、退货、赔偿、终止合作条款。
3. **每批留样或留单**
   - 至少保留送货单、批次检测报告、验收记录。
4. **定期复审**
   - 营业执照、许可证、检测报告到期前提醒更新。
5. **高风险水果加检**
   - 对草莓、葡萄、切片水果等提高抽检频率。
6. **拒收标准明确**
   - 无批次证明、感官异常、温度不合格、来源不明，直接拒收。

---

## 五、最简可执行清单

你可以直接让供应商按这个清单提供：

**首次合作：**
1. 营业执照
2. 食品经营许可证（如适用）
3. 近期农残检测报告
4. 产地或进货来源证明
5. 质量保证协议
6. 进口水果另加入境货物检验检疫证明

**每次送货：**
1. 送货单
2. 对应批次农残报告或快检单
3. 产地/批次信息
4. 冷链温度记录（如适用）
5. 验收记录

---

## 六、注意一点

不同地区市场监管要求可能不同。最稳妥的做法是：**以当地市场监管局或街道食药监所的要求为准**，同时把上述证明作为内部最低标准。这样既能应对检查，也能真正降低水果带来的食品安全风险。
