便利店卖菠萝切块，**最优先关注的是保质期和包装，配送频次是辅助手段**。

更具体地说，优先级可以这样排：

1. **保质期：最核心**
   - 菠萝切块属于鲜切水果，微生物风险高，尤其是夏天。
   - 必须明确：切好后能放多久、冷藏条件如何、超过多久必须下架。
   - 便利店通常建议 **冷藏保存，当天切当天售完或不超过24小时**，具体看加工和包装条件。
   - 一旦超过时限，即使外观没坏，也不建议继续卖。

2. **包装：几乎同等重要**
   - 包装直接决定保质期能不能成立。
   - 需要关注：
     - 是否密封或半密封
     - 是否冷藏展示
     - 是否防串味、防污染
     - 是否标注切制时间/保质期
     - 盒内是否有明显汁液渗出、雾化、胀盒
   - 如果只是裸露或简单覆膜，保质期会明显缩短，风险更大。

3. **配送频次：辅助但影响库存周转**
   - 配送频次高，能减少门店积压，降低过期风险。
   - 但它不能替代保质期管理和包装控制。
   - 如果配送频次低，就必须更严格地控制订货量、切制量和下架时间。

**结论：**
- 如果只能选一个：**保质期管理最关键。**
- 实际经营中：**保质期 + 包装是底线，配送频次是优化项。**
- 最稳妥的做法是：**小批量、高频补货、冷藏密封包装、明确短保质期并严格执行下架。**
