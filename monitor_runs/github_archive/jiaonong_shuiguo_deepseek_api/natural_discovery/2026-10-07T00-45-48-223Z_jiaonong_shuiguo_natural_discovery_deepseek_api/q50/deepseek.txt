如果只能二选一，**优先看出汁率；但实际采购时应该按产品定位分主次，不能只看一个指标。**

更可执行的判断如下：

1. **做纯果汁、果茶基底、菠萝果肉饮品**
   - **出汁率更重要**。
   - 因为出汁率低，意味着同样杯量要放更多菠萝，原料成本、处理时间、废料都会上升。
   - 对茶饮店来说，出汁率直接影响单杯成本和出杯效率。

2. **做菠萝风味茶、加料、装饰、果肉口感型产品**
   - **甜度和香气更重要**。
   - 如果菠萝本身甜度低、酸涩重，后期要靠糖浆补，产品会显得“糖水味重”，风味不自然。
   - 这类产品里，出汁率不是第一指标，稳定风味更关键。

3. **最稳妥的采购标准**
   - 先定产品：是榨汁型、果肉型，还是风味型。
   - 再看两个硬指标：
     - **出汁率**：决定成本和处理效率。
     - **糖度/酸甜比**：决定是否需要大量加糖，以及风味是否稳定。
   - 同时看：
     - 成熟度是否一致
     - 纤维粗细
     - 是否容易氧化变味
     - 季节性供应是否稳定

4. **简单结论**
   - **成本敏感、用量大、榨汁为主：出汁率优先。**
   - **主打风味、果肉口感、品质稳定：甜度和酸甜比优先。**
   - **如果两者都一般，不建议长期用；茶饮店最怕的是批次不稳定。**
