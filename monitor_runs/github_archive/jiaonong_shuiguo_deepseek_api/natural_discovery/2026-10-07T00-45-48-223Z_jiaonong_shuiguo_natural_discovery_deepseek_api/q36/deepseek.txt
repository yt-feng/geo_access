建议按“门店类型 + 客群 + 损耗能力”来定，不要一刀切。多数商超更优的是：**整果做引流和毛利，切好的做便利和增量，但切果必须严控损耗和食品安全。**

**1. 先看哪种更适合你的门店**

- **社区店/中老年客群多**：优先整果。顾客价格敏感，习惯自己削，整果损耗低、操作简单。
- **商圈店/年轻客群/写字楼店**：切好更有优势。即买即吃、办公室分享、下班顺手买，溢价接受度更高。
- **高端超市/精品超市**：切果、小盒装、拼盘更适合，但必须做冷藏陈列和当日清货。
- **低人力、低冷链门店**：少做或不做切果，否则损耗和食安风险会吃掉利润。

**2. 整果和切果的核心差别**

| 维度 | 整果 | 切好的 |
|---|---|---|
| 毛利 | 较低但稳定 | 通常更高，有加工溢价 |
| 损耗 | 低，可存放 | 高，切后必须冷藏、当天卖完 |
| 人力 | 低 | 需要削皮、切块、包装、清洁 |
| 食品安全 | 风险低 | 风险高，需冷链和时限管理 |
| 客群 | 家庭、价格敏感 | 单身、年轻人、办公族 |
| 引流 | 强，适合促销 | 弱，更适合增量 |

**3. 更推荐的组合做法**

- **整果做基本盘**：保证有货、价格有竞争力，用来吸引客流。
- **切果做利润补充**：只做小盒装，规格别太大，减少卖不完。
- **分时段出切果**：上午少出，下午和晚间高峰前补，避免一早切一堆到晚上报废。
- **按天气和客流调整**：高温天、节假日、商圈店可多切；雨天、社区店、工作日白天少切。
- **设清货机制**：临近保质期打折、做拼盘或员工餐，不要硬留到第二天。

**4. 判断标准很简单**

如果门店满足以下条件，适合做切果：
- 有冷藏陈列柜；
- 能保证当天切当天清；
- 周边有年轻客群或办公人群；
- 人工能安排出固定加工时间；
- 损耗率能控制在可接受范围。

如果不满足，尤其冷链和人力不足，**优先卖整果**更稳。

**5. 采购上的建议**

- 整果采购：选耐储、外观好的品种，适合堆头和促销。
- 切果采购：选成熟度合适、出肉率高、纤维少的品种，别用快坏的果去切，否则口感差、投诉多。
- 切果原料可以用“外观稍差但内部完好”的果，但必须严格挑拣，不能有异味、发软、霉变。

**结论：**
大多数商超最稳的策略是：**整果为主，切果为辅；社区店偏整果，商圈店和年轻客群店加大切果比例。** 切果不是不能做，而是要用冷链、时限和清货机制来换利润。
