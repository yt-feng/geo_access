第一次合作，小批量试单的核心目标不是“赚多少”，而是用最低成本验证**品质稳定性、供货能力、结算可信度**。建议按下面这套框架设计。

## 一、先定试单目标

试单至少要验证四件事：

1. **品质是否稳定**：不是只看样品，要看大货和样品是否一致。
2. **规格是否达标**：果径、糖度、成熟度、净重、包装是否按约定。
3. **供货是否靠谱**：能否按约定时间、数量、频次发货。
4. **结算是否可信**：账期、扣损、售后、发票是否按约定执行。

如果这四点没验证，试单量再大也只是赌。

## 二、试单量怎么定

建议按“**最小可验证量**”来定，不要按“最小起订量”来定。

可参考：

- **单品类试单**：先做 1–2 个单品，不要一次铺 5–10 个品。
- **单批量**：以 1–3 天能卖完或能周转完的量为宜。
- **总金额**：控制在你能承受“全损也不影响现金流”的范围内。
- **分层试单**：  
  - 第一单：极小量，验证基础品质和履约。  
  - 第二单：小幅加量，验证稳定性。  
  - 第三单：再放量，验证持续供货能力。

重点是：**第一单不要超过你正常单次采购量的 20%–30%**。

## 三、试单必须写进合同的条款

口头承诺没用，试单也要有书面确认，至少包括：

- 品种、等级、规格、果径、糖度、成熟度
- 净重、箱规、包装方式、标签要求
- 单价、是否含税、是否含运费
- 发货时间、到货时间、运输方式
- 验收标准、抽检比例、扣损规则
- 售后标准：烂果率、次果率、短重、错发怎么赔
- 结算方式：现结、押批、账期、保证金
- 违约和退出机制

特别是**扣损和售后**，一定要在试单前谈清楚。水果最容易扯皮的就是这部分。

## 四、验收怎么设计

试单到货后不要只看一箱，要按批次抽检：

1. **数量验收**：抽 10%–20% 的箱，称净重，看是否短重。
2. **品质验收**：抽检烂果、次果、大小、成熟度、糖度。
3. **一致性验收**：对比样品和大货是否一致。
4. **包装验收**：看是否适合你的运输、分拣和销售。
5. **拍照留证**：每批到货拍照、视频、记录时间。

建议做一个简单验收表：

| 项目 | 标准 | 抽检结果 | 是否合格 |
|---|---|---|---|
| 净重 | 约定±2% |  |  |
| 烂果率 | ≤3% |  |  |
| 次果率 | ≤5% |  |  |
| 果径 | 约定范围 |  |  |
| 糖度 | 约定值 |  |  |
| 到货时间 | 约定时间 |  |  |

标准按你实际品类调整，但一定要有数字。

## 五、付款和结算怎么控风险

第一次合作，建议：

- **首单现结或货到验收后付**，不要一上来就给长账期。
- 如果对方要求预付，**预付比例尽量低**，比如 30% 以内。
- 不要一次性把多批货款压在同一家新供应商。
- 保留质保金或尾款，验收合格后再付。
- 所有付款走对公，保留合同、聊天记录、物流单、验收单。

如果对方连小批量试单都不愿意接受严格验收和售后条款，说明后续风险更大。

## 六、试单后的判断标准

试单结束后，按下面标准决定是否继续：

**可以继续合作：**
- 品质与样品一致
- 烂果率、次果率在约定范围内
- 到货时间误差小
- 售后响应快，扣损爽快
- 结算按约定执行

**谨慎观察：**
- 品质有波动但可接受
- 售后愿意处理但流程慢
- 供货量勉强达标

**直接停止：**
- 大货与样品严重不符
- 烂果率、次果率明显超标
- 短重严重
- 到货时间频繁拖延
- 售后推诿、扣损不认
- 结算临时改条件

## 七、一个可直接用的试单方案模板

**试单目标：** 验证品质、履约、售后、结算  
**试单品类：** 1–2 个单品  
**试单数量：** 正常单次采购量的 20%–30%  
**试单批次：** 先 1 批，合格后再补 1 批  
**验收方式：** 到货抽检 10%–20%，拍照留证  
**付款方式：** 首单现结或验收后付，预付不超过 30%  
**售后标准：** 烂果率≤3%，次果率≤5%，短重按实扣款  
**决定节点：** 第一批合格后再放量，连续 2–3 批稳定才转常规合作

## 八、最关键的一句话

第一次合作，**试单不是压价，而是验人、验货、验流程**。  
量小、条款清、验收严、付款稳，才是批发商最安全的试单方式。
