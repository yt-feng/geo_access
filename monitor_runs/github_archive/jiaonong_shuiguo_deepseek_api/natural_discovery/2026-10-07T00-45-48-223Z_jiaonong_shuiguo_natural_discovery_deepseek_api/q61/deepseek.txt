判断香蕉批发对方能不能稳定供货，核心不是听他怎么说，而是看他在“产地—加工—物流—资金”四个环节有没有真实控制力。

给你一套可落地的判断方法：

**1. 先问产地结构，不听“我有基地”这种空话**
- 问清楚：货来自哪几个产区？是自有基地、长期合作农户，还是临时在市场调货？
- 稳定供货的人通常有**2—3个产区轮换**，比如云南、广西、老挝、缅甸、菲律宾等按季节切换。只靠单一产区的，遇到台风、寒害、封关就断。
- 让他说清楚当前这个季节主发哪里，下个月换哪里。答不上来的，多半是二道贩子。

**2. 看加工环节，这是最容易露馅的地方**
- 香蕉不是砍下来就能发，需要**催熟、分级、打包**。问他有没有自己的催熟库、加工棚、冷库。
- 稳定供货商一般有固定加工点，能控制成熟度和规格。没有加工能力的，货损和断供概率都高。
- 可以要求看加工现场视频，最好实地去看一次。

**3. 用“小单+连续单”测试，而不是一次大单**
- 第一次别压大货，先走**2—3车小批量**，间隔几天连续要。
- 观察：能不能按约定时间到货、规格是否一致、坏果率多少、缺货时怎么处理。
- 真正稳定的供货商，连续几车品质波动小；调货型的，第一批好，后面就乱。

**4. 查物流和资金链**
- 问发货方式：是产地直发、口岸中转，还是市场倒货？有没有固定车队或合作物流？
- 稳定供货商通常能说清**装车时间、在途时间、到货时间**，并且敢约定延误处理。
- 资金上，愿意给你一定账期或定金比例的，说明他有上游议价能力；要求全款且催得很急的，要警惕。

**5. 关键验证动作**
- 要**最近三个月的发货记录**：车牌、装货视频、过磅单、到货反馈。
- 问**上游是谁**：是农户、合作社还是产地代办？能不能直接对接？
- 打听**同行口碑**：问同市场其他档口有没有从他那里拿过货，断不断供。
- 看**淡季表现**：香蕉淡季或产地受灾时，他还能不能供。这时候最见真章。

**简单判断标准：**
- 能说清产区轮换、有加工能力、敢接连续小单、物流时间明确、淡季不断供——基本可长期合作。
- 只会说“价格便宜、要多少有多少”，但说不清产地和加工——大概率是临时调货，不稳定。
