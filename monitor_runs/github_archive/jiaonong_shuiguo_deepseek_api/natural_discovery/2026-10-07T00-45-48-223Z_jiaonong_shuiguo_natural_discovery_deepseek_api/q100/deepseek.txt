核心思路是把“采购量、到货成熟度、保存条件、消耗顺序”四件事管住，而不是只靠到货后抢救。

**1. 采购时控制成熟度，不要买“已经快熟透”的香蕉**
- 优先采购色度偏青、带一点黄的香蕉，例如 2–3 号色，而不是通体金黄带斑点的。
- 如果食堂 1–2 天内就要大量供应，可以要稍熟一些；如果 3–5 天逐步供应，就要偏青。
- 和供应商约定到货成熟度标准，比如“果身硬、无大面积黑斑、果柄青绿”，不合格可退换或折价。

**2. 到货后按成熟度分批管理**
- 到货当天立刻分拣：青的、微黄的、熟黄的、带斑点的分开。
- 青香蕉常温催熟或暂存；微黄香蕉放阴凉通风处；熟黄香蕉尽快冷藏或优先使用。
- 不要把所有香蕉堆在一起，成熟香蕉释放乙烯会加速旁边香蕉变熟。

**3. 保存方式要针对香蕉特点**
- 未熟或微黄：常温、阴凉、通风，避免暴晒和闷热。
- 已熟但暂时不用：可放冷藏延缓继续变软，但表皮会变黑，不影响内部果肉时可尽快加工使用。
- 不要整串长期密封在塑料袋里，容易闷坏、发霉。
- 切开后的香蕉必须冷藏并尽快使用。

**4. 消耗顺序要“先熟先出”**
- 食堂窗口、配餐、水果发放都按“最熟优先”原则出库。
- 每天标记批次，先到先出、先熟先出，避免新货压在旧货下面。
- 对已经很熟的香蕉，不一定要当鲜果卖，可以转到加工用途。

**5. 把“快熟透”的香蕉转成其他餐食，减少报废**
- 做香蕉奶昔、香蕉牛奶、香蕉燕麦粥。
- 做香蕉面包、香蕉蛋糕、香蕉松饼。
- 切段冷冻后用于后续打汁或烘焙。
- 如果食堂有早餐档，可做香蕉粥、香蕉煎饼等。
- 注意：已经发酸、发霉、有酒味的不要继续食用。

**6. 采购量按实际消耗倒推**
- 统计过去 1–2 周香蕉日均消耗量，再按未来天气、菜单、是否放假调整。
- 夏天、高温天、假期前少采购；有烘焙或奶昔计划时可适当多采购。
- 采用“小批量、多频次”采购，比一次囤很多更能减少过熟浪费。
- 和供应商谈可分批送货，比如每周 2–3 次，而不是一周一次大量到货。

**7. 建立简单可执行的制度**
- 到货验收：查成熟度、数量、有无压伤。
- 每日检查：挑出快熟透的香蕉，贴上“优先使用”标签。
- 出库记录：记录每天用了多少、剩多少、报废多少。
- 每周复盘：如果连续浪费多，就减少采购量或提高青香蕉比例。
- 设定加工触发线：比如“出现少量黑斑且果肉仍正常”就转做奶昔或烘焙，不再等。

**最实用的组合方案：**
偏青采购 + 小批量多频次送货 + 到货分拣 + 阴凉通风存放 + 先熟先出 + 快熟透转加工。这样通常能明显降低香蕉过熟浪费。
