三个都重要，但优先级要分场景。对企业食堂来说，建议按这个顺序判断：

**第一优先：食品安全**
这是底线，出问题就是群体性事件，远超成本和配送延误的影响。
- 必须索证索票：供应商资质、水果农残检测报告、进货凭证
- 关注高风险品类：草莓、葡萄、切开的水果、叶菜类附带品
- 有条件的做农残快检或留样

**第二优先：配送准时**
食堂是刚性供餐场景，水果到不了或迟到，直接影响当天供餐和员工体验。
- 水果保鲜期短，临时补货难
- 早餐/午餐有固定时间点，迟到等于缺供
- 建议约定到货时间窗口和迟到赔付条款

**第三优先：价格**
价格重要，但通常是可谈判、可替代的。
- 水果价格波动大，适合用周期性比价、多家备选来控制
- 不应为了低价牺牲食安或稳定性

**但要注意：优先级不等于只看一个。** 实际采购中三者是约束条件：
- 食安是**准入门槛**（不达标直接淘汰）
- 配送准时是**履约能力**（影响日常运营）
- 价格是**竞争维度**（在合格供应商里比价）

**一句话结论**：先卡食品安全，再保配送准时，最后在合格供应商中比价格。如果预算极紧，可以压缩品类档次，但不要压缩食安和配送要求。
