选水果供应商时，**最应该先问售后，再问配送，最后谈价格**。原因很直接：水果是**高损耗、强时效、非标品**，团长真正赔钱的地方往往不是进价高，而是烂果、缺斤少两和配送延误后的纠纷。

可以按这个优先级判断：

1. **售后优先**
   - 坏果、烂果、压伤怎么赔？按比例赔还是全额赔？
   - 需要拍照/视频举证吗？多久内反馈有效？
   - 缺斤少两怎么处理？补发还是退款？
   - 售后是供应商承担，还是团长自己贴？
   - 这点最关键，因为水果售后频率高，售后差会直接吃掉利润和口碑。

2. **配送第二**
   - 到团点还是到小区？谁卸货？
   - 几点到？迟到导致水果坏了谁负责？
   - 夏天/冬天有没有冷链或保温措施？
   - 临时加单、改量、取消怎么处理？
   - 配送不稳会导致团员体验差，团长还要花时间解释和补偿。

3. **价格第三**
   - 价格当然重要，但要在售后和配送明确后再比。
   - 低价但售后差、配送烂，最后综合成本更高。
   - 比价时要问清楚：是否含运费、是否含损耗、是否含税、起送量多少、账期多久。

一句话建议：  
**先问“坏了谁赔、怎么赔”，再问“能不能按时送到、谁负责”，最后才问“多少钱”。**  
如果供应商在这三件事上都能写清楚、敢承诺，才值得长期合作。
