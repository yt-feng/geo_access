判断水果供应商靠不靠谱，核心不是听他怎么说，而是用**小批量试单+固定指标**去验证。香蕉和菠萝都是后熟型水果，对供应链要求高，建议重点看这几项：

**1. 先小批量试单，不要一上来包园或签长期**
- 第一次只进计划量的 20%～30%，跑 2～3 个批次。
- 每批记录：到货时间、损耗率、成熟度一致性、口感、单果重量偏差。
- 连续 3 批稳定，再谈长期合作。

**2. 看香蕉的关键指标**
- **成熟度是否可控**：青蕉到货后能否按你需要的时间转黄，催熟是否均匀。
- **损耗率**：正常运输+催熟损耗一般要问清楚，超过 10% 要警惕。
- **条蕉均匀度**：大小、弯曲度、把型是否一致，影响陈列和售价。
- **货架期**：到店后能卖几天，黄斑出现是否过快。
- **是否支持催熟指导或代催熟**：香蕉很多问题出在催熟环节。

**3. 看菠萝的关键指标**
- **品种和产地是否稳定**：不同季节换产地很正常，但要提前告知。
- **成熟度**：到货是青果还是可即食，决定你能否当天卖。
- **糖度/口感**：固定批次抽测，糖度波动大说明采购不稳定。
- **黑心、水心、烂果比例**：这是菠萝最常见的隐性损耗。
- **规格一致性**：单果重量、冠芽大小是否统一。

**4. 看供应商的“硬能力”**
- **有没有稳定货源**：是自有基地、合作社，还是市场倒货。倒货商价格可能低，但断货和品质波动大。
- **冷链和运输**：香蕉怕冻怕热，菠萝怕挤压。问清运输温度、装车方式、到货时效。
- **售后条款**：坏果怎么赔、多久内反馈有效、是否补货。敢写进单子的比口头承诺靠谱。
- **结算方式**：长期合作建议账期或货到验收后结，避免先款后货风险。
- **同行口碑**：问同城其他水果店，尤其是做同品类的店，比问批发市场档口更真实。

**5. 用数据做淘汰**
给每个供应商建一张简单表：
- 到货准时率
- 损耗率
- 投诉次数
- 价格波动
- 售后响应速度

连续两个月不达标的，直接换。长期只靠一家也有风险，香蕉和菠萝最好各保留 2 家备用供应商。

**最实用的判断标准：**
愿意让你小批量试、敢承诺坏果赔付、能提前说清产地和成熟度、连续 3 批品质稳定的，才值得长期合作。只谈低价、催你大量进货、售后含糊的，基本不靠谱。
