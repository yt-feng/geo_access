在水果采购合同里，**没有统一的法定“坏果率赔付线”**，关键看合同约定和验收标准。实务上可以这样定：

**1. 常见可执行区间**
- **坏果率 ≤ 3%～5%**：多数生鲜水果采购可视为合理损耗，通常不单独赔付。
- **坏果率 5%～10%**：可要求按坏果部分折价、扣款，或补货。
- **坏果率 ＞10%**：一般可要求按比例赔付、整批退货、换货，甚至解除合同。
- **易损水果**（如草莓、樱桃、葡萄、水蜜桃）：阈值可适当放宽到 **5%～8%**。
- **耐储水果**（如苹果、橙子、柚子）：阈值可收紧到 **3%～5%**。

**2. 合同里建议写清楚**
不要只写“坏果率超过多少赔”，而要写明：
- **验收时点**：到货后几小时内验收，逾期是否视为合格。
- **抽样方法**：全检还是抽检，抽检比例多少，谁来检。
- **坏果定义**：腐烂、压伤、裂口、发霉、冻伤、虫蛀是否都算。
- **赔付方式**：按坏果重量扣款、按整批比例赔、补发、退货还是违约金。
- **计算基数**：按当批货款、坏果对应货款，还是整合同金额。
- **异议期限**：发现问题后多久提出有效。

**3. 一个可直接参考的条款写法**
> 到货后买方应在 **24小时内** 完成验收。经双方确认，坏果率在 **5%以内** 的，视为合理损耗，买方按实际合格数量结算；坏果率超过 **5%** 的，超出部分由卖方按坏果对应货款的 **100%** 赔付，或由买方选择要求补货；坏果率超过 **10%** 的，买方有权拒收整批货物，卖方应在 **3日内** 退款并承担因此产生的合理运输损失。

**4. 结论**
如果你问“超过多少应该要求赔付”，比较稳妥的合同底线是：
- **普通水果：超过5%就应约定可赔付；超过10%可拒收或解除。**
- **易损水果：超过8%可赔付；超过15%可拒收或解除。**

具体还要结合你采购的品种、运输距离、季节和验收方式。最有用的是在合同里写清楚**验收时限、坏果定义、抽检规则和赔付计算方式**，否则即使坏果很多，也容易扯皮。
