要避免香蕉到店后很快变黑，核心是控制**乙烯、温度、机械损伤和湿度**。采购时可以按下面做：

1. **买成熟度偏低的香蕉**
   - 选**颜色偏绿、但已开始转黄**的香蕉，不要买已经全黄、带黑点或果柄发黑的。
   - 甜品店如果 2–3 天内用完，可以选“微黄带绿”；如果当天用，选“黄熟但无黑斑”。

2. **看果柄和棱角**
   - 果柄**青绿、饱满**的通常更新鲜。
   - 香蕉棱角明显、手感硬的更耐放；棱角不明显、手感软糯的已经熟透，到店后很快会黑。

3. **避免有压伤、擦伤、冻伤**
   - 表皮有裂口、压痕、水渍状斑块的不要。
   - 香蕉对碰伤很敏感，受伤处会先变黑并释放乙烯，催熟整串。

4. **采购时按使用量分批**
   - 不要一次全买熟度相同的。
   - 可以一部分买偏生，一部分买偏熟，到店后按使用顺序取用。

5. **运输和到店后立刻处理**
   - 运输时不要堆压，最好用筐或纸箱分层放。
   - 到店后**不要先洗**，水会加速腐烂和变黑。
   - 拆掉塑料袋或密封包装，保持通风。
   - 如果室温高，放**阴凉通风处**；若想延缓成熟，可放**12–14℃**左右环境，但不要低于 10℃，否则会冻伤变黑。
   - 不要和苹果、梨、番茄等释放乙烯多的水果放在一起。

6. **分开挂放或分串存放**
   - 整串挂起来比堆在台面上好。
   - 已经熟了的可以拆开单根放，减少互相催熟。
   - 需要延缓时，可用保鲜膜包住**果柄**，但不要整根密封。

7. **到店后尽快做处理**
   - 如果 1–2 天内用完：阴凉通风，别冷藏。
   - 如果必须冷藏：只适合已经成熟、准备短期保存的香蕉，且用纸包一下，放冷藏室较暖位置，表皮可能变黑但果肉还能用。
   - 做甜品、奶昔、烘焙的香蕉，可以到店后熟度合适就**剥皮分装冷冻**，这样就不会继续变黑。

简单判断：
- **想放 2–3 天**：买微黄带绿、硬挺、无伤、通风挂放。
- **想当天用**：买黄熟无黑斑、果柄不黑、无压伤。
- **已经全黄有黑点**：尽快用掉或剥皮冷冻，不要再等。
