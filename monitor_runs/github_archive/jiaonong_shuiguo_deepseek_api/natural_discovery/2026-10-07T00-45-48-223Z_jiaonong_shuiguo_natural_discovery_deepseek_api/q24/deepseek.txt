超市采购防水果农残抽检风险，提前向供应商要这几类资料最实用：

1. **检测报告（最关键）**
   - 要 **第三方CMA/CNAS资质** 的农残检测报告。
   - 报告要能对应到 **具体品种、批次/采收日期**，不能只给一张“通用合格报告”。
   - 重点看是否覆盖常用农残项目，如有机磷、氨基甲酸酯、拟除虫菊酯等，并符合 **GB 2763** 食品中农药最大残留限量。
   - 报告日期尽量在 **近3-6个月内**，叶菜、草莓、豇豆等高风险品种最好按批次提供。

2. **产地证明/供货证明**
   - 产地证明、基地证明、合作社或供应商的供货凭证。
   - 能追溯：**哪个基地、哪天采收、哪批货、供货给谁**。
   - 如果是批发市场进货，至少要能提供档口名称、交易凭证和批次信息。

3. **承诺书/质量保证协议**
   - 供应商出具农残合格承诺书，明确“如抽检不合格承担退货、赔偿、监管处罚等责任”。
   - 合同中写清：**每批随货提供检测报告或合格证**，超标即拒收并追责。

4. **高风险品种的批批检测或自检记录**
   - 对韭菜、豇豆、芹菜、普通白菜、草莓、葡萄等易超标品种，要求 **批批检测**。
   - 供应商如有自检，要提供自检记录；但自检不能替代第三方报告，最好两者都有。

5. **资质文件**
   - 营业执照、食品经营许可证/食用农产品销售相关资质。
   - 种植基地可提供种植记录、用药记录、采收记录。
   - 若是有机/绿色认证，要核对认证证书和有效期，不能只看包装标识。

6. **随货凭证**
   - 每批货要有 **送货单/销售单**，写明品种、数量、产地、批次、采收或检测日期。
   - 最好做到“**一批一证一报告**”，方便抽检时快速对应。

实操建议：
- 对新供应商先要全套资料，老供应商按品种风险分级管理。
- 高风险水果蔬菜：**批批要报告或合格证**。
- 一般品种：至少定期要第三方报告，并保留进货台账。
- 收货时做快速农残检测，留样备查。
- 一旦抽检不合格，凭合同、承诺书、检测报告和进货台账向供应商追责。

简单说：**要第三方检测报告、产地/批次证明、合格承诺书、资质文件和随货凭证，高风险品种批批检测。** 这样既方便超市自保，也能在抽检出问题时把责任链条说清楚。
