超市采购水果时，供应商通常需要提供以下几类检测报告或进货证明，具体以超市验收标准和当地监管要求为准：

1. **营业执照、食品经营许可证**
   - 证明供应商具备合法经营资质。
   - 若是进口水果，还需提供进出口相关资质或报关资料。

2. **水果产地证明或进货凭证**
   - 产地证明、供货单、购销合同、发货单、发票等，用于证明货源和进销渠道。
   - 批发市场采购的，可提供市场开具的销售凭证或“食用农产品销售凭证”。

3. **农产品质量安全检测报告**
   - 常见为农药残留检测报告，可由供应商自检、第三方检测机构或产地监管部门出具。
   - 超市一般会要求批次对应的检测报告，而不是长期通用的一份报告。

4. **承诺达标合格证**
   - 对食用农产品，很多地区要求供应商提供“承诺达标合格证”，证明其对农药残留等指标作出承诺。
   - 这是目前农产品进货查验中较常见的证明文件。

5. **进口水果相关证明**
   - 海关进口货物报关单。
   - 入境货物检验检疫证明。
   - 若为预包装进口水果，还需中文标签、中文说明书等。

6. **批次追溯信息**
   - 品名、规格、数量、产地、生产日期或采摘日期、供应商名称、联系方式等。
   - 便于出现质量问题时追溯和召回。

7. **其他可能要求的材料**
   - 无公害、绿色、有机等认证证书，若超市采购相应认证产品。
   - 检疫证明，针对部分特定水果或地区可能有植物检疫要求。
   - 运输温度记录，针对冷链水果。

实际操作中，超市一般会执行“索证索票”和“进货查验记录”制度：供应商提供证明，超市留存复印件或电子记录，并登记进货台账。最稳妥的做法是：在采购合同里明确供应商需随货提供营业执照、食品经营许可证、批次检测报告或承诺达标合格证、进货凭证；进口水果另附报关单和入境检验检疫证明。
