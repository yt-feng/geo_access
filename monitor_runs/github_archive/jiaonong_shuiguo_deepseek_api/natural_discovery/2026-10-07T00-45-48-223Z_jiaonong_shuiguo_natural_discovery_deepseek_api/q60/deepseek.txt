核心原则：**在采购合同或订货单里提前约定"验收—扣款—补货"三段式规则，把补货时效和营业保障写死，而不是每次到货后临时扯皮。**

具体可以这样约定：

**1. 验收环节：定标准、定时限**
- 明确验收标准（品种、规格、成熟度、糖度、腐烂率上限，比如"腐烂/压伤果不超过5%"）。
- 明确验收时限：到货后当场或2小时内验完，超时未提异议视为合格——这条既是约束对方，也逼自己门店及时验货。
- 拍照留证，写明不合格数量。

**2. 不合格处理：先扣款，再补货**
- 不合格部分**当次不结算**，或按比例扣款。
- 约定补货时限，这是关键：比如"验收确认后X小时内送达"或"次日首班配送前到店"。
- 明确补货的**运费和损耗由供应商承担**。

**3. 营业保障条款（最容易被忽略，但最重要）**
- **保底替代权**：若供应商未在约定时限内补货，门店有权就近自采同等品质水果，差价由供应商承担。
- **缺货赔付**：因缺货导致某款饮品停售，可按停售时长或杯数约定违约金。
- **阶梯考核**：月度不合格率超过一定比例（如3%），触发降价、换供应商或解约。

**4. 实操建议**
- 把上述写成**一页纸的《供货验收与补货约定》**，附在采购合同后，双方签字。
- 高频水果（如柠檬、芒果、草莓）单独列时效，易损品要求更短补货窗口。
- 保留每次验收记录，作为后续议价或追责依据。

如果对方是长期合作供应商，"自采权+差价补偿"比单纯罚款更能保障你正常营业——因为罚款拿不到货，客人还是走了。
