核心是**按“计划吃的时间”反推成熟度**，而不是只看颜色。

**到店挑选时看这几点：**
- **想当天或1天内吃**：选全黄、带少量褐斑的，闻起来有甜香。
- **想2–3天吃**：选整体黄、两端略青、无明显褐斑。
- **想放4–6天**：选黄绿相间、果柄还偏绿、捏起来硬但不木。
- **想放更久**：选整体偏绿、果柄绿、按下去很硬。回家后和苹果/香蕉放一起可催熟，单独放冰箱冷藏会减慢成熟。

**避免踩坑：**
- 不要选表皮发黑、渗液、捏着软塌的。
- 不要选有霉点、裂口、大面积压伤的。
- 如果超市冷柜里的香蕉，通常成熟会慢一些，但可能表皮发暗，不代表一定坏。
- 散装比整把更容易挑，整把成熟度通常更一致。

**简单判断法：**
- **绿硬**：还要等几天。
- **黄硬**：1–3天吃。
- **黄软、有香**：马上吃。
- **有褐斑但仍成形**：当天吃最甜。
- **软塌+酒味/酸味**：不要买。

如果你今天买、明天吃，优先选“黄中带一点点青、捏着有弹性”的；如果今天就要吃，选“黄带褐斑、闻着香”的。
