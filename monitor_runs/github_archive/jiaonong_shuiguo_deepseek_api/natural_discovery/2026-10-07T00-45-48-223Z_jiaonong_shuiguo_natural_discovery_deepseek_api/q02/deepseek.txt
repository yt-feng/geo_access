对小水果店来说，这四个因素不是并列关系，建议按这个优先级判断：

**1. 熟度最关键**
香蕉是后熟水果，进回来还会继续变黄、变软。如果进得太生，可能几天才能卖；进得太熟，当天卖不掉就开始起黑点。小水果店客流有限，最怕“今天不能卖，明天又太熟”。所以熟度直接决定你能不能按计划卖完。

**2. 坏果率第二**
坏果率高的货，表面便宜也没用。香蕉一旦有挤压伤、水烂、黑斑，会传染、影响卖相，损耗直接吃掉利润。小水果店议价能力弱，更要算“到手能卖的钱”，不是“进货单价”。

**3. 送货速度第三**
香蕉周转快，送货慢会导致：订的熟度到店时已经变了，或者断货。尤其夏天，送货速度影响很大。但速度通常可以通过换供应商、调整订货频率解决，不像熟度和坏果率那样直接决定损耗。

**4. 价格最后看**
价格重要，但不能优先。小水果店利润薄，容易被低价吸引，结果进了一堆熟度不对、坏果多的货，最后损耗比省下的差价还多。正确做法是：**在熟度和坏果率达标的前提下，再比价格和送货速度。**

简单决策顺序：

1. 先定你要什么熟度：比如“到店能放1-2天，第三天必须卖完”。
2. 再验坏果率：开箱抽检，超过5%-10%就要谨慎。
3. 再看送货：能不能按你需要的频率和时段送到。
4. 最后比价：同等质量下选便宜的。

如果只能记一句话：**小水果店进香蕉，先保熟度和坏果率，再谈速度和价格。**
