会，而且通常会增加损耗风险。原因很直接：

1. **香蕉成熟快、周转窗口短**
   - 香蕉是呼吸跃变型水果，后熟速度快。起订量太高，如果不能在最佳销售/使用窗口内消耗掉，就容易集中转黄、起黑斑、腐烂。
   - 香蕉对温度、乙烯、挤压都敏感，库存一多，堆压和催熟管理难度都会上升。

2. **菠萝虽然相对耐放，但也会集中劣变**
   - 菠萝比香蕉耐储，但整果存放时间长也会出现果眼发黑、内部褐变、发霉、失水。
   - 如果起订量高，先用的和最后用的品质差异会明显拉大，尾货损耗概率高。

3. **高起订量会放大“预测偏差”**
   - 采购量一大，实际销量或用量只要低于预期，剩余库存就会变成损耗。
   - 香蕉、菠萝都属于生鲜，不能像干货那样长期压库，偏差很难靠“慢慢卖”消化。

4. **仓储和催熟管理压力上升**
   - 香蕉可能需要催熟或控温，菠萝需要通风、防压、防潮。
   - 量太大时，冷库/货架空间不足，先进先出执行不到位，损耗会更高。

**判断建议：**
- 如果**日均销量稳定、周转快、有冷库和催熟管理能力**，高起订量不一定会显著增加损耗。
- 如果**销量波动大、周转慢、仓储一般、没有稳定下游**，高起订量大概率会增加损耗。
- 重点看三个指标：
  1. **预计售罄天数**：香蕉最好控制在几天内清掉，菠萝也不宜压太久。
  2. **损耗率是否超过毛利承受范围**：高损耗会直接吃掉利润。
  3. **能否拆分批次/拼单/锁价退货**：能分批到货，风险会小很多。

**更稳妥的做法：**
- 不要一次性按最低起订量压满，先小批量试单，测实际周转天数。
- 和供应商谈**分批交货**，而不是一次发完。
- 对香蕉和菠萝分别设定**最大库存天数**和**安全库存**。
- 如果起订量无法降低，优先考虑拼单采购、找能代储的供应商，或把高起订量转成高频次小批量补货。

简单说：**起订量高本身不是问题，问题是它是否超过你的真实周转能力。超过越多，损耗风险越大。**
