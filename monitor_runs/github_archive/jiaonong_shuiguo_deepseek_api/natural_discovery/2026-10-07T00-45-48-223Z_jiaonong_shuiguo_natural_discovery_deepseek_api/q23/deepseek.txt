1. **陈列支持**
   - 免费或低价提供堆头、端架、水果筐、托盘、假底、围挡、价签牌等物料。
   - 派理货员/促销员到店帮忙摆陈、补货、挑次果。
   - 提供陈列图、主推位置建议、分层配色方案。
   - 承担部分陈列费、堆头费、端架费，或按销量返点抵扣。

2. **海报支持**
   - 提供产品图、卖点文案、产地故事、规格、价格素材。
   - 分摊 DM 海报、店内吊旗、地贴、电子屏广告费用。
   - 供应商自己出钱做门店专属海报、爆炸贴、跳跳卡。
   - 联合做“供应商品牌周”“产地直采节”等主题促销。

3. **试吃支持**
   - 提供试吃果、切片、牙签、试吃杯、手套、托盘、垃圾桶。
   - 派试吃员或承担试吃员人工费。
   - 承担试吃损耗，或在进货价里给试吃补贴。
   - 配合做“试吃+扫码领券”“试吃+满减”等转化动作。

**能不能拿到，关键看这几点：**
- 采购量/合作级别：量大、账期好、长期合作，供应商更愿意给。
- 谁主导促销：超市主动做活动，一般可要求供应商配套支持。
- 费用怎么算：纯免费较少，常见是“供应商出物料+超市出位置”“费用分摊”“从货款扣”“达量返”。
- 门店条件：有没有试吃区、冷藏条件、人员、垃圾处理能力。
- 合规要求：试吃要有食品安全管理，不能用过期货、切开后要控时控温。

**你可以直接这样跟供应商谈：**
- “这次水果促销，你们能提供哪些陈列物料？堆头/端架费用能不能分摊？”
- “海报素材你们出，印刷费我们各承担一半，还是你们全包？”
- “试吃果、耗材、试吃员人工，你们支持到哪一步？”
- “如果销量达到 X，费用能不能返？达不到怎么结算？”

**比较现实的组合通常是：**
供应商出试吃果+物料+部分费用，超市出位置+人员+收银转化，双方按销量或毛利分摊。
