小水果店做附近小区团购，水果供应商至少要能支持下面这些服务。你可以把它当成筛选供应商的清单，一项项确认。

**1. 稳定供货与品质分级**
- 能按团购量稳定供货，不是今天有明天没。
- 明确分级标准，比如大果/中果/小果、糖度、产地、规格。
- 能提供次果、坏果的赔付或补货规则。

**2. 团购专属价格与起批量**
- 有团购价、阶梯价，量越大价格越低。
- 明确起批量、混批规则、是否支持小批量试单。
- 价格最好能锁定一段时间，避免今天报价明天涨。

**3. 分拣、打包与贴标**
- 能按小区团购的份数提前分拣、称重、装袋。
- 支持按团购单贴标签，比如“3斤装”“家庭装”。
- 包装要适合配送，不易压坏、漏汁。

**4. 配送与到货时效**
- 能送到店里，或直接送到小区自提点。
- 明确截单时间、到货时间、冷链或常温配送。
- 支持次日达、隔日达，最好能配合你的团购节奏。

**5. 售后与损耗处理**
- 坏果、烂果、少重、错发能快速处理。
- 有明确赔付比例、补发流程、责任划分。
- 支持拍照报损，不用反复扯皮。

**6. 营销与素材支持**
- 提供产品图片、视频、文案、卖点。
- 能配合做团购海报、接龙文案、朋友圈素材。
- 最好有爆品推荐和应季产品排期。

**7. 结算与账期**
- 支持现结、周结、月结或押金合作。
- 对账清晰，有订单明细、发货单、结算单。
- 能开收据或发票，方便你核算利润。

**8. 试销与退换支持**
- 允许先小批量试卖，测试小区接受度。
- 不好卖或品质不稳定的品，能退换或调整。
- 有新品推荐机制，帮你持续换品。

**9. 冷链与保鲜能力**
- 易坏水果如草莓、荔枝、樱桃，要有冷链或冰袋。
- 能控制采摘、预冷、运输时间。
- 夏季高温时能保证到货品质。

**10. 数据与订单对接**
- 能按你的团购订单汇总发货，减少你二次分拣。
- 支持微信、表格、小程序等方式下单。
- 能提供每日库存和到货通知。

**你筛选供应商时，重点问这5个问题：**
1. 团购价多少，起批量多少，能不能锁价？
2. 坏果怎么赔，多久处理？
3. 能不能按份分拣、贴标、送到小区？
4. 截单和到货时间怎么定？
5. 有没有图片文案，能不能先试销？

**建议合作方式：**
先找1-2家供应商小批量试单，重点看品质稳定性和售后速度。跑通一个小区后，再扩到周边小区。不要一上来就压大量库存，水果团购最怕损耗和售后失控。
