香蕉配送途中压坏和变黑，核心是控制三件事：**机械损伤、温度波动、乙烯催熟**。可按下面执行。

## 1. 采摘/入库阶段：先控制成熟度
- 不要用全熟香蕉发远单。  
  远距离配送选**青熟蕉**，到仓或到消费者附近再催熟；同城即时配可选**微黄蕉**。
- 入库时按成熟度分拣，避免青黄混放。  
  成熟香蕉会释放乙烯，把青蕉催熟。
- 有条件的用**乙烯吸收剂**或通风库，降低后熟速度。

## 2. 包装：重点是防压、防摩擦、防闷
- **单根套袋或微孔膜**：减少表皮摩擦，避免直接磕碰。
- **纸浆托盘/蛋托式分隔**：一根一格，避免堆叠挤压。
- **抗压外箱**：选高强瓦楞纸箱，箱体开透气孔。
- **填充缓冲**：珍珠棉、气泡柱、牛皮纸团都可以，但不要完全密封。
- **不要整串裸装平压**：香蕉最怕受压部位发黑，尤其是果柄和弯背处。

## 3. 装箱：减少层数和晃动
- 箱内**层数不超过2-3层**，重物不压香蕉。
- 每层之间加纸板或软垫。
- 装箱后轻摇不明显晃动，避免运输中互相碰撞。
- 箱体标注“向上”“怕压”“勿倒置”。

## 4. 温控：不是越冷越好
- 香蕉对低温敏感，**低于12℃容易冷害，表皮更快变黑**。
- 配送温区建议：
  - 青蕉：**13-15℃**
  - 微黄蕉：**12-14℃**
  - 已熟黄蕉：**12-13℃**，且尽快送达
- 同城即时配可用保温箱+冰袋间接降温，冰袋不要直接贴香蕉。
- 夏季避免暴晒和车厢高温，冬季避免冷风直吹。

## 5. 运输与配送：减少中转和挤压
- 尽量**少中转、少分拣**，优先直发或前置仓发货。
- 运输中固定箱体，避免急刹导致箱内位移。
- 骑手配送时用保温箱竖放或平放固定，不要挂在车把上晃。
- 时效越短越好，同城控制在**2-6小时**，跨城用冷链或控温车。

## 6. 到货后处理：给用户明确指引
- 到货后先检查，轻微青黄可室温通风放置。
- 不要立刻放冰箱，低温会加速表皮变黑。
- 已熟香蕉再冷藏，且用纸袋或保鲜膜包果柄。
- 果柄用保鲜膜包住，可减少乙烯释放和水分流失。

## 7. 售后判断标准
建议提前定义：
- **轻微表皮擦伤、少量黑点**：正常，不赔付。
- **大面积压烂、果肉出水、异味**：按坏果赔付。
- **因冷害导致整根发黑但果肉未坏**：可部分赔付或补券。

## 最简执行方案
1. 远单发青熟蕉，近单发微黄蕉。  
2. 一根一格+纸浆托+抗压纸箱+透气孔。  
3. 箱内不超过3层，填充防晃。  
4. 控温13-15℃，冰袋不直接接触。  
5. 同城6小时内送达，减少中转。  
6. 果柄包膜，提醒用户不要马上冷藏。  

如果只做一件事：**用分隔托盘把每根香蕉固定住，再控制13-15℃配送**，压坏和变黑会明显下降。
