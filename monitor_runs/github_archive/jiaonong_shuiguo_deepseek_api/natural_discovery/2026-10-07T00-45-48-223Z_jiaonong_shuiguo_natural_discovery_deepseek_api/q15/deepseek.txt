水果店遇到坏果，处理的核心原则是：**先分清坏果发生在哪个环节、有没有约定、证据是否完整**，再谈结算或赔付。正常可以按下面几步走。

**1. 先看合同/订单约定**
- 有采购合同、供货单、微信/平台订单的，优先按约定处理。
- 常见约定有：到货验收合格后付款、坏果率超过多少由供应商承担、按实际合格数量结算、包退包换等。
- 如果约定“验收后不认”或“签收即合格”，你事后才发现坏果，追偿会难一些，但仍可看是否属于隐蔽瑕疵。

**2. 到货时立即验收并留证**
- 当场开箱抽检，拍视频：车牌/送货单、整批货、坏果特写、坏果数量、时间地点。
- 让送货员签字确认坏果数量；对方不签，也要在送货单上注明“抽检发现坏果XX箱/斤，待协商”。
- 最好当天发微信/短信给供应商，写明批次、数量、坏果情况，要求换货、补货或扣款。

**3. 按坏果比例结算**
常见做法有三种：
- **扣减结算**：按实际合格果数量结算。比如到货100箱，确认坏10箱，只结90箱的钱。
- **补货换货**：供应商补发同等数量合格果，坏果退回或就地处理。
- **折价赔付**：不补货的，按坏果货值扣款，或再协商一定比例赔偿。
如果坏果率很低，比如1%-3%，有些生鲜行业会按惯例由门店承担损耗；如果明显超过正常损耗，就应由供应商承担。

**4. 注意“正常损耗”和“质量问题”的区别**
- 运输途中轻微压伤、个别腐烂，可能算正常损耗。
- 大批量腐烂、发霉、异味、成熟度不对、以次充好，属于质量问题，供应商应负责。
- 如果是你自己储存不当导致，比如温度、湿度、堆放问题，通常不能找供应商赔。

**5. 供应商不认账时怎么办**
- 先书面催告，给出明确方案：比如“本批坏果32箱，要求补货32箱或扣款XX元，3天内回复”。
- 有平台交易的，走平台售后/仲裁，提交验收视频、聊天记录、送货单。
- 有合同的，可按合同争议条款协商、发律师函或起诉。
- 金额不大时，优先协商扣款或下次补货，诉讼成本可能不划算。

**6. 实操建议**
- 固定供应商也要每批留送货单，别只靠口头。
- 付款尽量留尾款，验收合格后再结清。
- 大额采购前明确写：坏果率标准、验收时限、赔付方式、退货费用谁承担。
- 发现坏果后先隔离，别和好果混放，避免扩大损失，也方便举证。

简单说：**有约定按约定；没约定按实际合格数量结算，坏果由供应商补货、换货或扣款；关键是把到货验收和证据做扎实。**
