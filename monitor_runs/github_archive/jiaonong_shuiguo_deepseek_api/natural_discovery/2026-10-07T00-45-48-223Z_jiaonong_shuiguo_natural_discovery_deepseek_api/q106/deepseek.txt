判断水果报价波动是否合理，关键不是盯“价格有没有变”，而是看它有没有对应的**可核验依据**。可以按下面几层来筛。

**1. 先看波动有没有落到“市场基准区间”里**
- 同一品种、同一等级、同一产地、同一包装规格，才有可比性。拿“一级果”和“统货”比价格，波动再大都没有意义。
- 每天至少对比三个来源：产地批发市场价、周边一级批发市场价、同类供应商报价。若你的报价始终落在市场高低价之间，通常算正常波动。
- 如果某家报价长期明显低于市场，要警惕规格缩水、等级掺混、称重或账期上做手脚。

**2. 看波动幅度和频率是否匹配品类特性**
- 叶菜、浆果、荔枝、杨梅这类易损、短周期水果，日波动 5%～15% 甚至更高都可能正常。
- 苹果、梨、橙子、土豆等耐储品类，日波动通常较小，若一天跳 20% 以上，就需要解释。
- 连续几天单向大涨或大跌，比单日跳动更值得关注。连续上涨要看产地是否减产、天气是否影响采收；连续下跌要看是否集中上市、库存抛售。

**3. 要求供应商给出波动归因，并且能验证**
合理波动通常能对应到具体原因：
- 产地天气：降雨、台风、寒潮、高温影响采收和运输。
- 茬口转换：换季、换产区、早熟果和晚熟果交替。
- 供需变化：节假日备货、餐饮团餐放量、竞品集中上市。
- 物流成本：油价、冷链运力、跨区调运、口岸通关。
- 等级变化：果径、糖度、色泽、伤损率、包装规格变了。

如果供应商只说“今天行情涨了”，但拿不出产地价、批次、等级变化或物流依据，就不能直接认定为合理波动。

**4. 用“同规格历史价 + 到货质检”交叉验证**
- 建自己的价格台账：日期、品种、等级、产地、包装、单价、到货损耗率、验收扣重。
- 把报价和到货实际可用量一起算。比如报价低 10%，但损耗高 15%，实际成本反而更高。
- 对同一批次留样或拍照，记录果径、色泽、成熟度、伤损。下次报价变化时，先确认是不是“货变了”，而不是“价变了”。

**5. 设定可执行的判断规则**
可以内部定几条线：
- 单日波动在历史同期正常区间内，且供应商能说明原因：正常。
- 单日波动超过阈值，比如耐储品超过 10%、易腐品超过 20%：要求书面说明并附产地或市场依据。
- 连续 3 天同方向波动，或一周累计超过 15%：启动比价，至少询 2～3 家替代供应商。
- 报价明显偏离市场且拒绝解释：暂停下单或改小批量试单。

**6. 合同和流程上提前约束**
- 约定调价机制：参考哪个市场、哪个等级、什么时间点的价格，波动超过多少才可调。
- 约定提前通知时间，比如调价需提前 1 天确认，紧急调价需提供凭证。
- 约定质检和扣重标准，避免用“价格波动”掩盖质量下降。
- 保留替代供应商，避免单一供应商在涨价时形成被动。

**简单判断口诀：**
同规格才能比；有基准才算数；有归因才可信；算损耗才是真成本；连续异常就比价。
