供应商在介绍时，可以把重点从“品种名称”转到“顾客买它做什么、好不好卖、好不好处理”。普通商家下单时最关心的是：能不能赚钱、损耗大不大、操作麻不麻烦。

建议按这个顺序讲：

1. **先对应到商家熟悉的品类**
   - “这个相当于菠萝里的金钻凤梨，不用泡盐水，切开就能吃。”
   - “这个香蕉类似普通香蕉，但更短更甜，适合做小份果切。”

2. **说清顾客为什么买**
   - 甜不甜、酸不酸、香不香
   - 能不能直接吃，还是要加工
   - 适合谁买：家庭、小孩、老人、奶茶店、果切摊、餐厅

3. **说清怎么卖**
   - 按个卖、按斤卖、按箱卖
   - 适合做引流款、利润款，还是搭配款
   - 能做什么：直接吃、榨汁、做果切、烘焙、甜品

4. **说清损耗和保存**
   - 几天会熟、几天会坏
   - 怕不怕压、要不要冷藏
   - 次果多不多，坏果怎么赔

5. **给一个最小下单建议**
   - “先拿一箱试卖，卖得好第二天再补。”
   - “这个适合和香蕉、菠萝一起做组合装，不用单独压太多货。”

一句话模板：

> “老板，这个你可以理解成‘升级版的某某’。顾客买回去主要是直接吃/做果切，比普通款更甜、更方便，损耗也低。你先拿一箱试，卖得动再补，不好卖我这边给你换/补。”

关键原则：**少讲专业品种名，多讲对标熟悉品类、使用场景、利润和风险。** 商家听懂了“跟我现在卖的有什么关系”，才更容易下单。
