能，但通常不是“你说做促销他就给”，而是看你进货量、合作稳定度、促销是否能带动他的销量。水果供应商常见支持分三类：

1. **价格支持**
   - **临时特价**：针对某几个单品，周末给你低于日常批发价，通常要求你集中推、走量。
   - **返点/返利**：按周末进货量或销售额给返点，事后结算。
   - **搭赠**：比如进10箱送1箱，变相降价，生鲜里很常见。
   - **损耗补贴**：易损水果可能给一点损耗补偿，但不是每家都给。

2. **物料支持**
   - 纸箱、周转筐、保鲜袋、标签、海报、价签、横幅。
   - 品牌类水果可能有厂家或总代提供：试吃盒、展架、促销贴纸、活动小礼品。
   - 单纯批发商物料能力弱，品牌代理商/厂家区域业务员支持更多。

3. **人员/活动支持**
   - 试吃推广、驻场促销员，通常只在大品牌或大卖场渠道常见。
   - 水果店周末小促销，更多还是靠自己店员，供应商最多给点试吃果。

**能不能拿到，主要看这几点：**
- 你周末进货量是否明显高于平时；
- 是否长期从他那进货，而不是临时比价；
- 促销单品是不是他主推、库存多的货；
- 你是否愿意把促销海报、陈列、朋友圈/社群一起帮他推；
- 竞争情况：附近批发商多，他更愿意给支持。

**比较实用的谈法：**
- 提前3-5天找供应商，不要周五晚上才说。
- 直接给方案：周末主推2-3个单品，预计进多少箱，想要什么支持。
- 优先谈“搭赠”和“单品特价”，比直接要现金返点更容易。
- 物料先要价签、海报、试吃盒、周转筐，这些成本低，供应商容易答应。
- 如果量不够大，可以联合附近水果店一起拿货，换更好支持。

**现实预期：**
- 小水果店、临时进货：很难拿到现金补贴，最多争取搭赠、特价、纸箱物料。
- 稳定合作、周末走量明显：可以谈单品特价+搭赠+海报。
- 品牌水果、连锁店、大进货量：才比较容易拿到厂家物料、试吃、促销员支持。

建议你这次先选1-2个供应商主推单品，用“周末预计销量”换“特价或搭赠”，比泛泛问“能不能支持”成功率高很多。
