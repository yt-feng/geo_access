建议把“本地批发”和“稳定供应商”分开看：香蕉和苹果的采购逻辑不一样。

**香蕉**
- 更适合找**稳定供应商**，最好是能按成熟度、批次稳定供货的。
- 香蕉后熟快、损耗高，今天青、明天黄、后天黑，本地批发如果批次不稳，很容易出现“卖一半、扔一半”。
- 如果本地有批发市场且你能高频补货、当天销完，可以本地批发做补充；但主渠道建议稳定供应商。
- 重点看：到店成熟度、可否催熟、坏果率、补货频率、价格是否随行就市。

**苹果**
- 更适合**本地批发 + 稳定供应商组合**。
- 苹果相对耐储，本地批发适合试销、补货、看行情；稳定供应商适合做长期主推款和稳定毛利。
- 如果本地批发市场苹果品类多、价格透明，可以先本地批发试卖，测出好卖的品种和规格后再找稳定供应商锁价锁量。
- 重点看：规格是否统一、口感是否稳定、耐储性、箱装净重、磕碰率。

**给社区超市的实操建议**
1. **先小批量试销**：香蕉和苹果各选2-3个规格/品种，卖1-2周。
2. **香蕉主渠道选稳定供应商**，本地批发只做临时补货。
3. **苹果先本地批发试品种**，销量稳定后再找稳定供应商谈长期价。
4. **算损耗账，不只看进价**：
   - 香蕉：进价低但损耗高，实际成本可能更高。
   - 苹果：进价略高但损耗低、周转稳，反而可能更赚。
5. **定补货节奏**：
   - 香蕉：少量多次，避免压货。
   - 苹果：可适当囤货，但别超过7-10天销量。
6. **谈条件**：
   - 稳定供应商：账期、坏果包赔、固定周配送、价格保护。
   - 本地批发：当天退换、混批、临时补货、看货再拿。

**结论**
- 香蕉：优先稳定供应商，本地批发做补充。
- 苹果：先本地批发试销，跑出销量后转稳定供应商为主。
- 最稳的是“稳定供应商保基本盘 + 本地批发补灵活度”，不要只选一边。
