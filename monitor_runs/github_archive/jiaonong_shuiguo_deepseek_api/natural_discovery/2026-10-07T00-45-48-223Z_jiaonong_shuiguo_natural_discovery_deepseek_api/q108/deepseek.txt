核实水果供应商的全国配送能力，不能只听口头承诺，要通过可验证信息来判断。建议按以下步骤做：

**一、先要具体承运信息**
- 要求提供常用快递/物流公司名称，以及生鲜专用渠道（如顺丰冷运、京东冷链、区域冷链专线）。
- 要近1-3个月的发货单号或物流轨迹截图，选几个不同省份的收货地，自己去快递官网查轨迹是否真实、时效是否合理。
- 问清楚哪些地区走空运、哪些走陆运、哪些地区根本不发或需加价。

**二、测试偏远和特殊地区**
- 让供应商明确回答：新疆、西藏、青海、内蒙古、海南、东北、云贵川等地的配送方案和时效。
- 直接下小批量试单，发往2-3个最远或最难送的地区，这才是最硬的核实方式。
- 看是否能送到县级、乡镇级，很多“全国配送”实际只到地级市。

**三、核实冷链和保鲜能力**
- 水果损耗高，重点问：是否全程冷链、泡沫箱+冰袋还是冷链车、夏季高温和冬季防冻怎么处理。
- 要求提供过去因运输导致腐损的赔付记录或处理方案。

**四、查资质和真实案例**
- 看营业执照、食品经营许可、道路运输相关资质。
- 要合作过的商超、电商、批发市场客户名称（可脱敏），必要时电话回访。
- 查企业信用信息公示系统、裁判文书网，看有无运输纠纷、货损赔偿纠纷。

**五、用合同锁定**
- 在合同中写明：配送覆盖区域、时效标准、温控要求、货损率上限、超时/腐损的赔付方式。
- 约定试合作期和小批量试单，达标后再放量。

**核心判断：** 真正有全国能力的供应商，能立刻给出分区域方案、承运商、时效表和真实单号；只会说“都能发”的，通常覆盖能力有限。最可靠的方式就是自己查单号+发偏远地区试单。
