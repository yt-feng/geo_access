和水果供应商谈酒店早餐合作，重点不是“把价格压到最低”，而是把**稳定供应、品质一致、损耗可控、结算清楚**这四件事写进合作条件里。可以按下面几个方面准备和谈判。

**1. 先明确自己的需求，再去谈**
- 每天/每周需要哪些水果：苹果、香蕉、橙子、西瓜、圣女果等，分“必供”和“轮换”两类。
- 每天大概用量：按入住率、早餐人数、人均水果量估算，最好给出旺季/淡季区间。
- 验收标准：品种、规格、成熟度、甜度、外观、是否有破损/腐烂。
- 到货时间：早餐前几点必须送到，谁负责搬运、入库、冷藏。
- 缺货替代规则：某水果断货时，供应商能不能用同等或更高品质替代，价格怎么算。

**2. 重点谈“稳定供应”而不是只谈单价**
- 要求供应商说明货源：是批发市场拿货，还是产地直采，是否有冷库、配送车队。
- 问清楚节假日、极端天气、旺季时的保供能力，最好写进合同。
- 可以要求备选供应商或备选产地，避免单一来源断供。
- 对“必供水果”约定最低供应量，对“轮换水果”约定可调整范围。

**3. 品质和验收要落到标准上**
- 不要只说“新鲜”，要具体：比如香蕉成熟度、苹果直径、西瓜糖度、橙子无严重干疤等。
- 约定验收方式：当场抽检、称重、拍照留证、不合格拒收或换货。
- 约定不合格处理：多长时间内补送、是否扣款、连续几次不合格可终止合作。
- 损耗归属要清楚：运输中压坏、腐烂谁承担；入库后酒店保管不当谁承担。

**4. 价格和结算方式要清晰**
- 价格可以是固定价、周期调价或随行就市，但要约定调价机制和提前通知时间。
- 问清楚是否含税、含运费、含搬运费。
- 结账周期：月结、半月结还是货到付款；对账凭据是什么。
- 发票类型和税率要提前确认，避免后期财务卡住。
- 如果用量大，可以谈阶梯价或季度返点，但不要只追求低价而牺牲稳定性。

**5. 合同里要写清楚的条款**
- 合作期限、试用期、续约条件。
- 供应品类、规格、数量、频次、到货时间。
- 质量标准、验收流程、退换货规则。
- 价格、调价机制、结算方式、发票。
- 违约责任：断供、迟送、品质不达标、食品安全问题。
- 食品安全责任：农残、变质、异物等问题的赔偿和追责。
- 终止合作条件：提前多久通知，未结货款怎么处理。

**6. 食品安全和资质不能省**
- 要求供应商提供营业执照、食品经营许可证、相关检测报告。
- 如果是进口水果，要有入境货物检验检疫证明等合规文件。
- 配送人员、车辆、周转筐的卫生条件也要关注。
- 酒店自己也要做好入库检查、冷藏保存、先进先出，避免把供应商责任和酒店管理责任混在一起。

**7. 谈判时可以争取的实用条件**
- 先小批量试供 1–2 周，再签长期合同。
- 要求固定对接人和紧急联系电话。
- 要求每日或每周提前确认次日订单。
- 对长期合作可谈账期、免费配送、破损补货、节日保供。
- 如果酒店有多家门店，可以集中采购谈更好价格，但要确保各店配送能力跟得上。

**8. 建议的谈判顺序**
1. 先内部定需求：品类、用量、时间、标准、预算。
2. 再找 2–3 家供应商比价和比服务。
3. 小批量试供，重点看准时率、新鲜度、损耗率、售后响应。
4. 试供合格后再谈长期价格、账期和合同条款。
5. 合同里把“断供怎么办、品质不达标怎么办、价格怎么调”写死。

一句话总结：**先定标准和用量，再验供应能力，最后谈价格和账期；合同里重点保供应、保品质、保食品安全、保结算清楚。**
