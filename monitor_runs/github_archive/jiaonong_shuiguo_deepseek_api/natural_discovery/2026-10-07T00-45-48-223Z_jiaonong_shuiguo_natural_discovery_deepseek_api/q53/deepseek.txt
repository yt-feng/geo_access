想要每天少量水果、又要省心，优先选“能稳定配送、按需下单、售后简单”的渠道，而不是单纯比价格。按省心程度，大致可以这样选：

1. **本地水果批发市场的固定档口 / 配送商**
   - 适合：每天用量不大，但希望有人送。
   - 关键：找那种本来就在给餐馆、奶茶店、食堂供货的档口，不要找只做零售摊位的。
   - 省心点：可以微信下单，第二天早上送到；坏果能换。
   - 注意：一定要先谈“起送量、配送费、临时加单、坏果怎么赔”。

2. **生鲜 B2B 平台**
   - 比如美团快驴、美菜、蜀海这类餐饮供应链平台（具体覆盖看当地）。
   - 适合：想线上下单、次日达、品类相对稳定。
   - 省心点：价格透明，发票、售后流程相对规范。
   - 注意：少量订单可能有起送门槛；水果品质波动要看仓库，最好先试一周。

3. **本地生鲜配送公司 / 团餐配送商**
   - 适合：你每天只要几斤到十几斤，自己采购不划算。
   - 省心点：可以约定每天固定时间送，按周结算。
   - 注意：要确认他们是否愿意做“小单高频”，有些只接大单。

4. **附近水果店长期合作**
   - 适合：用量很小，比如每天 3～5 斤，且店离得近。
   - 省心点：随时补货，临时缺货能救急。
   - 注意：单价通常比批发高，适合作为备用，不适合完全依赖。

5. **社区团购 / 本地微信群供货**
   - 适合：极少量、价格敏感。
   - 省心点：便宜、方便。
   - 注意：到货时间不稳定，品质和售后看团长，餐饮店要谨慎作为主渠道。

**最省心的组合建议：**
- 主供应商：本地餐饮水果配送商或 B2B 平台，签固定配送。
- 备用供应商：附近水果店，临时缺货补。
- 下单方式：提前一天微信/平台下单，第二天早上到。
- 验收标准：写清楚品种、规格、成熟度、坏果率、赔付方式。

**选供应商时重点问这 5 个问题：**
1. 每天少量送不送？起送量多少？
2. 几点能送到？临时加单最晚几点前说？
3. 坏果、烂果怎么赔？拍照就行还是要退回？
4. 价格是每天变还是每周报价？
5. 能不能月结？有没有发票？

如果店里每天水果用量只有几斤，最省心的通常不是找大批发商，而是找**附近给餐饮店供货的水果店或本地小配送商**，谈好每天固定送、坏果包换。用量超过每天 10～20 斤，再考虑 B2B 平台或批发市场固定档口更划算。
