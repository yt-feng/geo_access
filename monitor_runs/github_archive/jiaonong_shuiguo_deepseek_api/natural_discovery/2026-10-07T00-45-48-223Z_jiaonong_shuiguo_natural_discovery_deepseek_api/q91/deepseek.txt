建议优先做 **小把（2–4根）**，其次补 **单根**，整袋只作为少量补充。原因如下：

1. **便利店的核心场景是“即时吃、少量买”**
   - 香蕉是高频冲动型水果，顾客多是上班路上、午休、下班顺手买。
   - 一次买整袋对单人消费者负担太大，容易犹豫不买。
   - 单根最灵活，但客单价太低、损耗和理货成本偏高。

2. **小把最适合便利店**
   - 2–4根刚好满足1–2人当天到两天内吃完。
   - 比单根客单价高，又不像整袋那样有购买压力。
   - 陈列整齐，方便贴价签、补货和盘点。

3. **单根适合作为补充**
   - 适合只想马上吃一根的顾客。
   - 可放在收银台附近做冲动消费。
   - 但不要只卖单根，否则毛利和客单都偏低。

4. **整袋谨慎上**
   - 适合家庭客群或社区型便利店。
   - 如果门店在写字楼、地铁口、学校附近，整袋通常动销慢。
   - 整袋一旦熟过头，损耗会明显高于小把和单根。

更具体的组合建议：

- **写字楼/地铁口/学校店**：小把为主，单根为辅，不上或极少上整袋。
- **社区/家庭型店**：小把为主，整袋少量，单根少量。
- **测试期**：先上小把和单根，观察3–7天。
  - 如果单根卖得快、小把也稳定，就保留。
  - 如果整袋连续几天不动销，直接下架。

另外，香蕉上架关键不只是包装规格，还要控制熟度：

- 最好卖 **微黄带一点绿** 的香蕉，顾客买回去能放1–2天。
- 已经全黄甚至起黑点的，适合打折或做单根促销，不适合整袋正价卖。
- 便利店香蕉陈列量不要大，少量多次补货，比一次性堆很多更不容易损耗。

结论：**主推小把，搭配单根，整袋看商圈少量试。**
