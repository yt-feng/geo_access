判断供应商能不能按时到车，核心不是听承诺，而是看“可验证的履约记录 + 当天可追踪的节点”。给你一套可执行的判断法：

**1. 先看历史履约，不看口头保证**
- 问最近10车香蕉的实际到场时间，要求提供车牌、进场过磅时间、你或同行的收货记录。
- 重点看：准点率、平均迟到多久、迟到后怎么处理。
- 如果供应商只给“放心”“没问题”，拿不出记录，风险就高。

**2. 锁定“到场”定义**
- 是到批发市场门口、进市场过磅，还是到你的档口？
- 香蕉是青蕉还是熟蕉，是否要催熟、是否要卸货排队，都要提前写清。
- 很多纠纷是“车到了但进不了场”被算迟到，提前约定能避免扯皮。

**3. 当天追踪关键节点**
可要求供应商在以下节点发定位或照片：
- 装车完成、封车
- 上高速/发车
- 预计到达前2—3小时
- 到达市场附近
如果对方在这些节点含糊、失联、反复改时间，基本可判断有风险。

**4. 用合同/微信固定责任**
- 写明到场时间、迟到违约金、香蕉质量问题怎么扣款。
- 定金不要一次给太高，最好按车结算或货到验收后付尾款。
- 保留聊天记录、转账记录、车牌和司机电话。

**5. 看供应商的运力来源**
- 自有车/长期合作车队，通常比临时调车稳。
- 如果他说“临时找车”“司机还在路上”，尤其跨省长途，迟到概率会明显上升。
- 问清装车地、路线、是否中转。中转越多，越容易晚。

**6. 做小单测试**
- 新供应商先走1—2车小批量，别一上来压大单。
- 连续几次准点、质量稳定，再放大合作。

**7. 香蕉这个品类要特别注意**
- 香蕉怕冷怕热，迟到可能导致青蕉变黄、熟度失控。
- 夏季高温、冬季寒潮、节假日堵车、产地装车排队，都会影响到场。
- 如果供应商不提前说明天气和路线风险，说明他要么不专业，要么在掩饰。

**简单判断标准：**
- 能给出历史记录、车牌、司机电话、装车时间、路线，且节点主动同步：较可放心。
- 只给口头保证、不愿意写迟到责任、当天追问才回：风险高。
- 价格明显低于市场、还承诺随时到车：大概率有问题。

如果你告诉我具体是哪个产地到哪个市场、走公路还是铁路、大概几车，我可以帮你列一个更具体的“到车跟踪表”。
