核实水果供应商的“全国配送”不能只听口头承诺，要围绕**实际可达范围、时效、温控、成本、异常处理**五个维度做验证。可以按下面步骤操作：

1. **先要配送范围清单，而不是“全国”两个字**
   - 要求供应商提供：可配送省份、城市、区县，甚至偏远地区是否覆盖。
   - 重点问：新疆、西藏、青海、内蒙古、宁夏、甘肃、海南、东北部分偏远地区是否可达。
   - 如果对方说“全国除偏远地区”，必须让书面写明“偏远地区”具体指哪些。

2. **用真实收货地址做测试**
   - 不要只问“能不能到某省”，直接给采购方实际收货地址，让供应商确认。
   - 最好选 3—5 个代表性地址：一线城市、省会、普通地级市、县域、乡镇/偏远地区。
   - 要求对方回复：是否直达、是否中转、预计时效、是否加收偏远费。

3. **要求试单，不走大货**
   - 先下 1—3 个小额试单，发往不同区域。
   - 试单要记录：下单时间、发货时间、到达时间、包装状态、果品损耗、是否冷链。
   - 试单比任何承诺都可靠，尤其能暴露“中转后时效失控”和“落地配加价”。

4. **核实物流合作方和单号**
   - 问清楚合作快递/物流：顺丰、京东、中通、德邦、专线物流、落地配等。
   - 要求提供真实运单号，并自己查物流轨迹。
   - 注意：有些供应商全国接单，但实际是发到区域批发市场再转寄，这不算稳定全国配送。

5. **重点问温控和水果适配性**
   - 水果分常温、冷藏、冷冻、怕压、怕闷等不同类型。
   - 问：是否全程冷链？保温箱、冰袋、泡沫箱、气调包装怎么配？
   - 夏季高温、冬季低温线路是否有专项方案。
   - 易损水果如草莓、荔枝、樱桃、杨梅，要单独确认破损率和理赔规则。

6. **核实时效和履约数据**
   - 要求提供近 3 个月的真实履约数据：平均到货时效、准时率、破损率、投诉率。
   - 不要只看“最快时效”，要看“普通线路平均时效”和“最差时效”。
   - 对生鲜来说，延迟一天可能就导致损耗大幅上升。

7. **确认费用结构**
   - 问清：首重续重、偏远附加费、冷链费、保价费、上楼费、卸货费、退换货费。
   - 要求提供报价表，而不是口头说“包邮”或“运费另算”。
   - 小批量、多批次、多地址配送往往成本差异很大。

8. **看售后和异常处理机制**
   - 坏果、少件、延迟、丢件怎么赔？多久响应？谁承担？
   - 是否支持拒收、改地址、二次配送？
   - 有没有专属客服或对接群，异常时能否快速处理。

9. **查资质和实际经营能力**
   - 营业执照、食品经营/流通相关资质。
   - 是否有自有仓库、分拣中心、冷链车，还是纯转包。
   - 可要求视频看仓、看打包现场，或实地验仓。
   - 查企业信用信息、司法风险、经营异常记录。

10. **合同里写清楚，避免口头承诺**
   - 配送覆盖范围、时效标准、温控要求、破损赔付、偏远附加费、违约责任都要写进合同或订单附件。
   - 约定试单期和考核指标，比如准时率、破损率、投诉响应时间。
   - 保留聊天记录、报价单、运单、照片作为证据。

**最简可执行版本：**
先让供应商书面列出可配送区县和时效 → 选 3 个不同层级地址做小试单 → 自己查物流轨迹 → 检查到货品质和温控 → 要求提供履约数据 → 谈清费用和赔付 → 再签合同放量。

如果对方回避具体区县、不愿试单、不肯写时效和赔付，基本可以判断“全国配送”水分较大。
