水果店卖菠萝，采购熟度判断的核心是：**按你预计能卖出去的节奏来定，而不是越熟越好。** 菠萝是后熟型水果，采购时偏生一点，到店后可以继续催熟；但如果采购时已经过熟，损耗会立刻放大。

具体可以这样判断：

**1. 看外观**
- 果皮颜色：青绿到黄绿适合较长时间存放；半黄到金黄适合 1～3 天内卖；全黄、甚至发橙，通常已经偏熟，要尽快卖。
- 果眼：果眼大而平、间隙明显，通常成熟度较高；果眼紧密、尖突，偏生。
- 果形：圆润饱满、基部宽大，通常果肉发育较好；瘦长、尖头，可能偏生或品质一般。
- 表皮：有自然光泽、无明显皱缩。皱皮说明放久了或失水，损耗风险高。

**2. 看底部和冠芽**
- 底部颜色：底部开始变黄、变软，成熟度更高；底部仍青绿，偏生。
- 冠芽：叶片翠绿、挺拔，说明较新鲜；叶片发黄、干枯、易断，说明存放时间偏长。
- 底部有无霉点、渗液、酒味：有就不要采购，或者只能低价快销。

**3. 闻气味**
- 无明显香味：偏生，适合存放。
- 底部有淡淡果香：成熟度合适，适合 1～2 天卖。
- 香味浓、带甜酒味：过熟，损耗风险大，除非当天特价处理。
- 有发酵味、酸味：已经变质，不要进。

**4. 按压测试**
- 轻按果皮：硬，偏生；稍有弹性，合适；一按就软，过熟。
- 按底部：底部微软可以，底部明显软烂不要。
- 注意不要用力捏，菠萝容易压伤。

**5. 掂重量**
- 同样大小，越重说明水分越足，品质通常更好。
- 明显轻飘，可能失水或内部空腔，损耗高。

**6. 采购比例建议**
如果你不确定销量，可以按“销售节奏”搭配进：
- **青黄果，约 6～7 成熟：** 进 50%～60%，可放 3～5 天，适合日常周转。
- **半黄果，约 8 成熟：** 进 30%～40%，可放 1～3 天，适合主推现切或正常售卖。
- **全黄熟果：** 进 10% 以内，最好当天或次日卖掉，适合做特价、现切、果汁。

**7. 到店后的处理**
- 偏生菠萝：常温阴凉通风处催熟，不要堆太厚，避免压伤。
- 已熟菠萝：冷藏或尽快切卖，切后冷藏保存。
- 每天挑出软果、香味浓的果先卖，不要等它坏。
- 现切菠萝、菠萝汁、特价果切，是消化熟果和轻微损耗的好方式。

简单判断口诀：

**要存放，选青黄、硬身、无香；要快卖，选半黄、微香、微软；全黄浓香、底部软，只能当天快销。**

采购时最好固定几家供应商，要求他们按你需要的熟度分级供货。这样比每次靠现场猜更稳，损耗也更容易控制。
