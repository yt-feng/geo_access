三个都重要，但优先级要分场景。对企业食堂来说，更合理的排序通常是：

**食品安全 > 配送准时 > 价格**

理由如下：

1. **食品安全是第一底线**
   水果一旦出现农残超标、腐烂变质、霉变、致病菌污染等问题，可能引发员工集体不适，甚至食物中毒。对企业来说，这不是单纯采购问题，而是安全事故、法律责任和品牌风险。食堂采购水果必须要求供应商提供检测报告、进货凭证、保质期和储存条件，尤其是切果、拼盘类更要严格控制。

2. **配送准时直接影响食堂运营**
   水果通常是按餐次或每日供应，配送晚了会影响出餐、加餐或员工福利发放。特别是早餐、午餐高峰前必须到货。配送不稳定还会导致临时缺货、替代品混乱，甚至影响食堂正常供餐。因此准时和稳定供应非常关键。

3. **价格重要，但不能优先于前两者**
   价格影响成本，企业当然要控预算。但如果为了便宜选择资质差、冷链不完善、配送不稳定的供应商，后续的食品安全风险和停供风险往往更大。水果采购更适合在满足食品安全和配送要求的前提下，再比价、议价和优化品类。

更实际的做法是：

- **先设准入线**：供应商资质、检测报告、冷链能力、配送时效必须达标。
- **再定评分权重**：例如食品安全 50%、配送准时 25%、价格 20%、服务 5%。
- **按品类区分**：整果可稍微侧重价格；切果、鲜切拼盘必须最重视食品安全和冷链配送。
- **建立备选供应商**：避免单一供应商配送延误导致断供。
- **定期复盘**：看投诉率、损耗率、准时率、检测合格率，而不是只看单价。

所以，如果只能选一个最需要关注的，答案是：**食品安全**。但食堂采购不能只盯一个指标，理想状态是：**食品安全达标的前提下，保证配送准时，再争取价格合理。**
