香蕉损耗主要来自“到货太熟 + 卖不完”，所以采购时要把熟度、到货时间和后续销售节奏绑在一起要求。

**一、按销售节奏定熟度**

可以这样要求供应商：

- **当天要卖、次日还要卖**：要 **5～6成熟**，青黄相接，果肉硬，适合再放1～2天。
- **当天就要上架卖相好**：要 **6～7成熟**，表皮转黄但两端略青，果柄不黑。
- **只做特价/当天清货**：可接受 **7～8成熟**，但不能有黑斑、软烂、酒味。
- **不要**：到货已经全黄、果柄发黑、有梅花点、按下去软、有发酵味。

简单判断：
- 太青：卖相差，后熟慢。
- 太黄：当天好看，第二天就烂。
- 最好：**黄中带青、果柄青绿、棱角还明显**。

**二、按到货时间提要求**

- **最好早上到货**：当天能分级、上架、做陈列，下午还能处理次果。
- **不要傍晚或闭店前到货**：没时间挑拣，闷一晚容易加速成熟。
- **夏季/高温天**：要求 **冷链或空调车运输**，到货果温越低越好，但不能冻伤。
- **冬季**：避免冻伤，要求不低于约 **12～13℃** 运输。
- **到货频率**：小批量、多批次，比一次进很多更稳。比如每天或隔天到，而不是一次进一周量。

**三、采购单可以明确写**

可以要求供应商按下面标准供货：

1. 品种/产地：______
2. 熟度：**5.5～6.5成熟**，青黄相接，果柄青绿。
3. 到货时间：**上午10点前**。
4. 运输：夏季冷链，冬季防冻。
5. 外观：无黑斑、无裂口、无压伤、无酒味。
6. 规格：每把/每箱重量、条数统一。
7. 验收：到货抽检，太熟、压伤、黑斑超约定比例可退换。
8. 分批：先送___箱，卖动后再补。

**四、门店配合做法**

- 到货先 **拆箱、分级**：青的放后面，黄的先卖。
- 不要整箱闷着，尤其夏天。
- 陈列少量多次，别一次堆太多。
- 熟度高的做 **特价、果切、奶昔、香蕉面包**。
- 每天记录：到货熟度、到货时间、卖完天数、损耗。下一轮采购按数据调整。

**最实用的采购要求一句话：**
“要5.5～6.5成熟、上午到货、夏季冷链、无黑斑无压伤；先小批量送，卖得好再补，太熟可退换。”
