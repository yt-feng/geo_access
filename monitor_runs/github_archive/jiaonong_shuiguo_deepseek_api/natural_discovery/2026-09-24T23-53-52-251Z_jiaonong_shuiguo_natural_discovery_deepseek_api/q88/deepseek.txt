线上卖水果，差评大多集中在三件事：**收到就烂、放两天就烂、吃起来不稳定**。要减少这三类问题，核心不是“采购时更小心”，而是把采购标准、验货动作、供应商管理做成可执行的流程。

下面按可落地的做法讲。

## 1. 先定“可验收标准”，不要只凭感觉收货

采购前就要把每个单品写成一张验收卡，至少包含：

- **品种/产区/批次**：同一品种不同产区、不同批次口感差异很大，必须可追溯。
- **成熟度**：线上销售要区分“发货成熟度”和“到货可食成熟度”。太生口感差，太熟运输烂。
- **大小/重量区间**：例如单果 180–220g，避免大小混装导致客户预期落差。
- **糖度底线**：用折光仪抽检，例如某品种不低于 11–12 Brix，按品类定。
- **硬度/弹性**：适合运输的硬度范围，过软易碰伤。
- **外观缺陷容忍度**：允许轻微花皮，但不允许裂口、流汁、霉斑、明显软塌。
- **温度要求**：冷链品类必须记录到货中心温度。

没有标准的采购，最后只能靠售后赔钱。

## 2. 采购时重点看“批次稳定性”，不是单次好货

口感不稳定，往往不是某一个果差，而是**批次混杂**。

采购时要问清并验证：

- 这批货是不是同一果园、同一采摘期、同一成熟度？
- 是否混入了不同地块、不同采摘日、不同冷库库存？
- 供应商能不能做到**按批次发货**，而不是“今天有什么发什么”？
- 连续 3 批的糖度、硬度、坏果率是否稳定？

建议建立供应商批次记录：

| 指标 | 要求 |
|---|---|
| 到货坏果率 | 例如 ≤3% |
| 48小时腐损率 | 例如 ≤5% |
| 糖度波动 | 例如同一单品批次间 ≤1.5 Brix |
| 硬度波动 | 不能一批脆一批软 |
| 售后率 | 按单品设红线 |

连续不达标就降级或淘汰，不要只靠压价。

## 3. 验货要抽检，不要“看一眼”

到货后按批次抽检，建议：

- **随机抽 3–5 箱**，不要只打开最上面一箱。
- 每箱抽上、中、下三层。
- 记录：坏果数、软果数、裂果数、霉果数、糖度、硬度、中心温度。
- 对高客单价或易损品，做**48小时模拟运输/货架测试**：常温或冷链放 2 天，再看腐损和口感。

关键动作：

- 有霉斑、流汁、异味的，整箱隔离，不要“挑一挑再发”。
- 同一批次坏果率超红线，直接拒收或降级做特价，不要混入正常订单。
- 抽检结果拍照留档，和供应商结算挂钩。

## 4. 按品类选择不同采购策略

不同水果怕的点不一样：

- **浆果类（草莓、蓝莓、树莓）**：最怕挤压和霉变。要求小盒独立、单层、冷链，到货中心温度要低，抽检重点看霉果和软果。
- **核果类（桃、李、杏）**：最怕成熟度不一。要按硬度分拣，发货成熟度偏硬但不能生。
- **柑橘类**：相对耐运，但怕失水、浮皮、口感干。重点看失重率和糖酸比。
- **热带水果（芒果、香蕉、木瓜）**：要控制催熟批次，不能生熟混发。
- **瓜类**：怕过熟和内部软心，抽检要切开看。
- **葡萄/提子**：怕掉粒、压伤、霉变，重点看果梗新鲜度和单层包装。

## 5. 包装和物流不是采购之后的事，要提前一起定

很多坏果不是采购坏，是“采购标准 + 包装 + 物流”不匹配。

采购时就要确认：

- 这个成熟度能不能扛住你的物流时效？
- 是否需要冰袋、保温袋、泡沫箱、气柱？
- 是否单层摆放、防震分隔？
- 发货后预计 24h、48h、72h 到货，成熟度分别怎么定？
- 高温地区是否要限制某些单品？

如果物流 3 天，却采购接近全熟的果子，差评几乎必然。

## 6. 用“售后数据”反向管采购

每周复盘一次：

- 哪个单品售后率最高？
- 差评关键词是“烂”“酸”“没味”“太小”“太生”还是“熟过头”？
- 对应哪个供应商、哪个批次、哪个产区？
- 是采购成熟度问题、包装问题，还是物流问题？

然后做三件事：

1. 差评批次停止采购或降级。
2. 达标供应商增加采购比例。
3. 把售后原因写进下一批验收卡。

## 7. 最实用的采购红线示例

你可以先设几条硬红线：

- 到货坏果率超过 **3%**：拒收或扣款。
- 48小时腐损率超过 **5%**：该批次不再正常销售。
- 糖度低于单品底线：不采或降级。
- 成熟度混杂严重：拒收。
- 连续两批售后率超标：暂停供应商。
- 无批次追溯、无法提供采摘/冷库信息：不采。

## 一句话总结

减少坏果和口感不稳定，靠的是：**按单品定验收标准，按批次抽检，按数据淘汰供应商，采购成熟度匹配物流时效，坏批次绝不混发。**  
采购不是“找便宜好货”，而是“找到能稳定交付合格批次的供应商”。
