小水果店做附近小区团购，水果供应商最好能支持下面这些服务。重点不是“能不能供货”，而是能不能帮你把**损耗、配送、售后、结算**这四件事做轻。

1. **稳定供货与每日报价**
   - 能提前给次日/本周可供货清单和价格。
   - 价格波动时能及时通知，避免你团购价倒挂。
   - 最好支持小批量补货，不要强制一次进很多。

2. **按团购需求分拣打包**
   - 能按“每份/每袋/每箱”标准分好，而不是只发大货。
   - 支持不同规格：如3斤装、5斤装、家庭装、尝鲜装。
   - 包装要适合小区自提，不易压坏、渗漏。

3. **质量分级和坏果包赔**
   - 明确等级：果径、甜度、外观、成熟度。
   - 承诺坏果、烂果、少重怎么赔。
   - 最好有照片/视频验货或到货抽检机制。
   - 售后响应要快，别让你自己贴钱赔邻居。

4. **支持预售和按单发货**
   - 你先在群里接龙/小程序收款，再向供应商下单。
   - 供应商能按你的订单量备货，而不是让你压库存。
   - 能接受今天下单、明天到货这种节奏。

5. **配送到店或指定自提点**
   - 能送到水果店、小区门口、团长指定点。
   - 配送时间稳定，最好固定时段。
   - 有冷链或保温措施更好，尤其是夏季、草莓樱桃等易损品。
   - 能支持多小区分点配送更省事。

6. **退换货和补发**
   - 出现质量问题，能补发、退款或下次抵扣。
   - 不用你反复举证、扯皮。
   - 对团购常见问题有标准处理规则。

7. **账期与结算灵活**
   - 支持现结、周结、月结，或押金+账期。
   - 能提供对账单、订单明细、发票。
   - 价格、运费、包装费、损耗承担要提前写清。

8. **营销和素材支持**
   - 提供水果图片、卖点、产地、口感描述。
   - 能配合做爆品、试吃、限时团。
   - 有稳定爆款和应季品推荐，帮你选品。

9. **售后数据反馈**
   - 愿意根据你反馈的坏果率、投诉点调整批次。
   - 能告诉你哪些品种适合团购、哪些不适合远距离配送。

你选供应商时，建议重点问这8个问题：
1. 起送量多少？能不能小批量补？
2. 是否按份分拣？包装费谁出？
3. 坏果怎么赔？多久内有效？
4. 配送到哪？多久到？迟到怎么办？
5. 价格保几天？降价补差吗？
6. 能不能按单备货，支持预售？
7. 结算方式？能否对账开票？
8. 有没有团购素材和爆品推荐？

最适合小区团购的供应商，不一定是价格最低的，而是：**能小批量、能分拣、能赔付、能稳定送、售后不扯皮**。这样你才敢在群里长期开团。
