没有统一数字，但可以按“先小批量试卖、用数据决定是否放大”的原则来定。给你一个可执行的判断框架：

**1. 先定试卖量：按 3 个维度取最小值**
- **按门店数**：单店试卖先按 **1 箱/天** 或 **3～5 公斤/天**。  
  如果有多店，先选 **2～3 家代表性门店**试，不要全渠道铺。
- **按品类**：  
  - 高损耗、易熟水果（草莓、蓝莓、荔枝、桃）：**1～2 天量**，宁少勿多。  
  - 中损耗水果（苹果、橙、梨、葡萄）：**3～5 天量**。  
  - 耐储水果（柚、瓜、苹果）：可到 **5～7 天量**。
- **按供应商最小起订量**：如果 MOQ 很高，先谈 **拆包/拼车/混装**，不要为了拿低价一次压太多。

**2. 建议试卖周期**
- 快速验证：**3～7 天**。
- 慢热品类：**7～14 天**。
- 期间记录：**到货损耗、上架损耗、日销量、动销率、顾客复购/询问、退货原因**。

**3. 什么情况算“稳”**
满足以下 2～3 条再放大：
- 日均售罄率 **≥70%**；
- 损耗率低于品类可接受线（叶菜类另说，水果一般先控在 **5%～10%**，高损耗品单独算）；
- 连续 **3 天以上**有稳定动销；
- 顾客没有集中反馈“太贵/不新鲜/口感差”；
- 毛利扣掉损耗后仍为正。

**4. 放大节奏**
- 第一次补货：按试卖量的 **1.5～2 倍**。
- 连续稳定后：按 **周销量 × 1.2～1.5** 备货。
- 始终留 **10%～20% 安全库存**，不要一次顶满。

**5. 和新供应商谈的要点**
- 先要 **样品 + 小批量试单**，不要直接签大单。
- 谈清：**损耗谁承担、到货标准、退换货、账期、补货时效**。
- 最好做 **盲测/对比试卖**：同价位和现有同类水果比，看顾客选谁。

一句话：**先按“单店 1～2 天销量、2～3 家店、3～7 天”试，数据达标再按 1.5～2 倍放大。**
