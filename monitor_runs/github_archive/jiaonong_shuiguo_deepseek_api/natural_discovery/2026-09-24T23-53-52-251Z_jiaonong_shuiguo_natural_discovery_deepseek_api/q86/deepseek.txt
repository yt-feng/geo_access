做生鲜水果一件代发，供应商至少要具备以下几类仓配能力，否则很容易在履约端出问题：

**1. 仓储能力**
- **多温区或适配温区**：水果多数适合 0–10℃ 冷藏或阴凉通风，供应商要有对应冷藏库/恒温库，而不是普通常温仓。
- **分区与防串味**：不同水果对乙烯敏感度不同，要能分区存放，避免催熟、串味、压伤。
- **短保库存管理**：具备先进先出、批次管理、临期预警能力，减少腐损。
- **周转能力**：日均/峰值订单处理量要匹配平台销量，最好有弹性扩容空间。

**2. 分拣打包能力**
- **按单拣配**：支持一件代发的单件拣货、称重、贴单，不是只做整箱批发。
- **分级选果**：能按平台标准做果径、糖度、成熟度、外观分级，降低客诉。
- **防护包装**：针对易损水果具备缓冲、透气、防压、防冻/防热包装方案。
- **定制化包装**：可贴平台品牌标签、放卡片、做礼盒或组合装。

**3. 订单与系统能力**
- **WMS/OMS 对接**：能通过 API 或表格与平台订单系统对接，支持自动抓单、回传单号。
- **库存同步**：实时或准实时同步库存，避免超卖。
- **面单与物流对接**：能对接主流快递/专线，支持电子面单、多快递路由。
- **售后数据留存**：能提供发货照片、称重记录、批次信息，便于处理售后。

**4. 配送与快递能力**
- **快递资源**：有稳定合作的快递或专线，尤其是生鲜时效线路。
- **时效覆盖**：能覆盖平台主要销售区域，明确哪些地区可发、哪些不发货。
- **温控运输**：远距离或高温季节需具备冷链、冰袋、保温箱等方案。
- **异常处理**：丢件、破损、延误、拒收能快速响应并补发/退款。

**5. 品控与售后能力**
- **到货验收**：对上游果园/供应商有验收标准，能抽检糖度、硬度、农残等。
- **腐损率控制**：能承诺并实际控制一定范围内的坏果率，比如 5%–10% 以内。
- **售后响应**：有专门客服或对接人，能按平台规则处理坏果、少发、延迟。
- **赔付机制**：明确坏果包赔、补发、退款的责任边界和时限。

**6. 履约稳定性**
- **旺季峰值能力**：大促、节假日能加班发货，不爆仓。
- **多仓布局**：单仓发全国时效差，最好有 2–3 个区域仓或云仓合作。
- **应急方案**：天气、疫情、快递停发时有替代仓或替代快递。
- **数据复盘**：能提供发货时效、签收时效、破损率、售后率等数据。

**判断供应商是否合格，可以重点问这几个问题：**
1. 日均单量多少？峰值能到多少？
2. 用哪家快递？主要区域几天到？
3. 坏果率承诺多少？怎么赔？
4. 能不能 API 对接？库存多久同步一次？
5. 有没有冷藏库？哪些品类不能混放？
6. 大促期间会不会优先保你？

如果供应商只能做“产地直发、普通快递、无温控、无系统对接”，那更适合低客单、耐运输的水果，比如苹果、橙子；如果做草莓、荔枝、樱桃、榴莲等，必须具备更强的冷链、分拣和售后能力。
