社区超市找“每天配送”的水果供应商，核心不是先看价格，而是先判断对方能不能稳定、低损耗地支撑你的日常经营。建议重点看这几类条件：

1. **配送能力**
   - 是否能真正做到每天配送，而不是“满额才送”。
   - 固定送达时间是否稳定，比如每天早上 6–8 点前到店。
   - 临时补货、节假日、恶劣天气时能否加急或调整。
   - 配送范围是否覆盖你所在区域，距离越近通常越有利于新鲜度和补货。

2. **货源与品类**
   - 是否有稳定产地或一级批发渠道，不是临时倒货。
   - 能否覆盖你店里的常销品：苹果、香蕉、橙子、梨、葡萄、西瓜、时令水果等。
   - 是否支持小批量多品种混配，而不是只卖整箱大货。
   - 时令水果和反季水果的供应是否稳定。

3. **价格与结算**
   - 报价是否透明，是否随行就市但提前通知。
   - 是否有配送费、起送门槛、箱皮/筐子押金等隐性成本。
   - 结算方式：现结、周结、月结，能否对账清晰。
   - 价格是否比本地批发市场有明显优势，至少不能长期偏高。

4. **品质与损耗**
   - 是否允许验货、拒收明显坏果。
   - 坏果、压伤、腐烂的赔付或补货规则是什么。
   - 水果成熟度是否适合社区店：太生不好卖，太熟损耗大。
   - 是否按门店销售节奏配货，而不是硬塞库存。

5. **售后与稳定性**
   - 出现质量问题后，多久能补货或退款。
   - 是否有固定业务对接人，响应是否及时。
   - 供应商本身经营是否稳定，避免突然断供。
   - 是否只依赖单一供应商，建议至少备 1 家备选。

6. **试合作判断**
   - 先小批量试 1–2 周，重点看：到货时间、坏果率、补货速度、对账是否清楚。
   - 试合作期间不要只比价，要算“实际可售成本”：进货价 + 损耗 + 配送费 + 退货损失。
   - 如果对方能做到每天准时送、坏果可赔、品类能跟着季节调整，就可以进入长期合作。

简单说，优先选：**本地、能日配、可小批量混配、坏果有赔付、对账清楚**的供应商。价格重要，但稳定供货和低损耗更决定社区超市能不能长期做下去。
