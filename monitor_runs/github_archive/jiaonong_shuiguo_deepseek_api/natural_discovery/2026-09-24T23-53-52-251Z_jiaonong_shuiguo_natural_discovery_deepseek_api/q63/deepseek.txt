判断哪个规格更容易出货，核心不是看哪个“最好卖”，而是看**你的下游客户是谁、他们按什么标准拿货、哪种规格流转最快**。可以按下面这套方法快速判断。

## 1. 先看你的客户类型

不同下游，对应畅销规格完全不同：

- **水果店/社区店**：偏好中等个头、外观整齐、单果2～3斤左右，顾客按个买，太大太小都不好卖。
- **超市/连锁**：偏好规格统一、分级标准清晰，通常按直径或单果重分级，要求外观一致。
- **餐饮/果汁店/烘焙**：更看重出肉率和成本，往往偏好大果或统货，对颜值要求低。
- **批发市场二次批发**：走量最快的一般是主流中等规格，因为下游小贩最容易接。
- **电商/社区团购**：偏好单果1.5～2.5斤、适合装箱和配送的规格，太大容易压坏，太小显得不值。
- **加工厂/罐头厂**：偏好小果、次果或统货，价格敏感，不挑外观。

所以先明确：你主要供货给谁。没有这个前提，谈“哪个规格好出”没有意义。

## 2. 用三个指标判断

### ① 询问频率
让业务员或档口记录：
- 客户问得最多的是哪个规格
- 哪个规格被反复询价
- 哪个规格一问就成交

问得多但不成交，可能是价格问题；问得少但成交快，可能是刚需。

### ② 周转速度
同样一批货，统计：
- 哪个规格当天走完
- 哪个规格压了3天以上
- 哪个规格需要降价才出

周转最快的，通常就是当前渠道的主流规格。

### ③ 退换和损耗
- 大果如果经常被压伤、投诉，实际出货效率会下降。
- 小果如果被嫌小、压价严重，也不好出。
- 中等规格通常损耗最低，流转最稳。

## 3. 菠萝常见规格的出货逻辑

按单果重粗略分：

- **小果，1斤以下**：适合加工、果汁、团购引流，普通水果店不好卖。
- **中果，1～2斤**：适合社区团购、电商、小水果店，走量较稳。
- **中大果，2～3斤**：通常是最主流、最容易出货的规格，适合水果店、批发市场。
- **大果，3斤以上**：适合餐饮、果汁、超市堆头，但普通顾客可能嫌大，损耗也高。
- **统货**：适合价格敏感客户，走量快但利润薄。

多数批发场景下，**2～3斤的中大果往往是出货最稳的规格**，但不是绝对，要看你所在市场和客户结构。

## 4. 最实用的判断方法

你可以直接做一个小测试：

1. 把同一批菠萝按规格分成3～4档。
2. 每档定一个合理价，挂出去或报给客户。
3. 连续记录3～5天：
   - 各规格询价次数
   - 各规格成交数量
   - 各规格剩余库存
   - 各规格降价幅度
4. 算出每个规格的“日均出货量”和“清货天数”。

**日均出货量最大、清货天数最短、降价最少**的那个规格，就是当前最容易出货的规格。

## 5. 一句话结论

不要凭感觉判断，要看**下游客户结构 + 询价频率 + 周转速度 + 损耗**。  
多数批发场景里，**中等偏大、外观整齐、规格统一的菠萝通常最好出货**；但如果你供餐饮或加工，大果或统货可能更快。最终用3～5天的实际成交数据来定。
