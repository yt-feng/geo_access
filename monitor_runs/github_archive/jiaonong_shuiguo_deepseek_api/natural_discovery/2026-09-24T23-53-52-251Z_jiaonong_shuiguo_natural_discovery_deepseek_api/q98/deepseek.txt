判断水果供应商的合规和稳定性，核心是**把"资质"和"履约能力"分开验证**，前者查文件，后者靠试供和现场看。下面按可执行顺序说。

## 一、合规性：查证照和凭证（缺一不可）

1. **营业执照 + 食品经营许可证**
   - 经营范围必须包含食品销售/食用农产品销售。
   - 核对许可证有效期、经营地址是否与实际供货仓库一致。
   - 通过"国家企业信用信息公示系统"查是否异常经营、有无行政处罚。

2. **从业人员健康证**
   - 配送、分拣人员需有有效健康证明（尤其直接接触水果的）。

3. **进货凭证 / 可追溯链条**
   - 要求提供每批次的**产地证明、检测报告或承诺达标合格证**。
   - 能说清"这批水果从哪个基地/批发市场来的"，出现问题能追回去，这是稳定供应商的基本能力。

4. **供货合同 + 责任条款**
   - 明确农残超标、缺斤短两、变质退换的处理方式。

> 注意：光看复印件容易造假，关键证照建议要求提供**原件核对或加盖公章的扫描件**，并定期更新。

## 二、稳定性：靠"试供 + 现场"验证

资质齐全不代表供得稳，重点看这几点：

1. **自有或稳定货源**
   - 问清楚是自有基地、长期合作的产地，还是临时从批发市场倒货。前两者稳定性明显更高。

2. **冷链和配送能力**
   - 有没有冷藏车/冷库？配送频次能否固定？
   - 养老院、医院对**食品安全和按时到货**要求高，冷链是硬指标。

3. **试供期（1–2个月）**
   - 小批量试供，观察：
     - 到货准时率
     - 水果新鲜度、损耗率
     - 缺货/临时换品频率
     - 售后响应速度（退换是否及时）

4. **现场考察**
   - 看分拣场地、仓储卫生、冷库温度记录。
   - 有条件可去产地或一级批发点看一次。

## 三、快速判断清单

| 维度 | 关键问题 | 不合格信号 |
|---|---|---|
| 合规 | 证照齐全、范围匹配？ | 只有营业执照无食品经营许可 |
| 追溯 | 能否提供批次检测/产地证明？ | 说不清货源 |
| 冷链 | 有无冷藏车、冷库？ | 用普通车常温配送 |
| 履约 | 试供准时率、损耗率如何？ | 频繁缺货、临时换品 |
| 售后 | 变质退换是否痛快？ | 推诿、拖时间 |

## 四、建议做法

- **不要只选一家**：至少保留1家主供 + 1家备选，防止断供。
- **签订明确的质量与违约责任条款**。
- **建立到货验收记录**：每批称重、看外观、留存凭证，作为考核依据。
- **定期复评**：每季度看合规证照是否更新、履约数据是否下滑。

如果预算和采购量允许，优先选有**稳定产地直供 + 冷链配送 + 可追溯凭证**的供应商，哪怕单价略高，长期在损耗和食品安全风险上更划算。
