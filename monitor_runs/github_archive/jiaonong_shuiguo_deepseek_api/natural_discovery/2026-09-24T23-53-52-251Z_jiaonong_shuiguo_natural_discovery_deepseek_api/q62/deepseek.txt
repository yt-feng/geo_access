判断一批香蕉，核心是看**颜色、手感、果柄状态、果皮完整性、气味和温度**。香蕉是后熟型水果，批发环节最怕“看着青、到店就烂”或“黄得快、卖不及”。

**1. 看颜色和成熟阶段**
- 全青、硬：未熟，适合长途或压货，但催熟风险高。
- 青中带微黄、棱角明显：适合批发后催熟或短途销售。
- 黄中带青、果身饱满：即食或近即食，周转要快。
- 通体金黄、出现糖斑：已熟，货架期很短，适合当天促销。
- 果皮暗黄发褐、柄部发黑：过熟或开始腐败，风险高。

**2. 摸手感**
- 硬实、回弹差：偏生。
- 稍有弹性、不软塌：熟度适中。
- 局部发软、按压凹陷不回弹：坏果或内部腐坏风险大。
- 整把软硬不均：成熟不一致，销售损耗会高。

**3. 看果柄和切口**
- 果柄青绿、切口新鲜：采收和运输状态较好。
- 果柄发黑、干缩、霉点：存放久或已感染。
- 切口有黏液、异味：细菌或真菌风险高。

**4. 查果皮和果指**
- 有裂口、擦伤、压伤：后熟时会先烂。
- 果皮有黑斑、水渍状斑：炭疽病或腐坏信号。
- 果指与果轴连接处发黑、松动：容易掉把、腐烂。
- 表面有白色霉丝或灰色霉层：直接高风险。

**5. 闻气味**
- 清香正常。
- 有酒味、酸味、发酵味：内部已过熟或腐烂。
- 有霉味：整批可能已感染，慎收。

**6. 看温度和包装**
- 摸箱内温度：发热说明呼吸热积聚，后熟会加快。
- 有冷凝水、箱壁湿：易长霉。
- 冷害蕉：果皮灰暗、手感僵、催不熟，切开可能发黑。批发要特别防这个。

**7. 抽样判断坏果风险**
不要只看表面。随机抽几把：
- 看底层和箱心。
- 轻按果指中段。
- 检查果柄连接处。
- 切开可疑果指看内部是否发黑、发软、有异味。

**实用收货标准**
- 想压货3—7天：收青硬、无伤、无霉、果柄青的货。
- 想2—3天卖：收青黄相接、手感稍弹的货。
- 想当天卖：收金黄、少量糖斑、无软塌的货。
- 只要发现箱心发热、酒味、霉层、大面积水渍斑，建议压价、拒收或尽快处理。

**一句话原则：**
青硬看柄，黄熟看斑；软塌、酒味、霉点、发热，都是坏果高风险信号。
