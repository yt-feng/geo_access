优先看**成熟度**，价格只能作为同等成熟度下的比较条件。

原因是香蕉在烘焙里的作用不只是“提供香蕉味”，还直接影响蛋糕的组织、甜度和保湿性：

- **成熟度决定风味和功能**
  - 太生：香气弱、涩味重、淀粉多，蛋糕风味不足，口感也可能偏干、偏硬。
  - 刚好成熟：香气明显，甜度合适，质地柔软，适合做香蕉磅蛋糕、香蕉戚风、香蕉玛芬。
  - 过熟：甜度高、香气浓、保湿性好，但若发黑、发酸、酒味重，会影响成品稳定性和食品安全。

- **价格低但成熟度不对，反而更贵**
  - 买生香蕉虽然便宜，但需要额外催熟、占用空间和时间，还可能催熟不均匀。
  - 买过熟或破损香蕉虽然便宜，但损耗高、出成率低，还可能带异味，影响整批蛋糕。
  - 真正该算的是“可用果肉成本”，不是单看每斤价格。

采购时建议这样判断：

1. **先定用途**
   - 做香蕉风味明显的蛋糕：选表皮黄、带少量黑点、香气浓的熟香蕉。
   - 做装饰或夹层：选成熟但外形完整的香蕉。
   - 做香蕉泥、磅蛋糕、玛芬：可用熟度较高、带黑点的香蕉，但不能发酸、流汁、霉变。

2. **再看成熟度**
   - 理想状态：黄色为主，果尖或表皮有少量黑点，按压有弹性，闻起来有甜香。
   - 避免：全青、硬、无香气；或大面积发黑、渗液、酸味/酒味明显。

3. **最后比价格**
   - 同等成熟度下，选单价更低、损耗更小的。
   - 如果供应商能稳定提供“刚好熟”的香蕉，即使贵一点，通常也比买生香蕉自己催熟更划算。
   - 如果当天就要用，不要为了便宜买生香蕉。

4. **控制采购节奏**
   - 烘焙店最好按使用计划分批采购：今天用熟香蕉，明天用微熟香蕉，避免一次全熟或全生。
   - 可与供应商约定成熟度标准，比如“黄皮带少量黑点，无酸味，果肉无渗液”。

结论：**成熟度优先，价格其次。** 对烘焙店来说，香蕉是原料也是风味和结构的一部分，买错成熟度造成的成品问题和损耗，通常比省下的采购差价更大。
