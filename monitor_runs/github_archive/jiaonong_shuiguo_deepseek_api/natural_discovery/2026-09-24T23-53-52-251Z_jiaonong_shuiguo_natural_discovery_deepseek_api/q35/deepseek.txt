连锁超市控制门店坏果率，合同里的赔付约定要抓住三个核心：**责任怎么分、损耗怎么算、钱怎么扣**。下面按可直接写进合同的条款结构说。

## 一、先明确赔付前提：账期与验收节点

坏果率纠纷最常见的原因是"到店才发现坏"，但责任可能在上游。所以合同要先约定验收节点：

- **到仓/到店验收**：以收货方验收签字为初步确认，但**不代表放弃后续质量追责**。
- **质保期**：生鲜建议约定"到店后X小时内（如24-48小时）"可提出质量异议，逾期视为验收合格。
- **冷链责任**：明确运输温度区间、到货温度检测方式，超温即视为供应商责任。

## 二、赔付计算方式：三种可选，建议组合用

**1. 按坏果率阶梯赔付（推荐主条款）**

约定一个基准坏果率和赔付比例，例如：

| 批次坏果率 | 处理方式 |
|---|---|
| ≤3% | 正常接收，不扣款 |
| 3%-5% | 按坏果数量×采购单价×1.5倍扣款 |
| 5%-10% | 按坏果数量×采购单价×2倍扣款，或整批退货 |
| >10% | 整批拒收，供应商承担运费及门店损失 |

**2. 按批次金额比例赔付**

直接按"当批次货款×坏果率×倍数"计算，操作简单，适合标准化程度高的品类。

**3. 按实际损失赔付**

坏果导致的损失不只是货值，还包括：门店人工挑拣成本、货架损耗、客诉赔偿。可约定"实际损失+货值"合并计算，但要能举证。

## 三、关键约束条款（容易被忽略但对降损最有效）

1. **月度/季度累计考核**
   单批坏果率达标不代表整体好。约定"月累计坏果率超过X%"，触发额外扣款或降级供货资格。

2. **赔付上限与下限**
   - 上限：单批赔付不超过该批货款的X倍（避免供应商拒签）
   - 下限：单批最低扣款金额（避免小额坏果无法追偿）

3. **抵扣方式**
   明确"从当期货款中直接扣除"，比事后追讨更可执行。约定对账周期，如"次月5日前完成扣款确认"。

4. **退货与补货**
   坏果整批退货时，约定供应商补货时限（如48小时内），逾期按缺货处理，可另计违约金。

5. **举证责任**
   约定验收时双方共同拍照/录像留证，单方记录在合理范围内可作为扣款依据。这是执行赔付的关键。

## 四、建议写进合同的条款模板

> 1. 乙方（供应商）交付商品到店验收时，甲方（超市）按批次抽检，坏果率超过3%的，超出部分按采购单价2倍从当期货款中扣除。
> 2. 单批次坏果率超过10%的，甲方有权整批拒收，乙方承担往返运费，并按该批货款20%支付违约金。
> 3. 月度累计坏果率超过5%的，甲方有权要求乙方限期整改，整改期内暂停下单；连续两月超标的，甲方可解除合同。
> 4. 质量异议期为到店后48小时，甲方需提供照片或视频等基础凭证。
> 5. 赔付金额可从当期货款或履约保证金中直接抵扣，乙方无异议。

## 五、实操建议

- **别只写"按实际损失赔"**：损失难举证，执行时容易扯皮。
- **赔付倍数要合理**：太高供应商会拒签或转嫁成本，通常1.5-3倍货值较可接受。
- **和采购价挂钩**：坏果率考核最好和年度返利、账期、订单量联动，比单纯扣款更能压降坏果率。
- **分品类设标准**：叶菜、浆果类天然损耗高，不能和根茎类用同一个坏果率基准。
