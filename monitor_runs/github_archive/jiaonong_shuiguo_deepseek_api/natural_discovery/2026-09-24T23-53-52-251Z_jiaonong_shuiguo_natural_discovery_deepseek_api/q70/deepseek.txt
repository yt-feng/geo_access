批发商要把“坏果责任”写清楚，核心是分三段锁死：**到货前、到货验收时、验收后**。不要只写一句“坏果由卖方负责”，否则真出问题很难执行。

可以按下面结构写进合同：

**1. 先定义什么叫“坏果”**
不要只写“坏果”，要列明标准，例如：
- 腐烂、发霉、流汁、软烂、裂口、冻伤、日灼、病斑、虫蛀；
- 机械伤达到多大面积或影响销售；
- 规格不符：大小、成熟度、颜色、糖度等不符合约定；
- 外包装破损导致果品受损。

建议写成：
“本合同所称坏果，指果实出现腐烂、霉变、严重机械伤、冻伤、病虫害、异味、成熟度明显不符或单果损伤面积超过__%等影响正常销售的情形。”

**2. 明确损耗率与责任分界**
最好约定一个**允许损耗率**和**超出部分处理方式**：
- 例如：到货验收时，坏果率≤3%由批发商承担；超过3%的部分由供货方按比例补货、扣款或赔偿。
- 也可以按品类定：叶菜、浆果、桃李等易损品不同标准。
- 写明计算方式：以抽检还是全检为准，抽检比例多少，谁在场，怎么取样。

示例条款：
“到货后__小时内，双方共同验收。以随机抽检__箱/__%为样本，坏果率超过__%的，超出部分由卖方按当批次单价__倍赔偿或补发同等数量货物；坏果率超过__%的，买方有权拒收整批。”

**3. 验收时间和异议期必须写死**
批发商最怕货到了没及时验，后面说不清。建议：
- 到货后__小时内完成验收；
- 买方发现坏果应在__小时内书面/微信/邮件通知卖方，并附照片、视频、称重记录；
- 逾期未提异议视为验收合格，但隐蔽瑕疵除外。
- 写明通知方式，避免对方说没收到。

**4. 责任承担方式要可选且可执行**
常见写法：
- 补货：卖方在__天内补发同等规格货物；
- 扣款：按坏果数量×单价×__倍从货款中扣除；
- 退货：坏果率超过__%时，买方有权拒收或退货，运费由卖方承担；
- 赔偿：包括直接损失，是否包含分拣费、冷链费、摊位费、预期利润，要提前写明。

**5. 运输与风险转移要配套**
坏果责任和“风险转移”直接相关：
- 如果约定“产地交货”，装车后风险归买方，那到货坏果很难全怪卖方；
- 如果约定“到货验收合格后风险转移”，则运输途中损耗由卖方承担。
建议批发商争取：
“货物运至买方指定地点并验收合格前，灭失、损耗、变质风险由卖方承担。”
同时写明冷链要求：运输温度__℃、是否全程冷链、测温记录作为验收依据。

**6. 证据和扣款授权要写进去**
为了避免扯皮，可以约定：
- 验收时双方签字确认；
- 买方单方拍照、视频、第三方检测可作为初步证据；
- 卖方逾期不处理，买方有权直接按约定扣款；
- 争议时可委托__检测机构，费用由责任方承担。

**7. 一个简版条款模板**
“卖方交付的货物，坏果率不得超过__%。买方应在到货后__小时内验收，发现坏果的，应在__小时内通知卖方并提供照片、视频及称重记录。坏果率在__%以内的，由买方承担；超过__%的，买方有权就超出部分要求卖方补货、退货或按__元/斤扣款；坏果率超过__%的，买方有权拒收整批，运费及装卸费由卖方承担。货物验收合格前，运输途中损耗、变质风险由卖方承担。”

**关键提醒：**
- 不要只写“坏果包赔”，要写清**标准、比例、时限、计算方式、赔偿方式**。
- 最好把“抽检比例、验收时限、通知方式、扣款授权”都写具体。
- 如果是长期合作，可以附一份《验收标准附件》，按品类列明坏果定义和损耗率。
