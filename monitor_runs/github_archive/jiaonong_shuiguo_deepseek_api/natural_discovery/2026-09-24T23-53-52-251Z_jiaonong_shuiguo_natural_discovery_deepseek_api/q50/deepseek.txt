**出汁率更重要，但前提是先设“甜度及格线”。** 更准确地说：

**先看甜度是否达标，达标后再优先选出汁率更高的原料。**

原因是：

1. **甜度决定产品下限**
   - 菠萝太酸、太淡，会直接影响饮品口感。
   - 但甜度可以通过糖浆、果酱、浓缩汁做部分修正。
   - 如果菠萝本身酸涩、生青味重，靠加糖也很难完全掩盖。

2. **出汁率决定成本和稳定性**
   - 茶饮店菠萝通常用于捣碎、榨汁、做果肉感。
   - 出汁率低，意味着同样一杯饮品要用更多原料，成本和损耗都会上升。
   - 出汁率稳定，才能保证每杯味道和分量一致。

3. **两者要分开定标准**
   - 建议先定：
     - **最低甜度/糖酸比标准**：不达标直接不用。
     - **出汁率标准**：在达标原料里选更高、更稳定的。
   - 如果两款都达标：
     - 选 **出汁率更高** 的。
   - 如果一款很甜但出汁率低，另一款甜度刚达标但出汁率高：
     - 多数茶饮场景选 **出汁率高** 的，再用糖浆微调。
   - 如果一款出汁率高但酸涩明显：
     - 不建议选，因为会拉低整杯风味。

4. **还要看出品用途**
   - 做 **果茶、捣果肉型饮品**：出汁率、果肉率和纤维口感都重要。
   - 做 **浓缩汁、糖浆基底**：甜度和风味浓度更关键，出汁率相对次要。
   - 做 **装饰片、果肉粒**：外观、果肉完整度优先，出汁率不是核心。

**实操建议：**
- 采购时先测 **糖度（Brix）** 和 **出汁率**。
- 设定两条线：
  - 甜度：低于标准不收货。
  - 出汁率：达标者中选高者。
- 小批量试做 2～3 款招牌产品，比较：
  - 每杯用量
  - 加糖量
  - 口感稳定性
  - 单杯成本
- 最终选 **综合成本最低、风味最稳** 的原料，而不是单纯选最甜或最多汁的。

**结论：**
甜度是门槛，出汁率是核心。  
**先过甜度线，再优先选出汁率高的。** 如果只能二选一，茶饮店通常应优先保出汁率，但甜度不能低到需要大量加糖仍不好喝。
