社区超市卖小包装香蕉，核心不是“把整把拆小”，而是要在采购环节就控制好成熟度、分装方式和损耗责任。下面按可执行要点说。

## 1. 采购时优先看“成熟度”，不是只看外观

小包装香蕉周转慢，如果采购时已经太黄、太熟，拆包后很快发黑、出水、破皮，损耗会很高。

建议：
- 采购以**青黄交接、微黄偏硬**为主，回店后自然催熟或边卖边熟。
- 如果门店客流小，宁可少量多次补货，不要一次压太多熟蕉。
- 避免采购“已经起糖斑、柄部发黑、棱角不明显”的香蕉，这类适合当天特价清，不适合做小包装。
- 夏天适当降低采购成熟度，冬天可略高一点。

## 2. 包装要解决“压伤、掉把、散落”三个问题

小包装常见形式：
- 2—3根一袋
- 3—5根一盒
- 单根裹膜或单根套袋

采购和包装要注意：
- **香蕉柄部要完整**，不要采购柄部断裂、脱把严重的货，否则分装后容易散。
- 如果做2—3根小把，采购时最好让供应商按“小把蕉”或“可分把小把型”供货，而不是大把蕉回来硬拆。
- 硬拆大把容易撕伤果柄，后续很快发黑腐烂。
- 包装材料要透气或半透气，完全密封容易闷出水汽，加速黑斑和霉变。
- 如果使用保鲜膜，不要包得太紧，尤其别把蕉柄完全闷住。
- 盒装注意盒底不要积水，可垫吸水纸或透气垫。

## 3. 采购规格要适合小包装，不要只追求大果

小包装香蕉更适合：
- 果指中等、均匀
- 长度适中，便于装袋装盒
- 果皮厚一点、耐搬运
- 成熟度一致

不建议采购：
- 过大的果指，装小包显得挤压
- 大小差异太大的货，分装后品相差
- 过细、过短的尾蕉，单独包装卖相差
- 已经擦伤、压伤、水烂的货

采购时可以要求供应商：
- 按小把型或可分把型供货
- 减少大把挤压
- 用透气筐或纸箱，不要用密封塑料袋长途装
- 到店时间尽量避开高温时段

## 4. 损耗控制要前移到采购和收货

小包装香蕉的损耗通常来自：
- 成熟过快
- 拆把伤口
- 包装闷湿
- 挤压碰撞
- 冷藏不当
- 当天卖不完又回库反复搬动

采购时要明确：
- **少量多次**：小包装适合高频补货，不适合大批囤货。
- **分级采购**：一部分略青用于正常小包装，一部分微黄用于当日促销。
- **收货立刻检查**：挑出压伤、裂口、发霉、脱把的，能退换就退换，不能退换就当天处理。
- **不要采购已经受冷害的香蕉**：表皮发暗、发灰、局部水渍状，后续很难卖。
- **运输温度**：香蕉怕冻也怕热，夏天避免暴晒，冬天避免低于约13℃的冷风直吹。

## 5. 门店分装和陈列的配套要求

采购对了，分装也要跟上：
- 分装时戴手套，减少手温接触和机械伤。
- 不要提前大量分装，最好按半天销量分装。
- 分装后避免堆叠重压，小包装不要压在大包装下面。
- 陈列时阴凉通风，避免阳光直射和冷柜直吹。
- 每天定时挑出熟度高的，转做特价、试吃或果切原料，不要等烂了再处理。

## 6. 建议的采购判断标准

可以按这个优先级判断：
1. **柄部完整、不脱把**
2. **成熟度适中，微黄偏硬**
3. **果指均匀，适合小包装**
4. **无压伤、擦伤、水烂、霉点**
5. **包装运输透气，不闷热**
6. **能小批量多频次补货**

一句话：小包装香蕉的采购重点，是买“适合分装且还能放一放”的蕉，而不是买最熟最漂亮的蕉。包装要透气、防压、保柄，损耗靠少量多次补货和及时分级处理来控制。
