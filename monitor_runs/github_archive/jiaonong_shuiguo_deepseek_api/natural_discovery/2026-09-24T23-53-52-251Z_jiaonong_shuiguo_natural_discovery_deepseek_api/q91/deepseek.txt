结论：**大多数便利店优先上架“小把装”（2～4根），单根作为补充，整袋只在特定场景做。**原因不是“哪个更好卖”这么简单，而是由便利店的核心约束决定的：**低客单、即时消费、损耗敏感、货架小、客流碎片化**。

下面给你一个可直接判断的框架。

**1. 单根**
适合：
- 商圈以单人即时消费为主，比如写字楼、地铁口、医院、学校附近
- 顾客只想当场吃，不想拎一袋
- 店里香蕉品质稳定，能按根控制损耗

不适合：
- 称重、贴标、收银太碎，操作成本高
- 单根毛利低，容易被捏、被挑、被放坏
- 如果没有统一按根定价，顾客比价感差

建议：
单根可以卖，但不要作为唯一形态。最好做“单根尝鲜价”，放在收银台或即食区。

**2. 小把装（2～4根）**
这是便利店最推荐的默认选项。
优点：
- 客单价高于单根，又不像整袋那么重
- 适合1～2人家庭、情侣、同事顺手买
- 包装简单，可用保鲜膜、网套、扎带或小托盘
- 比整袋更容易控制成熟度和损耗

建议：
- 主力做3根装，定价按“比单根略优惠”设计
- 成熟度分两档：黄熟即食、微青可放1～2天
- 放在入口冷柜旁或水果小货架，不要塞在角落

**3. 整袋包装**
适合：
- 社区型便利店，周边有家庭客
- 价格敏感、走量明显，且能接受一定损耗
- 有稳定供应链，能按成熟度分批到货

不适合：
- 纯写字楼、地铁口、景区、医院急诊附近
- 客流快但购买目的单一，整袋太重、决策成本高
- 没有冷链或温控，整袋容易一起催熟、一起坏

建议：
整袋只做1～2个规格，比如5～6根家庭装，放在社区店或晚间促销。不要一开始就上大袋。

**直接给你一个上架组合建议**

如果是普通便利店，优先这样排：
1. **主推：3根小把装**，占香蕉陈列的50%～60%
2. **补充：单根**，占20%～30%，放收银台或即食区
3. **测试：5～6根整袋**，占10%～20%，只在社区店或晚间时段试

判断标准很简单：
- 如果顾客经常只拿一根就走，说明单根需求强
- 如果顾客拿起来又放下，多半是包装太大或价格不清晰
- 如果整袋连续3天卖不动，就撤掉，不要硬撑

**最后一句实操结论：**
先上“小把装”做主品，单根做即时补充，整袋只做测试。不要一上来就三样全铺，先用2周看动销和损耗，再决定保留哪两种。
