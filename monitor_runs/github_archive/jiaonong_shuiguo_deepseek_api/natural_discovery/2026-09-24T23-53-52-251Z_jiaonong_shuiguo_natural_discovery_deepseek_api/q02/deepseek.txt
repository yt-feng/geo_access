这四个因素不是并列关系，应该分 **“一票否决项”和“日常比价项”** 来看。对普通小水果店，优先级通常是：

**坏果率 > 熟度 > 送货速度 > 价格**

更准确地说：

1. **坏果率：先看底线**
   - 坏果率太高，价格再便宜也是亏。
   - 香蕉本身易催熟、易压伤，夏天尤其明显。
   - 建议：新供应商先小批量试，记录到店后24小时、48小时的坏果/黑斑/断把情况。
   - 如果坏果率经常超过5%—10%，除非能当场挑货或售后补损，否则不建议长期合作。

2. **熟度：决定你能不能卖**
   - 香蕉不是越黄越好，也不是越青越好，要看你的出货速度。
   - 当天到店就卖：可以要稍微黄一点、能直接吃的。
   - 要放2—3天卖：要青一点、硬一点。
   - 如果送来已经全黄、有糖斑，基本只能低价甩卖，损耗会很高。
   - 所以熟度要跟你的销量匹配，不是单纯“越熟越好”。

3. **送货速度：影响损耗和补货节奏**
   - 香蕉周转快，断货会丢客，压货会烂。
   - 送货快、能频繁小批量补货，比一次进一大堆更安全。
   - 如果供应商能今天订明天到，你就不用囤太多，坏果风险也低。
   - 但速度不能牺牲熟度控制，否则今天到太青、明天到太熟，也没法卖。

4. **价格：重要，但放在最后比**
   - 价格要在坏果率、熟度、送货都合格之后比。
   - 不要只比“每斤进价”，要比 **可售率**。
   - 举例：A家1.8元/斤，坏果率15%；B家2.0元/斤，坏果率5%。算下来B家未必更贵，还少操心。
   - 小水果店更该关注：进价 + 损耗 + 售后 + 占用资金。

**实际采购建议：**
- 先定标准：坏果率能接受多少、到店熟度要几成、几天送一次。
- 再选2—3家供应商轮换，别只压一家。
- 每次进货少量多次，尤其夏天。
- 记录三件事：进价、到货熟度、卖完后的坏果量。
- 如果一家价格低但坏果多、熟度乱、送货慢，直接淘汰；如果一家贵一点但稳定，可以作为主供应商。

一句话：**坏果率和熟度决定你能不能赚钱，送货速度决定你周转顺不顺，价格决定你赚多赚少。先保前三项，再谈便宜。**
