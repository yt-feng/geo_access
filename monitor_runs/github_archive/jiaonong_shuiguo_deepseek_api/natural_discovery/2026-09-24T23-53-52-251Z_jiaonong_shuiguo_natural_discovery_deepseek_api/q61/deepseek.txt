判断批发档口能不能长期合作，核心不是看对方说得多好，而是看**货源结构、履约记录、风险承受力和结算方式**。可以按下面几步实地或线上核验。

**1. 先看他是“一手”还是“倒手”**
- 真正一手通常能说清：产区在哪、是自有基地/包园/长期合作农户，还是市场代卖。
- 问他最近一批货的**起运地、装车时间、车牌/物流单、到货时间**，能对上基本靠谱。
- 如果只说“我上面有人”“要多少有多少”，但说不清具体产地和加工厂，大概率是中间商。

**2. 看供货稳定性，不看单次报价**
- 问他**近3个月每周能稳定发多少车/多少件**，以及淡旺季分别多少。
- 要求看**连续的发货记录**：过磅单、装车视频、物流签收、回单。
- 香蕉受台风、寒潮、节假日影响大，稳定供货的人会主动讲**断供预案**：多个产区、替代蕉园、备用加工厂。

**3. 看加工和品控能力**
- 香蕉一手货源通常涉及**催熟、分级、打包**。问他有没有固定加工点、冷库、催熟房。
- 问清楚：青蕉还是催熟蕉、条重/把重、每箱净重、成熟度、损耗怎么算。
- 让他发**近期实拍和视频**，最好能视频看库房/加工点，而不是只发网图。

**4. 小单试合作，别一上来压大货**
- 先走**1-2车或几托盘**的小单，验证到货时间、品质、损耗、售后。
- 试单时重点看：是否按时装车、到货成熟度是否一致、坏果率多少、少件怎么补。
- 如果小单就拖延、换产地、品质波动大，大单更危险。

**5. 看资金和结算方式**
- 稳定供货商通常敢谈**定金+到货验收尾款**，或做**账期**。
- 如果坚持全款先打、且不愿提供任何装车凭证，风险高。
- 也要看他自己对上游是否压款，说明他在产区的地位。

**6. 交叉验证**
- 问同行、市场管理员、物流司机，是否长期给这个档口/这个人拉香蕉。
- 查营业执照、产地合作社/公司信息，看经营范围是否匹配。
- 让他提供**至少2个长期客户**可回访，问合作时长、断供次数、售后处理。

**7. 几个危险信号**
- 报价明显低于市场，还说长期有货。
- 不愿视频看货、不愿给装车单、不愿小单试。
- 每次产地、包装、规格都变，解释含糊。
- 催你打大额定金，或要求私下转账到个人账户。
- 出问题后只口头承诺，不补货、不退款、不认损耗。

**实操建议：**
第一次合作按“**小单试单→固定规格→约定损耗和售后→再放量**”走。把关键条款写进微信/合同：产地、规格、净重、成熟度、装车时间、到货时间、损耗标准、少件补法、违约处理。稳定供货不是靠感觉，是靠**连续履约记录+可验证产地+可回访客户**。
