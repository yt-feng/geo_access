重要，而且往往是多门店水果品质能不能“统一”的第一道关口。

如果供应商没有稳定、清晰、可执行的分级标准，多门店超市通常会遇到几个直接问题：

1. **同款水果不同门店品质不一致**
   同一供应商同一批次，可能 A 店拿到的大果多、B 店小果多；或者熟度、糖度、外观差异明显。门店会各自投诉，采购也很难追责。

2. **采购验收没有统一尺子**
   没有分级标准，验收就容易靠个人经验。有人觉得“还行”，有人觉得“不合格”，最后变成扯皮。尤其是多门店，店长、理货、收货员的判断标准很难天然一致。

3. **定价和陈列会混乱**
   一级果、二级果如果混在一起，既影响高端陈列，也影响促销处理。多门店如果有的按精品卖，有的按普通品卖，价格体系会被打乱。

4. **损耗和客诉会上升**
   分级不清，往往意味着成熟度、大小、瑕疵率不稳定。门店容易出现“今天卖得很好，明天一堆坏果”的情况，客诉和报损都会增加。

5. **供应商管理失去依据**
   没有分级标准，就无法稳定考核供应商：到底是供应商问题、物流问题，还是门店储存问题，很难界定。

所以，多门店超市要做水果统一品质，供应商分级标准不是“重要不重要”的问题，而是基础条件。更实际的做法是：

- 和核心供应商约定**可量化的分级标准**：品种、产地、规格、单果重、色泽、糖度、成熟度、瑕疵率、允许损耗等。
- 标准要**按品类分别制定**，不能用一套标准套所有水果。
- 验收环节要能**抽检和记录**，比如糖度抽测、大小抽检、瑕疵比例。
- 对多门店要统一**收货口径**，必要时总部把验收标准做成图文卡或视频，减少门店各自理解。
- 分级要和**采购价、门店售价、陈列等级、促销处理**挂钩。

简单说：供应商分级标准越清晰、越可执行，多门店水果品质才越可能统一；否则只能靠运气和门店个人经验，很难长期稳定。
