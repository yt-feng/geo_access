大型超市对水果供应商的要求，通常拆成两条线：**食品安全合规能力**（准入底线）和**物流交付能力**（稳定供货）。以下是可对照自查的清单。

## 一、食品安全能力（准入必备）

**1. 资质与合规**
- 营业执照、食品经营许可证（或食品生产许可证，视加工环节而定）
- 种植/加工基地的相关备案或认证
- 若进口：进出口资质、海关报关和检验检疫证明

**2. 检测与追溯**
- 每批次可提供农残检测报告（第三方或自检）
- 建立批次追溯体系：从基地→加工→仓储→配送可倒查
- 能配合超市做定期抽检和飞行检查

**3. 质量分级与验收标准**
- 能按超市标准做分级（大小、糖度、外观、成熟度）
- 明确残次率上限、拒收规则
- 有分级包装能力，避免“统货”交付

**4. 仓储与温控**
- 采后预冷能力（这是水果保鲜的关键环节）
- 冷库分级温控（不同水果不同温度区）
- 防虫、防鼠、防交叉污染管理

**5. 管理体系**
- 最好有 HACCP、ISO22000、GAP 等体系认证（大超市常作为加分或硬性项）
- 有食品安全责任人制度和召回机制

## 二、物流交付能力

**1. 冷链运输**
- 全程冷链车（或保温车+控温措施），能记录运输温度
- 不同品类分区运输，避免串味和压伤

**2. 配送时效与频次**
- 能按超市要求做到日配或多频次配送
- 有稳定的发车计划和到店时间承诺
- 高峰期（节假日、促销）能加量保供

**3. 订单与信息系统**
- 能对接超市的订单系统（EDI/API 或至少规范的订单流程）
- 有库存和到货数据反馈能力

**4. 损耗控制**
- 包装和装卸规范，降低磕碰损耗
- 有到货合格率和损耗率的可量化指标

**5. 应急能力**
- 有备用车辆、备用冷库、替代产地
- 能应对天气、疫情、交通中断等突发情况

## 三、大超市通常重点看的几项

实际谈判和审核中，最容易被卡的是这几条：
1. **农残检测报告能不能每批都给**
2. **有没有预冷和全程冷链**
3. **能不能稳定日配、按时到店**
4. **出问题时能不能快速追溯和召回**
5. **分级标准能不能达到超市要求，而不是自己定标准**

## 四、给你的判断建议

如果你是在评估自己是否够格：
- **只做本地小超市**：资质+检测报告+基本冷链通常够用
- **做全国性大型连锁**：需要体系认证、预冷能力、信息系统对接、稳定多频次配送
- **做高端/进口水果**：还要加海关合规、更高等级冷链和成熟度管理
