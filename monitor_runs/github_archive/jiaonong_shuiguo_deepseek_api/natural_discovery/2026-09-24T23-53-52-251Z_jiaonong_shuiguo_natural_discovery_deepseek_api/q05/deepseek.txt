结论：**优先让顾客自己挑整果，门店现场按需去皮；不要提前大量去皮陈列。** 少量“去皮好、即买即走”的可以保留，但只作为补充。

理由和做法如下：

1. **整果更适合顾客挑**
   - 菠萝成熟度差异大，顾客通常看外观、闻气味、掂重量。
   - 让顾客自己挑，购买决策更快，也减少“你帮我挑的不好吃”的售后争议。
   - 整果耐放，损耗比去皮果低很多。

2. **去皮果只能少量做，不能大量提前做**
   - 去皮后水分流失快、氧化变色、易污染，卖相和口感下降。
   - 如果提前去皮一堆，当天卖不掉基本就是损耗。
   - 适合做“爆款时段”或“赶时间顾客”的补充，比如切好装盒、冷藏陈列、标注去皮时间。

3. **最好的模式：整果自选 + 现场免费/收费去皮**
   - 顾客挑整果，称重后门店现场去皮、切块、装盒。
   - 这样既保留挑选权，又解决“不会削、嫌麻烦”的问题。
   - 如果人手不够，可以设“去皮加1元”或“买两个免费去皮”，把人工成本覆盖掉。

4. **陈列建议**
   - 整果区：堆头陈列，按大小/品种分区，标价清晰。
   - 去皮区：只放少量，冷藏、覆膜、当天清货。
   - 试吃：切一小盘插牙签，比提前去皮整果更好卖。

5. **什么时候可以多卖去皮果**
   - 写字楼、学校、车站等赶时间场景。
   - 下午下班高峰前1—2小时少量切。
   - 已经熟透、必须尽快处理的果，才适合去皮装盒打折卖。

简单说：**整果是主力，顾客自选；去皮是服务，现场做、少量做。**
