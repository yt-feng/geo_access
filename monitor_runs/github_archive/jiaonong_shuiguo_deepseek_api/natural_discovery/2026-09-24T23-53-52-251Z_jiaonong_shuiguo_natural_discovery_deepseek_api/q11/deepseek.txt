会有影响，但影响程度取决于你卖的是“整箱批发”还是“拆散零售”。

**1. 整箱走批发/团购**
影响较小，但价格会被压。采购方通常默认整箱有大小差异，只要不是烂果、青熟不均、缺重太离谱，一般能接受。但如果大小差太多，对方会认为你以次充好，压价或退货风险高。

**2. 拆散零售/按根卖**
影响明显。顾客挑香蕉时优先拿大小均匀、颜色一致的，剩下的大果或小果容易滞销、变黑，最后损耗算你的。周边水果店多、竞争大时，大小不均会直接降低购买意愿。

**3. 做果切、奶昔、烘焙原料**
影响最小。只要成熟度合适、口感正常，大小不影响出杯或出餐，这种渠道可以消化不匀称的货。

**可执行建议：**
- 采购时先明确用途：零售就尽量选大小均匀的箱，果切/加工可以放宽。
- 如果已经进了大小不一的货，按大小分级卖：大果、中果、小果分开定价，别混在一起让顾客挑。
- 小果可做特价、搭配促销；大果可单卖或做礼盒；品相差的尽快转果切。
- 抽检几箱，看大小差异比例。如果超过约三成明显不匀，零售端就比较难卖，采购价要压低。

简单判断：**零售怕不匀，批发能接受，加工无所谓。**
