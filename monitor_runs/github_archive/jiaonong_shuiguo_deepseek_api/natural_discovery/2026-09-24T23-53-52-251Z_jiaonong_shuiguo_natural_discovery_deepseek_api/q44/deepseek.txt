判断供应商售后是否稳定，不能只听口头承诺，要在合作前和合作中用具体动作验证。可以从这几个方面入手：

**1. 合作前：问清并测试售后承诺**
- 明确索赔条件：破损、腐烂、重量不足、成熟度不符、到货延迟分别怎么赔、赔多少、多久到账。
- 问响应时效：发现问题后多久回复、多久给方案、多久补货或退款。让对方写进合同或订单备注。
- 索要历史凭证：近几个月的售后处理记录、赔付记录、客户名单（可侧面回访）。

**2. 用小单试单验证**
- 先下小批量订单，故意制造一个真实售后场景（如到货有压伤、催熟不均），观察对方反应速度和解决态度。
- 记录首次响应时间、方案是否合理、是否主动跟进，而不是只承诺不落地。

**3. 看合同和票据是否规范**
- 合同里写明售后条款、违约责任、争议解决方式。
- 要求每批货有质检单、重量单、物流单，售后时有据可依，避免扯皮。

**4. 合作中持续观察**
- 统计每次售后的响应时长、解决率、重复问题率。如果同一问题反复出现且解决慢，说明售后体系不稳。
- 关注对接人是否固定。频繁换人、找不到负责人，通常意味着内部管理混乱。
- 节假日、旺季、天气异常时是否还能及时响应，这是检验稳定性的关键节点。

**5. 侧面打听**
- 问同行、批发市场其他采购商对该供应商的评价，尤其是出问题后的处理口碑。
- 看供应商是否有稳定的仓储、冷链和客服团队，而不是只有销售。

**简单判断标准：**
- 好：承诺写进合同，试单售后24小时内响应，有明确赔付，主动跟进。
- 差：只口头保证，出问题推给物流或天气，拖延、压价、不补货。

建议至少试单1-2次、观察1个月再放量，别一上来就大额采购。
