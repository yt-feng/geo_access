评估水果供应商的仓配覆盖，核心是判断它能否稳定、低成本地把货送到你每个门店，而不是只看它宣传的“覆盖全国”。可按下面几步做。

**1. 先明确你的门店需求画像**
- 门店清单：城市、地址、周边交通限制（如货车限行、卸货时间窗）。
- 单店需求：日均/峰值订货量、SKU数、包装规格、温层（常温/冷藏/冷冻）。
- 时效要求：是次日达、当日达，还是允许隔日/周配。
- 验收要求：是否需要拆零、分拣到店、退换货处理。

**2. 把供应商仓配能力拆成四个可核验维度**
- **仓网位置**：它在哪些城市有仓？是中心仓、区域仓还是前置仓？距离你门店的直线/实际运输距离。
- **配送半径与时效**：每个仓承诺覆盖多远、多久送达，是否写进合同或SLA。
- **运力类型**：自营车队、外包、第三方快递/零担？水果怕压怕冻，是否用冷链车或保温箱。
- **末端能力**：能否进市区、进商场、进地下车库，能否按门店预约时间送达。

**3. 做覆盖匹配，而不是听“覆盖”**
把门店按城市分组，逐一对照供应商仓的位置：
- 门店在仓的常规配送圈内：可视为强覆盖。
- 门店在边缘：要问清时效、加价、是否每周只配几次。
- 门店在圈外：要么中转、要么供应商转包，成本和损耗都会上升。

**4. 重点评估水果特有的风险**
- 温控：不同水果对温度敏感，仓配全程是否有温控记录。
- 损耗：运输时长、装卸次数、包装方式都会影响损耗率。
- 库存周转：水果保质期短，供应商在你门店城市是否有安全库存。
- 季节波动：旺季、节假日、极端天气时运力是否够。

**5. 用数据验证，而不是只靠承诺**
- 要求提供：仓网清单、配送范围图、SLA、历史准时率、损耗率、异常处理记录。
- 做试运行：选3—5家典型门店，跑2—4周，记录准时率、到货温度、损耗、缺货率、退换货响应。
- 算总成本：不只比运费，还要算起订量、加急费、损耗、门店等待人工、缺货损失。

**6. 给出可判断的结论标准**
可以按门店覆盖率、时效达标率、损耗率、单店履约成本四项打分：
- 强覆盖：核心城市有仓，次日达稳定，损耗可控，末端能进店。
- 弱覆盖：依赖中转或零担，时效波动大，水果损耗高，末端常出问题。
- 不建议合作：门店所在城市无仓、无稳定运力，或只能靠临时调货。

**7. 实操建议**
- 不要选一家供应商覆盖所有城市，可按区域选2—3家，降低单点风险。
- 合同里写清：配送时效、温控标准、损耗赔付、缺货补货、旺季运力保障。
- 建立月度评分：准时率、损耗率、缺货率、客诉率，连续不达标就调整份额。

一句话：**评估水果供应商仓配，关键不是看它“能到多少城市”，而是看它在你每个门店所在城市，能否稳定、温控、低损耗、按你要求的时间送到店。**
