夫妻店第一次找水果供货商，建议把“试单”当成一次小规模压力测试：不是看对方能不能发货，而是看他能不能稳定、按约定、少扯皮地供货。下面按品类和流程给你一套可执行的方法。

## 一、先定试单原则

1. **不要一次只找一家**  
   同时联系 3 家左右：本地批发市场档口、生鲜配送商、产地/一级批发商各一类。第一次都只下小单。

2. **试单量要小**  
   每家每品先拿 1～2 箱，或者按你日常 1～2 天销量拿。不要因为“便宜”一次压太多。

3. **先谈清楚再下单**  
   重点问：能不能送货、几点送、坏果怎么赔、是否支持退换、账期还是现结、起送量多少。

4. **用同一标准比**  
   同一时间、同一品类、同一规格去比三家，不然价格没有意义。

## 二、三个常见品类怎么试

### 1. 香蕉
香蕉最容易暴露供货商水平，因为它涉及熟度、催熟、损耗。

试单重点：
- **熟度**：你店里想卖几天？要青一点还是黄一点。第一次建议拿“可放 2～3 天”的熟度，不要拿当天必须卖完的。
- **规格**：问清是几斤装、每箱几把、单根大概多重。
- **伤果**：看有没有压伤、黑斑、断把、水烂。
- **催熟方式**：如果对方说“已经催好”，你要问还能放几天。
- **补货频率**：香蕉最好 2～3 天补一次，不要一次进太多。

试单判断：
- 到店后 24 小时是否大面积变黑、发软？
- 顾客是否挑剩很多？
- 第二天再向同一家补一小单，看他是否还能稳定给同样熟度。

### 2. 苹果
苹果相对耐放，重点看等级、大小、口感、碰伤。

试单重点：
- **规格**：70、75、80、85 果，还是统货？大小混不混？
- **品种**：红富士、嘎啦、冰糖心等，要明确，不要只听“苹果”。
- **外观**：有没有碰伤、虫眼、裂口、打蜡过重。
- **口感**：自己切一个试吃，脆度、甜度、酸度是否适合你周边顾客。
- **箱重**：毛重还是净重？有没有底层小果、纸板加重？

试单判断：
- 一箱里坏果超过 3～5 个，就要警惕。
- 大小是否均匀，决定你能不能按个卖或按斤卖。
- 放 5～7 天后损耗是否明显。

### 3. 橙子
橙子重点看水分、皮厚、酸甜度、是否干瘪。

试单重点：
- **品种和产地**：脐橙、冰糖橙、血橙等要写清。
- **规格**：直径多少、几斤箱、净重多少。
- **新鲜度**：皮是否发皱、蒂是否干枯、有没有霉点。
- **口感**：切开试吃，汁水多不多，酸不酸。
- **损耗**：橙子容易有压伤和霉变，第一箱要翻底看。

试单判断：
- 如果底部有软果、霉果，说明分拣或仓储有问题。
- 如果口感偏酸，先别大量进，看周边顾客接受度。
- 放 3～5 天看失水情况。

## 三、试单具体流程

### 第 1 步：列需求
写清楚：
- 品类：香蕉、苹果、橙子
- 规格：几斤箱、什么等级、什么品种
- 数量：每品 1～2 箱
- 送货时间：比如早上 6～8 点
- 结算：现结还是周结
- 售后：坏果怎么赔

### 第 2 步：找 3 家报价
可以问：
- 本地批发市场档口
- 生鲜配送平台/本地配送商
- 产地或一级批发商

不要只问价格，要问：
- 起送量
- 配送费
- 是否开发票
- 坏果赔付比例
- 能不能固定时间送

### 第 3 步：同一时间下单
尽量同一天到货，方便对比：
- 实际净重
- 外观
- 口感
- 坏果数量
- 送货是否准时
- 沟通是否顺畅

### 第 4 步：记录数据
建议做个简单表：

| 供货商 | 品类 | 规格 | 报价 | 净重 | 坏果数 | 口感 | 送货 | 售后 |
|---|---|---|---|---|---|---|---|---|
| A | 香蕉 | 20斤/箱 |  |  |  |  |  |  |
| B | 苹果 | 80果 |  |  |  |  |  |  |
| C | 橙子 | 70mm |  |  |  |  |  |  |

### 第 5 步：二次补单
第一次满意不代表稳定。  
隔 2～3 天再向同一家补一次小单，看：
- 品质是否一致
- 是否临时缺货
- 是否换规格
- 送货是否还准时

### 第 6 步：定主次供应商
最后不要只留一家：
- **主供货商**：价格、品质、送货最稳的
- **备用供货商**：防止主供缺货或涨价
- 每个品类最好有 1 主 1 备

## 四、谈价和售后要问死

第一次合作，下面这些话要提前确认：

1. **“这箱是净重还是毛重？”**
2. **“坏果超过几个可以赔？”**
3. **“是拍照赔还是下次补货？”**
4. **“当天送还是隔天送？”**
5. **“临时加单能不能送？”**
6. **“节日涨价怎么算？”**
7. **“如果品质不对，能不能退？”**

最好微信文字确认，不要只口头说。

## 五、夫妻店实操建议

- 香蕉：少量多次，别囤。
- 苹果：可以稍多，但先试口感。
- 橙子：先试一箱，重点看底部和水分。
- 第一次试单总金额控制在你能承受的范围内，比如几百元。
- 不要因为单价便宜 5 毛就选一家售后差的。
- 最终看的是：**到店损耗 + 顾客复购 + 你的时间成本**，不是单纯进货价。

一句话：  
**每家先小单试，三个品类分开比，重点看坏果、净重、口感和送货稳定性；第一次满意后再补一次小单，确认稳定了再放量。**
