节假日水果需求暴增，核心不是“临时找货”，而是提前把**需求、货源、物流、门店执行**四件事锁死。可执行做法如下：

1. **提前做节日需求预测**
   - 按去年同节日、同门店、同品类的销量做基线，结合今年假期天数、天气、促销力度、竞品情况修正。
   - 重点分品类：礼盒类、高客单水果、易爆量单品（如车厘子、榴莲、柑橘、苹果、香蕉、西瓜等）分别预测。
   - 不要只做总量预测，要拆到：门店、品类、SKU、到货日期、日销量。

2. **提前锁定核心供应商产能**
   - 对主力单品提前 30–60 天和核心供应商签“保供协议”，明确：
     - 供货量区间
     - 锁价或浮动价机制
     - 每日/每批次供货能力
     - 缺货赔付或优先补货条款
   - 对节前旺季，最好支付定金或预付款锁定产能，避免临时被高价截胡。
   - 同一关键单品至少准备 2–3 家供应商，避免单一产地天气、物流、疫情等断供。

3. **产地直采 + 批发市场双备份**
   - 大单品走产地直采，提前包园、包车、包冷库，锁定采摘和发货档期。
   - 同时保留一批批发市场、区域代理商作为应急补货渠道。
   - 对进口水果提前确认船期、清关、港口拥堵和冷链仓情况，预留到货缓冲。

4. **提前锁定冷链和运输**
   - 节日前后运力紧张，要提前和物流商签节日运输计划，锁定车辆、冷柜、司机和仓位。
   - 对跨区域调货，提前规划备用路线和备用承运商。
   - 对易损水果，明确温控标准、装卸要求、到店验收标准，减少损耗。

5. **建立安全库存和分级补货**
   - 节前 7–15 天逐步把核心单品库存提到安全线以上，但不要一次性压太多易腐品。
   - 按门店销售能力分 ABC 类：
     - A 类高销店：优先保供、加大备货
     - B 类店：按正常备货 + 少量弹性
     - C 类店：少备、快补，避免滞销损耗
   - 设置“触发补货点”，例如库存低于 2 天销量就自动向区域仓或供应商要货。

6. **用预售和团购提前锁需求**
   - 节前开启水果礼盒、企业团购、社区团购预售，先收订单再集中采购。
   - 对爆款单品做“预售+到店自提/配送”，减少门店盲目备货。
   - 这样既能提前锁定销量，也能反向锁定供应商供货量。

7. **门店执行要统一**
   - 总部提前下发节日陈列、定价、促销、主推单品和库存红线。
   - 门店每天上报销量、库存、缺货和损耗，总部按数据动态调货。
   - 对缺货率高的门店，优先从区域仓或周边低销店调拨，而不是只等供应商。

8. **设置应急预案**
   - 关键单品断供时，立即启动替代品：同价位、同用途、同消费场景的水果。
   - 例如车厘子缺货可推蓝莓、草莓礼盒；榴莲缺货可推菠萝蜜、山竹组合。
   - 提前准备好替代品的供应商和促销话术，避免节日当天临时乱阵脚。

一句话总结：**节前用预测锁量、用合同锁价、用定金锁货、用冷链锁运力、用预售锁需求，同时保留备用供应商和替代单品。**  
最关键的落地动作是：提前 30–60 天和核心供应商签保供协议，并把节日需求拆到门店和 SKU。
