选择适合公司下午茶批量配送的水果供应商，核心看四点：**稳定供货能力、配送准时率、损耗处理机制、开票与结算配合度**。下面按可执行的判断标准来说。

**一、先明确自己的需求边界**
- 人数与频次：比如每周1次、每次80人，还是每天都有。
- 预算档位：人均5元、10元还是15元以上，直接决定选批发市场、本地果商还是品牌供应链。
- 水果形态：整果、果切、拼盘，果切对冷链和资质要求更高。
- 配送要求：固定时间送达、送到前台还是分到工位。

**二、优先考虑的供应商类型**
1. **本地果蔬批发商/农批市场商户**：价格低、品类全，适合预算有限、能接受自己分装。缺点是配送和售后不稳定，要确认是否支持送货上门。
2. **生鲜B2B配送平台**：如美菜、快驴这类，适合有对公账户、要发票、要固定配送的公司。优点是流程规范、可批量下单；缺点是价格随行就市，需提前锁价。
3. **本地连锁水果店/精品果切店**：适合品质要求高、量不大的公司下午茶，配送灵活，但单价偏高。
4. **企业团餐/下午茶综合服务商**：如果公司同时要点心、饮品、水果，打包给一家更省事，但水果可能不是其强项，要单独试吃。

**三、筛选供应商的硬指标**
- **供货稳定性**：问清楚应季水果替换方案，避免临时缺货。
- **配送准时率**：要求承诺送达时间窗口，比如14:00前送到，并写进订单备注。
- **损耗与售后**：明确坏果、压伤、缺斤少两怎么赔，最好是拍照反馈后按比例退款或下次补货。
- **资质与开票**：食品经营许可证、对公转账、增值税发票能否提供，这三点决定能否长期合作。
- **试单机制**：先下一单小批量试配送，重点看准时、新鲜度、分装是否干净、售后响应速度。

**四、批量配送的实操建议**
- **提前1-2天下单**，避开当天临时采购导致品类不全。
- **选择耐运输水果**：香蕉、橘子、苹果、梨、圣女果、提子等，比草莓、蓝莓、切好的西瓜更适合批量配送。
- **按人数预估量**：一般每人200-300克净果比较合适，例如80人约准备16-24公斤。
- **要求分装或按部门装箱**，减少现场分发混乱。
- **固定1-2家主力供应商加1家备选**，避免单一供应商临时掉链子。

**五、快速决策顺序**
先定预算和频次 → 找2-3家本地B2B平台或果商报价 → 小批量试单 → 对比准时率、新鲜度、售后和发票 → 签月度或季度框架价 → 保留备选供应商。
