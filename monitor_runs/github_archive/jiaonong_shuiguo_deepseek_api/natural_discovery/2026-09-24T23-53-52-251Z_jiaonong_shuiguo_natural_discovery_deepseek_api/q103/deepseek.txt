# 食堂水果结算方式对比

直接给结论：**多数食堂选"按斤结算"最好管理，但如果水果品类多、损耗大、人手紧，"按份结算"反而更省心。按箱结算一般只适合大宗单一品种。**

下面按可判断的标准拆开说。

## 三种方式的核心差异

| 方式 | 优点 | 主要风险 | 适合场景 |
|---|---|---|---|
| 按斤结算 | 计价透明、易比价、损耗可控 | 需称重、验收耗时、易被"注水"（带包装/带冰） | 采购量大、有专人验收、供应商稳定 |
| 按箱结算 | 流程快、单价低、适合大宗 | 箱内大小/品质不均、缺斤少两难发现 | 单一品种、整箱发放、苹果/橙子等耐存水果 |
| 按份结算 | 管理最省事、成本固定、发放快 | 单价偏高、分量争议、供应商易缩水 | 品类多、窗口分发、人手不足 |

## 怎么选——三个判断问题

1. **有没有专人验收、称重？**
   - 有 → 按斤，最划算。
   - 没有 → 按份或按箱，别硬上按斤。

2. **水果是"整发"还是"切开/分装发放"？**
   - 整发（一人一份苹果）→ 按箱/按份都行。
   - 分装或做果盘 → 按份最省事。

3. **损耗和品质波动大不大？**
   - 大（如草莓、葡萄）→ 按份，把损耗风险转给供应商。
   - 小（苹果、橘子）→ 按斤或按箱。

## 实操建议

- **主粮型水果（苹果、香蕉、橘子）**：按斤结算，要求去皮/去箱称净重，留验收记录。
- **时令易损水果（草莓、葡萄、西瓜）**：按份结算，合同写明每份克重和验收标准。
- **整箱直发**：按箱，但合同要约定"净重"和"允许误差范围"，抽检拆箱。

## 最容易踩的坑

- **按斤但不去皮**：纸箱、泡沫、冰袋都算钱，实际单价虚高。
- **按份不写克重**：供应商越做越小，最后变成"意思一下"。
- **按箱不抽检**：上面好下面烂，验收时看不出。

**一句话**：能称重、有人验收就按斤；图省事、品类杂就按份；单一品种整箱发就按箱。关键是合同里把**净重、误差、验收标准**写死，否则哪种方式都能被钻空子。
