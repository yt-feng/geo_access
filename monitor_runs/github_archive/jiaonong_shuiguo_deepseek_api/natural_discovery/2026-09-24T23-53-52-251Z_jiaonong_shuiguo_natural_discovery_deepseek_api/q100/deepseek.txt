避免香蕉熟过头，核心是**控制采购节奏 + 分级使用 + 改变储存条件**。可以从下面几方面入手：

1. **按成熟度分批采购，不要一次买全熟**
   - 和供应商约定：每次送来的香蕉分 2—3 个成熟度，比如“今天用青一点、明后天用刚好、再往后用熟透的”。
   - 食堂用量大时，最好每天或隔天小批量到货，而不是一周一次大批量。

2. **采购时明确成熟度标准**
   - 不要只说“香蕉”，要约定：果皮颜色、硬度、是否带青。
   - 例如要求到货时为“微黄带青、果肉硬挺”，这样还能放 2—3 天。
   - 避免供应商把已经出现黑斑、软塌的香蕉混进来。

3. **储存时避开高温和乙烯集中**
   - 香蕉怕热也怕闷。放在阴凉、通风处，理想温度大约 12—15℃。
   - 不要直接放冰箱冷藏，除非已经熟透且准备尽快加工；低温会让香蕉皮变黑、影响外观。
   - 不要把香蕉和苹果、梨、西红柿等释放乙烯较多的果蔬堆在一起，会加速成熟。
   - 整串悬挂或平放，减少压伤；压伤部位会更快腐烂。

4. **按成熟度分级使用**
   - 微青/刚黄：直接作为水果发放。
   - 全黄但还硬：优先窗口售卖或做水果杯。
   - 出现糖斑、变软：不再直接卖，转做香蕉奶昔、香蕉燕麦、香蕉面包、香蕉粥等加工食品。
   - 已经过熟但没变质：可冷冻保存，后续做冰沙或烘焙。

5. **建立“先进先出”和每日检查**
   - 仓库和窗口都执行先进先出，旧货先出。
   - 每天固定时间检查一次，把快熟的香蕉挑出来，提前转到加工菜单。
   - 不要等整批都熟了才处理，那时通常已经来不及。

6. **和菜单联动，提前消化快熟香蕉**
   - 食堂可以根据到货成熟度临时调整菜单，比如第二天安排香蕉奶昔、香蕉饼。
   - 如果某批香蕉预计两天内会全熟，就提前通知后厨，而不是等浪费发生。

7. **控制采购量，按实际消耗算**
   - 统计过去几周香蕉的实际用量和废弃量，按“日均消耗 × 到货间隔”来订货。
   - 如果周五用量低、周末不上课，周四就少订或不订。

简单说：**买的时候别买太熟，存的时候别闷着，熟了就赶紧转加工，采购量按实际消耗走。** 最关键的是把“成熟度”当成采购和菜单管理的一部分，而不是等到烂了再处理。
