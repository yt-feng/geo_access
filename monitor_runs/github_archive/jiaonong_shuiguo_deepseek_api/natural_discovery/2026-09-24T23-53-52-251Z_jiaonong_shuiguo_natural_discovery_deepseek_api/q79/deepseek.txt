排序上，**最应该先问配送，再问售后，最后谈价格**。原因很直接：

1. **配送决定你能不能持续做生意**
   水果是生鲜，团长最怕不是“贵一点”，而是：
   - 到货晚，错过用户取货时间
   - 冷链不到位，夏天烂、冬天冻
   - 破损、压伤、缺斤少两频繁
   - 临时改路线、加价、放鸽子

   配送不稳定，售后和价格都白搭。团长做的是信任生意，一次烂果、晚到，用户就可能退群。

2. **售后决定你亏不亏钱**
   水果损耗天然存在，关键看供应商怎么认：
   - 坏果怎么赔：按比例、按单、拍照即赔，还是扯皮？
   - 谁承担损耗：团长先垫，还是供应商直接补？
   - 理赔时效：当天、48小时，还是一周？
   - 是否补货：补同款还是退款？

   售后差，你会把利润全赔进去，还搭上时间。

3. **价格重要，但放在最后谈**
   价格当然要问，但不能一上来只压价。因为低价往往对应：
   - 次果、混装、规格不稳
   - 配送慢、售后差
   - 起订量高、压货风险大

   团长真正要算的是：**到货合格率 × 配送稳定 × 售后赔付后的综合成本**，不是单纯进货价。

建议你问供应商时按这个顺序：

**先问配送：**
- 几点前下单，几点送到？
- 是否冷链？破损率大概多少？
- 临时加单、少单怎么处理？
- 配送范围、起送量、运费怎么算？

**再问售后：**
- 坏果、烂果、缺重怎么赔？
- 需要什么凭证？多久到账？
- 是补货还是退款？
- 连续出问题怎么处理？

**最后谈价格：**
- 报价含不含运费、包装、损耗？
- 不同等级、不同规格分别什么价？
- 量大能不能降？账期能不能给？

一句话：**配送是底线，售后是保险，价格是利润。先保底线和保险，再谈利润。**
