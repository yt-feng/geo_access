超市卖菠萝，最该关注的不是单一指标，而是**按经营目标排序**：

1. **切果损耗（最优先，直接影响利润）**  
   菠萝皮厚、眼深、两端废料多，损耗通常高。要算“可售果肉率”，而不只是进货价。  
   关注：去皮去眼后出肉率、切口氧化/出水、当天切果报废率、员工操作熟练度。

2. **甜度（决定复购和口碑）**  
   菠萝不甜，顾客买一次就不回头。尤其鲜切、试吃、会员复购场景，甜度权重很高。  
   关注：糖酸比、成熟度、品种差异，避免“看着黄但不甜”。

3. **外观（决定首次购买和陈列吸引力）**  
   外观影响顾客拿起来的第一动作，但菠萝有厚皮，外观对最终口感判断有限。  
   关注：果形端正、颜色均匀、无腐烂黑心、冠芽新鲜，别过度追求“大”。

4. **大小（相对次要，看渠道定位）**  
   大小影响单价、陈列和家庭购买决策，但不等于好吃或损耗低。  
   关注：目标客群偏好。家庭装可偏大，单身/小家庭可偏中小果或鲜切小份。

**简单决策：**  
- 做鲜切/果切：先看**出肉率和切果损耗**，再看甜度。  
- 做整果促销：看**外观和大小**，但甜度必须达标。  
- 做长期复购：**甜度 > 损耗 > 外观 > 大小**。  
- 只选一个核心指标：**卖鲜切看损耗，卖整果看甜度与外观平衡。**
