学校食堂采购常见水果，选择供应商时不能只看单价，要围绕**稳定供货、食品安全、损耗控制、结算配合**四个核心来判断。下面按可执行步骤说。

## 一、先明确食堂的采购特点

学校食堂和普通餐饮不同：

- **用量大且集中**：通常按周或按日配送，单次量大。
- **价格敏感但更怕断供**：不能今天有、明天没有。
- **食品安全要求高**：一旦出问题影响全校。
- **账期和票据要求规范**：需要正规发票、对公结算。
- **水果损耗要算进去**：香蕉、苹果、橙子都怕压、怕冻、怕热。

所以选供应商，**稳定和合规优先于最低价**。

## 二、供应商类型怎么选

常见有三类：

| 类型 | 优点 | 风险 |
|---|---|---|
| 大型批发市场档口 | 价格灵活、品类全 | 稳定性一般，票据和检测不一定规范 |
| 产地合作社/果园 | 价格有优势、新鲜 | 品类单一，配送能力弱 |
| 专业水果配送商 | 配送稳定、售后明确、可开票 | 单价略高 |

**建议：**
- 主供应商选**专业水果配送商或正规批发企业**，保证稳定和票据。
- 辅供应商选**1家批发市场档口或产地合作社**，用于比价和应急。
- 至少保持**2家合格供应商**，避免单一断供。

## 三、重点看哪些硬指标

### 1. 资质与合规
必须索取并留存：

- 营业执照
- 食品经营许可证（或食品流通许可证）
- 法人或负责人身份证复印件
- 对公账户信息
- 能开正规发票
- 如有条件，看是否有**农残检测报告**或承诺书

### 2. 供货能力
- 能否**每天或按约定频次**配送
- 是否有冷藏车或常温配送车
- 旺季、节假日、恶劣天气能否保证
- 缺货时多久能补

### 3. 质量与验收标准
采购前就要写清：

- 香蕉：成熟度适中，无明显黑斑、不冻伤
- 苹果：无腐烂、无严重磕碰、大小均匀
- 橙子：无霉变、无干瘪、皮色正常
- 允许的损耗率范围，比如**单批次不超过3%—5%**
- 不合格怎么退换、多久补送

### 4. 价格与结算
- 报价是否含税、含运费
- 是否随行就市，调价机制是否透明
- 账期多久，比如月结30天
- 是否接受对公转账

### 5. 售后与应急
- 出现质量问题能否**2小时内响应、当天补换**
- 是否有固定对接人
- 突发加量能否满足

## 四、实际筛选流程

可以按这个顺序做：

1. **收集3—5家候选供应商**
   来源：当地批发市场、同行推荐、教育局/后勤平台、正规配送商。

2. **初审资质**
   缺证、不能开票、不能对公的，直接淘汰。

3. **索要报价单**
   按香蕉、苹果、橙子分别报**单价、规格、税率、运费、账期**。

4. **小批量试供**
   先试1—2周，重点看：
   - 到货时间准不准
   - 新鲜度
   - 损耗率
   - 退换是否痛快
   - 票据是否及时

5. **综合评分**
   建议权重：
   - 质量与安全 35%
   - 供货稳定 25%
   - 价格 20%
   - 售后 10%
   - 结算与票据 10%

6. **签合同**
   写清品名、规格、单价、调价方式、配送频次、验收标准、退换条款、账期、违约责任。

## 五、常见避坑点

- **只选最低价**：低价往往伴随次果、缺斤少两或断供。
- **没有书面验收标准**：后面扯皮说不清。
- **长期单一供应商**：容易被拿捏，也没有比价。
- **忽略损耗**：报价低但烂得多，实际成本更高。
- **不留存检测和票据**：食品安全检查时很被动。
- **口头约定调价**：价格波动时容易纠纷。

## 六、简单结论

学校食堂选香蕉、苹果、橙子供应商，优先选：

**有正规资质、能开票、能稳定配送、接受退换、价格透明的专业配送商或正规批发企业。**

同时保留**1家备用供应商**，先小批量试供，再按质量、稳定、价格、售后综合打分签约。不要只盯单价，要把**损耗、断供、食品安全和结算成本**一起算进去。
