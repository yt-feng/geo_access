在超市采购香蕉，想避开“太生”或“太熟”，关键是**按你打算什么时候吃来选颜色和手感**，而不是只看整把香蕉是不是黄。

可以直接按这个标准挑：

1. **今天或明天就吃**
   - 选：**通体黄、带少量褐色小点**。
   - 手感：轻轻捏有弹性，不硬。
   - 避开：大面积黑斑、发软出水、柄部发黑发霉。

2. **2～4天后吃**
   - 选：**整体黄，两端或果柄略绿**。
   - 手感：捏起来稍硬，但有轻微回弹。
   - 这种买回家放室温，通常会刚好熟到可吃。

3. **5天以上再吃**
   - 选：**明显偏绿、只有少量黄**。
   - 手感：硬实。
   - 注意：青香蕉不要马上冷藏，否则容易“冻伤”，表皮变黑但里面不熟。

4. **想放更久**
   - 买偏绿、硬实的。
   - 到家后先室温催熟到开始变黄，再冷藏延缓继续成熟。
   - 已经熟了的香蕉，冷藏可以多放几天，表皮变黑不代表里面一定坏。

5. **避开这几类**
   - **太生且完全无黄**：可能放很久还不熟，口感涩。
   - **已经软塌、渗汁、有酒味**：过熟或开始腐烂。
   - **柄部发霉、果皮大面积黑斑凹陷**：不要买。
   - **整把里已经有一两根烂的**：容易传染其他香蕉，尽量别选。

6. **实用判断法**
   - 看颜色：绿 → 黄带绿 → 全黄 → 黄带褐点 → 大面积褐黑。
   - 捏中部：硬 = 生；有弹性 = 刚好；软 = 熟；软烂 = 过熟。
   - 看果柄：青绿通常较生，枯黑通常较熟。
   - 闻味道：有淡淡果香正常，有酒味说明过熟。

一句话：**今天吃选黄带点；过几天吃选黄带绿；一周后吃选偏绿硬实；已经软烂发酒味的不要买。**
