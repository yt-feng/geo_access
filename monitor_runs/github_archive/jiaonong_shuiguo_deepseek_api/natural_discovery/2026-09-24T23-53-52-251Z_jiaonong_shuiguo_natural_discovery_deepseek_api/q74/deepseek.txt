先分清你的档口定位：是给餐饮客户做**原料供货**（后厨加工用），还是做**果切/配送**（直接入口）。两种定位规格差别很大。下面按餐饮常见用途拆开说，你可以直接照着备货。

## 一、菠萝（餐饮客户主要用途：菠萝炒饭、咕咾肉、饮品、果切、烘焙）

餐饮客户对菠萝的核心要求是**出肉率稳定、酸甜一致、去皮省工**。

| 规格方向 | 具体建议 | 适合客户 |
|---|---|---|
| 鲜果整只 | 单果 1.2–1.8 斤（小果，出肉率高、损耗低） | 果切店、饮品店、小炒店 |
| 鲜果整只 | 单果 2–3 斤（中果，主流） | 中餐馆、酒楼、食堂 |
| 鲜果整只 | 3 斤以上（大果，偏酸、纤维粗） | 低价走量、果汁厂 |
| 去皮菠萝 | 整只去皮、去眼，真空或清水浸泡 | 后厨省工的中大型餐饮 |
| 菠萝块/丁 | 2–3cm 方丁，真空袋装，1kg/袋 | 炒饭、咕咾肉、沙拉 |
| 菠萝片 | 0.8–1cm 厚圆片 | 摆盘、汉堡、烘焙 |
| 冷冻菠萝丁 | IQF 速冻，1kg/袋 | 跨季稳定供货、饮品店 |

**关键点：**
- 餐饮最在意**品种**：香水菠萝/金钻凤梨偏甜、无眼或少眼，适合直接入口和果切；普通巴厘菠萝偏酸，适合炒菜和果汁。
- 报价时要区分“**带皮价**”和“**去皮净重价**”，餐饮采购算的是净料成本。
- 建议主推：**中果整只 + 去皮真空块/丁** 两个 SKU，覆盖大部分客户。

## 二、香蕉（餐饮客户主要用途：果切、饮品、烘焙、员工餐）

香蕉的难点是**成熟度**，餐饮客户对熟度要求比零售更明确。

| 规格方向 | 具体建议 | 适合客户 |
|---|---|---|
| 生蕉（青蕉） | 7–8 成熟，耐存放 | 需要自己催熟、控损耗的客户 |
| 熟蕉 | 8–9 成熟，可直接用 | 果切、饮品、食堂 |
| 单根规格 | 单根 100–150g，主流 | 果切、员工餐 |
| 单根规格 | 150g 以上大蕉 | 烘焙、香蕉奶昔 |
| 整箱 | 净重 12–13kg/箱，常规 | 所有餐饮 |
| 冷冻香蕉 | 去皮段冻，1kg/袋 | 饮品店、奶昔、烘焙 |

**关键点：**
- **成熟度是核心卖点**：餐饮客户最怕香蕉到货太生没法用、或太熟当天烂。建议按“**到货即用**”和“**可放 2–3 天**”两种熟度分开报。
- 果切客户要**无黑斑、无机械伤**；烘焙客户可以接受外观稍差但要求熟度稳定。
- 香蕉毛利薄、损耗高，建议搭配菠萝一起做“**果切原料包**”，提高客单价。

## 三、给你的落地建议

1. **先锁定 2–3 类餐饮客户**：快餐/食堂、酒楼、饮品/果切店，规格需求不同，别一次上全。
2. **主推组合 SKU**：
   - 菠萝：中果整只 + 去皮真空丁
   - 香蕉：8–9 成熟整箱 + 去皮冷冻段
3. **报价单写清**：品种、单果重量、成熟度、净重/毛重、去皮损耗率、起订量、配送频次。
4. **先小批量试单**：餐饮客户换供应商谨慎，先用 1–2 周稳定供货证明损耗率和到货品质，再谈长期。
