对绝大多数餐饮连锁，**中央厨房统一收货更好**，但前提是你有中央厨房且能覆盖配送；如果中央厨房只管加工不管配送、或门店分布极散，门店分开收货反而更现实。

**直接判断：**

1. **有中央厨房 + 有冷链配送能力 → 中央厨房统一收货**
   - 水果集中验收，标准统一，避免各店各判。
   - 采购量大，议价能力强，价格更低。
   - 农药残留、品质、规格更容易抽检管控。
   - 减少门店收货人力，店长不用天天盯水果。
   - 做净果、切果、分装的门店尤其适合。

2. **没有配送能力，只让门店自己去中央厨房拉 → 要慎重**
   - 门店自提会增加物流和损耗。
   - 到店时间不一致，水果新鲜度波动大。
   - 中央厨房可能变成“中转仓库”，反而增加成本。

3. **门店分散、单店用量小、水果保质期极短 → 可门店分开收货**
   - 例如高端现切果盘、精品单店，要求当天本地采购。
   - 本地供应商直送门店，响应更快，损耗更低。
   - 但必须统一验收标准和供应商准入，否则品质失控。

**建议的落地模式：**

- **主模式：中央厨房统一收货 + 统一配送**
  适合苹果、橙子、西瓜、柠檬等耐储或可标准化水果。

- **补充模式：门店本地直采**
  适合草莓、蓝莓、荔枝、杨梅等极短保、区域性强水果。
  但必须：
  - 总部定供应商白名单；
  - 总部定验收标准；
  - 门店拍照/系统留痕；
  - 总部不定期飞检。

**关键判断指标：**

- 门店数量：越多越适合中央厨房统一收货。
- 配送半径：超过 3 小时冷链覆盖，门店直采比例要提高。
- 水果品类：越耐储越集中，越短保越分散。
- 单店用量：太小就别强制统配，否则起送量和损耗不划算。
- 中央厨房能力：只收货不加工、不配送，价值有限。

**结论：**
优先中央厨房统一收货，但不要一刀切。  
**耐储、标准化、用量大的水果走中央厨房；极短保、区域性强、小批量水果允许门店合规直采。** 这样成本、品质、损耗最平衡。
