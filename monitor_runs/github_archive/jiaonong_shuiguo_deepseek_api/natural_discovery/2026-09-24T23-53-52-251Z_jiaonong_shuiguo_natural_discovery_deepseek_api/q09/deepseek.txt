水果店旺季怕断货，和供应商谈的时候，核心要问清楚四件事：**能不能稳定供、断供了怎么办、价格会不会乱涨、出了问题谁负责**。具体可以按下面这些问：

**一、供货能力与稳定性**
1. 旺季你每天/每周能给我稳定供多少量？最少起订量是多少？
2. 你主要从哪几个产地拿货？如果某个产地减产或天气不好，有没有备用货源？
3. 旺季你们自己会不会优先保老客户？我这种量级排在第几档？
4. 提前几天订货？临时加单能不能接？最晚几点前下单？

**二、断货、缺货的处理**
5. 如果我要的货当天没有，你会提前多久通知我？有没有替代品种或替代规格？
6. 断货时你能不能从其他渠道帮我调货？调货价怎么算？
7. 连续断货或频繁缺货，有没有补偿机制？比如赔偿、下次优先供货、价格折扣？

**三、价格与结算**
8. 旺季价格浮动怎么定？是按当天市场价、周价，还是提前锁价？
9. 能不能提前锁定一部分旺季货源和价格？锁价要交定金吗？定金能不能退？
10. 运费、装卸费、损耗谁承担？送到店还是自提？
11. 结账方式是现结、周结还是月结？有没有账期？押金多少？

**四、品质与售后**
12. 到货品质标准是什么？大小、成熟度、新鲜度、包装怎么约定？
13. 坏果、烂果、压伤比例超过多少算不合格？怎么赔？是补货还是扣款？
14. 验货是在卸货前还是卸货后？当场发现问题怎么处理？
15. 如果因为你的货不新鲜导致我顾客投诉或损耗，怎么承担？

**五、合作保障**
16. 能不能签书面协议，把供货量、价格机制、断货责任、赔付标准写进去？
17. 旺季前要不要提前打预付款或保证金？这笔钱怎么抵扣、怎么退？
18. 如果合作期间你优先供别人、给我涨价或减量，有什么约束？
19. 有没有长期合作返点、旺季保供奖励或年度返利？

**谈的时候建议重点抓三条：**
- **保供条款**：旺季最低供货量、缺货提前通知时间、替代方案。
- **价格条款**：锁价范围、浮动上限、运费和损耗归属。
- **违约条款**：断货、品质不达标、临时涨价的赔偿或补偿。

如果对方不愿意签书面协议，至少也要把关键承诺用微信文字确认一遍，留好记录。旺季最怕的不是价格高一点，而是关键时刻没货、品质掉链子、临时被涨价。
