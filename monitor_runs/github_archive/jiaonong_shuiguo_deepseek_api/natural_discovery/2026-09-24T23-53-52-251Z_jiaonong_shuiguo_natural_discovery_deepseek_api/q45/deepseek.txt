连锁超市和水果供应商签年度合同，最容易踩坑的通常不是价格本身，而是围绕“价格怎么定、货怎么收、损耗谁担、账怎么结、出问题怎么退”的条款。按风险从高到低，重点盯这几类：

**1. 价格条款：别只写“随行就市”**
这是水果年度合同第一大坑。水果价格波动大，如果只写“按市场价结算”，后期必然扯皮。  
建议写清：
- 定价基准：以哪个市场、哪个等级、哪天报价为准
- 调价周期：每周/每旬/每月调一次
- 调价触发条件：涨跌超过多少比例才调
- 锁价期：年度合同里哪些单品、哪些月份锁价
- 异常波动处理：极端天气、产地减产时怎么协商

**2. 质量标准：别只写“符合国家标准”**
水果非标性强，只写国标等于没写。必须细化到：
- 品种、产地、规格、单果重、糖度、色泽、成熟度
- 允许的瑕疵率、碰伤率、腐烂率
- 验收方式：到仓检还是产地检，抽检比例多少
- 不合格判定后：退货、换货、折价，还是扣款

**3. 损耗与验收：最容易吃暗亏**
水果从产地到门店损耗大，关键要分清：
- 运输途中损耗谁承担
- 到仓验收后损耗谁承担
- 门店陈列损耗谁承担
- 验收时限：几小时内完成，逾期是否视为合格
- 短装、烂果、等级不符的处理时效

**4. 供货量与弹性：别把自己绑死**
年度合同常写“预计采购量”，但要注意：
- 是承诺采购量还是意向采购量
- 是否允许超市根据销售情况上下浮动
- 供应商断供、少供的违约责任
- 超市未达量的责任是否对等
- 旺季优先供货权、淡季最低供货保障

**5. 账期与结算：现金流杀手**
- 账期起算点：收货日、对账日还是开票日
- 对账周期和异议期
- 扣款项目：质量扣款、损耗扣款、促销扣款、返利
- 返利是月返、季返还是年返，是否可抵扣货款
- 逾期付款是否计息，供应商能否停供

**6. 退换货与售后：别只写“可退换”**
- 哪些情况可退：质量问题、滞销、临期、包装破损
- 退货费用谁承担
- 换货时效
- 门店端发现问题的追溯期
- 是否支持部分退货、跨店调拨

**7. 违约责任：必须对等且可执行**
常见坑是只约束供应商，不约束超市。要写：
- 延迟交货、短供、质量不合格的违约金
- 超市延迟付款、无故拒收的责任
- 违约金计算基数：订单金额、未履行部分还是年度总额
- 连续违约能否解除合同

**8. 独家与排他：小心被反锁**
- 是否约定某单品只能从这家进
- 超市能否同时采购其他供应商
- 供应商能否给周边竞品供货
- 排他期和排他范围

**9. 不可抗力与政策风险**
水果受天气、疫情、关税、检疫影响大。要明确：
- 哪些算不可抗力
- 通知义务和证明要求
- 能否部分免责、延期履行
- 长期无法供货时能否调价或解约

**10. 合同期限与续约**
- 年度合同起止日
- 自动续约条件
- 提前终止通知期
- 终止后库存、在途货、返利怎么处理

**实操建议：**
签之前让采购、财务、门店运营三方各审一遍。重点做三张表：  
1. **价格调整表**：什么条件、什么周期、谁确认  
2. **验收标准表**：每个单品的规格、瑕疵率、扣款标准  
3. **对账扣款表**：账期、返利、扣款项、争议处理时限  

如果只能抓三个最关键的，就是：**价格调整机制、验收与损耗归属、账期与扣款规则**。这三块写不清，年度合同执行到第三个月就容易变成天天扯皮。
