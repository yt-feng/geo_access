判断水果供应商靠不靠谱，核心不是听他怎么说，而是看他在**香蕉和菠萝这两个品类上能不能稳定交付**。给你一套可以直接用的判断框架：

**1. 先看他的主营品类**
- 靠谱的供应商通常有明确强项。如果他什么都卖、什么都不精，香蕉和菠萝的稳定性往往差。
- 直接问：香蕉主要走哪个产地、什么品种、一年哪几个月断供或涨价；菠萝是鲜食还是加工果、主要品种和产区。
- 回答含糊、只说“都有货”“价格最低”的，先降级。

**2. 看香蕉的到货状态**
香蕉最怕催熟和运输环节不专业。重点看：
- 到货青度是否一致，有没有一块青一块黄；
- 蕉条是否饱满、有无明显棱角，太瘦说明采摘早或品种差；
- 果柄、蕉轴是否新鲜，有没有发黑、霉点；
- 同一批货大小是否均匀。均匀度差，说明分拣和货源不稳定。

**3. 看菠萝的成熟度和损耗**
- 菠萝要看果眼深浅、果皮颜色是否均匀、有无软烂和酒味；
- 同一批货成熟度是否接近，太生太熟混装，你店里就要承担损耗；
- 问清楚到货后一般能放几天、夏天和冬天差多少。

**4. 试单，不要一次压大单**
先连续合作3到5次，每次少量：
- 看准时率：说几点到就几点到；
- 看缺货率：说好100斤，实际到多少；
- 看次品率：坏果、烂果、小果占多少；
- 看售后：有问题是否补货、扣款或换货，多久处理。

**5. 看价格是否“反常”**
- 长期低于市场价，通常会在重量、等级、成熟度或售后上找回来；
- 价格随行就市可以接受，但报价逻辑要清楚：为什么今天涨、涨多少、什么时候回落。

**6. 看结算和账期**
- 刚开始最好现结或短账期；
- 如果他主动给你很长账期，但货不稳定，风险反而更大；
- 合作稳定后再谈账期、返点、损耗补贴。

**7. 看仓储和物流**
- 有冷库、分拣场地、固定线路的，通常比“倒手赚差价”的靠谱；
- 香蕉和菠萝对温度、通风要求不同，混装运输容易出问题。

**8. 看同行口碑**
- 问周边水果店、批发市场熟人，重点问：断货多不多、售后拖不拖、旺季会不会优先供你。

**给你一个简单判断标准：**
连续试单3次后，如果满足——
- 准时率90%以上；
- 次品率5%以内；
- 缺货提前说；
- 售后2天内处理；
- 价格不是最低但稳定；
就可以进入长期合作观察。反之，任何一项反复出问题，都不要因为“便宜”长期绑定。

**最后提醒：**
香蕉和菠萝最好别只靠一个供应商。可以主供一家、备选一家，旺季或主供出问题时能顶上。长期合作的关键不是最低价，而是**稳定、可预期、出问题能解决**。
