判断香蕉供应商能否全年稳定供货，不能只问他“能不能”，要看他有没有可核验的**产地结构、补货机制和风险对冲**。香蕉是典型的全年需求品，但生产受气候、产地轮换、病虫害影响很大。建议按下面几层判断：

**1. 看他有没有多产地、多基地布局**
- 香蕉主产区有季节差：国内海南、云南、广西、广东，以及菲律宾、越南、厄瓜多尔等进口来源，上市期不同。
- 真正能全年供货的供应商，通常有“国内+进口”或“多个产区”组合，而不是单一基地。
- 问清楚：全年每个月主要从哪几个产区拿货，各产区占比多少，能不能提供近12个月的逐月供货记录。

**2. 看他的冷库和催熟能力**
- 香蕉不是采下来直接卖，通常要经过催熟加工。
- 有稳定供货能力的供应商，一般有自有或长期合作的冷库、催熟库，能调节上市节奏。
- 重点问：催熟库容量、冷库容量、日加工能力、旺季和淡季怎么调节发货。

**3. 看他的补货和替代方案**
- 遇到台风、寒潮、病害、海运延误时，他有没有备份产地和备份物流。
- 让他给出具体预案：比如海南减产时从哪补，进口船期延误时怎么保证不断供。
- 没有预案、只会说“没问题”的，风险较高。

**4. 看合同和履约数据**
- 要求提供过去12个月的供货台账：每月实际到货量、缺货次数、缺货原因、补货时间。
- 看合同里有没有全年保供条款、最低月供量、违约赔偿、价格调整机制。
- 注意：只签“随行就市、按量供应”的合同，基本不能算稳定保供。

**5. 实地或视频核验**
- 看基地、加工厂、冷库、催熟库是否真实存在。
- 看是否有稳定的包装线、质检流程、物流车队或长期合作物流商。
- 如果供应商只是贸易商，要看他上游是谁，上游是否稳定。

**6. 用小批量试单验证**
- 先签3—6个月试供，按月考核到货率、合格率、缺货次数。
- 试供期覆盖一个淡季和一个旺季，才能真正看出稳定性。
- 设定考核指标：月到货率≥95%、缺货提前通知≥7天、单次补货≤3天等。

**简单判断标准：**
- 只有单一产地、没有冷库催熟、没有进口或备份渠道、拿不出12个月供货记录的，基本不能算全年稳定供应商。
- 有多产地组合、有冷库催熟、有备份预案、有历史履约数据、愿意签保供合同的，才值得进入长期合作。
