通常 **直接买成品果丁的综合损耗更低**，但前提是你要把“损耗”算全：不只算削皮去眼的废弃率，还要算人工、冷藏、过期报废、品控不稳定带来的隐性损耗。

### 直接判断

- **只比原料利用率**：鲜果自己切，表面上看你能控制，但菠萝削皮、去眼、去芯后，实际可用果肉通常只有 **50%～65%** 左右，具体看品种、成熟度和刀工。
- **买成品果丁**：供应商已经承担了削皮、修整、分级，你到手基本是可用部分，**可见废弃率接近 0**。
- **算上人工和时效**：甜品店如果每天用量不大，鲜果切配会出现“切多了用不完、切少了不够用”的问题，成品果丁虽然单价高，但**报废和人工更可控**。

### 关键看这几个条件

1. **日均用量**
   - 用量大且稳定：鲜果切配可能更划算，损耗可控。
   - 用量小或波动大：成品果丁损耗更低，因为不押人工、不押库存。

2. **成品果丁的质量**
   - 如果成品果丁含水高、破损多、保质期短，那它的损耗可能转成“出水、变味、报废”。
   - 如果供应商冷链稳定、规格统一，成品优势明显。

3. **你的隐性成本**
   - 鲜果切配要算：削皮人工、清洗消毒、冷藏空间、切配时间、员工熟练度。
   - 成品要算：进货价差、解冻/沥水损耗、开封后保质期。

4. **甜品用途**
   - 用于装饰、要求块形整齐：成品果丁更稳。
   - 用于熬酱、打泥、烘焙馅料：鲜果甚至冷冻果肉可能更划算，因为外观要求低。

### 实操建议

- **先做 3 天称重测试**：买同重量鲜菠萝，记录削皮去眼后的净果肉重量，算出真实出成率。
- **再对比成品**：记录到货重量、沥水后重量、可用果丁重量、报废重量。
- **最后算总成本**：
  - 鲜果：进货价 ÷ 出成率 + 人工分摊 + 报废分摊
  - 成品：进货价 ÷ 可用率 + 报废分摊
- **小甜品店优先成品果丁**；**中大型、用量稳定、有人工余力的店可以鲜果切配**。

一句话：**如果只问损耗率，成品果丁通常更低；如果问总成本，要看你的用量、人工和报废控制。**
