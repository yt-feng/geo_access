做水果礼盒，核心不是“把水果凑齐”，而是让顾客一眼觉得值、送得出手、你还能赚到钱。苹果、橙子、香蕉、菠萝这四样搭配，建议这样做：

**一、先定主结构：1个主角 + 1个撑体积 + 1个提色 + 1个提香**

- **苹果**：主角，寓意平安，耐放，适合撑门面。
- **橙子**：第二主角，颜色亮，寓意心想事成，和苹果是经典组合。
- **香蕉**：提色、提香，但**不适合放多**，容易压坏、变黑，适合当点缀。
- **菠萝**：提香、提档次，但带刺、占地方、熟度难控，适合做“升级款”而不是每盒都放。

**二、最好卖的3种组合**

**1. 基础走量款：苹果 + 橙子 + 香蕉**
- 比例建议：苹果4个 + 橙子4个 + 香蕉2根  
- 卖点：平安、吉利、颜色好，成本低，适合日常送人、员工福利。
- 包装：牛皮纸盒 + 红色丝带，写“平安橙意”。
- 定价：按你当地水果均价，毛利控制在30%左右，走量。

**2. 中档主推款：苹果 + 橙子 + 菠萝**
- 比例建议：苹果4个 + 橙子4个 + 小菠萝1个  
- 卖点：有“旺来”寓意，体积大，显得礼盒满，适合探病、开业、节日。
- 注意：菠萝要选小果，提前问顾客是否接受带皮，最好配开果器。
- 定价：比基础款高15—25元，主推这个，利润最好。

**3. 高端混合款：苹果 + 橙子 + 香蕉 + 菠萝**
- 比例建议：苹果3个 + 橙子3个 + 香蕉2根 + 小菠萝1个  
- 卖点：四样齐全，颜色丰富，适合春节、中秋、开业。
- 注意：香蕉和菠萝不要贴在一起，菠萝扎破香蕉会很快坏。
- 定价：可以做到基础款的1.8—2倍，但量不要大，做形象款。

**三、摆放和保鲜的关键**

- **香蕉不要放底层**，容易被压，也怕冷，别放冷藏柜旁边。
- **菠萝单独隔开**，用纸托或小网套，避免刺破其他水果。
- **苹果和橙子放底层**，耐压，也撑得起盒子。
- **礼盒不要装太满**，留一点空间，看起来更高级，也避免挤压。
- **当天配当天卖**，香蕉和菠萝熟得快，隔夜卖相会掉。

**四、好卖的小技巧**

- 给组合起名字：  
  - 苹果+橙子 = “平安橙意”  
  - 加菠萝 = “旺来平安”  
  - 四样全 = “四喜临门”
- 盒子上贴一张小卡片，写寓意和食用顺序，顾客送人时不用解释。
- 做两个价格档：  
  - 59—79元走量款  
  - 99—129元主推款  
  - 159元以上高端款  
  顾客更容易选中间那个。
- 如果顾客是送病人，别放菠萝和香蕉太多，优先苹果、橙子，再加一点提子或猕猴桃更好。

**五、最推荐的搭配结论**

如果你只想做一个最好卖的款：  
**苹果4个 + 橙子4个 + 香蕉2根 + 小菠萝1个**，叫“四喜平安礼盒”，主推中档价位。  
如果控制成本走量：  
**苹果4个 + 橙子4个 + 香蕉2根**，叫“平安橙意礼盒”。  
菠萝不要每盒都硬塞，用它做升级款和利润款，反而更好卖。
