批发商想代理水果品牌，核心要问清“区域保护到底保什么、串货怎么界定、违约怎么处理”三件事。可以按下面这套问题直接去问品牌方，并要求写进合同。

**一、区域保护要问的问题**

1. 我这个代理区域具体是哪些？按省、市、区县，还是按渠道（商超、水果店、社区团购、电商）划分？
2. 区域内是独家代理，还是多家代理？如果是多家，我的保护范围是什么？
3. 品牌方自己或总部电商会不会在我区域内直营、开店、发货？算不算抢我的市场？
4. 区域内原有经销商、老客户怎么处理？是划给我，还是继续保留？
5. 区域保护有没有期限？续约条件是什么？完不成任务会不会取消独家？
6. 如果品牌方要在我区域内新增代理或渠道，需不需要我同意？有没有补偿？
7. 区域内出现低价乱价、跨区销售，品牌方有没有巡查和处罚机制？

**二、串货问题要问的问题**

1. 什么算串货？是跨区域销售算，还是跨渠道销售也算？
2. 线上销售算不算串货？比如淘宝、拼多多、抖音、社区团购，规则是什么？
3. 我区域内客户从外地进货，品牌方管不管？怎么查、怎么罚？
4. 我被别人串货冲击时，品牌方多久处理？处理结果怎么反馈？
5. 如果是我下面的二级商串货，责任算谁的？我会不会被罚？
6. 串货的处罚标准是什么？罚款、扣返利、断货、取消代理，分别对应什么行为？
7. 有没有保证金？串货扣不扣保证金？扣了之后怎么补？
8. 品牌方能不能提供每箱货的追溯码或区域码？没有追溯码，串货很难查。

**三、合同里必须写清楚的内容**

1. 代理区域、渠道、期限、独家还是非独家。
2. 年度/季度任务量、考核方式、完不成怎么办。
3. 品牌方直营、电商、新渠道的边界。
4. 串货定义、举报流程、处理时限、处罚标准。
5. 保证金、返利、账期、退换货、损耗承担。
6. 区域保护被破坏时，你的退出机制和补偿。
7. 争议解决方式，最好约定你所在地法院或仲裁。

**四、问的时候注意判断对方靠不靠谱**

- 如果对方说“区域保护没问题”“串货我们肯定管”，但不肯写进合同，要谨慎。
- 如果品牌方自己还在网上低价卖，却要求你不得线上销售，要问清是否双标。
- 如果连追溯码、区域码都没有，串货基本管不住。
- 如果任务量很高、保证金很高、退出很难，先算清自己的动销和资金压力。

**五、可以直接照着问的简版清单**

1. 我的区域是独家还是多家？保护范围写不写进合同？
2. 品牌方自己和电商在我区域卖不卖？算不算串货？
3. 串货怎么定义？线上算不算？二级商串货算谁的？
4. 发现串货找谁？多久处理？处罚标准是什么？
5. 有没有追溯码？没有的话怎么查串货？
6. 我被串货冲击，有没有补偿或退出机制？
7. 任务量、保证金、返利、退换货怎么定？

建议把这些问题整理成书面清单，让对方逐条回复，并作为合同附件。口头承诺不要作为依据。
