做稳定大客户，核心不是“要一个长账期”，而是把**账期、额度、价格、履约绑定成一个可交换的组合**。水果还有损耗、行情波动、回款风险，谈法比普通标品更细。

下面按可执行框架说。

## 一、先明确：你要的不是账期，是“资金占用+风险可控”

批发商想稳定大客户，通常希望：
- 账期长一点，缓解现金流
- 额度高一点，能接大单
- 价格稳一点，不被行情频繁打乱
- 供货稳一点，不断货、不临时涨价

但供应商关心的是：
- 回款是否安全
- 销量是否稳定
- 损耗谁承担
- 行情跌了客户还拿不拿货
- 账期一长，坏账和资金成本谁背

所以谈判要围绕一句话：**用确定性和量，换账期和额度。**

## 二、账期怎么谈：分层给，不要一口价

建议不要直接说“给我60天”。而是设计成阶梯：

| 合作阶段 | 账期建议 | 交换条件 |
|---|---|---|
| 首月/试单 | 现款或7天 | 先建立履约记录 |
| 稳定合作1-3个月 | 15天 | 月采购量达到约定底线 |
| 核心大客户 | 30天 | 月采购量稳定+保证金/担保 |
| 战略客户 | 30-45天 | 独家或主供+预付款+年度框架 |

实操话术：
“我们先按15天跑一个月，如果我月采购量稳定在X吨、退货率低于X%，第二个月调到30天。30天以上我可以接受部分预付款或保证金。”

关键点：
- **账期从短到长，不要一次要到底。**
- 账期要和“月采购量底线”绑定，达不到就回调。
- 水果行情波动大，账期最好写“对账日后X天”，不要写“发货后X天”，否则对账扯皮会拖长实际账期。
- 遇到节假日、春节前，供应商现金流紧，账期可能被压缩，提前谈好“节前现款、节后恢复”。

## 三、额度怎么谈：按“历史回款+可抵押”定

额度不是拍脑袋，通常按这几个维度定：

1. **月均采购额**：额度一般设为月均采购额的0.5-1倍。
2. **回款记录**：连续3个月准时回款，可申请提额。
3. **担保方式**：保证金、法人担保、房产/车辆抵押、第三方担保，都能换额度。
4. **单品风险**：叶菜、草莓、荔枝等损耗高的，额度要保守；苹果、橙子、土豆等耐储的，可适当放宽。

建议方案：
- 初始额度：月均采购额的50%
- 稳定3个月后：提到80%-100%
- 超过额度部分：现款或提前打款
- 超额临时提额：提前3天申请，单笔单议

话术：
“额度我不要求一步到位。先按50%跑，回款准时的话每季度提一次。超过额度的部分我现款，不让你垫资。”

## 四、必须谈清楚的5个风险条款

水果供应商最怕的不是账期长，而是账期长+扯皮。以下必须写进合同或书面确认：

1. **质量标准**：什么等级、什么规格、允许多少坏果率。避免“到了市场卖不动就压价”。
2. **验收和对账**：到货后几小时内验收，过期视为合格；对账单几日内确认，逾期视为认可。
3. **损耗承担**：运输损耗、卸货损耗、仓储损耗分别谁承担。通常发货前供应商承担，到货验收后客户承担。
4. **行情涨跌机制**：不能只锁价不锁量。建议“基准价+随行就市浮动”，但约定浮动上限，比如±10%内不调价。
5. **逾期和停供**：逾期几天开始计息、停供、取消额度。供应商也需要这个安全感。

## 五、最有效的谈判筹码

你手里能换账期和额度的，不只是“我会买很多”：

- **预付款**：哪怕10%-20%，也能明显换到更长账期。
- **保证金**：存一笔钱在供应商处，额度可以放大。
- **年度框架量**：承诺全年最低采购量，换30天账期。
- **主供地位**：减少他的销售不确定性。
- **自提/少退货**：你承担物流和部分损耗，他愿意放账期。
- **准时回款记录**：这是最硬的信用，前3个月一定要做到。

## 六、一个可直接用的谈判结构

你可以这样和供应商谈：

1. **先给确定性**：我计划每月稳定拿X吨，全年不低于X吨。
2. **再给安全**：首月现款或7天，第二个月15天，稳定后30天；可交保证金/预付款。
3. **再要条件**：账期30天，额度按月均采购额80%，超额现款。
4. **最后锁机制**：价格随行就市但设浮动上限；对账后X天付款；连续准时回款每季度提额。

## 七、一句话建议

**先用短账期和小额度建立回款记录，再用稳定采购量、预付款或保证金，逐步换到30天账期和月均采购额80%左右的额度；同时把质量、验收、损耗、涨跌机制写清楚。**  
这样供应商敢放账，你也能稳定拿货，双方才做得久。
