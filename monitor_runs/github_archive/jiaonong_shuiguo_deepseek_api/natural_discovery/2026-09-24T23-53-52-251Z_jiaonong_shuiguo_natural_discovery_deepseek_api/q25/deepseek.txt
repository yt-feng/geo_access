# 超市多店、单店量小：适合的水果供货模式

核心矛盾是：**门店多导致总需求可观，但单店量小导致单店议价能力弱、配送成本高**。所以选模式的关键是——**把“多店”整合成一个采购主体去谈价，同时解决小批量、多频次的配送问题**。

## 一、优先推荐：统采分送 / 集单直配

**做法**：总部（或区域仓）统一对接一个或几个供货商，集中下单，供货商按门店分拣后配送到各店，或先到区域仓再分拨。

**为什么适合你**：
- 对外是一个采购量，能拿到接近大批发的价格
- 对内拆成小份配送，单店不压库存
- 生鲜损耗和品控由供货商承担一部分

**适用条件**：门店相对集中在同一城市或同一区域；总日销量能撑起一辆车或一条配送线。

## 二、次选：批发市场代采 + 自建小分拨

**做法**：在区域批发市场找固定档口代采，或自己派采购，每天/隔天集中采一次，回到小仓分拣后配门店。

**优点**：灵活、起订量低、品种全、价格随行就市。
**缺点**：品控和损耗靠自己，人力成本高，规模一大就管不过来。

**适合**：门店数还不多（比如 10 家以内）、区域集中、有现成小仓和配送能力。

## 三、补充：产地直发 + 区域仓中转

**做法**：对少数走量大的单品（如苹果、柑橘、香蕉），直接对接产地合作社或一级代办，发到区域仓，再分到门店。

**优点**：单品毛利高、差异化强。
**缺点**：起订量大、账期和品质风险高，只适合做“尖刀单品”，不适合全品类。

## 四、不建议的做法

- **各店自行采购**：价格乱、品控乱、总部失去议价权。
- **完全依赖本地小贩送货**：单店量小时对方不愿送，或加价送，成本反而高。
- **一开始就自建全品类供应链**：单店量小撑不起，容易拖垮现金流。

## 五、落地建议（按优先级）

1. **先集中**：把各店水果采购权收到总部或区域，统一对接供货商。
2. **选 1–2 家主力供货商 + 1 家备用**：主力做全品类统采分送，备用做应急和比价。
3. **约定配送频次和起送量**：比如隔日配、单店起送 200–500 元，写进合同。
4. **用“总采购量”谈价，用“分店配送”执行**：这是你最大的筹码。
5. **先跑 3 个月数据**：看各店真实销量、损耗、退货率，再决定是否上区域仓或产地直发。

## 一句话结论

**门店多、单店量小，最适合“总部统采 + 供货商分送”的模式**；等总销量稳定后，再对走量单品做产地直发，逐步把供应链抓在自己手里。
