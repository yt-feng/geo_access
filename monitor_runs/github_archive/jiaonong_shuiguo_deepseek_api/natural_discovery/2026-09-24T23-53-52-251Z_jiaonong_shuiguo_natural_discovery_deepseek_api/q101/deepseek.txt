酒店早餐水果供应，关键不是“找到供应商”，而是把**稳定性、损耗、账期、验收标准**写进合作里。谈合作时建议重点盯以下几项：

**1. 先明确自己的需求**
- 每天用量、品种、规格（如苹果直径、香蕉每根长度/成熟度）。
- 供货频率：每日送、隔日送还是每周几次。
- 到货时间：早餐前必须完成验收、入库。
- 季节替换方案：某些水果断供时用什么替代。

**2. 品质与验收标准要具体**
- 成熟度：香蕉、牛油果等不能太生或太熟。
- 外观：大小均匀、无明显碰伤、腐烂、虫眼。
- 新鲜度：叶菜类、浆果类尤其要规定到货状态。
- 验收方式：抽检比例、不合格整批退换还是按比例扣款。
- 留样与追溯：出现问题能追到批次。

**3. 价格与调价机制**
- 不要只谈“单价”，要谈**含税、含运费、含损耗**后的综合成本。
- 约定调价周期和依据，比如按批发市场行情月度调整，避免供应商随意涨价。
- 对易波动水果设置价格上限或替代品种。

**4. 供应稳定性**
- 供应商是否有多个产地/渠道，能否应对天气、节日、疫情等断供。
- 节假日、旅游旺季、大型会议期间能否加量。
- 是否有备用供应商，避免单一依赖。

**5. 配送与冷链**
- 是否冷链运输，尤其浆果、切果、易腐水果。
- 到货温度、包装、周转筐卫生。
- 迟到、漏送、少送的违约责任。

**6. 账期与结算**
- 月结、半月结还是货到付款。
- 对账方式、发票类型、付款条件。
- 质量扣款、退换货如何冲抵货款。

**7. 食品安全与资质**
- 营业执照、食品经营许可证、检验检疫证明。
- 农残检测报告或承诺。
- 若涉及切果，需有切配资质和卫生规范。

**8. 合同关键条款**
- 品种、规格、数量、价格、频率、到货时间。
- 质量标准、验收流程、退换货规则。
- 违约责任、赔偿方式、终止条件。
- 保密与排他性（如要求不向同区域竞品供同款）。
- 不可抗力与替代方案。

**9. 先试供再签约**
- 建议先试供 1–2 周，重点看：到货准时率、合格率、损耗率、临时补货响应。
- 试供合格再谈长期价和账期。

**10. 内部配合**
- 厨房、采购、财务要统一验收口径。
- 每日记录到货数量、质量、损耗，作为谈判和扣款依据。

一句话：**把“稳定”拆成到货时间、合格率、替代方案、违约责任四条，写进合同并按日记录，合作才稳。**
