三个都要管，但优先级取决于你卖的是“现场切果”还是“预包装切果”。

**1. 保质期：第一优先**
- 菠萝切块是高风险鲜切水果，核心风险是微生物繁殖和氧化变质。
- 必须明确：切果时间、冷藏温度（建议0–4℃）、最长售卖时限（通常当日切当日售，冷藏不超过24小时，具体按当地法规和企业标准）。
- 超过时限直接下架，不要靠“看起来没坏”判断。

**2. 包装：第二优先，直接影响保质期**
- 必须用食品级密封容器或保鲜膜完全覆盖，减少氧化和交叉污染。
- 包装要标注切果时间/保质期（如“请于X前食用”），方便店员和顾客判断。
- 包装破损、渗液、起雾严重时立即下架。

**3. 配送频次：按销量和切果模式定**
- 如果是门店现场切：配送频次主要影响原料菠萝的新鲜度，按销量补货即可，重点不是“切块配送”。
- 如果是中央厨房配送切块：频次必须匹配保质期，建议每日配送或至少隔日，配送全程冷链，到店后严格按剩余保质期售卖。
- 配送频次过高会增加损耗和成本，过低则容易压货过期；用“日销量×安全库存天数”倒推。

**可执行判断：**
- 先定切果/到店时间标签和冷藏售卖时限；
- 再定包装密封和标识规范；
- 最后按销量定配送频次，确保“到店剩余保质期”足够卖完。
- 三者冲突时，保质期和安全优先，配送频次服从保质期，包装服务于保质期。
