建议以“整果为主、切果为辅”，但要看你的门店类型和客流结构，不能一刀切。

**优先卖整果更合适的场景**
- 社区超市、生鲜超市、菜市场旁门店：顾客有回家自己处理的习惯，整果周转快、损耗低、毛利更稳。
- 菠萝产季集中、进货价低时：整果走量快，适合做堆头促销。
- 门店人手紧：切果需要削皮、去眼、盐水浸泡、冷藏陈列，人工和损耗都高。
- 周边顾客以家庭采购为主：整果单价低、可挑可拿，接受度高。

**切果更适合作为补充的场景**
- 商圈店、写字楼店、年轻客群多的门店：即食需求强，切果能提升客单价和冲动购买。
- 门店有现切水果操作间和冷藏陈列条件：能控制卫生和鲜度。
- 整果出现外观瑕疵但品质没问题时：切果可消化部分次果，降低报损。
- 夏季下午到晚间客流高峰：小份切果、拼盘、杯装更适合即买即吃。

**采购和运营上的判断标准**
1. 先看门店过去水果品类数据：整果类销量占比、切果类销量占比、报损率。
2. 整果重点控“周转”：菠萝不耐长期存放，采购量按2—3天销量匹配，避免积压。
3. 切果重点控“损耗和食安”：必须冷藏、当日切当日售、明确标注切果时间，卖不完的及时处理，不要隔夜再卖。
4. 切果不要一开始铺太多SKU：先做小份装、单一口味，测试1—2周再决定是否扩品。
5. 定价上整果做引流和走量，切果做毛利补充；切果溢价要覆盖人工、包装和损耗。

**结论**
大多数商超门店：**整果是基本盘，切果是增量品**。如果门店在商圈、年轻客群集中、有现切条件，可以提高切果陈列比例；如果是社区店、人手有限、周转偏慢，优先把整果做好，切果只做小份试销。
