1. **价格支持**
   - 常见形式：周末特价供货、限时返点、满量返利、临期/尾货折扣、搭赠（进10箱送1箱）。
   - 供应商愿不愿意给，主要看：你平时采购是否稳定、周末促销量能否提前预估、是否主推它的品牌/单品、能否接受现款或批量进货。
   - 谈法：提前1–2周给供应商“周末单品预计销量+促销价+需要支持”，要求“专项供货价”或“卖完返差”，比空口要折扣更容易成。

2. **物料支持**
   - 常见形式：纸箱/陈列筐、海报/价签、试吃物料、品牌围挡、遮阳棚、小礼品、冷链周转箱。
   - 品牌类供应商通常有现成物料预算；本地批发商物料少，但可给陈列筐、包装盒、价签。
   - 谈法：把物料和进货量绑定，比如“周末进XX箱，能否配海报+价签+陈列筐”，并明确物料到店时间。

**判断建议：**
- 先找**你采购量最大的2–3个供应商**谈，别广撒网。
- 优先要**能直接降零售价的价格支持**，物料是加分项。
- 如果供应商不给直接降价，可谈**搭赠、返利、卖完补差**，效果接近。
- 小水果店议价弱，可用“周末集中主推你家单品+端头陈列+社群预告”换支持。

**注意：** 促销价要算清损耗和毛利，别为了拿支持进太多易损水果；物料支持最好书面/微信确认数量和时间，避免周末到不了店。
