供应商介绍产品时，最容易犯的错是堆术语、报参数，商家听不懂，自然不敢下单。核心思路是：**用商家熟悉的“大品类”做锚点，再把新品挂到他的经营场景上**。

具体可以按这个结构说：

**1. 先给“一句话定位”——用他懂的东西类比**
不要说“这是台农17号凤梨，糖度18”，而说：“这个就是菠萝的升级版，比普通菠萝甜、不用泡盐水，切开就能吃。”
类比公式：**它像什么（他熟悉的）+ 不一样在哪（一句话）+ 对他有什么好处**。
香蕉也可以类比：“这个比普通香蕉短一半，皮薄、熟得快，适合做小份果切或儿童零食。”

**2. 再讲“三个场景”——让他脑子里出现货架和顾客**
不要讲产地、品种编号，讲：
- **谁买**：上班族？宝妈？学生？
- **怎么吃/怎么用**：直接吃、做果切、榨汁、烘焙、送礼？
- **什么时候好卖**：早餐、下午茶、节日、夏季解暑？
例：“这个凤梨适合放收银台旁边做即食果切，下午三点到六点最好卖，一盒切四块，客单价能提两块钱。”

**3. 用“对比三句话”讲清差异**
商家最关心“和现有货比，凭什么进它”。只说三点：
- 比大品类**更好卖在哪**（口感、颜值、便利性）
- 比大品类**更省心在哪**（耐放、损耗低、不用额外处理）
- 比大品类**更赚钱在哪**（毛利空间、复购、搭配销售）
例：“比普通菠萝耐放两天，损耗低；不用削眼泡盐水，店员省事；切片卖毛利能高15%。”

**4. 给“最小试单方案”——降低决策门槛**
不要一上来推整箱整柜，说：“先拿一箱试试，放店里三天，卖不动我教你调陈列；卖得动再补。”
同时给一个**可执行的判断标准**：“三天内如果每天能卖出去8份果切，就值得长期上。”

**5. 最后留一个“傻瓜式话术”**
商家不会介绍产品，供应商可以直接给他一句对顾客说的话：“这是不用泡盐水的甜菠萝，切开就吃。”商家一听就知道怎么卖，下单意愿会明显提高。

**总结成一句话**：介绍新品时，**用大品类做翻译，用场景做画面，用对比做理由，用试单做台阶**。商家听懂的不是品种名，而是“这个货放我店里怎么卖、能多赚多少”。
