先抓核心：这两件事不能只听口头承诺，要把“区域保护”和“串货”拆成可写进合同、可核验、可追责的条款来问。建议按下面顺序谈。

一、先问区域保护：到底保护什么

1. 授权区域是“独家”还是“非独家”？独家的话，是只给你一家，还是按渠道/品类再分？
2. 保护边界按什么划：行政区、商圈、渠道（商超/餐饮/批发/电商），还是按客户名单？跨渠道算不算越界？
3. 品牌方在授权区域内是否还直营、开旗舰店、做电商、供货给其他批发商？这些要不要提前书面排除？
4. 授权期限多长？续约条件是什么？达不到销量是否自动降级或取消独家？
5. 区域内出现其他供货来源时，品牌方承担什么责任：限期处理、补偿、还是你有权解约并退货？
6. 线上销售怎么算？你是否被允许开网店、做直播、上社区团购？线上订单归属按发货地还是收货地？

二、再问串货：定义、证据、处理

1. 什么行为算串货：跨区域销售、低价倾销、把货供给非授权二级商、电商乱价，分别怎么认定？
2. 品牌方怎么查串货：有没有批次码/防窜码/物流追踪？你是否能申请查询？
3. 发现串货后处理流程：谁举证、多久响应、先停货还是先罚款、处理结果是否书面反馈？
4. 对串货方的处罚标准是什么？对受影响经销商有没有补偿或调货支持？
5. 你自己被误判串货时怎么申诉？有没有复核机制？
6. 如果品牌方自己或大客户串货，是否同样处理？这条要特别问，很多矛盾出在“只罚小商不罚大商”。

三、必须落到合同里的内容

- 授权区域、渠道、期限、独家属性写清楚；
- 区域保护的具体义务和违约后果；
- 串货定义、举证责任、处理时限、处罚与补偿；
- 价格体系与最低限价/建议零售价规则；
- 退货、换货、临期品处理；
- 解约条件与库存回购安排。

四、谈判时的判断标准

可以优先合作的情况：能明确写独家区域、有批次追踪、串货处理有时限和补偿、品牌方自己受同样约束。
需要谨慎的情况：只说“放心不会串”、保护范围含糊、处罚只针对你、线上归属说不清、没有书面串货处理机制。

一句话问法可以这样开场：“请把授权区域按行政区和渠道写进合同，并明确品牌方直营及电商是否排除；同时请提供串货认定标准、追踪方式和处理时限，作为合同附件。”
