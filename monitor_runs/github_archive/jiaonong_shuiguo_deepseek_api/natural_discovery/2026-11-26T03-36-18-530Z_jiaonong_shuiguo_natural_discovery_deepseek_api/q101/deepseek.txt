酒店早餐水果供应，核心是“稳定+可追溯+成本可控”。和供应商谈合作，建议重点盯以下几类事项：

1. **明确供应标准**
   - 按品种约定规格：单果重量/直径、成熟度、糖度、外观瑕疵率。
   - 约定等级和验收标准，最好写进合同附件，避免“看货再说”。
   - 早餐常用水果可分批分级：香蕉、苹果、橙子、西瓜、哈密瓜、圣女果等，分别定标准。

2. **锁定稳定供应能力**
   - 问清产地、季节替代方案、日供应量上限、节假日和极端天气预案。
   - 要求供应商说明冷链能力、仓储条件、配送频次和到店时间窗口。
   - 约定缺货时的替代品种和提前通知时限，避免早餐断档。

3. **价格与结算机制**
   - 不要只谈单价，要谈“含税、含运费、含损耗”的到店价。
   - 约定价格调整机制：按周/月报价，或参考批发市场指数，设置涨跌幅上限。
   - 明确账期、发票类型、对账周期和付款方式。

4. **质量与食品安全**
   - 要求提供营业执照、食品经营许可证、检测报告/承诺达标合格证。
   - 约定农残、重金属等抽检责任和超标处理方式。
   - 明确退货、换货、扣款规则：坏果率超标怎么赔，到货不合格怎么处理。

5. **损耗与验收**
   - 约定验收时间、验收人、抽检比例和拍照留证流程。
   - 明确“到店损耗”和“酒店储存损耗”的责任边界。
   - 早餐水果通常要求去皮切配，若供应商提供净果/切配服务，要单独约定加工卫生标准和配送温度。

6. **配送与应急**
   - 约定每日配送频次、最晚到货时间、临时加单响应时间。
   - 要求备用联系人、备用车辆或备用供应商方案。
   - 节假日、大型会议、团队入住前要有增量保供确认。

7. **合同关键条款**
   - 供应品种、规格、单价、数量预估、结算方式。
   - 质量标准、验收流程、退换货和违约责任。
   - 食品安全责任、赔偿条款、保密与廉洁条款。
   - 合同期限和退出机制，避免被单一供应商绑定。

8. **先试供再签约**
   - 建议先做2—4周试供，按实际到货合格率、准时率、缺货次数、客诉情况评估。
   - 可同时保留1家备选供应商，形成“主供+备用”格局。

谈判时最值得坚持的三件事：**验收标准写清楚、缺货预案写清楚、坏果扣款写清楚**。这三项直接决定早餐水果是否真的“稳定”。
