社区团购旺季锁库存，核心不是“打个招呼让供应商留货”，而是用**可执行的合同+分阶段锁量+备选供应+品控前置**把口头承诺变成可追责的供货安排。建议按下面做：

## 1. 先做需求预测，按SKU给供应商“分级锁量”
- 把旺季拆成周/日，按历史销量、活动排期、天气和节假日做**保守/基准/乐观**三档预测。
- 对水果分三类：
  - **爆款大单品**（如苹果、橙子、砂糖橘）：锁70%–80%需求量，留20%–30%机动补货。
  - **易损耗高波动品**（草莓、荔枝、樱桃）：只锁短期3–7天量，分期下单。
  - **引流小单品**：不重仓锁，按周滚动补。
- 锁量用“**基础量+浮动量**”：基础量供应商必须保供，浮动量提前48–72小时确认，避免一次性压死库存。

## 2. 和供应商签“锁量不锁价/部分锁价”的书面协议
协议至少写清：
- **锁定数量、规格、等级、产地、包装标准**；
- **分批次交付时间、每日/每车上限**；
- **价格机制**：旺季可接受部分锁价，但约定涨价上限或随行就市公式；
- **违约条款**：供应商少供的赔偿、采购方不提货的赔偿，双向约束；
- **质量扣罚**：坏果率、糖度、大小规格不达标如何处理；
- **优先供货权**：旺季期间供应商对同区域其他客户不得优先挤占你的量。

口头“留货”在涨价时最容易失效，必须落到订单/合同/定金。

## 3. 用定金和预付款换优先权，但分批支付
- 对核心供应商支付**10%–30%定金**锁定基础量，尾款按批次验收后付。
- 预付款不要一次性打给单一供应商，按“周锁量、周结算”滚动推进。
- 要求供应商提供**每日可发量确认单**，你方按确认单安排团购开团，避免超卖。

## 4. 建立“主供+备供”双通道
- 每个爆款至少准备**2家供应商**，主供锁60%–70%，备供锁20%–30%。
- 备供平时给小单养着，旺季才调得动。
- 跨产区备份：比如砂糖橘主供广西，备供云南/广东；苹果主供山东，备供陕西。
- 提前确认备供的**包装、冷链、到仓时效**是否匹配，别等断供才试。

## 5. 品控和收货能力前置
爆单时最大风险是“货来了但烂了/分拣不过来”。提前做：
- 要求供应商**提前采摘/预冷/分级**，约定到仓验收标准；
- 旺季前在仓库附近设**临时周转仓或分拣点**；
- 对易损耗水果要求**到仓抽检+照片留证+当日反馈**；
- 约定“不合格批次可拒收且不计入锁量完成率”，防止供应商用次果充数。

## 6. 用滚动订单替代一次性大单
每周给供应商下**滚动3周预测+1周确定订单**：
- 第1周：确定订单，供应商必须保供；
- 第2–3周：预测订单，供应商备货但不承担全部违约责任；
- 每周更新，既让供应商敢备货，又避免你压错品。

## 7. 关键动作清单（可直接执行）
1. 本周内拉出旺季Top20水果SKU，按周做三档销量预测。
2. 每个SKU确定主供、备供各至少1家，签锁量协议。
3. 对Top5爆款支付定金锁基础量，约定每日确认发量。
4. 建立供应商每日报量群，要求前一天18点前确认次日可发量。
5. 设定断供预案：备供切换阈值（如主供当日缺量超20%即启动备供）。
6. 到仓验收标准写成一张表，发给所有供应商并签字确认。

**一句话判断标准**：如果供应商只是口头说“给你留着”，不算锁定；只有**书面数量+时间+定金/违约条款+每日确认机制**同时具备，才算旺季库存真正锁住。
