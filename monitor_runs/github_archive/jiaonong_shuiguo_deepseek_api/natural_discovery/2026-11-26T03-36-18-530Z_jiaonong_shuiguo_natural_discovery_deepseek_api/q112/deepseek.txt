坏果率赔付没有全国统一的法定阈值，关键看你合同怎么约定、按什么环节验收。实务建议：

1. **合同里最好明确写“允许坏果率”和“超标赔付”**
   - 常见做法：约定一个**允许损耗率**，例如到货验收坏果率≤3%～5%视为合格；超过部分按比例扣款或换货。
   - 更严谨的写法：坏果率超过约定值后，**超标部分按重量/金额比例赔付**，而不是一超标就全批拒收。例如约定允许3%，实际8%，则对超出3%的5%部分按货值扣减或索赔。
   - 若坏果率极高（如超过10%～15%），可约定买方有权拒收、退货或解除该批次合同。这个“拒收线”要单独写，不要和“扣款线”混在一起。

2. **不同水果、不同运输距离，阈值应不同**
   - 易腐水果（草莓、樱桃、荔枝、水蜜桃）允许值通常更低；耐储水果（苹果、橙子）可略高。
   - 长途冷链运输可适当提高允许损耗，但应要求卖方提供冷链记录。
   - 不要只写一个笼统的“坏果率超过5%赔付”，要写清楚是**到货验收时**还是**卸货后若干小时内**检测。

3. **验收和取证条款比阈值更重要**
   - 约定到货后**多长时间内**完成验收（如2小时/4小时/24小时），逾期视为合格。
   - 约定抽样方法：随机抽取若干箱/若干公斤，还是全检；抽样不合格如何扩大检测。
   - 约定双方共同验收、拍照/视频留证、第三方检测机构介入的条件。
   - 明确“坏果”定义：腐烂、霉变、机械伤、冻伤、虫害是否都算，避免扯皮。

4. **赔付计算方式要可执行**
   - 推荐写：`赔付金额 = 超标坏果重量 × 该批次单价 × 赔付倍数`，或`按超标比例扣减该批次货款`。
   - 也可约定固定违约金+实际损失赔偿，但违约金过高可能被调整。
   - 若已约定质量保证金，可从保证金中直接扣除。

**结论**：不要问“超过多少法定该赔”，而应在合同中写清三档：**合格线（如≤3%～5%）、扣款线（超标部分按比例赔）、拒收线（如>10%～15%）**，并配套验收时限、抽样方法和取证规则。具体数值按水果品类、运输方式和双方议价能力确定。
