先按“水果品类特性”分开定标准，再用同一套准入和考核流程选供应商。香蕉、苹果、橙子保鲜期和损耗差异大，不建议用同一家供应商硬配全品类，优先找有对应单品优势的供应商，或让综合供应商分品类报价。

**一、先定采购策略**
1. **苹果、橙子**：耐储，适合按周/半月集中采购，可招综合供应商或产地/一级批发商。
2. **香蕉**：后熟、易压伤，适合小批量高频配送，优先选有催熟/控温能力、能按成熟度分档配送的供应商。
3. 学校食堂要明确：是“送到食堂”还是“送到库房”，是否含卸货、分拣、退换货。

**二、供应商准入硬门槛**
- 营业执照、食品经营许可证齐全；涉及食用农产品承诺达标合格证或产地证明。
- 有固定经营场所、分拣场地、冷藏/常温运输能力；香蕉供应商最好有催熟库或稳定控温配送。
- 能提供每批次农残检测报告或承诺达标合格证，学校可定期抽检。
- 有学校、机关食堂或团餐配送经验；能接受账期、退换货和应急补货。
- 报价单必须列明：品名、规格、产地、等级、单价、配送费、损耗承担方式、结算周期。

**三、分品类验收标准**
- **香蕉**：按成熟度分档，如“青蕉/微黄/黄熟”；到货黄熟比例要匹配当天或次日食用；无严重压伤、黑斑、断把；单把重量和每箱净重稳定。
- **苹果**：品种、果径、等级统一；无腐烂、无明显磕碰伤；脆度或口感按学校要求抽验；箱内净重不能靠大果充数。
- **橙子**：果径、糖酸度、皮厚薄稳定；无霉变、裂果、严重失水；按品种和产区锁定，避免同价换低质品种。

**四、比价不要只看单价**
用“可食率+损耗率+配送频次”算实际成本。比如香蕉损耗高，单价低但压伤多、配送频次高，总成本可能更高。要求供应商按“净重结算”或明确损耗赔付，避免毛重计价比价失真。

**五、合同和考核**
- 合同写清：质量标准、验收方法、不合格退换货时限、缺货替代方案、价格调整机制、食品安全责任。
- 每批次留样或拍照记录，验收单双方签字。
- 按月考核：到货合格率、损耗率、准时率、缺货率、投诉处理。连续不达标降量或退出。
- 至少保留2家备选供应商，香蕉单独备一家，防止单一供应断档。

**六、实际执行顺序**
先发询价单收集3—5家报价和资质；再带样品试吃、看分拣场地和配送车辆；然后小批量试供2—4周；试供合格后签框架合同，按周下单、按月结算；每学期重新比价或议价，但不要只换低价，先看合格率和损耗。

一句话：苹果、橙子找稳定耐储的批发/产地供应商，香蕉找有催熟和控温配送能力的供应商；准入看证照和检测，验收看成熟度、净重和损耗，合同把退换货和考核写死。
