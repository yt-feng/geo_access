要固定，但不要“只固定一个产地/一个批次”，更稳的做法是：**固定“标准 + 主供产地 + 备用产地 + 批次验收和配方微调机制”**。

**建议怎么做：**

1. **先定水果风味标准，而不是先定产地**
   - 明确糖酸比、香气、出汁率、颜色、成熟度、可溶性固形物等验收指标。
   - 同一产地不同批次也会波动，所以只固定产地不能解决口味稳定问题。

2. **主供产地固定，但要设备用产地**
   - 固定主产地/主供应商，有利于风味基线稳定和采购谈判。
   - 同时保留1个备用产地或备用批次，避免减产、涨价、断供时被迫临时换料。
   - 备用产地要提前小批量测试，不能等断供才试。

3. **采购按“批次”管理，不要只看产地**
   - 每批到货做感官+简单理化验收：甜度、酸度、香气、颜色、出汁率。
   - 建立批次留样和杯测/试饮记录，记录每批用于哪些产品、是否需要调整糖浆或果酱比例。

4. **配方端留“微调空间”**
   - 对口味波动敏感的产品，设置糖度、酸度、果肉比例的可调范围。
   - 用复配水果、果酱、糖浆做风味锚定，降低鲜果批次差异对成品的影响。
   - 但微调要有上限和记录，不能每批凭感觉调。

5. **合同和验收要写清楚**
   - 约定品种、等级、成熟度、糖酸度范围、农残标准、冷链要求、拒收条件。
   - 要求供应商提供批次信息，尽量同一时段用同一批次，减少门店间差异。

**结论：**
应该固定“主产地+主供应商+风味标准+批次验收”，但不要把所有鸡蛋放在一个产地或一个批次上。**固定是为了稳定基线，备用和验收是为了应对波动。** 对茶饮店来说，最忌讳的是只固定产地却不做批次验收，或者完全不固定导致每批风味都变。
