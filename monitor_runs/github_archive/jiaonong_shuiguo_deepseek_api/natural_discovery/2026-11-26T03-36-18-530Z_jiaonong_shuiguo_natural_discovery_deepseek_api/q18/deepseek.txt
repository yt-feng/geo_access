想避免“到店太生或太熟”，核心是**先按用途定熟度，再按超市现场的外观+手感挑，不要只看颜色**。给你一套可直接执行的判断法。

### 1. 先定你要什么时候吃
- **当天/明天吃**：选**通体金黄、少量褐斑**的。
- **2–3天内吃**：选**金黄带一点青肩**（蒂部附近略青）。
- **4–6天后吃**：选**黄绿相间、棱角明显**的。
- **买回去做奶昔/烘焙**：可选**带褐斑但果肉不软烂**的。
- **别买**：大面积青绿且硬、或通体深褐且发软流汁的。

### 2. 到店快速判断
**看颜色**
- 青绿：很生，适合放几天。
- 黄中带绿肩：偏生到适中，耐放。
- 全黄：适口，通常1–2天内吃。
- 黄带少量褐斑：最甜，尽快吃。
- 大面积褐黑、蒂部发黑：过熟或已坏。

**看棱角**
- 棱角很分明、像有“脊”：偏生。
- 棱角圆润不明显：成熟度高。

**摸手感**
- 硬邦邦：生。
- 轻按有弹性、不塌：刚好。
- 一按就陷、局部发软：过熟。
- 表皮黏、渗汁、有酒味：别买。

**看果柄和两头**
- 果柄青绿、切口新鲜：较新。
- 果柄发黑干枯：放久了。
- 两头开裂、发黑、霉点：不要。

### 3. 超市采购的实用技巧
- **别买一整串熟度完全一样的**：挑“黄中带青”的一串，回家可分批吃；如果只想两三天吃完，再选全黄。
- **优先拿货架里层/下层**：灯光直射和频繁翻动会让表层香蕉更熟或碰伤。
- **避开冷藏区旁边的香蕉**：低温易冻伤发黑，虽然不一定坏，但口感和外观差。
- **看有没有挤压伤**：局部透明/水渍状软斑，回家很快烂。
- **不要买整串最外侧被压的那几根**，除非你当天吃。
- **买回家后**：想催熟可和苹果放纸袋常温；想延缓成熟，成熟后拆散、蒂部包保鲜膜放阴凉处，别整串放冰箱冷藏（会黑皮）。

一句话：**当天吃选全黄微斑，几天后吃选黄中带青、棱角略明显、手感硬中带弹的。**
