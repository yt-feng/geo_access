对餐饮连锁采购水果，**多数情况下“中央厨房统一收货（或至少统一定供应商+统一下单+分区配送/验收）”更好**；但水果品类差异大，建议采用“**统采统控、分级收货**”的混合模式，而不是一刀切。

## 结论
- **水果作为连锁采购品类：优先中央统一收货/统一管控**，尤其是苹果、橙子、香蕉、西瓜等耐储、标准化程度较高的品类。
- **浆果、叶菜类水果、熟度敏感水果（草莓、蓝莓、荔枝、桃等）**：可门店直收或“越库配送+门店验收”，但价格、供应商、质量标准仍由总部统一。
- **不建议完全门店分开收货**：容易造成价格不透明、质量不一致、供应商管理失控、食品安全追溯困难。

## 为什么中央统一收货更好
1. **议价与成本**：总部集中采购量，价格更稳，减少门店各自谈价。
2. **质量标准统一**：糖度、规格、成熟度、损耗标准可统一验收。
3. **食品安全与追溯**：供应商资质、检测报告、批次追溯集中管理。
4. **供应商管理**：减少门店私下换供应商、吃回扣。
5. **数据与损耗分析**：统一收货数据可做采购预测、门店损耗对比。

## 什么时候门店分开收货更合适
1. **鲜度要求极高、周转极快**：如门店现切水果、精品果切。
2. **中央厨房距离远、冷链能力弱**：长途配送导致损耗高于门店直收。
3. **门店密度低、单店销量小**：统一配送成本不划算。
4. **本地特色水果/季节性强**：需要本地快速采购。
5. **门店有成熟验收能力**：能执行总部统一验收标准。

## 推荐落地模式
**总部统采 + 中央厨房/配送中心统一收货 + 门店分级验收**
- **总部**：定供应商、定价格框架、定质量标准、定合同。
- **中央厨房/配送中心**：对耐储水果统一收货、分拣、配送。
- **门店**：对熟度敏感水果做到店验收，按总部标准拍照/称重/记录。
- **例外直收**：门店直收需总部审批，供应商仍在总部合格名录内，价格按框架执行。
- **考核**：损耗率、验收合格率、投诉率、门店私自采购率。

## 判断标准
如果满足以下多数条件，选**中央统一收货**：
- 门店数量多、采购量大；
- 水果SKU相对稳定；
- 有冷链/配送中心；
- 质量投诉和损耗需要统一管控；
- 食品安全追溯要求高。

如果满足以下多数条件，选**门店直收+总部管控**：
- 门店少且分散；
- 水果以本地鲜销、熟度敏感为主；
- 配送半径大、冷链成本高；
- 单店采购量小；
- 总部已有强验收和巡检体系。

**一句话建议：不要“门店完全分开收货”，而是“总部统采统控，中央厨房收耐储品，门店验收鲜度敏感品”。**
