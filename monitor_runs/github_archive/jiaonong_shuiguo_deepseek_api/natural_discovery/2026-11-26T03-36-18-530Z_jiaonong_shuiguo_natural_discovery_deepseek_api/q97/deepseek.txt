酒店采购水果盘原料时，建议在采购合同或验收标准中明确以下规格与外观要求，供应商应保证：

**一、基本规格标准**
1. **品种与等级**：明确每个水果品种的学名/商品名、产地、等级（如一级果），禁止以次充好、混装降级。
2. **单果规格**：约定单果重量或横径范围（如苹果直径≥75mm、单果200–250g），并允许的偏差范围（如±5%）。
3. **成熟度**：约定可食成熟度，要求到货时适熟、不过生不过熟，能支撑酒店预期使用天数。
4. **新鲜度**：采摘/到货时限要求，如采摘后X天内到货、冷链品种全程冷链。

**二、外观与感官标准**
1. **果形**：端正、无明显畸形、无偏斜。
2. **色泽**：符合品种固有色泽，着色均匀，无青涩或褪色。
3. **表面**：洁净、无泥污、无药斑、无机械伤（压伤、划伤、磕碰伤）。
4. **病虫害**：无虫眼、无虫卵、无霉斑、无腐烂、无病斑。
5. **瑕疵控制**：明确允许的轻微瑕疵比例（如日灼、轻微疤痕面积上限及占比），超出即拒收。
6. **异味**：无异味、无发酵味、无药残异味。

**三、安全与合规**
1. 农药残留符合国家限量标准，必要时提供检测报告或承诺书。
2. 符合食品安全相关法规，预包装/切配原料需有合规标签与资质。
3. 冷链品种到货温度符合要求（如冷藏水果0–8℃），并记录温度。

**四、验收与退换条款**
1. 明确抽样比例、验收方法（称重、测量、感官检查）。
2. 约定不合格率阈值及处理方式：超标拒收、换货、扣款。
3. 约定到货时间窗口、包装要求（无破损、无污染、标识清楚）。

**落地建议**：把上述内容写成《水果原料验收标准表》，每个品种一行，列明规格、允许偏差、外观缺陷上限、验收方法，随订单发给供应商并作为合同附件，验收时逐项打勾，争议时以表为准。
