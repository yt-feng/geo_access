建议按“能不能证明这批货合规、可追溯、出了问题能定位”这条线去要资料，不要只要一张合格证。

**一、优先索取的资料**
1. **批次对应的检测报告**
   - 要求检测报告上的**产品名称、供应商/生产企业、检测日期、批次或产地信息**与本次到货能对应。
   - 重点看是否有**农药残留项目**，检测依据是否为现行食品安全国家标准，结论是否合格。
   - 不接受“一份报告长期通用、与批次无关”的做法；至少要求按供货批次或按约定周期提供。

2. **供应商资质**
   - 营业执照。
   - 若为生产企业：食品生产许可证或相关许可资质。
   - 若为种植合作社/基地直供：产地证明、种植基地信息、合作社资质等。
   - 若为贸易商：其上游供货来源和资质链条。

3. **进货凭证和追溯信息**
   - 发票或送货单，注明品名、数量、批次、产地、供货日期。
   - 产地证明或承诺达标合格证；承诺达标合格证不能替代检测报告，但可作为追溯和自律材料。
   - 包装标识、采收日期、入库/出库记录等能实现批次追溯的信息。

4. **质量保证/合同条款**
   - 合同中明确农残超标的责任、退货赔偿、抽检不合格处理方式。
   - 要求供应商对每批货物提供合格承诺，并约定超市可自行送检、费用及责任承担。

**二、建议的验收动作**
- 每批到货核对：**报告批次与实物批次是否一致**。
- 对高风险品种、新供应商、季节性品种提高抽检频次，可自行送第三方检测。
- 建立供应商档案和批次台账，留存检测报告、送货单、产地信息至少按企业制度期限保存。

**一句话：** 先要“**批次对应的农残检测报告 + 供应商资质 + 产地/进货追溯凭证 + 合同质量责任条款**”，其中检测报告必须能和这批水果对上，否则参考价值有限。
