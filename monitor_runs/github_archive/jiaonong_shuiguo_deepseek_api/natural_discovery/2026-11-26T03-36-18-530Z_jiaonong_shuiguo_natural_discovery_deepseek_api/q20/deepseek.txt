社区超市找每日配送的水果供应商，重点不是“谁便宜”，而是**能否稳定按你的节奏交付、损耗可控、账期和退换可执行**。建议按下面条件逐项筛选和试单。

**1. 配送能力（一票否决项）**
- 能否**每天固定时段送达**，是否支持临时加单、节假日配送。
- 配送车辆是否有**冷藏/保温能力**，叶菜、浆果、切果类对温度敏感。
- 从批发市场/产地到你店里的**运输时长**，超过几个小时会明显增加损耗。
- 缺货时怎么处理：是提前通知、替代品补位，还是事后扣款。

**2. 货源与品类匹配**
- 是否有**稳定基地或一级批发渠道**，不是临时倒货。
- 能否覆盖你日常销量最大的**10—20个核心单品**，而不是样样都有但都不稳。
- 是否支持**小批量多频次**，社区超市单店销量有限，大批量压货风险高。
- 季节性替代方案是否提前给，避免某个单品断供后货架空置。

**3. 品质与验收标准**
- 要求提供**明确分级标准**：果径、糖度、成熟度、允许瑕疵比例。
- 是否接受**到店验收、当场拒收**，拒收部分怎么补、怎么扣款。
- 破损、腐烂、短斤少两的**赔付比例和时限**要写进合作约定。
- 先看样品不够，必须**连续试配7—14天**，观察不同天气和周末高峰的表现。

**4. 价格与结算**
- 报价要问清是**含税含运费到店价**，还是市场自提价。
- 是否随行就市每天报价，有没有**价格保护或涨跌幅约定**。
- 账期是现结、周结还是月结；押金、最低起送量、退换货成本谁承担。
- 不要只看单价，算**综合损耗率后的实际成本**。

**5. 售后与响应**
- 出现品质问题，**几小时内响应、多久补货**。
- 是否有固定对接人，避免每天换人报价。
- 旺季或极端天气是否有**备选供应方案**。

**6. 合规与安全**
- 营业执照、食品经营相关资质是否齐全。
- 有无**农残检测或进货凭证**，至少能提供批次来源。
- 配送人员健康证、车辆卫生情况也要看。

**可执行做法：**
先找2—3家同时试配，连续两周记录：到货时间、缺货率、损耗率、拒收处理速度、实际结算价。两周后按“**稳定性＞损耗＞价格＞账期**”排序，再签短期合作协议，约定试配期和退出条件。单店日销量不大时，优先选**本地一级批发商或区域配送商**，比直接找产地更现实。
