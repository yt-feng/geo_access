可以，但要分清“供应商能提供什么”和“商超自己要定什么”。通常水果供应商/包装厂能提供以下几类支持：

1. **包装形式支持**
   - 提供现成包装袋、保鲜袋、吸塑盒、纸盒、礼箱、网套、标签等。
   - 按商超要求做定制印刷：品牌名、规格、产地、等级、追溯码、条码位置等。
   - 提供不同克重/厚度/透气性的保鲜膜、包装袋建议。

2. **规格支持**
   - 按果径、单果重、个数/盒、净重等分级。
   - 做不同规格组合：如单果装、2个装、4个装、家庭装、礼盒装。
   - 提供分级设备或人工分选，但**规格标准要商超确认**。

3. **包装与保鲜适配**
   - 根据水果品类建议包装方式，比如草莓用透气盒、葡萄用保鲜袋+吸水纸、苹果用网套+纸箱。
   - 提醒哪些包装会影响呼吸、压伤、冷凝水。

4. **标签与合规支持**
   - 打印标签、贴标、喷码。
   - 提供产地、等级、净含量、执行标准、保质期/贮存条件等信息模板。
   - 但**自有品牌商标、条码、责任主体、标签合规审核要商超自己负责**。

**商超不能完全交给供应商的事：**
- 自有品牌定位和价格带；
- 最终规格标准与验收标准；
- 商标授权、条码归属；
- 包装稿合规审核；
- 品质稳定性和损耗责任划分。

**建议落地做法：**
先选1—2个单品试点，商超给出“规格书+包装稿+验收标准”，供应商打样，做小批量试销，测损耗、陈列效果和客诉，再放大。合同里明确：包装打样确认、批次一致性、破损率、标签错误责任、最小起订量和换版费用。

一句话：**包装和规格执行供应商能支持，但标准和品牌责任必须商超自己定。**
