建议按“香蕉走本地批发、苹果走稳定供应商”为主，再用小批量试销和损耗数据调整。

- **香蕉：优先本地批发**
  - 香蕉成熟快、损耗高、价格波动大，社区店单次量小，更重要的是“勤进快销、可退换、能补货”。
  - 本地批发便于控制成熟度（青一点/黄一点）、缩短到店时间，卖相和损耗更好。
  - 谈条件时重点问：能否按成熟度分级供货、次品/烂果能否换货、每周能否多次小批量补货、到货时间是否固定。

- **苹果：优先稳定供应商**
  - 苹果耐储、规格和口感稳定更重要，顾客复购看的是“每次差不多”。
  - 稳定供应商更容易保证等级、糖度/脆度、包装规格和持续供货，适合做日常主推款。
  - 谈条件时重点问：等级标准、产地/品种是否稳定、最小起订量、破损率赔付、节假日前能否保供、价格调整提前多久通知。

**可执行做法：**
1. 先各选2家：香蕉找2个本地批发商，苹果找2个稳定供应商。
2. 每个单品先小批量试销7—10天，记录日销量、损耗率、毛利率、缺货次数、顾客反馈。
3. 香蕉看“损耗率+补货频次”，苹果看“规格稳定+复购反馈”。
4. 试销后用数据定主供应商，但保留一个备选，避免单一渠道断供。

**判断标准：** 如果本地批发能稳定小批量、换货及时，香蕉就本地；如果苹果本地批发等级波动大、断货多，就选稳定供应商。不要只看进价，社区超市更应看“损耗后毛利+缺货损失+顾客复购”。
