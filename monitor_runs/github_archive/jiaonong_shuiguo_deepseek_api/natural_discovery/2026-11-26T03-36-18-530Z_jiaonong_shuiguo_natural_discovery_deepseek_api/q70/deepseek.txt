# 生鲜批发合同中坏果责任的写法

核心思路：**把“谁承担、怎么认定、怎么赔、何时提异议”四件事写死**，避免到货后扯皮。以下是可直接套用的条款要点。

## 一、先明确验收与风险转移节点

关键句建议：

> 货物交付以买方或其指定收货人在收货单上签字/盖章为交付完成。交付前的一切损耗（含腐烂、压伤、霉变、失水等）由卖方承担；交付后因买方储存、运输不当造成的损耗由买方承担。

注意：**签字不等于认可质量**，要单独约定质量异议期（见第三条），否则签收后难追责。

## 二、损耗率的认定标准（最关键）

不要只写“坏果由卖方负责”，要可量化：

> 双方约定到货验收合格率为不低于 ___%（建议按品类定，如叶菜95%、浆果90%）。验收时按随机抽样 ___ 箱/件，坏果（腐烂、霉变、严重压伤、异味）重量占比超过 ___% 的部分，视为卖方责任，由卖方按下列方式补偿。

同时约定**认定方法**：抽样比例、以重量还是件数计、由谁共同验货、拍照录像留存、必要时第三方检测。

## 三、质量异议期与举证

> 买方应在到货后 ___ 小时内（建议易腐品类6–24小时）完成验收并书面（含微信、邮件）提出异议，附照片/视频及抽样记录。逾期未提出的，视为质量合格；但存在隐蔽性腐烂、内部霉变的，买方可在 ___ 日内提出，并保留证据。

> 卖方有权在接到异议后 ___ 小时内到场复验或委托第三方复验，复验费用由责任方承担。

## 四、赔偿方式（三选一或组合）

1. **扣款/折价**：超出约定损耗率的部分，按该部分货值的 ___%（建议100%–150%）从货款中扣除。
2. **补货**：卖方在 ___ 日内补发同等数量合格货物，运费由卖方承担。
3. **退货退款**：整批不合格率超过 ___%（如30%）的，买方可整批退货，卖方退还货款并承担往返运费。

建议写：**“买方有权选择上述方式之一，卖方不得拒绝。”**

## 五、包装与运输责任

> 卖方负责包装符合长途运输要求（如加冰、透气、防压），因包装不当导致的损耗由卖方承担。运输由 ___ 方负责，运输途中因温控/挤压造成的损耗由承运方或按其约定承担；买方自行安排运输的，装车后风险转移，但货物本身质量问题仍由卖方负责。

## 六、兜底与争议解决

> 本合同未约定的损耗争议，双方应先行协商并共同取样封存；协商不成的，提交 ___ 仲裁/法院。封存样品保留至争议解决完毕。

## 实操提醒

- **按品类分别约定损耗率**，别用一个数字套所有货。
- 条款里避免只写“坏果包赔”这种模糊表述，一定要有**比例、时限、举证方式、赔偿计算**。
- 建议附一份《验收标准与抽样方法》作为合同附件，写清抽样基数、判定标准（如腐烂面积>1cm²计为坏果）。
- 首次合作可先小批量试单，把实际损耗数据写进后续合同。
