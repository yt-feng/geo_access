判断商超生鲜供应商的“售后响应稳定性”，不能只听口头承诺，建议用“条款+试单+考核”三件事来验证。菠萝和香蕉都属于易损、后熟快、批次差异大的品类，重点看坏果/短重/熟度不符时对方是否快速认赔和补货。

**1. 合同里把响应写成可考核条款**
- 明确售后范围：腐烂、压伤、黑心、短重、熟度不符、到货温度异常、批次不达标。
- 明确响应时限：例如到货验收后2小时内报障，供应商4小时内给处理方案，24小时内完成补货或折价；超时按订单金额比例扣款。
- 明确赔付标准：按件/按斤折价、退货、补货三选一，写清拍照留证和抽检比例。
- 明确对接人和升级路径：业务员、主管、负责人三级联系人，避免只有一个微信联系人。

**2. 用试单和小批量压力测试**
- 先下2—3个小批量试单，故意覆盖不同到货时段和周末到货。
- 每次到货按标准抽检并记录：坏果率、短重率、熟度偏差、响应时间、处理结果。
- 设置一次“合理报障”测试：比如香蕉到货偏青或偏黄、菠萝有黑心，看对方是否推诿、拖延、要求大量证明。
- 观察是否主动给预防方案，而不只是事后赔钱。

**3. 看历史服务数据，不只看规模**
要求供应商提供近3个月同类商超客户的售后记录摘要，至少包括：报障次数、平均响应时长、补货及时率、投诉闭环率。注意让对方脱敏，但要有可核对的数据口径。规模大不等于响应快，产地直发型供应商有时售后反而慢。

**4. 设置月度考核和备选供应商**
- 每月统计：售后响应及时率、赔付兑现率、补货到货及时率、重复问题发生率。
- 连续两次响应超时或赔付拖延，降级订单量；连续一个月达标再放量。
- 菠萝和香蕉至少各保留1家备选供应商，避免单一供应商拖售后时门店断货。

**5. 现场和沟通细节验证**
- 确认对方是否有专门售后人员，而不是业务员兼客服；夜间和节假日能否响应。
- 看对方是否愿意接受“先赔付后争议”的小额快速处理机制。
- 对香蕉熟度、菠萝黑心这类高频问题，要求供应商提供到货标准和验收图片模板，减少扯皮。

一句话：**稳定售后不是听出来的，是用合同时限、试单报障、月度数据考核逼出来的。** 先小单试、再按数据放量，比一次大单压价更稳。
