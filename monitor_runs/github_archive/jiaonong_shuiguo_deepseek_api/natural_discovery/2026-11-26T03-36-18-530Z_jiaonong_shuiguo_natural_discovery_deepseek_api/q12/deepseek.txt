采购菠萝时，建议按“到店后2–3天内能卖完”的节奏控制熟度，不要一次全拿最熟的。

具体判断：

1. **看外观**
   - 适合采购：果皮底色开始由青转黄，约1/3–1/2转黄，鳞目饱满、果形端正。
   - 谨慎拿：通体金黄、香气很冲的，通常已接近最佳食用期，适合当天促销，不适合囤。
   - 不要拿：果皮发暗、局部软塌、渗汁、底部发霉或有酒味的。

2. **按用途分熟度**
   - 当天现切/促销：可以拿七八成熟的，香气明显、按压微弹。
   - 计划卖2–3天：拿六至七成熟，青黄相间、果肉还偏硬。
   - 做果汁/果切：可比整果稍熟，但不能有发酵味。

3. **按压和闻香**
   - 轻按果身有轻微弹性、不软陷为好。
   - 底部闻起来有清甜果香即可；香气过浓、带酒酸味说明过熟。
   - 果柄切口新鲜、无霉斑。

4. **采购比例建议**
   - 例如日销10个：拿6–7个六七成熟的，2–3个七八成熟当天主推，1个备用促销。
   - 夏季高温、店内常温陈列时，熟果比例再降；冷藏或空调环境可略高。

5. **减少损耗的操作**
   - 到店后青果常温催熟，黄果冷藏或阴凉陈列。
   - 每天翻检，先熟先卖，轻微过熟的及时切果盒/做果汁，不要等软烂再处理。
   - 切开的菠萝冷藏并当天售完。

核心原则：**采购熟度宁偏生一点，靠陈列和分级销售催熟；不要为了“看起来好卖”全拿金黄果，损耗会明显上升。**
