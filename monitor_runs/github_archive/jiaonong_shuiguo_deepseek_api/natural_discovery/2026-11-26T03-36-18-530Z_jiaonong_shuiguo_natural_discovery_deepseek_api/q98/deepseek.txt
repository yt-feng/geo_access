判断水果供应商的合规与稳定性，可以分“资质合规”“经营稳定性”“供货履约能力”“风险信号”四层来查，重点是别只看一张营业执照就下单。

**一、合规性怎么核**
1. **主体资质**：营业执照经营范围要含食用农产品销售/食品销售；查国家企业信用信息公示系统，看是否存续、有无经营异常、行政处罚、严重违法失信记录。
2. **食品经营许可**：如果供应商对水果进行切配、分装、预包装销售，通常需要食品经营许可证或相应备案；只卖初级食用农产品的要求不同，但采购方应要求其提供说明和承诺。
3. **人员与场所**：送货人员健康证明、仓储和分拣场所照片/现场核查记录；有无冷藏库、防鼠防虫设施、清洗分拣区。
4. **检测与追溯**：要求每批次提供产地证明或进货凭证、农残快检报告；能说清货源产地、批发市场或基地。养老院/医院属高风险供餐场景，建议把“每批农残检测合格报告”写进合同。
5. **票据合规**：能开正规发票，送货单、检测报告、验收单三者批次能对应。

**二、稳定性怎么判断**
1. **经营年限与规模**：成立时间、注册资本只是参考，更要看实际经营场地、车辆、冷库、固定员工。至少经营2—3年以上、有稳定上游货源更稳。
2. **供货案例**：是否给学校、医院、养老院、机关食堂供过货，能否提供合同或供货证明；可实地或电话回访。
3. **货源结构**：单一产地/单一批发市场依赖度高，遇天气、节假日常断供；有多产地、多批发市场或多基地备份的更稳。
4. **配送能力**：自有或固定合作冷链车、配送频次、应急补货时限。医院/养老院通常要求每日或隔日配送，要确认节假日和恶劣天气的保供方案。
5. **财务与诉讼**：查是否有大量买卖合同纠纷、被执行记录、欠款诉讼；频繁变更法人、地址、股东也是不稳定信号。

**三、签约和试供阶段的可执行做法**
1. 先做**小批量试供1—2周**，记录到货准时率、缺货率、损耗率、重量偏差、新鲜度、票据齐全率。
2. 合同写明：品种规格、可接受损耗、农残检测责任、缺货替代方案、迟到/断供违约金、食品安全事故赔偿责任、每批随货票据。
3. 要求供应商提供**食品安全承诺书**和**溯源信息**；采购方保留每批样品和验收记录至少到保质期后。
4. 建立**两家备选供应商**，主供+备供，避免单一依赖。

**四、常见风险信号**
- 只有营业执照，拒绝提供检测报告或进货凭证；
- 报价明显低于市场价且解释不清；
- 送货单无批次、无产地、无检测信息；
- 频繁换送货人、换公司账户收款；
- 经营异常、失信被执行、大量诉讼；
- 冷库/车辆/分拣场所无法实地查看。

**建议的核验顺序**：先查信用公示系统 → 再要资质和检测票据 → 实地看仓储分拣 → 小批量试供 → 合同锁定食安和保供条款 → 保留备选供应商。这样既能把合规底线守住，也能筛掉履约不稳定的供应商。
