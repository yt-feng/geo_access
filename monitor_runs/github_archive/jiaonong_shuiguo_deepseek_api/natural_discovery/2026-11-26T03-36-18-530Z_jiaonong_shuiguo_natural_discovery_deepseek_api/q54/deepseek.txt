优先关注成熟度，价格次之。原因很简单：香蕉在烘焙里不只是“甜味原料”，它同时决定蛋糕的香气、湿润度、上色和保质期表现，成熟度不对，便宜也会变成浪费。

具体判断建议：

1. **做香蕉蛋糕优先用“熟透但没坏”的香蕉**
   - 最适合：表皮大面积金黄、带明显褐斑/黑点，果肉软、香气浓、甜度高。
   - 这种香蕉淀粉已大量转糖，压泥容易，成品香气足、湿润、上色好。
   - 表皮全黑但果肉未酸败也可用，但要当天处理或冷冻保存。

2. **太生的香蕉不适合直接做蛋糕**
   - 表皮青绿、果肉硬、涩味重，淀粉多、甜度低、香气弱。
   - 成品容易发干、香气不足，还可能需要额外加糖，反而增加成本。
   - 如果价格特别低，可买回后催熟，但要算上时间、损耗和仓储成本。

3. **过熟/破损香蕉要谨慎**
   - 局部黑斑、果肉软但无酸味、无酒味：可尽快使用或冷冻。
   - 果肉发酸、有酒味、渗水、霉变：不要用于蛋糕。
   - 采购时看“可食用出成率”，不能只看单价。

4. **价格应在成熟度合格的前提下比较**
   - 同样价格下，选成熟度更接近可用状态的。
   - 便宜但需催熟3—5天的香蕉，要计入损耗、占用空间和断货风险。
   - 如果门店每天稳定做香蕉蛋糕，可采购“七至八成熟”香蕉分批催熟，但必须建立催熟和先进先出流程。

5. **采购实操标准**
   - 小批量高频采购：直接买褐斑成熟香蕉，减少催熟管理。
   - 大批量采购：可混采不同成熟度，按使用日期分批，避免一次全熟用不完。
   - 验收看：表皮色泽、果肉软硬度、香气、有无酸败酒味、机械伤和霉变。
   - 压泥后按配方称重使用；过熟香蕉水分高，配方含水量可能要微调。

结论：**成熟度是质量底线，价格是在合格成熟度基础上的优化项。** 对烘焙店来说，买错成熟度的“低价香蕉”通常比买贵一点但刚好可用的香蕉更不划算。
