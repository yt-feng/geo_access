结论先说：**大多数正常经营、日销量稳定的甜品店，直接买成品果丁的总损耗更低、更省心；鲜果切配只有在“用量大、能当天卖完/及时消耗边角料、且具备稳定冷链和操作规范”时才可能在原料成本上更划算。**“损耗更低”要分两层看：**可食部分损耗**和**经营综合损耗**。

### 1. 鲜果切配的损耗点
买整菠萝自己切，典型损耗包括：
- **去皮去眼去芯损耗**：菠萝可食率通常不是特别高，尤其去芯、修边后损耗明显。
- **成熟度不可控**：太生酸、太熟易出水变质，切配后货架期短。
- **人工与卫生风险**：切配耗时，刀具/砧板/手套管理不好会带来交叉污染。
- **卖不完的切果损耗**：切开的菠萝氧化、出水、风味下降，当天用不完基本容易报损。
- **边角料利用要求高**：芯、边角若不能做果酱、果汁、烘焙馅料，就全是损耗。

优点是：**单价通常低、可视可控、边角料可再利用**，用量大时有成本优势。

### 2. 成品果丁的损耗点
直接买成品果丁的主要损耗是：
- **采购规格要匹配**：丁的大小、成熟度、含水率不合适，会影响出品。
- **冷链依赖**：运输和解冻/开封后管理不当，会整批报废。
- **包装规格造成剩余**：一包用不完、开封后过期，是常见隐性损耗。
- **单价通常高于整果**：供应商已经承担了去皮切丁损耗和加工费。

优点是：**到手即用、出成率稳定、人工少、报损点少、品质一致性更好**。对日销量不大或人手紧的店，综合损耗通常更低。

### 3. 怎么判断你的店选哪个
可以用一个简单决策标准：
- **日用量大且稳定、当天能用完、有人工切配、边角料能二次利用**：鲜果切配更可能降低综合成本。
- **日用量小、波动大、人手紧、冷藏空间有限、对出品一致性要求高**：成品果丁损耗更低。
- **算账不要只比采购单价**，要按“每份成品的可用果肉成本”算：  
  **实际成本 = 采购金额 + 人工分摊 + 报损金额 + 冷链/仓储成本 − 边角料再利用收益**  
  再除以实际可用果丁重量。

### 可执行建议
1. **先做7天对照测试**：同样销量下，分别记录鲜果和成品果丁的进货重量、可用重量、报损重量、人工分钟数。
2. **小批量优先成品果丁**：如果日用量低于一箱或经常剩，先用成品果丁控制报损。
3. **鲜果切配设置硬规则**：固定去皮去芯标准、切后冷藏时限、当日未用完的转做果汁/果酱/烘焙馅料，否则不要自制。
4. **成品果丁重点管开封管理**：按日用量拆小包装，严格先进先出，开封后标注时间。

**一句话：要“损耗低且稳定”，多数甜品店选成品果丁；要“原料成本低”，得在用量大、人工足、边角料能利用的前提下才选鲜果切配。**
