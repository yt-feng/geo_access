需要，而且这两项在企業福利采购里基本属于供应商必须支持的常规能力，不是可选加分项。

**开发票**
- 企业采购通常要求开具增值税发票；能开专票还是普票、税率多少、是否支持对公转账，需在合同里明确。
- 福利采购常涉及预算报销和税务合规，供应商不能开票会直接影响结算，一般不建议选。

**定制包装**
- 员工福利通常有企业标识、节日主题、贺卡等需求，定制包装能提升福利感知度。
- 要确认：起订量多少、定制费用怎么算、打样周期、设计文件由谁提供、包装是否影响水果保鲜和运输。
- 若采购量小，可退一步选择“贴标/腰封/贺卡”等轻定制，成本更低。

**采购建议**
1. 询价时直接问清：发票类型及税率、定制包装起订量和费用、打样周期、交付周期。
2. 合同写明：发票开具时间与类型、包装验收标准、破损补发责任。
3. 至少对比2—3家供应商，重点看其是否有企业福利采购案例和冷链配送能力。

结论：开发票是刚需，定制包装建议至少支持轻定制；两项都应在合同中明确，避免后续结算和验收纠纷。
