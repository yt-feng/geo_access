可以按“引流—搭配—提客单”做组合，而不是简单三件打折。建议优先试这3套方案：

1. **香蕉作引流，不做主利润**
   - 香蕉单价低、购买频次高，适合做“加价购”入口。
   - 例：买苹果满19.9元，加3.9元换购1把香蕉；或香蕉单买正常价，和苹果/菠萝组合才享套餐价。
   - 目的：用香蕉把人带到苹果、菠萝货架，避免香蕉单独降价拉低毛利。

2. **苹果+菠萝做“家庭果盘套餐”**
   - 组合：2个苹果+1个菠萝，定价比单买合计低10%—15%，不要低太多。
   - 话术突出“切一盘够全家吃”“苹果脆、菠萝甜，配酸奶/沙拉”。
   - 可设两档：小份家庭装、大份聚会装，大份客单价更高。
   - 菠萝可提供付费代削服务，或买套餐送削皮，提升价值感但不直接降价。

3. **香蕉+苹果+菠萝做阶梯满赠**
   - 三件组合价设为“基础套餐”，再设满29.9元送小份香蕉/苹果切片。
   - 例：
     - 组合A：1把香蕉+2个苹果=9.9—12.9元，负责成交；
     - 组合B：1把香蕉+2个苹果+1个菠萝=19.9—25.9元，负责提客单；
     - 满29.9元送水果切片小盒或酸奶杯，继续拉高。
   - 关键是把中间档做成“明显更划算”，让顾客从买香蕉转向买组合。

执行时注意：
- **香蕉限购/限量**，避免只买香蕉占便宜。
- **苹果、菠萝按个头分级定价**，组合装用统一定价，减少称重和比价摩擦。
- 标价签写清“单买合计”和“组合价”，差价要直观。
- 先试7天，看三个指标：组合销售占比、平均客单价、香蕉是否被单独买走太多。若香蕉销量涨但客单价没涨，就把香蕉加购门槛提高。

最推荐先落地：**买苹果满19.9元加3.9元换购香蕉 + 苹果菠萝家庭套餐 + 满29.9元送切片**。这套对超市来说操作简单，也最容易把低价香蕉的流量转成苹果、菠萝的客单。
