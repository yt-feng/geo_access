建议不要先问“试卖多少斤”，而是先定一个**低风险试卖包**：以“能在1–2周内卖完、卖不完损失可接受、能验证真实复购”为标准。实操可以这样定：

1. **先小批量多批次**
   - 单店/单渠道首单建议控制在**3–7天销量**，不要一次压1–2周以上库存。
   - 新品没有历史数据时，可按同类水果日常销量的**20%–30%**做首单上限；例如同类水果日均卖100斤，新品首单先拿20–30斤/天×3–5天。
   - 多门店可先选**2–3家代表性门店**试销，而不是全渠道铺开。

2. **设一个“止损量”**
   - 首单金额建议不超过该门店/渠道**单日水果采购额的5%–10%**，或新品最大可承受损耗金额的1/3。
   - 到货后第2天看动销：若日销量低于预期的50%，立即促销/调拨，不再补货。
   - 损耗率超过**10%–15%**（视品类和毛利而定）就暂停追加。

3. **用数据判断是否加量**
   - 连续**3–5天**满足：售罄率≥80%、损耗可控、顾客复购/询问出现、毛利达标，再按**1.5倍**补货。
   - 第二次补货仍稳定，再扩到更多门店。
   - 不要因为供应商说“爆款”就压货，先看自己渠道的试吃转化和复购。

4. **和供应商谈试卖条件**
   - 争取小起订量、坏果包赔、可调换货、账期或首批铺货支持。
   - 明确到货成熟度、规格、损耗赔付标准，避免“试卖”变成“清库存”。

一句话：**首单按3–5天销量、同类品20%–30%、单日采购额5%–10%封顶，选2–3个店试；3–5天动销达标再1.5倍追加。**
