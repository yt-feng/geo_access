判断一批香蕉，核心看“颜色阶段 + 手感硬度 + 果指状态 + 切口/果柄 + 气味 + 抽检切开”，不要只看表面颜色。批发拿货建议按下面顺序做。

**1. 先定颜色阶段**
- 全绿、硬：适合长途或压货，但催熟风险高，要确认冷库/运输温度，避免“冷伤后不熟”。
- 绿中带黄、棱角明显：耐放，适合批发周转。
- 黄多绿少、棱角变圆：适销窗口短，适合快走货。
- 全黄、少量糖斑：零售好看但货架期短，批发要压价或快出。
- 大面积褐斑、发黑：坏果风险高，除非当天处理，否则不建议拿。

**2. 摸硬度，不要只捏中间**
- 果身硬、果柄硬：偏生，耐放。
- 果身略软、果柄仍硬：接近适销，较稳。
- 果身软、果柄也软：熟度高，压货风险大。
- 局部软塌、按下去不回弹：内部可能已烂。

**3. 看果指和果梳**
- 果指饱满、棱角清楚、无凹陷：正常。
- 果指有压痕、瘪缩、裂口：机械伤或失水，易转黑腐。
- 果梳连接处发黑、发霉、渗液：整梳风险高。
- 果柄切口新鲜、干爽：较新；切口发黑、湿黏、有味：存放久或已感染。

**4. 查冷伤和催熟异常**
- 表皮有暗灰、水渍状斑，摸起来发凉发硬：可能冷伤，后续难正常转黄。
- 颜色黄但果身很硬：可能催熟不均或“青硬黄”，口感差。
- 颜色不均、一块黄一块绿且边界明显：催熟不匀，批发分级难。

**5. 闻气味**
- 正常是清淡果香。
- 有酒味、酸味、霉味：过熟发酵或已感染，整批要警惕。

**6. 抽检切开和翻箱**
- 随机抽不同位置、不同箱层，切开看果肉：中心发褐、发黑、水化、空心、黑心都要记风险。
- 翻底层和靠箱壁的货，看是否有压伤、闷热、渗液。
- 看箱内是否有果蝇、霉点、汁液污染。

**7. 给批发商的快速判断口径**
- **可拿且耐放**：绿中带黄、果身硬、果柄硬、切口干爽、无酒味、抽检果肉正常。
- **可拿但快走**：黄多绿少、果身略软、果柄尚硬、少量糖斑、无渗液异味。
- **谨慎或压价**：颜色不均、局部软、切口发黑、箱底有压伤、冷伤疑似。
- **不建议拿**：大面积褐斑/发黑、酒味酸味、果柄湿黏发霉、切开黑心水化、箱内渗液。

拿货时最好按“同批次抽 3—5 箱，每箱上中下各抽几梳”做记录；如果做催熟，还要确认上一手冷链温度和是否已进过冷库，冷伤货再催熟很容易整批报废。
