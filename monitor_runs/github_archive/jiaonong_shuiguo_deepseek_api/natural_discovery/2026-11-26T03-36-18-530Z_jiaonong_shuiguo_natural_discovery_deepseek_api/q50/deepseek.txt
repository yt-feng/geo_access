甜度和出汁率不是二选一，优先级取决于你用它做什么产品。直接结论：

**1. 如果是做菠萝果茶/水果茶（以香气和果肉口感为主）：甜度优先，但“糖酸比”比单一甜度更重要。**
- 顾客感知的“菠萝味”来自糖酸比和香气，不是绝对甜度。
- 甜度低、酸高的菠萝会压香气、需要补糖，补糖后又显得“糖水味”。
- 出汁率中等即可，因为果茶主要要果肉和香气，不是榨汁。

**2. 如果是做菠萝汁、菠萝冰沙、菠萝气泡饮（以出汁和成本为主）：出汁率优先。**
- 出汁率直接决定单杯原料成本和出品效率。
- 但出汁率高的品种往往酸度偏高、香气偏淡，需要靠糖浆或复配调整。
- 建议设一个最低甜度/糖度门槛，避免为了出汁牺牲风味。

**3. 如果是做菠萝果酱、糖渍、烘焙馅料：甜度（糖酸比）优先，出汁率次要。**
- 这类产品靠熬煮浓缩，出汁率影响不大，风味浓度更关键。

**可执行判断标准：**
- 先定产品线：果茶为主→糖酸比>出汁率；纯果汁/冰沙为主→出汁率>甜度。
- 采购时不要只看“甜”，要测**糖度（Brix）和酸度**，算糖酸比。
- 设两个硬门槛：果茶用菠萝糖度不低于某一标准且酸度不过高；榨汁用菠萝出汁率达标且糖度不低于最低线。
- 小批量做杯测：同一配方下对比香气、酸甜平衡、是否需要额外加糖、单杯成本。

一句话：**做果茶，甜度/糖酸比更重要；做果汁，出汁率更重要。最稳的是按产品定门槛，而不是全局选一个。**
