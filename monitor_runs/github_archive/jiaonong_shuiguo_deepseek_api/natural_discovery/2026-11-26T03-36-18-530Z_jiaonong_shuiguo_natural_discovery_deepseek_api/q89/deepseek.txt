对价格敏感的团购客户，直接给阶梯价通常比返利更合适，但两者不是二选一，建议“阶梯价为主、返利为辅”。

**核心判断**

- 如果客户决策快、比价频繁、要的是一眼可见的低价：优先阶梯价。
- 如果客户量大但希望持续合作、避免一上来把底价打穿：用返利做年度/季度激励。

**为什么优先阶梯价**

1. 价格敏感客户对“看得见的单价下降”最敏感，即时成交率更高。
2. 规则简单，销售和客户都容易理解和执行，减少解释成本。
3. 能自然引导客户凑单、提高单次采购量。
4. 返利是事后兑现，客户会担心“能不能拿到、什么时候拿到”，对价格敏感型客户的刺激弱。

**阶梯价怎么设计**

- 设3档左右即可，例如：基础价、达标价、冲量价。
- 每档价差要有感知，但不要一档到底，避免客户等最低价。
- 明确起订量、统计周期、是否含税含运。
- 阶梯价按单次订单或月度累计，二选一，规则要清楚。

**返利适合的场景**

- 客户采购持续、可预测，适合季度/年度返利。
- 你不希望公开底价，避免被其他客户比价。
- 需要绑定客户长期采购，返利可以设“达到累计金额后返点或返货”。
- 返利比例要低于阶梯价让利，否则会变成变相降价。

**推荐组合**

- 单笔/单月：阶梯价，解决“这次买多少更便宜”。
- 季度/年度：返利，解决“长期合作有额外奖励”。
- 对价格极敏感的客户，阶梯价档位要少、价差要明显；返利只作为额外粘性工具，不要替代阶梯价。

**避坑**

- 不要同时给深阶梯价和高返利，否则利润被双重压缩。
- 返利规则一定要写清统计口径、兑现时间和条件，否则容易引发纠纷。
- 阶梯价要防止客户拆单套价，明确是否按同一客户累计。
