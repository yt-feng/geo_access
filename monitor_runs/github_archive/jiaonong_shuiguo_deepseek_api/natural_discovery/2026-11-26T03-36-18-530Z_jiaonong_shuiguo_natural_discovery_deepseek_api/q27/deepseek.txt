判断超市采购的苹果和橙子规格是否适合门店销售，建议从“分级标准、门店定位、验收可操作”三个层面看，直接按下面执行即可。

**一、先定门店销售规格，不要只看产地大小**
按用途分档，采购前就写进订单：

- **苹果**
  - 小果：单果约150–180g，适合散卖、社区店、家庭小份购买。
  - 中果：约180–250g，最通用，适合大多数超市散卖和袋装。
  - 大果：约250–350g，适合礼盒、精品陈列，但单价高、动销慢。
  - 看横径：常见中果横径约75–85mm，大果85mm以上；不同品种差异大，最好以“单果重+横径”双指标验收。
- **橙子**
  - 小果：约120–160g，适合散卖、促销。
  - 中果：约160–220g，门店最稳妥的主力规格。
  - 大果：约220–300g，适合礼盒或精品区。
  - 脐橙常见中果横径约70–80mm；冰糖橙、血橙等品种果型小，不能套同一标准。

**二、判断是否适合门店销售，看四个匹配**
1. **价格带匹配**：同品种大果若进价明显高，门店周边客群偏日常买菜，优先中果；礼盒占比高的门店才放大大果。
2. **陈列和包装匹配**：散卖区适合中果，大小均匀、堆头好看；袋装适合中小果，控制单袋总价；礼盒才用大果。
3. **动销匹配**：先小批量试销3–7天，看同品种不同规格的日销和损耗。大果若日销低、剩货多，就不适合作为主力。
4. **消费场景匹配**：社区日常店以中果为主；商圈精品店可增加大果；食堂、水果切配渠道可接受中小果，但要求出成率稳定。

**三、现场验收的可执行标准**
- **均匀度**：同一批货单果重极差不宜过大，目测大小明显不齐的不要按同一规格收。
- **果径抽检**：用果径圈或卡尺随机抽20–30个，记录横径分布；不能只看样品。
- **外观**：苹果看着色、果锈、碰压伤；橙子看果皮粗细、油胞、裂口、霉斑。规格合适但伤果多，实际可售率会下降。
- **可售率**：抽一箱称重，剔除伤果、畸形果、过小果后算可售比例。可售率低时，即使名义规格合适，也不适合门店销售。
- **成熟度和货架期**：苹果要分清脆果和粉果；橙子要测糖酸或至少试吃。规格达标但成熟度过高，门店损耗会大。

**四、简单决策规则**
- 社区超市日常散卖：苹果中果、橙子中果为主，小果做促销补充。
- 精品超市/礼盒区：可采大果，但必须控制数量，搭配中果走量。
- 任何规格，先看“单果重区间是否集中、可售率是否够、试销动销是否正常”，三项都过再放量采购。

最稳妥的做法：把门店要的规格写成“品种+单果重区间+横径下限+可售率+外观标准”，采购按这个验收，试销后再调整。
