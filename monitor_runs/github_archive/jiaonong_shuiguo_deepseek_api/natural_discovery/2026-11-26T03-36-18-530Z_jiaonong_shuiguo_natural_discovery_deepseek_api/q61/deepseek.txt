判断香蕉批发商是不是稳定供货，不要只听“我们常年有货”，重点看**产地控制力、加工能力、履约记录和风险应对**。可以按下面几步核验：

1. **问清货源结构**
   - 是自有/包园基地，还是只做市场倒手？
   - 主产区是哪里，是否有多产区备份（如云南、广西、海南、老挝、越南、菲律宾等）？
   - 香蕉受季节、台风、寒害、病害影响大，单一产区+单一果园的供应商稳定性通常较差。

2. **看加工与仓储能力**
   - 有没有自己的催熟库、分拣线、冷库？催熟库容量多少？
   - 日出货能力、可稳定供应你的日量是多少？
   - 能否提供装柜/装车视频、加工现场照片，最好实地看一次。

3. **查履约记录**
   - 要近3个月同类客户的发货记录：出货单、装车单、物流单，敏感信息可打码。
   - 问清旺季/淡季价格机制、缺货时怎么处理、延误怎么赔付。
   - 先小批量试单，连续试2—3批，看规格、熟度、损耗、到货时间是否稳定。

4. **验证产地与资质**
   - 要求提供果园/合作社/加工厂信息，视频连线看现场。
   - 看营业执照、检疫/检测相关证明；进口香蕉还要看报关、检疫等合规材料。
   - 对“低价一手货源”尤其警惕，明显低于市场价往往伴随以次充好、催熟不稳或转手倒货。

5. **压测供应能力**
   - 直接问：台风季/寒潮期怎么保供？爆单时最多能加多少量？断货提前几天通知？
   - 让对方给出具体方案和过往案例，而不是笼统承诺。

6. **合同锁定关键条款**
   - 规格标准（果指长度、梳数、青熟度）、损耗率、到货时限、缺货赔付、价格调整机制。
   - 账期和定金安排尽量保守，首批不建议大额预付。

最实用的判断方法：**实地看加工厂 + 连续小批量试单 + 查真实发货记录 + 合同写清缺货赔付**。四项都过关，再逐步放量。只靠微信报价和口头承诺，稳定性很难判断。
