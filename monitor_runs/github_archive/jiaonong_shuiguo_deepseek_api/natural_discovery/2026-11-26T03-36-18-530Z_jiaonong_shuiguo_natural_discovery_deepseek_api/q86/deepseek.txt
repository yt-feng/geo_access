做生鲜水果一件代发，供应商的仓配能力直接决定履约质量。建议按以下维度评估和确认，并在合作前要求供应商提供可验证的证明（如仓库照片/视频、系统截图、近30天履约数据、冷链记录、异常处理流程）。

一、仓储能力
1. 仓库类型与资质：常温库/保鲜库/冷藏库/冷冻库是否齐全；是否有食品经营许可、产地证明、质检报告；仓库消防、卫生、防鼠防虫记录。
2. 温区匹配：水果按品类分温区存储（如热带水果常温、浆果冷藏），能提供库温记录和断链应急方案。
3. 库内作业：收货质检、分级分拣、称重、贴单、打包能力；是否支持按SKU/订单混装；日峰值处理单量（需有历史大促数据支撑）。
4. 库存与批次管理：WMS是否支持批次/效期/先进先出；库存准确率、盘点频率；临期/损耗处理机制。
5. 包装能力：是否提供防撞、透气、吸水、冰袋/保温箱等适配水果的包装方案；能否按平台要求定制箱规和面单。

二、配送与履约能力
1. 快递资源：是否与顺丰/京东/中通等有稳定协议价；能否按平台要求选择快递；偏远地区、高温地区是否有覆盖方案。
2. 时效承诺：截单时间、发货时效（如24/48小时）、揽收扫描时效；能否提供近30天发货及时率、揽收及时率。
3. 冷链能力：冷链快递覆盖范围、保温箱+冰袋方案、温控记录；断链赔付与补救流程。
4. 面单与系统对接：是否支持平台电子面单、ERP/OMS对接、自动推单、物流轨迹回传；异常件（破损、延迟、拒收）处理SLA。
5. 售后与赔付：坏果率标准、理赔流程、补发/退款时效；是否有履约保证金或质保金机制。

三、品控与损耗管理
1. 到货质检标准：糖度、大小、外观、成熟度抽检比例；不合格品处理。
2. 分拣标准：按规格分级、剔除次果；称重误差范围。
3. 损耗率数据：近3个月各品类损耗率、坏果率、客诉率；是否有持续改善记录。
4. 溯源能力：批次可追溯、产地证明、农残检测报告。

四、系统与数据能力
1. 订单处理系统：能否实时接单、自动分仓、库存同步、超卖拦截。
2. 数据回传：发货及时率、签收时效、破损率、客诉率等可按平台要求日报/周报。
3. 异常预警：库存不足、物流停滞、温控异常能否主动预警。

五、合作前必须核验的硬指标
- 近30天发货及时率≥98%、揽收及时率≥95%（按平台要求调整）。
- 坏果率/破损率承诺值及赔付标准写进合同。
- 峰值日处理单量≥预估单量的1.5倍。
- 冷链品类必须提供温控记录和断链赔付方案。
- 系统对接联调通过后再放量，先小批量试跑2-4周。

建议先做小批量试单，重点看：截单后是否按时揽收、包装是否适配、坏果率是否达标、异常件响应速度。合作合同里明确时效、坏果率、赔付、保证金和退出机制。
