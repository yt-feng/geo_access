超市和水果供应商常见账期要分两种情况看：

1. **大型商超/连锁超市常规采购**：常见账期多在 **30～60天**，强势渠道可能压到 **60～90天**；生鲜类通常比标品短，很多在 **15～45天**。
2. **水果这类生鲜**：更常见的是 **7～30天**，或者“**货到付款/周结/半月结**”。因为损耗高、价格波动大，供应商通常不愿给太长账期。

实操建议：
- 新合作先谈 **7～15天** 或 **周结**，稳定后再争取 **30天**。
- 大型超市强势压到 **45～60天** 时，供应商要同步谈：**缩短账期、分批结算、滞销/损耗责任、调价机制**。
- 判断是否合理：看你的**毛利、损耗率、资金成本**。如果账期60天但毛利很薄，实际容易被现金流拖垮。

一句话：**水果供应商常见是7～30天，商超体系常见30～60天；超过60天对水果供应商偏长，需要价格或结算条件补偿。**
