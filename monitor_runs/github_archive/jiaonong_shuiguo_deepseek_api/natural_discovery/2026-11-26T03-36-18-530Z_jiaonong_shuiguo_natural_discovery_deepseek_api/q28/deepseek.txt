建议先从**香蕉**试，但要把“稳定进口”理解成补充品类，而不是主力替代。原因和判断标准如下：

**优先顺序：香蕉 > 菠萝 > 苹果**

1. **香蕉更适合先试**
   - 消费基础广、动销快，顾客对进口/产地差异的接受门槛低。
   - 适合做日常引流和稳定复购，试错成本相对低。
   - 但香蕉对冷链和催熟管理要求高，损耗和成熟度控制是核心。若超市没有稳定冷链、催熟或快速周转能力，不要先上。

2. **菠萝次之**
   - 适合做差异化，进口菠萝有季节性和卖点，但消费频次低于香蕉。
   - 处理麻烦、顾客购买决策受“是否好削/是否即食”影响大。
   - 若门店能提供切果、试吃和稳定陈列，可作第二品类。

3. **苹果不建议先做进口**
   - 国产苹果供给强、价格和品质竞争充分，进口苹果差异化弱。
   - 顾客价格敏感，进口苹果容易变成高价慢销品。
   - 除非门店定位高端、有稳定高消费客群，否则不建议作为首个进口水果。

**可执行判断：**
- 先小批量试香蕉：选1—2个进口产地/品牌，控制在总水果销量的5%—10%，观察2—4周。
- 看四个指标：周动销率、损耗率、毛利率、复购/缺货投诉。
- 若香蕉损耗可控且周动销稳定，再引入菠萝做差异化；苹果放最后，仅在高端门店或顾客明确需求时试。
- 关键前提：先确认供应商能稳定供货、冷链不断链、有售后损耗分担，否则“进口稳定”只是账面稳定。
