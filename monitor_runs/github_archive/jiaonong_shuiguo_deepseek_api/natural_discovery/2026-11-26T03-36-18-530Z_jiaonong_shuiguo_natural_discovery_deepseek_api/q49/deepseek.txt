旺季临时补货，核心不是“口头打个招呼”，而是把**触发条件、补货量、价格、时效、验收和违约**提前写清楚。建议按下面做：

## 1. 先定“临时补货规则”
和供应商补充一份简短的《旺季临时补货协议》或在原合同里加附件，明确：

- **触发方式**：例如每天16:00前报次日需求；或库存低于2天用量时触发补货。
- **补货量**：按“日用量×1.5～2天”设安全库存，单次补货不超过约定上限，避免压货。
- **响应时效**：例如接到订单后24小时内到店；紧急单12小时内到店，需加急费另计。
- **价格机制**：临时补货价可按“基准价+浮动上限”约定，避免旺季坐地起价；明确是否含运费、损耗。
- **品质标准**：菠萝成熟度、单果重量、无黑心、无腐烂、到货温度/包装要求。
- **验收与拒收**：到货2小时内验收；不合格可拒收或按比例扣款，并要求补发。
- **违约与替代**：供应商断供时提前多久通知；断供赔偿或允许你临时向备选供应商采购且差价由对方承担。

## 2. 用“滚动预报+安全库存”管理
不要等断货才补。每天给供应商发**未来3天用量滚动预报**，每周确认一次旺季总需求区间。自己店里设**2天安全库存**，低于安全库存立即触发补货。这样供应商能提前备货，你也不至于被临时加价。

## 3. 锁量不锁死
可以和供应商约定：
- **保底量+弹性量**：例如旺季每周保底X箱，临时可追加不超过保底量的30%；
- **价格封顶**：临时补货价不超过基准价的10%～15%；
- **优先供货权**：你报的临时单在同等价格下优先安排。

## 4. 准备备选供应商
至少保留1家备用供应商，先小批量试单，确认品质和配送。主供应商断供时能立即切换，避免旺季停售。

## 5. 留好书面记录
临时补货尽量用微信/邮件/订单系统下单，写清品名、数量、单价、到货时间、验收标准。不要只打电话，避免后期扯皮。

**一句话建议**：先补签一页《旺季临时补货条款》，把“提前报量、24小时到货、价格上浮上限、不合格拒收、断供赔偿”写进去，再每天滚动预报用量，基本就能稳住旺季供应。
