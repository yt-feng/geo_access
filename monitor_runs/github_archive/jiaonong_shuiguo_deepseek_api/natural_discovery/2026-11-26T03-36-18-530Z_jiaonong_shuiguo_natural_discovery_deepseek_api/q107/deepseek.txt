**香蕉**
- 主要风险：催熟后销售窗口短，批量到货集中变黄，若门店/渠道消化速度跟不上，容易从“好货”变“折价货”。
- 高起订量会放大：到货集中、催熟批次难拆、后熟不一致，尾货只能降价或报损。
- 判断建议：按“日销量 × 到货后可售天数 × 安全系数”倒推起订量；如果供应商起订量明显高于这个数，要求分批到货或分批次催熟。

**菠萝**
- 主要风险：整箱到货后成熟度不一致，过熟果易发黑、发软、出水；整果周转慢时损耗上升。
- 高起订量会放大：单次压货多、挑果和分级压力大、尾货处理慢。
- 判断建议：优先看“可售期”和“分级能力”；起订量超过 3—5 天销量时，要求供应商按成熟度分级或拆批。

**可执行判断**
1. 先算单店/单仓日均销量和最短可售天数，起订量不宜明显超过“日均销量 × 可售天数”。
2. 若起订量高于安全库存，优先谈：分批到货、拆箱混装、按成熟度分级、坏果赔付条款。
3. 香蕉重点控“催熟批次和到货节奏”，菠萝重点控“成熟度和分级”；两者都不建议一次性压超过一周销量的货。
4. 做小批量试单，记录到货成熟度、3天/5天损耗率，再决定是否接受高起订量。

结论：**会显著增加损耗风险，尤其是短保、后熟型水果；起订量应受可售天数和消化速度约束，而不是只看单价。**
