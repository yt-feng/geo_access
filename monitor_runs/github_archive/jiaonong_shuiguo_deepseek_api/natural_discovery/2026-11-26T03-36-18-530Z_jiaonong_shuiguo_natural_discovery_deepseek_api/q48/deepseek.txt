判断一家菠萝供应商能不能稳定按规格送货，别只看样品和大货照片，要抓住“规格定义、历史履约、产地周期、分级能力、验收规则、违约成本”六个可验证点。

1. **先把规格写成可验收的SOP**
   - 品种/产地：如金钻凤梨、巴厘菠萝，明确允许替代的品种范围。
   - 单果重区间：如1.2–1.5kg/个，超出区间拒收或降级比例。
   - 成熟度：糖度下限、果心温度、表皮转色比例、是否允许催熟。
   - 外观缺陷：黑心、裂口、冠芽损伤、机械伤、日灼、药斑的允许比例。
   - 包装：箱规、单箱个数、净重公差、托盘/冷链要求。
   - 到货时效：从采摘/加工到到仓小时数，冷链温度记录。
   没有量化标准的“新鲜、大果、甜”无法追责。

2. **查历史履约，不查口头承诺**
   要求供应商提供近3–6个月同类客户的送货记录：批次合格率、规格符合率、准时率、缺货/换货次数。最好直接向其现有茶饮或水果客户侧面核实。新供应商可先做“小批量多批次”试单，比如连续4周、每周2车，按同一验收标准统计。

3. **看产地周期和备货能力**
   问清菠萝来源是自有基地、合作基地还是市场代采。自有/合作基地要看面积、当前挂果量、采收排期；市场代采稳定性通常更差。重点问：非产季或雨季时从哪里补货？同时供几家？旺季你的采购量占其出货量比例多少。占比过低，断货时你容易被排后。

4. **看分级和预处理能力**
   稳定按规格送货，核心是供应商有没有分级线、称重分级、糖度抽检、预冷和冷链。现场看：分选是否按重量自动/半自动分级，是否有批次追溯码，冷库和冷藏车温控记录是否可导出。没有分级能力的供应商，靠人工挑果，批次波动会很大。

5. **把验收和赔付写进合同**
   - 每批抽检比例、糖度抽检方法、单果称重抽样数。
   - 规格符合率低于约定值（如95%）的扣款/退货规则。
   - 迟到、缺货、以次充好的违约金和补货时限。
   - 连续两批不合格的暂停供货或终止条款。
   - 留样和追溯：每批留样48小时，出现黑心、变质可追责。
   违约成本太低，供应商会优先保其他客户。

6. **用试单数据做判断**
   建议连续试单4–6批，记录：准时到货率、规格符合率、损耗率、糖度达标率、异常响应时间。若规格符合率稳定≥95%、准时率≥98%、异常2小时内响应，才考虑放量。放量也要分阶段，先占其产能的合理比例，避免单一供应商断供。

一句话：让对方用“可抽检的规格+可查的历史数据+可赔的合同”证明稳定性，而不是用样品证明。
