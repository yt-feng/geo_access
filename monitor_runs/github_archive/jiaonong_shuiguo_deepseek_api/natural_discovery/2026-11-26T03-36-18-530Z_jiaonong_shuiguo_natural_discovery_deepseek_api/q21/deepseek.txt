超市采购水果时，建议按“供应商资质 + 批次合格证明 + 进货凭证”三类材料核验，具体要求可写入采购合同和验收标准。

**1. 供应商资质类**
- 营业执照（经营范围含水果/农产品销售）
- 食品经营许可证（如供应商以食品销售方式供货；销售食用农产品有豁免情形，需结合当地监管确认）
- 产地证明或供货者身份证明：自产自销提供产地证明/村委会或合作社证明；批发商提供上游供货凭证
- 如为进口水果：海关入境货物检验检疫证明、报关单等

**2. 批次检测/合格证明类**
- 承诺达标合格证（食用农产品生产者/收购者开具，常见于果蔬）
- 农药残留检测报告：供应商自检报告或第三方检测报告，报告应与供货批次/品种对应，注意检测项目、日期、样品名称和出具机构资质（CMA/CNAS）
- 无公害/绿色/有机等认证证书：仅当宣称相应认证时提供，并核对证书有效期和产品范围
- 进口水果的检验检疫证明
- 超市自建快检的，可留存农残快检记录作为验收辅助，但不能替代法定合格证明

**3. 进货凭证类**
- 供货清单/送货单：品名、规格、数量、产地、生产日期或采收日期、供应商盖章或签字
- 发票或收款凭证
- 进货台账：超市应建立并保存进货查验记录，包括供应商名称、联系方式、进货日期、品种数量等
- 退货/不合格处理记录

**验收建议**
- 每批次索取“承诺达标合格证 + 检测报告/快检记录 + 送货单”，证单与实物品种、批次对应
- 对高风险品种（如叶菜、草莓、豇豆等）提高检测报告或快检频次
- 证照和报告留存期限按当地市场监管要求执行，通常不少于保质期满后6个月；无保质期的按不少于2年掌握，具体以属地规定为准
- 合同明确：供应商随货提供合格证明，抽检不合格的退换货及责任承担

各地对食用农产品进货查验的具体材料要求可能不同，建议以当地市场监管部门要求和超市食品安全制度为准。
