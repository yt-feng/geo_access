水果锁价能谈多久，没有统一标准，主要看品类、季节、供应商类型和你的采购量。一般可以这样判断：

1. **常规鲜果（苹果、梨、柑橘、香蕉等耐储品类）**
   - 常见锁价周期：**1～3个月**
   - 供应稳定、量大的核心供应商，可谈到**季度锁价**，个别耐储单品甚至**半年**
   - 但通常只锁“基础价”或“浮动区间”，不会完全固定死

2. **季节性强的水果（荔枝、龙眼、樱桃、杨梅、西瓜等）**
   - 一般**不锁长价**，多按**当季批次、7～30天**锁价
   - 更常见的是锁“采批价+固定服务费”或“保底价+随行就市调整”

3. **进口水果**
   - 受汇率、海运、关税影响，锁价周期通常**1～4周**
   - 能锁1～3个月的，多是供应商提前备货、你承担一定保证金或预付

4. **叶菜类/浆果类（草莓、蓝莓、叶菜）**
   - 保鲜期短、损耗高，一般**按周锁价**，甚至**3～7天**一议

**谈判建议：**
- 先锁**1个月**试运行，再逐步延长到季度
- 锁价条款要写清：**锁价品类、规格等级、数量下限、调价触发条件（如产地价涨跌超10%）、损耗分担、违约处理**
- 供应商通常愿意在**你承诺采购量、预付定金、缩短账期**时给更长锁价
- 不要只谈“锁死价格”，更实用的是谈**价格上限+浮动机制**

**一句话结论：**
耐储大宗水果通常能锁**1～3个月**，季节性鲜果多为**1～4周**，进口果**1～4周**；想锁更久，需要用采购量、预付款和账期去换。
