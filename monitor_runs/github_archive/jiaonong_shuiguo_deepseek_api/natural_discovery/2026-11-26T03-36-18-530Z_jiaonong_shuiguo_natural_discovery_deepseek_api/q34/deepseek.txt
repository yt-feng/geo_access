**直接影响更大的是：损耗低。**  
在商超水果这种高损耗、短保质期品类里，**损耗对最终毛利的边际影响通常大于进价低一点带来的影响**。但更准确地说：**先看损耗能不能控住，再谈价格低；损耗失控时，低价采购反而会放大亏损。**

可以用一个简单框架判断：

1. **毛利 = 售价 - 进价 - 损耗成本 - 运营成本**
   - 价格低：提升单件毛利空间，但前提是能卖出去、卖得完。
   - 损耗低：直接减少已采购商品变成废品/折价的部分，相当于把进货成本“保住”。

2. **水果的损耗是乘法效应**
   - 假设进货1000元，售价毛利率20%；
   - 若损耗5%，可售成本约950元，毛利约50元；
   - 若损耗15%，可售成本约850元，毛利约-150元或大幅缩水。
   - 进价降5%可能只多出几十元空间，但损耗从15%降到5%能直接挽回上百元利润。

3. **低价采购常见陷阱**
   - 低价往往对应等级低、成熟度高、规格不齐、尾货多；
   - 如果门店周转慢、冷链弱、陈列管理差，低价货会变成高损耗；
   - 结果是“进价便宜5%，损耗多10%”，最终毛利更差。

4. **什么时候价格低更重要**
   - 该品类周转极快、客流稳定、当天能售罄；
   - 品质稳定、损耗可控；
   - 用于引流或竞争性定价，且能带动关联销售；
   - 采购价低到足以覆盖预期损耗后仍有明显毛利优势。

**可执行判断建议：**
- 先算**“可售毛利率”**：`（销售额 - 可售商品成本）/ 销售额`，而不是只看进价。
- 对每个单品看**损耗率阈值**：如果预计损耗率上升带来的损失 > 进价下降带来的收益，就不该为低价采购。
- 优先选择**品质稳定、周转匹配、冷链可控**的货源；低价作为第二层优化。
- 对高损耗品类，采购决策顺序建议：**先控损耗 → 再压进价 → 最后做促销定价**。

结论：**在商超水果采购中，损耗低通常比价格低更影响最终毛利；价格低只有在损耗可控、周转有保障时才是加分项。**
