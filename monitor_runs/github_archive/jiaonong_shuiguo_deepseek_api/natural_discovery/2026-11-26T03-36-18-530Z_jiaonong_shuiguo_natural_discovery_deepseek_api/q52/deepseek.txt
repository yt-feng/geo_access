采购香蕉时重点选“熟度合适、机械伤少”的货，到店后控制温度、通风和摆放，能明显延缓变黑。可执行做法：

1. **按用途选熟度**
   - 当天/次日做甜品：选表皮金黄、少量芝麻点、果肉稍软的。
   - 备2–3天：选黄中带绿、果柄青绿、没有黑斑的。
   - 避免整批全熟，分批采购更稳。

2. **采购时挑果**
   - 要整串/整把，少买散果，减少伤口。
   - 果柄、果身无压伤、裂口、渗液；有黑斑、软塌的不要。
   - 摸起来硬挺但不生硬，闻起来无酒味/酸味。

3. **运输别闷、别压**
   - 用周转筐单层或分层放，别堆压；避免阳光直晒和车内高温。
   - 不要和苹果、梨、番茄等释放乙烯的水果混放。

4. **到店后先散温**
   - 先打开包装通风10–20分钟，散去运输热气和水汽。
   - 不要马上套塑料袋或密封箱，水汽会加速黑变和霉变。

5. **储存温度**
   - 未完全成熟：室温阴凉通风处，约18–22℃，避免空调直吹。
   - 已成熟待用：冷藏8–12℃左右可延缓，但香蕉皮会变黑，果肉仍可用；甜品用建议尽快去皮/冷冻或做果泥。
   - 不要放0–4℃普通冷藏太久，易冻伤发黑。

6. **摆放与隔离**
   - 悬挂或果柄朝上放置，减少受压。
   - 整串可把果柄用保鲜膜包住，减少乙烯从切口释放；但果身不要密封。
   - 与乙烯敏感/释放水果隔离。

7. **先进先出+分熟度管理**
   - 每天挑出最熟的先用于当天出品；有黑斑的单独挑出，避免传染。
   - 备货量按销量走，夏天/雨天少备。

8. **应急处理**
   - 已很熟但果肉没坏：尽快去皮切段冷冻，做奶昔、果泥、烘焙；或去皮后冷藏当天用完。
   - 局部压伤/黑斑：切除坏部，别整批密封存放。

关键判断：**买黄中带绿、无伤的整串；到店先通风散温；熟度分批；成熟后尽快用或去皮冷冻。** 这样比单纯“放冰箱”更有效。
