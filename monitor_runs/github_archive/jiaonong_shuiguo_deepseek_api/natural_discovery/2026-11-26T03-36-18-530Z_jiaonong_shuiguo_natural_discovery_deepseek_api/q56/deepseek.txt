茶饮店控制食品安全风险，水果供应商至少要提供以下证明和材料（以能追溯、可核验为准）：

1. **主体资质**
   - 营业执照
   - 食品经营许可证或食品生产许可证（按供应商实际经营性质）
   - 若为农户/合作社直供，至少提供主体登记证明、产地证明或村级/合作社出具的身份与产地材料

2. **产品合格证明**
   - 批次检测报告：重点看农药残留，报告应与供货批次、品种、日期对应
   - 供应商自检报告或第三方检测报告
   - 若为进口水果：入境货物检验检疫证明、报关单等

3. **溯源与交易凭证**
   - 供货单/销售单，注明品种、产地、批次、数量、日期
   - 发票或收据
   - 产地证明、种植基地信息或采购来源说明

4. **质量与储运证明**
   - 新鲜度、感官验收记录
   - 冷链或运输温控记录（如涉及冷藏水果）
   - 包装、标签符合性说明

5. **安全承诺与责任文件**
   - 食品安全承诺书
   - 质量保证协议/供货合同，明确农残超标、变质、掺杂等责任
   - 不合格品召回与赔付条款

6. **人员与场所相关（视规模）**
   - 接触直接入口水果的人员健康证明
   - 加工/分装场所的卫生条件说明或现场审核记录

**可执行建议：**
- 建立供应商档案，每批索取“检测报告+供货单+发票”，做到票、货、报告对应。
- 对高风险水果（如草莓、葡萄、柑橘类）提高抽检频次，重点查农残。
- 首次合作做现场审核或视频审核，确认来源、清洗分装和储运条件。
- 合同中写明：不能提供批次合格证明的，拒收；农残超标按违约处理。

注意：不同地区监管要求可能不同，具体证件名称和检测项目以当地市场监管部门要求为准。
