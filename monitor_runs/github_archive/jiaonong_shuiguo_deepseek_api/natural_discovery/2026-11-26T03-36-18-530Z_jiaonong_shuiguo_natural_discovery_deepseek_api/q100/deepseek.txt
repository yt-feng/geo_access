1. **按“七成熟”收货**：采购时明确验收标准，香蕉果皮以青黄为主、少量黄、无黑斑，果肉硬挺；熟蕉比例控制在当批次10%以内。  
2. **小批量高频次采购**：按每天预计用量拆单，隔天或每周2—3次到货，避免一次囤货。  
3. **分区存放**：青蕉放阴凉通风处，不冷藏；已熟蕉单独放，优先使用。不要和苹果、梨等催熟水果混放。  
4. **先进先出+每日巡检**：按到货日期贴标，每天检查，出现少量黑斑的香蕉优先做香蕉牛奶、烘焙、水果沙拉等。  
5. **设置预警线**：库存超过2天用量或熟蕉超过当日用量时，暂停采购并启动促销/加工。  
6. **合同约定退换/补货**：与供应商约定到货成熟度不符可退换，并保留紧急补货渠道。  
7. **用数据定量**：记录每日领用和废弃量，按“日均用量×1.5天”设安全库存，旺季或假期前下调采购量。  

核心原则：**控制成熟度、缩短库存周期、熟蕉优先消耗、用数据定采购量。**
