连锁超市和水果供应商签年度合同，最容易踩坑的集中在“价格与数量不锁定、质量验收标准模糊、损耗和退货责任不清、账期与返利口径不一致、独家与违约条款失衡”这几类。下面按条款给出可执行建议。

**1. 价格与调价机制**
- 坑：只写“随行就市”或“参考市场价”，没有基准、采样来源、调价周期和上限。水果价格波动大，年底结算容易扯皮。
- 建议：约定基准价来源（如某批发市场某品类均价或双方确认的报价单）、调价触发幅度（如涨跌超5%可调）、调价频率（月度/季度）、提前通知期，并设单次调价上限。年度合同最好写“价格公式+封顶”，不要只写“协商”。

**2. 数量与最低采购量**
- 坑：写“预计采购量”却附加最低采购承诺，或反过来供应商承诺供货量但无违约后果。
- 建议：区分“预估量”和“承诺量”。若给供应商最低采购承诺，要写明未达量的补偿方式；若要求供应商保供，要写缺货违约金和替代采购差价承担。水果有季节性，按品类、月份设阶梯量比一个全年总量更合理。

**3. 质量标准与验收**
- 坑：只写“新鲜、无腐烂”，没有等级、规格、糖度、农残标准、抽检比例和验收时限。
- 建议：附质量标准附件，按品类写清等级、单果重/规格、成熟度、糖度、外观缺陷允许比例、农残检测要求（如每批次合格证明或抽检）。明确验收地点、抽检比例、不合格判定和拒收流程，以及到货后几小时内提出异议有效。

**4. 损耗、退货与短装**
- 坑：到货验收合格后，门店端损耗谁承担没写；临期、滞销、品质下降能否退货没写；短装按重量还是件数计没写。
- 建议：明确“验收前损耗归供应商、验收后归超市”，但可约定到货后24—48小时内发现内部腐烂的追溯规则。写清短装允许误差（如±2%）及超出部分的补货或扣款。退货条款要区分质量问题退货和超市滞销退货，后者若允许，应约定比例上限和费用承担。

**5. 账期、返利与费用**
- 坑：账期起算点不清（到货日、对账日还是开票日）；返利按进货额还是销售额、含不含税、是否扣退货；进场费、促销费、损耗补贴等费用口头约定。
- 建议：账期写明起算日和付款日，对账争议不影响无争议部分付款。返利写清计算基数、是否含税、退货是否冲减、结算周期和支付方式。所有通道费、促销费、陈列费列明项目和上限，避免“其他费用另行协商”。

**6. 独家与排他**
- 坑：供应商要求某品类独家供货，但未约定价格保护、缺货责任和超市解约权。
- 建议：谨慎给品类独家。若必须给，绑定最低供货量、价格不高于市场同类、缺货时的替代采购权和独家期限，并设超市在供应商连续缺货或价格失去竞争力时的单方解除权。

**7. 违约责任与解除**
- 坑：只约束超市（如未达采购量赔偿），对供应商断供、质量事故、农残超标责任轻描淡写。
- 建议：双方违约责任对等。重点写断供违约金、质量事故（含农残超标）的召回和下架配合、赔偿范围、食品安全事件的处理时限。约定连续若干次质量不合格或断供可单方解除且不承担剩余合同责任。

**8. 不可抗力与季节性风险**
- 坑：把产地减产、天气异常一律当不可抗力，供应商借此免责断供。
- 建议：限定不可抗力范围，要求供应商提供证明并及时通知；对季节性减产约定提前预警和替代方案，不能简单免责。

**9. 发票与食品安全合规**
- 坑：农产品发票、产地证明、检测报告责任不清，出现抽检不合格时互相推。
- 建议：明确供应商提供合规票据、产地证明和批次检测报告的义务；约定因供应商原因导致超市被处罚、下架、召回的赔偿责任和配合义务。

**10. 合同期限与续约**
- 坑：年度合同自动续约，价格和量却没重新确认。
- 建议：到期前若干天书面确认续约和新年度的价格、量、返利，未确认则不自动续约。

实操上，最优先处理三件事：把质量验收标准做成附件、把价格调价公式写死、把损耗和退货责任按时间节点切分。这三项谈清楚，大部分年度合同纠纷能提前避免。
