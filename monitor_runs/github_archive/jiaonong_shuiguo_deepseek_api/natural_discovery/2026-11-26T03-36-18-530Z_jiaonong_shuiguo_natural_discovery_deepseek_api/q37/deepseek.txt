商超会员日水果活动的核心是“提前锁量、锁品质、锁到店时间、锁应急方案”。供应商需要重点配合以下准备：

**1. 提前确认活动量并锁货**
- 活动前7~10天确认SKU、会员价、预估销量、日均销量峰值。
- 按“预估销量×1.2~1.3”备货，易损耗品不宜按1.5倍以上压货。
- 与商超确认锁量方式：买断、代销、保底+返利，避免活动后压货扯皮。

**2. 品质标准与验货前置**
- 提前提供活动批次的质量标准：糖度、规格、单果重、着色度、瑕疵率上限。
- 活动前2~3天完成首批到货验货，不合格批次的替换方案要提前书面确认。
- 对草莓、蓝莓、荔枝等易损品，明确运输温控、包装层数、托盘要求。

**3. 到店时间与分批配送**
- 会员日通常早高峰前完成陈列，供应商需按“前一日晚间+当日清晨”分批到店。
- 明确每店到货时间窗、卸货口、验收人；避免所有门店同一时段集中到货。
- 高峰补货频次提前排好，例如上午10点、下午3点各补一次。

**4. 包装与陈列物料**
- 按商超要求提供预包装、称重标签、产地/等级标识、会员价签配合。
- 提前送陈列道具：堆头箱、托盘、保鲜冰袋、试吃物料。
- 确认包装规格与会员价匹配，避免“小包装卖会员价”导致毛利倒挂。

**5. 价格与费用确认**
- 书面确认供货价、会员价、促销折让承担比例、损耗承担方。
- 明确活动后未售完库存的处理：退货、调拨、折价清仓，避免口头承诺。

**6. 应急预案**
- 准备替代SKU：主推品缺货时24小时内可切换的同类水果。
- 准备备用车辆和备用货源，活动日安排专人驻场或电话值班。
- 天气、交通、产地减产等风险提前报备，并给出替代方案。

**7. 人员配合**
- 活动前完成供应商理货员/促销员培训：卖点、试吃规范、补货标准。
- 明确供应商现场负责人及联系方式，活动日响应时间控制在30分钟内。

**可执行检查清单：**
活动前10天锁量定价 → 前7天确认包装物料 → 前3天首批验货 → 前1天晚间首配到店 → 活动日清晨补配+驻场 → 活动结束当日盘点损耗并确认退换货。

一句话：供应商不是只“送货”，而是要和商超共同把**量、质、时、价、损、急**六件事提前书面锁定。
