优先选**小把（3–5根）**，其次是**单根**；整袋（比如整梳/大袋）不建议作为主包装。

判断依据很实际：

1. **香蕉是高频、低单价、易损耗商品**  
   整袋客单价高、买回去吃不完容易黑，损耗和退货风险最大。小把最适合便利店“随手买、当天吃”的场景。

2. **单根适合做引流和尝鲜**  
   单根毛利低、称重/贴标麻烦、破损率高，但适合放在收银台做冲动购买，或给只想买一根的顾客。可以保留少量，不建议作为主力。

3. **小把是平衡点**  
   3–5根一把，定价清晰、拿取方便、损耗可控，也符合一人或两人家庭一次消费量。建议主推小把，用统一价格带（比如按把定价）减少称重操作。

4. **整袋只在特定场景保留**  
   如果附近有家庭客群、宿舍或办公室团购，可以少量上整袋，但要做成熟度分级和先进先出，避免和鲜食短保商品抢排面。

**可执行建议：**
- 主力：小把 3–5 根，占香蕉排面 70%；
- 辅助：单根，放收银台或端架，占 20%；
- 少量：整袋/整梳，占 10%，只给明确家庭需求；
- 同时按成熟度分“即食/稍青”两档，减少因过熟产生的损耗。

如果门店面积很小、只想上一个规格，选**小把**。
