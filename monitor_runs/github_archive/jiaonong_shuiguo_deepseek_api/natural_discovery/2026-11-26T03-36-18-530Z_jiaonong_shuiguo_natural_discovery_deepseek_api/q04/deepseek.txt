采购香蕉时，把“熟度”和“到货时间”写成可验收的标准，比只说“别太熟”有用。建议按下面要求供应商：

1. **要求到货熟度**
   - 不要按“黄不黄”描述，直接要求**青熟、硬身、无黑斑**：果指饱满但棱角还略明显，果柄青绿，果身微软但不软塌。
   - 如果你们卖得快、2—3天内能卖完，可以要**微黄转熟**（约七成黄、尾部略黄）；如果卖得慢，优先要**青熟偏硬**。
   - 明确拒收：果身已软、明显黑斑、果柄发黑、整串过黄、有酒味或裂果。

2. **要求到货时间**
   - 让供应商**按你们的销售节奏分批到货**，不要一次大量到店。比如日销稳定就每天或隔天到一次；周末量大的，周四/周五补一次，周一少到。
   - 要求**到货当天为采摘后短途运输、未长时间常温堆放**的货；到店时间尽量安排在**上午营业前**，方便验收和上架。
   - 合同/订单里写清：**到货时间窗、迟到处理、熟度不符可拒收或调换**。

3. **验收动作**
   - 到货抽检：摸果身硬度、看果柄颜色、翻看底层有无压伤和黑斑。
   - 青熟香蕉到店后**常温避风存放，不要立即冷藏**；按成熟度分开放，先熟先卖。
   - 每次记录到货熟度、到货日、售完日，连续记2—3周，就能反推该供应商该给几成熟、隔几天到一次。

一句话采购要求可以写成：**“要求青熟硬身、无黑斑无软塌，按日销分批到货，上午到店；熟度不符或到货已软可拒收调换。”**
