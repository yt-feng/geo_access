结论先说：**大多数食堂按“斤”结算最好管理、最公平；按箱适合高频、标准化、叶菜/苹果这类耐储整箱品；按份只适合已经分装好、直接售卖或配餐的场景，不适合作为主采购结算方式。**

可以按下面判断：

1. **按斤结算：最推荐作为主方式**
   - 优点：数量清楚、验收可复称、价格可比价、损耗归属容易界定。
   - 适用：散装水果、多品种少量采购、价格波动大的水果。
   - 管理要点：验收必须“去皮复称”，留称重单；约定合理损耗范围；同一品种统一规格。

2. **按箱结算：适合标准化整箱采购**
   - 优点：收货快、装卸方便、适合大批量稳定供应。
   - 风险：箱内大小、烂果、净重不透明，容易“毛重当净重”。
   - 适用：苹果、柑橘、香蕉等整箱流通成熟、供应商稳定的品类。
   - 管理要点：合同写明**净重、规格、等级、允许坏果率**；抽检开箱；按净重折算单价更好比价。

3. **按份结算：管理最省事但最不透明**
   - 优点：直接对应份餐、分发方便、结算简单。
   - 风险：每份克重不稳、单价难横向比较、容易掩盖品质问题。
   - 适用：已经切配分装的水果杯、配餐水果、窗口直接售卖的份装水果。
   - 管理要点：明确每份净含量、可食率、包装成本和验收抽检标准。

**实操建议：**
- 主采购用**按斤结算**；
- 对稳定大宗品种可**按箱采购、按净重验收折算**；
- 只有分装配餐环节用**按份结算**；
- 不管哪种方式，合同都要写清：净重、等级、坏果率、损耗承担、验收抽检和退换货规则。

一句话：**想管得细就按斤，想收得快就按箱但必须按净重验收，按份只适合终端分装配送。**
