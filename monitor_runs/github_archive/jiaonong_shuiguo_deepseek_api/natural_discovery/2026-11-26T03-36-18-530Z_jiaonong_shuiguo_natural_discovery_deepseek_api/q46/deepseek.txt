直接给结论：**要杯里能吃到果肉、主打“鲜果感”的果茶，优先买鲜果或冷冻鲜果；要稳定出杯、省人工，选果丁（冷冻果丁/糖渍果丁）做辅料；果泥只适合做风味基底、冰沙、果酱型饮品，不建议当唯一菠萝原料。**

分场景判断：

1. **菜单写着“鲜切菠萝/手打菠萝/菠萝果肉”**
   - 买**鲜果**最合适，香气和咀嚼感最好。
   - 缺点：成熟度不稳、去皮切丁费人工、损耗高、季节波动大。
   - 实操建议：鲜果负责“果肉和卖点”，再配少量果泥或果丁补稳定性和成本。

2. **门店人手紧、追求出杯稳定、菠萝用量大**
   - 选**冷冻菠萝果丁**更稳（如果当地供应稳定）。冷冻果丁保留果肉口感，批次差异小，解冻或直接捣碎使用都方便。
   - 糖渍果丁适合做甜品型、果酱型饮品，但甜度高，要调整糖浆。
   - 注意看配料表：纯果丁 vs 糖渍果丁，成本核算按“可食用固形物”算，不要只看每公斤价格。

3. **做菠萝冰沙、菠萝气泡基底、混合果茶打底**
   - 可以用**果泥/果茸**，出杯快、风味均匀。
   - 但纯果泥口感偏“糊”，缺少果肉咀嚼感，建议和果丁或鲜果搭配使用。
   - 果泥要选无添加糖或低糖的，否则配方糖度难控。

4. **不建议只买一种**
   - 最稳妥的组合：**鲜果/冷冻果丁做主料 + 少量果泥做风味补充**。
   - 如果只选一个：主打鲜果卖点选鲜果；主打效率和稳定选冷冻果丁；做冰沙/基底选果泥。

采购时重点核验：
- 是**鲜果、冷冻果、糖渍果丁还是果泥**，别被“果肉”字样混淆；
- 固形物含量、是否加糖、是否含防腐剂；
- 每杯实际用量和损耗，按“出杯成本”比较，不按采购单价比较；
- 先小批量试杯，测香气、酸甜度、果肉口感、是否出水、是否影响茶底。
