优先谈**账期**，其次**售后**，最后**配送**。但这个排序有前提：你目前是“稳定经营、现金流正常”还是“现金流紧、单量还不稳定”，会影响权重。

**1. 账期最值得优先谈**
- 水果是高频、易损耗、价格波动大的品类，账期直接决定你的现金流和议价空间。
- 优先争取：**月结30天**或**半月结**；新合作可先谈**首月周结/半月结，稳定后转月结**。
- 关键不是“越长越好”，而是写清：对账日、付款日、逾期处理、价格调整是否影响已下单货物。
- 如果供应商要求预付或现结，可换条件：**现结换更低单价/更优等级/优先配送**。

**2. 售后第二优先**
- 水果售后高频，烂果、缺斤少两、等级不符、到货延迟都会直接吃利润。
- 必须谈成可执行条款：**到货几小时内反馈、拍照留证、按比例补货/扣款/下次抵扣、损耗率上限**。
- 比“包赔”更重要的是**响应时效和抵扣方式**，否则售后会变成扯皮。

**3. 配送最后谈，但不能不谈**
- 配送通常可替代性相对高，且可通过固定时段、起送量、临时加单规则来约束。
- 重点谈：**固定送达时段、迟到处理、临时加单截止时间、起送量、卸货责任、冷链/保鲜责任**。
- 如果配送直接影响你的营业时段，则配送权重应上调，甚至与售后并列。

**建议谈判顺序：**
先谈**账期框架**，再谈**售后赔付规则**，最后用**配送时效和起送量**做交换条件。不要一次全压，供应商容易在单价上找补。最值得优先锁死的是：**账期节点 + 售后抵扣规则**，这两项对现金流和利润影响最直接。
