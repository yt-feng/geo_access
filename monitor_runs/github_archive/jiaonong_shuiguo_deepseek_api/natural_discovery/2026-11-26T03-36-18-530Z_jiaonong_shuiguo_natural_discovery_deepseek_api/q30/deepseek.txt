# 超市水果到货品相不好的售后流程约定建议

核心思路：**把"谁验收、何时提、怎么赔、超时怎么办"写成可执行条款，并区分"当场验收"和"到家后才发现"两种场景。**

## 一、合同/订单里必须写清的5个要素

1. **验收时限**
   - 到货当场验收：卸货后 X 小时内（建议 2–4 小时）完成清点，逾期视为外观验收合格。
   - 隐蔽瑕疵（切开后发现内部坏、霉变）：收货后 24–48 小时内可提，超期不认，但需保留实物和照片。
   - 明确"品相不好"的定义：按国标/行标分级，或双方约定验收标准（如腐烂率≤3%、碰伤面积≤某尺寸、果径范围）。

2. **提出方式**
   - 书面（微信/邮件/系统工单）提出，附照片/视频，注明批次、数量、问题类型。
   - 口头提出的须当日补书面，否则不生效。

3. **处理方式（按问题严重程度分档）**
   - 轻微（个别碰伤、大小略偏差）：折价扣款，按比例从货款中扣。
   - 中等（一定比例腐烂/压伤）：**换货**或**按坏果数量折价**，二选一由超市定或双方约定。
   - 严重（整批变质、不符合食品安全标准）：整批退货退款，供应商承担运费；涉及食安的按《食品安全法》处理，可另行追偿。

4. **时限与责任**
   - 供应商收到通知后 X 小时内响应、Y 天内完成换货/退款。
   - 逾期未处理：超市可自行折价处理，损失从应付货款中直接扣除。
   - 生鲜易腐品特别约定：**不得以"已签收"为由拒绝外观瑕疵索赔**，但超市须在时限内提出并保留证据。

5. **证据与争议**
   - 到货拍照/录像留存，双方各留一份。
   - 争议时以留存实物+照片为准；必要时送第三方检测，费用由责任方承担。

## 二、两种场景分开约定

| 场景 | 谁负责 | 关键条款 |
|---|---|---|
| 到货当场发现 | 收货员验收 | 当场清点、当场签字确认问题清单，超时视为合格 |
| 上架/顾客退回后发现 | 超市 | 限时（24–48h）书面提出，保留实物和批次信息，供应商按比例赔付 |

## 三、可直接抄用的条款示例

> "乙方（供应商）交付水果后，甲方（超市）应在卸货后4小时内完成外观验收，逾期未提出书面异议的，视为外观验收合格。切开后发现内部腐烂、霉变的，甲方应在收货后48小时内书面提出并保留实物及照片。经确认属乙方责任的，按以下方式处理：腐烂率≤3%的按实际坏果数量折价扣款；3%–10%的换货或折价；超过10%或不符合食品安全标准的整批退货退款，运费由乙方承担。乙方应在收到通知后24小时内响应、3日内处理完毕，逾期甲方可自行处理并从货款中扣除相应损失。"

## 四、落地要点

- **标准量化**：别只写"品相不好"，写清腐烂率、碰伤比例、果径、色泽等可判定指标。
- **流程留痕**：验收单、照片、工单三者齐全，避免扯皮。
- **区分责任**：运输损耗、仓储损耗、供应商源头问题分开约定，别让供应商背全部锅，也别让超市吃哑巴亏。
- **定期对账**：每月汇总扣款/换货记录，作为下一年度供应商评级依据。
