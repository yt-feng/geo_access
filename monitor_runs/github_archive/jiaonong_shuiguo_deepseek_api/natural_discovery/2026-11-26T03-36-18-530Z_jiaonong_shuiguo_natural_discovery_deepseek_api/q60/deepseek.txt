核心思路：**把“补货”写成可执行的义务+违约后果，而不是只写“及时补货”。** 补货要快到不影响营业，关键在到货验收、补货时限、替代方案和扣款四条。

**1. 到货验收当场定性，别事后扯皮**
- 合同里约定验收标准：品种、规格（克重/果径）、成熟度、糖度、新鲜度（无腐烂、无压伤、无虫害）、农残证明。
- 约定“到货后X小时内完成验收，当场拍照/视频留证并书面签收异议”，逾期未提异议视为合格。这条能避免供应商事后不认。
- 不合格处理分档：轻微（可挑选使用）折价接收；严重（腐烂、变质、规格不符）整批拒收并要求补货。

**2. 补货时限写死，按“影响营业”分级**
建议约定：
- **当日补货**：上午10点前验收不合格的，供应商须在当日营业高峰前（如14:00前）补到；下午验收不合格的，次日开店前（如9:00前）补到。
- **紧急补货**：门店缺货影响出品的，供应商须在X小时内（如4小时）送达，或由供应商承担门店就近采购的差价。
- 补货运输、装卸费用由供应商承担；补货同样适用验收标准，二次不合格按违约处理。

**3. 给门店留“替代权”，不把营业绑在供应商身上**
- 约定：供应商未在时限内补货，门店有权自行就近采购同品质水果，差价及合理交通费由供应商承担，并从货款中直接扣除。
- 这比单纯索赔更实用——营业不受影响，损失可追偿。

**4. 扣款和违约责任要能直接执行**
- 迟延补货按小时计违约金（如每小时扣当批货款的X%），设上限但要有威慑力。
- 同一月度累计X次补货不及时或不合格，门店有权解除合同并扣质量保证金。
- 因不合格水果导致饮品报废、客诉、食安问题的，供应商承担实际损失（可约定最低赔偿额）。

**5. 付款节点做抓手**
- 保留部分货款作为质量保证金（如每批扣5%—10%，季度结算），补货和扣款从保证金/货款中直接抵扣，不用另走索赔流程。

**一句话合同条款模板：**
“乙方交付水果经甲方验收不合格的，应在验收后X小时内补足合格货品；影响甲方正常营业的，甲方有权自行采购替代品，差价及费用由乙方承担并从应付货款中直接扣除；乙方迟延补货的，每迟延1小时按该批货款的X%支付违约金，累计X次甲方有权解除合同。”
