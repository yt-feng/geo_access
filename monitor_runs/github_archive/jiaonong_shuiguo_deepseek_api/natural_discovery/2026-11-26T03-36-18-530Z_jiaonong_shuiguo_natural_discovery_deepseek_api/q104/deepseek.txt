采购水果到货品质不一致，核心是**验收时把“抽检规则、判定标准、留证方式”定死，售后按合同约定分级处理**。下面按可执行流程说。

## 一、到货前先约定好（避免扯皮）

验收能否顺利，取决于采购合同/订单里有没有写清楚：

1. **规格标准**：品种、产地、单果重量范围、糖度下限、成熟度（如七成熟/全熟）、外观（无腐烂、无机械伤、无病虫害）。
2. **允许差异比例**：例如“抽检不合格率≤5%视为合格；5%–15%按比例扣款或换货；>15%整批拒收或退货”。
3. **验收方式**：抽检比例（如每批随机抽3–5箱/每箱抽10个）、抽检时点（到货当场、卸货前）。
4. **售后时限**：到货后多少小时内提出异议有效（如24小时内），以及举证方式（照片/视频/封样）。
5. **处理方式**：补发、换货、按比例折价、退货退款，各自适用情形。

## 二、到货验收怎么操作

**1. 当场验，不留盲区**
- 卸货前先看外箱：有无破损、水渍、异味、挤压变形。
- 随机抽检，不要只开最上面一箱。按约定比例开箱，每箱分层抽（上、中、下）。
- 冷链/易损水果（草莓、蓝莓、荔枝、水蜜桃）抽检比例应更高。

**2. 逐项对照标准记录**
- 单果重量：随机称10–20个，记录平均值和最小值。
- 外观：数腐烂果、压伤果、裂果、虫眼果数量。
- 成熟度：过硬/过软分别计数。
- 糖度：有约定糖度的用糖度计抽测。

**3. 算不合格率，按约定判定**
- 不合格率 = 不合格果数 ÷ 抽检总果数。
- 对照合同阈值：合格放行 / 折价 / 换货 / 拒收。

**4. 全程留证（关键）**
- 拍视频：开箱、抽检、称重、计数过程连续拍摄。
- 拍照片：整批外观、问题果特写、箱唛/批次号、到货时间。
- **封样**：对争议批次留存样品，双方签字封存，作为售后依据。
- 验收单双方签字，写明抽检数量、不合格数、判定结论。

**5. 异常当场处理**
- 品质明显不一致的，**先隔离、不卸货或单独堆放**，避免与合格品混放后责任不清。
- 当场通知供应商到场或视频连线确认。

## 三、售后怎么处理

按不合格程度分级：

| 情形 | 处理建议 |
|---|---|
| 轻微差异（如大小略偏小、少量压伤） | 按比例折价扣款，继续收货 |
| 部分批次不合格（如10%–20%腐烂/压伤） | 不合格部分换货或按比例退款，合格部分正常收 |
| 整批品质严重不符（如腐烂超标、品种不对、成熟度失控） | 拒收/退货，要求补发，费用由供应商承担 |
| 影响食用的食品安全问题（霉变、异味） | 整批拒收，保留证据，必要时追责 |

**售后执行要点：**
- 在约定时限内书面提出（邮件/微信文字+照片视频），不要只口头说。
- 明确诉求：补发数量、退款金额、换货时间。
- 换货/补发到货后**重新验收**，不能默认合格。
- 建立供应商质量记录，同一供应商反复出问题的，调整采购或更换。

## 四、给单位的落地建议

1. **做一张验收单模板**：批次、到货时间、抽检数、不合格数、不合格率、判定结果、双方签字。
2. **固定抽检比例和判定阈值**写进采购合同，别每次临时谈。
3. **易损水果要求供应商冷链+加固包装**，并在合同里约定运输损耗责任。
4. **验收和付款挂钩**：验收合格单是付款前提，异常批次暂缓付款。

一句话总结：**验收靠“抽检+留证+按约定判定”，售后靠“分级处理+书面留痕+重新验收”**，前提是合同里先把标准和比例写清楚。
