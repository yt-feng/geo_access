选下午茶水果供应商，核心看**批量配送稳定性、品控一致性、结算和售后**，不要只看单价。可以按下面几步判断和落地：

**1. 先明确采购约束**
- 人数、预算/人、配送频次（每周几次）、配送时间窗口（如下午2点前到）。
- 水果形态：整果、果切、拼盘。下午茶建议**整果+少量易剥果切**，果切对冷链和时效要求高。
- 是否需要发票、月结、固定配送地址和签收人。

**2. 供应商类型优先级**
- **本地水果批发商/配送商**：适合批量、价格低，但要确认是否支持小批量多频次配送和售后。
- **生鲜B2B平台**：履约稳定、票据规范，适合公司采购，缺点是价格略高。
- **连锁水果店/社区团购供应商**：适合中小批量、响应快，但要确认高峰期能否准时。
- **产地直供**：价格有优势，但品控和售后风险高，不适合对稳定性要求高的下午茶。

建议至少对比**3家**：1家本地批发配送、1家B2B平台、1家连锁水果店。

**3. 重点核验这6项**
- **配送能力**：是否有冷藏车/保温箱，能否固定时段送达，迟到怎么处理。
- **品控标准**：坏果率承诺多少（如≤3%），是否有到货验收和拍照留证流程。
- **售后条款**：坏果是否补配/退款，响应时限，是否影响下次配送。
- **报价口径**：是否含配送费、切配费、包装费、税费；是否随行就市调价。
- **结算方式**：能否月结、开票，是否需要押金。
- **食品安全**：果切类要有冷链和分切卫生条件，查看相关资质。

**4. 先试单再签长期**
先下**1-2次小批量试单**，重点看：准时率、坏果率、实际净重、包装是否适合办公室分发、售后响应。试单合格再谈月度框架价。

**5. 合同/订单里写清楚**
品名规格、净重、单价、配送时间、验收标准、坏果赔付、临时加单规则、节假日保障、发票和账期。避免只口头约定。

**简单判断标准**：能稳定准时送到、坏果少且售后快、报价透明可开票的供应商，优先于单价最低的。下午茶水果最怕“便宜但迟到、坏果多、售后扯皮”。
