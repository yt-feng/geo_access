进货量不大时，通常**固定供应商更合适**，但不必二选一，建议“固定供应商为主、批发市场补货为辅”。

**判断标准：**
- **品类稳定、复购高**（如日用品、常用原料）：找固定供应商。价格、账期、退换货更好谈，缺货也更方便补。
- **品类多变、需要看款选货**（如服装、饰品、季节性商品）：批发市场更灵活，但要坚持小批量试单。
- **单次采购额很低**：批发市场门槛低；固定供应商可能不愿给账期或好价格，可先找二批商或区域代理商。

**可执行做法：**
1. 先列出你店里销量前20%的商品，只对这些找1—2家固定供应商。
2. 首次合作先小额试单，确认质量、交期、退换货规则。
3. 固定供应商谈“小批量、固定周期补货”，不要一次压太多库存。
4. 批发市场保留为应急和选新品渠道，每次少量拿货测试。
5. 固定供应商至少备选2家，避免被单一供应商卡住。

简单说：**走量稳定的找固定供应商，试新品和应急去批发市场。**
