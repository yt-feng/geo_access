社区超市卖小包装香蕉，采购和包装要围绕“少批量、快周转、控压伤、稳成熟度”来做。重点注意这些：

1. **规格不要过大**
   - 小包装建议按 **2～3根/袋** 或 **300～500g/袋** 做，避免家庭一次吃不完。
   - 单根过大、整串过大都会增加剩货和压伤，采购时优先选中等果指、均匀度好的批次。

2. **成熟度要分批采购**
   - 不要一次全进同一成熟度。建议同时有：
     - 少量即食黄熟果：当天、次日卖；
     - 多数转黄果：2～3天进入最佳销售期；
     - 少量青黄果：后补陈列。
   - 社区店客流稳定但量小，采购频次可比大卖场高，单次量少。

3. **包装方式优先“透气+防压”**
   - 不建议完全密封塑料袋，易闷热、结露、加速腐烂。
   - 可用带孔保鲜袋、网袋、开窗纸袋或浅托盘+透气膜。
   - 袋上留透气孔，避免水汽积聚。
   - 若用托盘覆膜，膜要薄、有孔，不要紧裹果柄和果指弯曲处。

4. **减少果指挤压和机械伤**
   - 香蕉怕压、怕磕、怕摩擦。小包装不要硬塞，袋内留少量空间。
   - 采购箱内要用纸隔板、纸丝或分隔托盘，避免整箱堆压。
   - 陈列时不要叠放过多层，小包装最多轻叠2层，避免底层压伤变黑。

5. **果柄和切口要处理**
   - 分切整串时，切口要整齐，避免撕裂果柄。
   - 分切后尽快包装，减少切口氧化和汁液污染。
   - 若做单根或2根装，果柄端可用食品级纸或小护套隔开，防止刺破相邻包装。

6. **控制结露和温差**
   - 香蕉对低温敏感，社区店不要放冷柜或低温风幕柜直吹。
   - 采购运输和店内暂存避免忽冷忽热；从较凉环境移到常温陈列易结露，结露后易长霉。
   - 暂存放阴凉通风处，温度相对稳定，避免阳光直射和空调风口直吹。

7. **采购验收看“伤、柄、色、味”**
   - 看果指是否有压痕、裂口、黑斑扩散、霉点；
   - 看果柄是否发黑、发霉、断裂；
   - 看成熟度是否均匀，避免一袋里有的已熟透、有的还青；
   - 闻是否有发酵味、酸味。有异味批次不要进小包装。

8. **先进先出和日清管理**
   - 小包装标注包装日期或到店日期，按成熟度分区陈列。
   - 每天挑出黑斑明显、过熟、破袋的，及时打折或转熟食/员工处理，不要混在新包里。
   - 社区店建议“少量多次”补货，宁可下午补一次，也不要早上堆满。

9. **损耗责任和退货要提前约定**
   - 采购时和供应商明确：机械伤、水烂、霉变、青果不熟等退换标准。
   - 小包装分切后的损耗通常由门店承担，所以采购时就要控制成熟度和批量，不要指望后期挑拣解决。

10. **陈列位置和包装标识**
   - 放在阴凉、客流可见处，避免靠近热源、灯下长时间直射。
   - 包装上标清规格、价格、包装日期，最好提示“常温阴凉保存，尽快食用”。
   - 不建议做太多促销大堆头，小包装香蕉堆高后底层压伤和过熟损耗会明显增加。

简单执行标准：**单包2～3根、少量多批、透气包装、轻拿轻放、成熟度分级、日清挑拣、不退不换的伤果不进货。**
