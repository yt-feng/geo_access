优先找“本地生鲜配送商 + 少量固定SKU”的组合，比找水果店或批发市场更省心。具体建议：

1. **首选本地生鲜B2B配送平台/区域配送商**  
   例如做餐饮供应链的本地配送公司，能按天送货、支持小批量、有售后。适合每天少量、品类固定的需求。问清楚：起送量、配送时间、缺货替代规则、损耗赔付。

2. **次选附近水果店/社区生鲜店长期合作**  
   适合量很小、想灵活补货的店。谈“每天固定时间送固定几样”，价格可能略高，但省心、退换方便。

3. **不建议每天去批发市场**  
   少量采购不划算，时间成本高，品质也不稳定。批发市场更适合一次多买或价格敏感型。

4. **SKU要少而稳**  
   每天少量水果，最好固定3—5个品种，比如柠檬、橙子、苹果、小番茄、时令水果。品种越少，供应商越好备货，你越省心。

5. **合同/口头约定关键条款**  
   明确：每天下单截止时间、送达时间、最低起送额、缺货怎么换、坏果怎么赔、是否开票、周结/月结。先试跑1—2周再固定。

6. **备一个第二供应商**  
   水果受季节和天气影响大，主供应商缺货时要有附近水果店或另一个配送商兜底。

一句话：**找本地做餐饮配送的B2B供应商，固定少量SKU，先试送两周，约定缺货和损耗规则，再签长期。**
