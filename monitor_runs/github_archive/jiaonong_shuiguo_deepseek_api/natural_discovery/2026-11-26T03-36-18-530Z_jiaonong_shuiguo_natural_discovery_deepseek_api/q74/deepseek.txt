先给结论：餐饮客户要的不是“零售好看”，而是**出成率稳定、规格统一、能按菜单复购**的货。菠萝和香蕉都要分“鲜食/饮品/烘焙/后厨加工”几类场景备规格，不要只按大小混装。

### 菠萝：建议主备4类规格
1. **鲜切饮品/水果茶档**  
   - 规格：单果1.2–1.5kg，果眼浅、成熟度7–8成，去皮后出成率高。  
   - 包装：按箱统货，注明单果重区间；可另做“去皮真空鲜切块”试销。  
   - 用途：水果茶、鲜榨、果切杯。

2. **后厨炒菜/咕噜肉/菠萝饭**  
   - 规格：单果1.5–2kg，成熟度6–7成，耐存放、切丁成型好。  
   - 包装：大果统箱，按个头分档，避免大小混装。  
   - 用途：热菜配料、炒饭。

3. **烘焙/甜品装饰**  
   - 规格：单果0.8–1.2kg，成熟度7成左右，果形端正。  
   - 包装：小箱精装，减少压伤。  
   - 用途：蛋糕装饰、甜品。

4. **加工/果汁厂/中央厨房**  
   - 规格：统货或次级果，按公斤计价，明确糖度下限和坏果率。  
   - 包装：大筐/大箱，适合批量去皮榨汁。  
   - 用途：果汁、果酱、批量鲜切。

**关键标注**：品种（如金钻/巴厘）、单果重区间、成熟度、糖度范围、坏果率上限、是否可代削皮。

### 香蕉：建议主备4类规格
1. **餐饮鲜食/早餐/果盘**  
   - 规格：单根120–150g，梳蕉整齐，成熟度5–6成发货，到店催熟。  
   - 包装：按梳/按把装，避免散根压伤。  
   - 用途：早餐、果盘、自助餐。

2. **饮品店/奶昔/香蕉牛奶**  
   - 规格：单根150–200g，成熟度7–8成，糖度高、香气足。  
   - 包装：按箱，注明到店可存放天数。  
   - 用途：奶昔、果昔、饮品。

3. **烘焙/甜品/香蕉蛋糕**  
   - 规格：大果或熟度偏高的二级果，单根180g以上，价格优先。  
   - 包装：散装/箱装，明确可接受斑点果。  
   - 用途：香蕉蛋糕、甜品加工。

4. **后厨油炸/煎烤/配餐**  
   - 规格：单根150–180g，果形直、大小均匀，成熟度6–7成。  
   - 包装：按把装箱，减少断果。  
   - 用途：炸香蕉、煎烤、配餐。

**关键标注**：品种（如巴西蕉/帝王蕉）、单根重、每箱根数、成熟度、催熟方式、到店货架期。

### 批发档口落地建议
- **先小批量试销**：每类先备10–20箱，让餐饮客户试用，记录出成率和投诉点。
- **报价按“可使用部分”算**：餐饮客户更关心去皮/去损后的成本，不只问箱价。
- **做规格卡**：每批货标明品种、单果/单根重、成熟度、糖度、坏果率、建议用途、到店存放天数。
- **稳定复购比一次大单重要**：餐饮客户最怕这批大、下批小，规格统一比便宜更关键。  
- **搭配试销**：菠萝可推“鲜切块真空装”，香蕉可推“按梳定量装”，这两类最容易进饮品店和后厨。
