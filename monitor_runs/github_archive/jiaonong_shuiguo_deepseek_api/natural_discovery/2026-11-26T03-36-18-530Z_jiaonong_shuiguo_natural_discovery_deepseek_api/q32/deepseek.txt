判断香蕉供应商能否全年稳定供货，不能只听“我们有基地、全年不断货”，要按**产能—季节—物流—风控—履约**五层去验。给你一套可直接执行的判断框架：

## 1. 先问清“全年稳定”的真实来源结构
要求供应商明确说明供货来源占比，而不是只报一个总数：

- 自有基地多少亩/多少株？分布在哪些产区？
- 合作基地/代采比例多少？主要在哪几个县市？
- 是否跨产区调配？比如海南、云南、广西、老挝、缅甸、菲律宾、厄瓜多尔等能错季互补的来源。
- 每个产区的主要上市月份、预计月供量。

**判断要点：** 单一产区几乎不可能真正全年稳定。供应商如果只有一个基地却承诺全年，基本不可信。要看它是否有“主产区+备用产区”的错季组合。

## 2. 用“月度供货能力表”压测，而不是看年度总量
让对方按月份列出过去12个月实际发货量、未来12个月预计可供量、最低保供量。重点看：

- **最淡季**（通常冬春交替、台风季、主产区换茬期）能供多少；
- 你所在区域超市的**周需求峰值**是多少，供应商淡季保供量是否覆盖；
- 是否愿意把“月度最低保供量”写进合同并设违约条款。

**可执行动作：** 拿你超市过去12个月香蕉周销量做一条需求曲线，再让对方填供货曲线，两条曲线叠加，缺口月份就是风险点。

## 3. 核查基地与产能的真实性
不要只看照片和宣传册，要求提供可核验材料：

- 基地地址、面积、种植年限、当前在园株数、预估单产；
- 近6个月的水肥、病虫害防治、采收记录；
- 合作基地的采购合同或授权证明；
- 最好安排**实地或视频验厂验园**，看包装厂、冷库、催熟能力是否匹配。

**判断要点：** 产能要从“株数×单株产量×商品率”倒推，而不是听亩产口号。还要问清台风、寒害、枯萎病（TR4）等风险下的历史减产情况。

## 4. 看采后与物流能力，这决定“能不能稳定到店”
香蕉稳定供货不只靠种出来，还靠采后处理：

- 是否有产地包装厂、清洗保鲜、分级线；
- 冷链车/常温车数量，到你们配送中心的运输时长；
- 催熟库能力：是供应商催熟还是你们自己催熟，催熟批次稳定性如何；
- 旺季日发货能力、淡季最低发车频次；
- 极端天气/节假日是否有备用车辆和备用路线。

**判断要点：** 问“去年台风季/春节前，你们最晚一次到货延迟多久、怎么补货”，让对方给具体案例和补救记录。

## 5. 查履约历史与财务/经营稳定性
要求提供：

- 近12个月给其他连锁商超或批发市场的供货记录（可脱敏）；
- 连续供货客户名单及合作年限；
- 近一年是否有断供、质量退货、账期纠纷；
- 企业工商信息、涉诉情况、社保人数、是否有频繁变更法人/股东。

**判断要点：** 经营年限短、客户集中度高、频繁换主体、靠低价抢单的供应商，全年稳定性通常弱。

## 6. 用“小单试供+压力测试”验证，而不是一次签全年
建议分三步：

1. **试供2—4周**：覆盖正常周和周末高峰，记录到货准时率、缺货率、损耗率、催熟一致性。
2. **淡季压测**：在最难供的月份要求按合同最低量供货，看是否兑现。
3. **双供应商备份**：主供占70%—80%，备供占20%—30%，备供也要能小批量随时切换。

## 7. 合同里必须写死的稳定性条款
- 月度最低保供量及缺口违约金；
- 断供提前通知期（如不少于15天）和替代方案；
- 价格调整机制（避免旺季坐地起价）；
- 质量分级标准、损耗赔付、到货时限；
- 连续N次未达标可终止并扣保证金。

## 一句话判断标准
**能拿出“多产区错季结构+月度保供表+可核验基地+采后冷链+淡季履约案例+合同保供条款”的供应商，才值得谈全年稳定；只靠口头承诺和低价报价的，不要押主力份额。**
