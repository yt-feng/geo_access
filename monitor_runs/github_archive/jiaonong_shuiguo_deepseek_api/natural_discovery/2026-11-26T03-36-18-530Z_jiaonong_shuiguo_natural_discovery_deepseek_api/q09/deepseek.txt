旺季谈供应商，核心是把“可能断货”的风险提前变成可执行的约定。建议按下面几组问题问，并尽量落到书面：

**一、产能与货源**
1. 旺季你每天/每周能稳定给我供多少？最低保供量是多少？
2. 你上游是自有基地、合作社还是批发市场？货源断了有没有备用渠道？
3. 我常卖的几款单品，旺季供应周期和高峰时段是什么时候？
4. 遇到产地减产、天气异常，你一般怎么处理？有没有替代品种或替代产地？

**二、价格与锁价**
5. 旺季价格怎么定？按日价、周价还是锁价？锁价能锁多久？
6. 涨价提前几天通知？有没有涨幅上限？
7. 量大有没有阶梯价？长期合作有没有返点或账期支持？

**三、品质与验收**
8. 规格、等级、成熟度、瑕疵率怎么约定？以谁的验收标准为准？
9. 到货后发现品质不达标，退换货规则是什么？损耗谁承担？
10. 能不能提供样品或首批试供？试供不合格怎么处理？

**四、配送与时效**
11. 每天几点前下单、几点送达？旺季配送频次能不能增加？
12. 缺货、延迟、少送时提前多久通知？有没有应急补货方案？
13. 送货到店还是到仓？装卸、运费、冷链谁负责？

**五、结算与风险**
14. 结算方式是现结、周结还是月结？要不要押金或保证金？
15. 如果旺季你供不上，违约怎么处理？有没有保供协议或备选供应商机制？
16. 出现食品安全或农残问题，责任怎么划分？有没有检测报告？

**六、合作机制**
17. 旺季前能不能先签保供意向，明确单品、数量、价格区间和违约条款？
18. 平时能不能固定每周对一次库存和需求预测，提前备货？

**实操建议：**
- 不要只谈一家，旺季至少准备“主供+备供”两家，主供占70%左右。
- 把保供量、通知时效、退换货、违约处理写进简单协议或微信书面确认。
- 先小批量试供1—2周，再放量。
- 关键单品提前7—15天做需求预测给供应商，别等到缺货才追。

一句话：旺季谈供应商，重点不是“能不能便宜”，而是“量能不能保、货能不能到、坏了谁负责、断供怎么办”。
