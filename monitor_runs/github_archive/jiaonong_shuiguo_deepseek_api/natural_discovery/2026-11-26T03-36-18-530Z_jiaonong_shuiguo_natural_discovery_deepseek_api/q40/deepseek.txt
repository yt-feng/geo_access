节假日水果需求暴增，提前锁定货源的核心是“把不确定的需求变成可执行的订单和库存计划”，分四步做：

**1. 用历史数据做需求预测，而不是拍脑袋**
- 拉出近2–3年同节假日的门店/品类销售数据，按单品（如车厘子、砂糖橘、礼盒装）拆到日销量和峰值系数。
- 结合今年节假日天数、促销档期、天气和周边竞品活动做修正，输出“安全库存+峰值日销量”两套数字。
- 预测要分门店层级：旗舰店、社区店、乡镇店需求结构差异很大，避免一刀切压货。

**2. 提前锁量：和核心供应商签“框架+滚动订单”**
- 节前45–60天与主供应商谈框架协议，约定品类、规格、价格区间、最低保供量和违约条款，而不是临时下单。
- 用“滚动订单”锁定产能：每周给供应商未来2–3周的预估量，节前两周转为日订单，供应商按约定比例备货。
- 对爆款单品（礼盒、进口水果、高端单品）可支付少量定金锁货，明确到货时间和质量验收标准。

**3. 多源备份，降低单一产地/供应商风险**
- 每个核心单品至少准备2–3个供应商或产地（如国产+进口、不同产区），主供占60%–70%，备份占30%–40%。
- 提前确认物流运力：节假日冷链车紧张，节前锁定车队或签订运输保障协议，避免“有货运不到”。
- 对易损耗单品控制锁货比例，更多用“短周期高频补货”代替一次性囤货。

**4. 用门店分层和动态补货机制消化波动**
- 按门店销量分级分配锁货量，节前3天开始每日根据实际销售调整补货，避免部分门店断货、部分门店积压。
- 设置库存红线：对保质期短的水果设“最高库存天数”，超过即启动促销或调拨。
- 节中保留10%–15%的应急采购额度，用于补爆款缺口。

**可直接执行的清单：**
- 节前60天：完成销量预测和供应商框架谈判。
- 节前45天：签锁量协议、付定金、确认物流。
- 节前30天：首轮备货到仓，启动滚动订单。
- 节前7天：按门店分级铺货，建立每日补货会议。
- 节中：每日复盘销量与库存，启动应急采购和调拨。

关键判断标准：如果某个单品只有单一供应商、且没有书面保供量，就算“没锁定货源”，节前必须补上备份。
