水果店遇到坏果，先按“证据—责任—规则—结算”四步处理，核心是先固定证据、再按合同或交易习惯划分责任，最后用扣款、换货或补发解决，避免口头扯皮。

**1. 到货当场验货并固定证据**
- 卸货时立即抽检/全检，坏果拍照或录像：带包装、批次、送货单、坏果切面、数量同框。
- 让司机或送货员在送货单上签注“发现坏果X箱/斤，待处理”，或当场拍照发供应商确认。
- 保留聊天记录、通话录音、送货单、付款凭证。没有书面合同的，微信确认也算证据。

**2. 区分责任和赔付范围**
- **运输/装卸造成**：压伤、冻伤、闷坏，通常由供应商承担，因其负责交货前质量及运输。
- **产地/批次本身问题**：腐烂、霉变、内部黑心，供应商承担。
- **到货后因门店储存不当**：如未及时冷藏、堆压，一般门店自担。
- **自然损耗**：叶菜、浆果等易腐品，按行业惯例或合同约定损耗率处理，常见约定1%—5%，但以你们合同/习惯为准，不能凭空套用。

**3. 结算方式优先按合同**
- 有合同：按合同质量条款、扣款标准、换货期限执行。
- 无合同：按双方长期交易习惯，通常采用“坏果扣款、换货补发、下批补差”三种方式之一。
- 建议结算公式：**应结金额 = 送货金额 − 坏果对应货款 − 约定违约金/损耗补偿**。坏果对应货款按实际进货价计算，不按售价。
- 若坏果比例高，可整批拒收或要求退货退款，不要先签收再争议。

**4. 实操建议**
- 当天发书面通知给供应商：列明批次、数量、照片、诉求（换货/扣款/补发），要求限时回复。
- 供应商不认：先暂停该批付款，保留货物和证据，必要时请市场管理方或行业调解。
- 长期合作：在采购单上增加质量条款，如“到货24小时内验货，坏果超X%可拒收或按实扣款，换货48小时内补到”。
- 不要擅自把坏果扔掉后再索赔，先留证、留样，避免对方不认。

一句话：**先验货留证，再按合同/惯例定责，能换货优先换货，不能换就按进货价扣款，争议未决前暂缓结算该批货款。**
