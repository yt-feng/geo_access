商超会员日水果活动的成功，很大程度上取决于供应商的提前配合。如果准备不足，容易出现缺货、损耗高、现场混乱或毛利不达标等问题。

以下是供应商需要提前配合商超完成的**6个核心准备模块**，按优先级排列：

**1. 数据与选品准备（活动前10-15天）**
- **历史数据复盘**：提供去年或上季度会员日同类水果的销售数据（含促销占比、客单价、连带率）。
- **爆品锁定**：根据商超的会员画像，确定**2-3款引流爆品**（如应季榴莲、车厘子）和**4-6款毛利补充品**（如常规苹果、柑橘）。
- **价格带设计**：明确会员价与日常价的价差建议，确保会员价有**冲击力**，同时保证供应商毛利不低于**10%-15%**（生鲜一般标准）。

**2. 货源与供应链锁定（活动前7-10天）**
- **锁量锁价**：根据商超预估销量（核对采购订单），提前向产区或基地**锁定货源**，签订保量协议，防止活动期间产地涨价。
- **备货计划**：准备**日常1.5-2倍**的安全库存，特别是爆品要预留机动库存（应对突发人流）。
- **应急预案**：确认第二备选货源（如A基地断货，B基地的冷链发货时间）。

**3. 品质与包装标准（活动前3-5天）**
- **分级标准升级**：会员日需明显提高出货标准，**剔除瑕疵果、软化果**，避免售后差评。
- **预包装方案**：提前制作**小规格包装**（如3粒装、4粒装）方便会员单次消费，减少现场称重排队压力。
- **防损设计**：对易碎水果（如葡萄、草莓）使用吸塑盒+防震垫，提前准备活动专用分拣筐。

**4. 冷链与配送协同（活动前24-48小时）**
- **分波次到货**：与商超确定**错峰发货**时间（例如活动前晚到一半，活动当天早晨到一半），忌一次性到货导致冷库堆压。
- **温度监控**：全程冷链记录需交接给商超收货员（特别是对于非冷链车会拒收的品类），确保到店商品中心温度达标。
- **损耗承担规则**：提前书面确认路途损耗、上架前损耗的责任划分（通常供应商承担到店前损耗的80%）。

**5. 人员与陈列支持（活动前1天）**
- **理货员支援**：安排专职促销员在高峰时段（如会员日下午4-7点）驻场补货、去皮试吃。
- **陈列道具配合**：提供异型陈列架（如金字塔堆头）、爆炸贴、价格签，并协助商超理货员调整排面。
- **试吃物料**：准备足量的牙签、纸巾、一次性手套，以及**分流试吃台**（防止试吃堵塞过道）。

**6. 数据复盘与结算对接（活动期间及结束后）**
- **实时动销反馈**：每天闭店后向商超采购发送当日库存余量、售罄预警，便于次日调货。
- **价差补贴核算**：如果供应商对会员价有补贴，需提前准备好**价差费用结算单**模板，活动结束后当天整理单据，避免拖延对账。
- **退货条款确认**：活动结束前再次确认临期商品的退货窗口期，防止滞销品积压。

---

**给您的实操建议：**
- **拉群沟通**：建议商超在活动前7天建立包含采购、供应商老板、仓管、财务的专属微信群，每日同步销售数据。
- **供应商避坑点**：不要只备大果，会员中家庭用户多，**中等规格（如8-9个/斤的苹果）** 销量通常比大果高30%。
- **最关键的配合动作**：一定要在活动前夜让供应商**亲自到店巡场**，检查冷库温度、排面位置是否正确，这是降低当天沟通成本的最有效手段。
