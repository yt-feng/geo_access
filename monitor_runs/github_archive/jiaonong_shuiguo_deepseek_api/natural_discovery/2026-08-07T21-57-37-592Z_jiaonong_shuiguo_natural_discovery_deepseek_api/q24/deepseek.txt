在超市采购水果时，为避免农残抽检不合格，建议在签订采购合同或首次供货前，向供应商**索要并核验**以下核心资料，并保留纸质或电子版存档：

**1. 基础资质类（证明主体合法）**
- **营业执照**（经营范围须包含水果销售或种植）。
- **食品经营许可证**或**食品生产许可证**（若涉及分装或加工）。
- **法定代表人身份证复印件**及**授权委托书**（若为代办）。

**2. 农残检测核心文件（最关键）**
- **每批次出厂或进货的农残检测报告**：必须是**近3个月以内**、由**有CMA/CNAS资质的第三方检测机构**（如SGS、华测、谱尼等）出具的，且检测项目需覆盖国家禁用及限用农药（如甲胺磷、氧乐果、毒死蜱、克百威、多菌灵等）。**注意：** 供应商自检报告效力较低，不能替代第三方报告。
- **产地证明**：由产地村委会、农业合作社或当地农业农村局开具，证明水果来源于备案基地（有具体地块信息）。
- **进货凭证**：包括供货商与产地之间的采购发票或转账记录，确保货品来源可追溯。

**3. 种植与追溯证明（降低风险）**
- **农产品合格证**（食用农产品电子合格证或纸质合格证，需注明品名、数量、产地、检测结果）。
- **绿色食品/有机认证证书**（如有，可大幅降低风险，但需核对证书有效期及是否覆盖本批次）。
- **种植基地备案证明**及**农事记录**（涉及用药周期，可要求供应商提供最近一次施药日期及安全间隔期说明）。

**4. 承诺与协议文件**
- **质量保证承诺书**（供应商书面承诺本批次水果农残符合GB 2763-2021《食品安全国家标准 食品中农药最大残留限量》）。
- **进货查验记录表**：你方超市需留存供应商签字盖章的该表格，作为溯源依据。

---

**特别提醒（执行建议）：**

1. **抽检前确认**：若当地市场监管部门即将抽检，务必确认上述报告中**检测日期**是否覆盖当前在售批次（报告日期必须晚于水果成熟采收日期），否则要求供应商提供该**具体到货批次**的检测报告。
2. **风险兜底**：若供应商无法提供第三方报告，建议在合同中明确写明“若因农残超标导致超市被处罚或损失，供应商承担全部赔偿责任”，并拒绝接收无报告批次。
3. **抽样留样**：每次收货时，随机抽取2-3个样品（每个样品不少于1公斤），封存于阴凉处保留48小时，以便用于复检（自留样可应对抽检异议）。

**最后建议：** 若无法确保第三方报告真实性，可要求供应商在送货当日提供一份**快速检测卡当场检测**（如胶体金法），虽非权威，但可作初步筛查。此外，**优先采购贴有“食用农产品合格证”的规模化基地产品**，其风险远低于散户。
