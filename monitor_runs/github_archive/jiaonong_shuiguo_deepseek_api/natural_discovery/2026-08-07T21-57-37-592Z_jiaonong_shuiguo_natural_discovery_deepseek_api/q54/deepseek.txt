采购香蕉用于烘焙时，**成熟度是第一优先级的核心指标，价格只能作为次要考量**，甚至应该为了成熟度主动让步于价格溢价。

原因如下：

**1. 成熟度直接决定成品的风味和结构**
- **熟透（带黑斑）**：糖分高、水分含量适中、淀粉已转化为糖，香味浓郁，是做香蕉蛋糕（尤其香蕉磅蛋糕、马芬）的首选。烤出来质地湿润，香蕉香气突出。
- **过熟（发黑软烂）**：容易导致蛋糕水汽过重、塌陷或口感发黏，且可能带发酵酸味。
- **未熟（青硬）**：淀粉感重，甜味不足，烤出来组织干涩，蛋糕没有香蕉味，还会出现苦涩的丹宁感。

**2. 成熟度还影响操作可行性**
- 烘焙需要香蕉泥，过于生的香蕉难以压成顺滑泥状，需要额外蒸煮，增加工时且风味不佳。

**3. 价格差异对成本影响有限**
- 香蕉在水果中单价较低，即便采购成熟度优质的香蕉，单价差异通常每斤在几角到一元内。而制作一批蛋糕可能需要几斤到十几斤，成本差异非常小，远低于因产品口感差导致的退单或口碑损失。

**采购建议（可执行）**
- 到店或电商下单时，明确要求“用于烘焙的熟香蕉”，描述标准为：表皮出现**大面积褐黑色斑点，但捏起来不软塌、无破损**（太软易运输碰伤）。
- 如果进货周期长，可以采购8成成熟度（表皮微黄带青），放在室温自然催熟1-2天再使用，比买全熟更耐储存，但**不建议采购全青硬果**。
- 谈价格时，优先谈**整箱或批量价格**，而不是斤价，因为烘焙单次用量大，批量能弥补单价略高的问题。

**一句话总结**：宁可多花一点钱买成熟的香蕉，也不要为了省钱买不熟的，成熟度不合格的香蕉做出来的蛋糕不会有回头客。
