在超市卖菠萝时，**最核心的优先级排序应该是：甜度 > 切果损耗 > 外观 > 大小**。

具体分析如下：

1. **甜度（决定复购率）**：这是**第一要素**。如果菠萝不甜，再好看也卖不掉或复购率极低。建议：
   - 随批次做试吃推广，或者用“糖度计”抽测（成熟可食的菠萝糖度一般应≥12%）。
   - 从源头选品时，优先选择产区气候好（如海南、广东湛江）的品种，并控制从采摘到上架的时间，越新鲜、后熟越充分的甜度越稳定。

2. **切果损耗（直接决定毛利）**：这是**经营利润的隐形杀手**。菠萝削皮去眼后损耗率通常高达**30%~40%**。关注点：
   - 优先选果眼浅、表皮薄且平整的品种（如某些“无眼”或短刺品种），降低人工切果难度。
   - 如果现场提供切果服务，要测算切果废弃物的重量占比。如果损耗超过40%，要么提价，要么停止现场切果，改为整果促销。
   - 同时要控制“成熟度”，太熟的菠萝切果时果肉容易软烂，加剧损耗；但太生顾客又不买切果，平衡点最好是：切果只切当天“适熟可食”的，其余放整果区域。

3. **外观（决定第一印象）**：**不是不重要，而是排在甜度和损耗之后**。顾客主要看：
   - 果皮颜色黄中带绿（或全黄但无黑斑），无大面积发霉、软塌。
   - 叶丛青绿、有韧性（不死黄、不干枯），果眼无发黑渗水。
   - 有一点要提醒：很多顾客喜欢“全黄”的菠萝，但全黄往往意味着过熟，甜度高但损耗也大，需要根据货架期匹配销售速度。

4. **大小（决定定价和客单价）**：
   - 统一规格（如单果1.2~1.5斤）便于定价，也方便顾客预算。
   - 但大小不是关键卖点，除非你能提供“切好果肉按克重卖”的选项来吸引便宜尝鲜客。

**实操建议（可直接落地）**：
- 上架前：按甜度抽测，不合格的批次标注为“炖汤/酸度偏高”打折处理。
- 陈列时：混合卖——整果（挑外观好的）和切果（挑当天最甜、损耗低的）分开陈列，切果用保险膜包好并标注“当日现切”。
- 损耗控制：每次切果后记录果皮+果芯重量，一周一统计，如果损耗率持续>40%，就减少切果比例，加大整果促销。
- 话术与标识：在整果区挂“甜度≥13%”或“今日试吃甜”标牌，用看得见的证据引导购买。

**总结**：甜度是里子，损耗是口袋，外观是面子，大小是便利。不要为外观牺牲甜度，也不要只追甜度放弃损耗，尤其是超市经营中切果损耗往往是“隐形利润黑洞”。
