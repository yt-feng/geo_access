选择水果供应商时，很多人关注价格、品种和送货速度，但这些“大项”往往是表面功夫。长期稳定生意的核心，恰恰藏在那些不起眼、容易忽视的细节里。以下是你最容易踩的坑和应对思路：

### 1. 忽视“损耗率”而非“进货价”
- **最容易忽视的点**：只看每斤便宜几毛钱，没人算账内损耗。
- **破解方法**：水果是生鲜，损耗是利润杀手。你要和供应商明确**“三包”条款（包退、包换、包补差）**。比如：到货后因运输挤压、成熟度过高导致的自然损耗，供应商是否无条件赔付？有些供应商报价低，但坏果率高达15%，而报价高5%的供应商坏果率控制在3%以内，整体算下来后者更划算。**合同里必须写清楚“收货抽检标准”和“赔付比例”**。

### 2. 忽视“分级标准”而只看“一口价”
- **最容易忽视的点**：同一个品种（如苹果），框装和散装、统货和精品果价格差一倍，但很多新手以为“都是一个品种”。
- **破解方法**：要求供应商提供**产地证明+等级标注**（如：果径、糖度、瑕疵比例）。合作前让他发实物照片和视频，确认“上中下三层果品是否一致”，防止“上面精品、下面次品”的“阴阳筐”。

### 3. 忽视“冷链物流的实时温度记录”
- **最容易忽视的点**：以为“冷链车”= 全程低温。
- **破解方法**：要求供应商提供**车辆温控记录单**（尤其是跨省运输）。很多供应商用常温车装水果，夏天一车货到货后表面完好，但内部已经“回温熟化”，第二天就烂。**合作时要约定：到货后核心果温超过设定值（如10℃），整批拒收或按次品处理。**

### 4. 忽视“供应商的库存周转周期”
- **最容易忽视的点**：以为供应商仓库里常年有货，就没风险。
- **破解方法**：问清他的**冷库容量和进货频率**。如果他每周只进货一次，且库存只有3天，一旦遇到暴雨、台风等极端天气，你的供货就会断档。长期合作要找**有自建冷库、且备货周期能覆盖你7天销量的供应商**。

### 5. 忽视“账期背后的隐性成本”
- **最容易忽视的点**：账期长=占便宜，但忽略了供应商把账期利息加到价格里。
- **破解方法**：对比“现结价”和“月结价”的差额。如果月结比现结贵5%，而你月销售额10万，相当于每月多付5000元，年化成本60%。**尽量争取“周结+3%返点”模式**，比单纯拖账期更划算。

### 6. 忽视“售后响应速度”而非“售后条款”
- **最容易忽视的点**：合同里写了“坏果包赔”，但真正赔付要等一周，影响你二次销售。
- **破解方法**：**现场测试**。合作前发一小单（如10箱），故意挑出1箱有问题的，看他在2小时内是否响应、24小时内是否补货。如果他磨磨唧唧，多好的条款都是废纸。

### 7. 忽视“产地直采的伪承诺”
- **最容易忽视的点**：供应商说“我们是产地直采”，其实是从批发市场二道贩子拿货。
- **破解方法**：要求提供**产地收购凭证、冷链物流单号、海关/检疫证明（如进口水果）**。或者你直接去他的仓库看，如果仓库里同时堆着大量包装箱，说明他可能就是“倒包装”的，稳定性堪忧。

---

### 总结：长期合作的三条铁律
1. **写进合同比口头上“你放心”重要100倍**——损耗率、分级标准、温控记录、响应时效，全部白纸黑字。
2. **用数据代替感觉**——每次进货都记录：到货损耗率、实际可售卖天数、顾客退货率。三个月后对比，你自然知道哪个供应商“便宜但不划算”。
3. **保留一个“B计划”**——永远有第二个备用供应商，避免被一家卡脖子。

如果你已有一家固定供应商，不妨现在就去翻翻你们的合同和近三个月送货单，对照上面几点自查一下。
