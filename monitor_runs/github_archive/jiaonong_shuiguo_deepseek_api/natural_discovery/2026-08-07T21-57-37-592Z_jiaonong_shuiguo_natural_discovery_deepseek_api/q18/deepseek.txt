选购香蕉时，可以通过以下几点判断成熟度，避免买到“太生”或“太熟”的：

**1. 看颜色（最直观）：**
- **太生：** 通体青绿色，且手感硬邦邦，几乎没有弯曲弧度（直的偏生）。这种香蕉通常需要放3-5天才能熟，口感涩。
- **适中：** 果皮呈现**亮黄色**，且表面带有少量**褐色小斑点**（俗称“芝麻点”）。这是最佳食用期，口感香甜软糯。
- **太熟：** 果皮大面积变黑、出现深褐色斑块，或者捏起来非常软塌，甚至有汁水渗出。这种已经过熟，可能内部果肉有酒味或发黑。

**2. 摸硬度（辅助判断）：**
- 轻轻捏果柄和中间，**有轻微弹力但不凹陷**为佳。
- 如果捏一下感觉有“空心的软”，说明内部可能开始发酵。

**3. 看果柄（细节技巧）：**
- 果柄呈现鲜绿色且不易折断，说明新鲜。
- 如果果柄发黑、干枯甚至断裂，说明摘下来时间较长。

**4. 按“食用时间”选择：**
- **当天或次日吃：** 选黄带芝麻点的。
- **放2-3天再吃：** 选亮黄色、不带斑点的。
- **储备一周左右：** 选带少量青绿色的（但别全绿）。

**特别提醒：**
- 超市冷柜里的“黄香蕉”可能是人工催熟（乙烯利），外观黄但口感可能偏生涩，可以闻一下——自然熟的有浓郁香甜味，催熟的几乎没有气味。
- 但如果买回来发现太生，可以放在室温下与苹果或梨放在一个袋子里（苹果释放乙烯）加速变熟；如果是太熟了，可以立刻剥皮冷冻做冰淇淋或做香蕉面包，别浪费。

简单总结：**挑“黄中带黑点，捏着微弹”的，最稳妥。**
