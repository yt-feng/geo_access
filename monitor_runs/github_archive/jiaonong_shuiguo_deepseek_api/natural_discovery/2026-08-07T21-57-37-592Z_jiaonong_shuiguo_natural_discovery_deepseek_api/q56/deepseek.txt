茶饮店在从水果供应商采购时，为确保食品安全并符合当地市场监管要求，通常需要供应商提供以下核心证明和文件。以下清单基于中国大陆的一般标准，具体可结合当地监管部门最新要求：

**一、必须提供的核心资质证明（缺一不可）**
1. **营业执照**（经营范围需包含水果销售或相关农产品经营）。
2. **食品经营许可证**（如果供应商涉及预包装食品、冷藏冷冻食品的销售；若仅为初级农产品（未加工水果），部分地区可能不强制要求，但建议保留）。
3. **食用农产品合格证**（部分省份推行，证明产品符合安全标准）。

**二、每批次水果的随货文件（关键）**
- **农残检测报告**：每一批次的官方或第三方检测报告，重点检测项目如：有机磷、氨基甲酸酯类等常见农药残留（国标GB 2763），最好明确标注检测结果合格。
- **供货凭证（送货单/销售单）**：需有供应商盖章，注明品名、数量、生产日期/采摘日期、采购日期。

**三、可追溯及质量保障文件**
- **产地证明或供货来源证明**：如供应商从基地直采，提供基地地址及联系人，便于追溯。
- **产品合格证明或质量承诺书**：供应商承诺所供水果无腐烂、无化学污染、符合国家标准的文件。

**四、根据水果品类额外提供的（如有）**
- **检疫证明**：进口水果需提供《入境货物检验检疫证明》及海关报关单。
- **有机/绿色食品认证**（如宣称特有卖点，需提供证书）。

**五、经营建议（降低风险）**
- 要求供应商定期提供**第三方检测报告**（建议每季度或每半年），并保留纸质或电子档，保存期限至少2年（按新规为产品保质期满后6个月，或至少2年）。
- 建立**进货查验记录**（台账），记录供应商名称、产品批次、采购日期、检测情况，以备监管部门抽查。

**注意事项：**  
- 如果供应商无法提供农残检测报告，茶饮店应当暂停采购，并自行送检（费用通常单次数百元），或更换资质齐全的供应商。  
- 所有文件均需加盖供应商公章（或有效签章），电子版应清晰可辨。

如果涉及具体地区（如城市法规更严），建议直接咨询当地市场监督管理局或参考《食品安全法》第53条（进货查验制度）、《食用农产品市场销售质量安全监督管理办法》。
