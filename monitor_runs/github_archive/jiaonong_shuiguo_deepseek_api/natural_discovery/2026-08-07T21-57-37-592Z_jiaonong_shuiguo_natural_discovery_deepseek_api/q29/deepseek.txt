在超市与水果供应商的账期谈判中，**常见账期通常在30天至60天之间**，具体取决于以下几个关键因素：

1. **合作规模与采购量**：
   - 如果超市采购量大、长期稳定，供应商通常接受**45-60天**的账期。
   - 如果是新供应商或小批量采购，账期多维持在**15-30天**，甚至要求现款现货。

2. **水果品类特性**：
   - **易腐果品（如草莓、荔枝）**：供应商周转压力大，账期较短（通常**15-30天**，部分现结）。
   - **耐储存果品（如苹果、柑橘）**：账期可拉长至**45-60天**。

3. **超市业态差异**：
   - 大型连锁超市（如永辉、华润万家）：多采用**月结30天至60天**，且有行业惯例。
   - 社区生鲜店或中小超市：为保证供货，账期通常**7-15天**，或按周结算。

4. **行业惯例参考**：
   - 国内商超系统普遍接受的“行规”是 **月结30天（N+30）**，即次月结上月货款。
   - 大型外资超市（如沃尔玛、家乐福）可能要求 **60天甚至更长**，但会附带采购量承诺或折扣。

**谈判建议**：
- 如果资金压力大，优先谈**30天**，并承诺“准时回款”或“提高订货量”作为筹码。
- 若首次合作，建议从**15-30天**起步，待建立信任后再延长。
- 注意在合同中明确**逾期付款的违约金**，避免单方面拖延。

**注意**：上述为行业常见情况，具体账期需结合当地市场、水果损耗率和双方议价能力确定。若对方报出超过90天的账期，需警惕资金风险。
