针对长期合作的水果供应商，**建议优先谈“账期”**，其次是**配送**，最后是**售后**。

理由如下（按优先级排序）：

**1. 账期（最优先）**
- **核心原因**：这直接关系到你的**现金流安全**。水果是生鲜易腐品，损耗风险极高。如果货到即付（现结），一旦这批货出现质量问题或销路不畅，你将独自承担全部损失。谈下“账期”（如月结、铺底货），本质上是把部分经营风险转嫁给供应商，让你有缓冲期去销售和回款。
- **可行动建议**：首次合作争取“首批铺货、售完结账”或“月结30天”。即使谈不下来，也一定要约定“质量问题无条件退货，账期相应顺延”。

**2. 配送（次优先）**
- **核心原因**：水果的**新鲜度**和**破损率**完全取决于配送时效和包装。如果供应商配送不及时或包装简陋，到货损耗可能高达10%-20%，这部分损失最后往往是你自己买单。
- **可行动建议**：谈“配送时效承诺”（如下单后24小时内送达）和“到货破损包赔”（如破损率超过5%的部分由供应商承担）。这比售后条款更能直接减少你的即时损耗。

**3. 售后（最后谈）**
- **核心原因**：售后的“退换货”条款虽然重要，但执行起来往往依赖供应商的自觉和配合度。如果账期和配送谈妥了，即使售后处理拖沓，你也可以通过“暂缓支付当前账期货款”来施压。
- **注意**：售后条款不要只谈“退换”，要具体到“换货时效”（如48小时内补发）和“坏果比例超过多少全额退款”。

---

**最终策略建议**：
- **谈判顺序**：先用“长期合作量”作筹码，**先锁死账期**（这是企业的生命线），**再压配送损耗**（这是利润的漏点），**最后明确售后责任比例**（这是兜底）。
- **补充提示**：如果供应商在账期上分毫不让，建议立刻转向找备选供应商，因为生鲜行业的规矩本身就有赊销空间，完全不接受账期的供应商要么规模太小，要么风险控制过严，后续合作摩擦会很大。
