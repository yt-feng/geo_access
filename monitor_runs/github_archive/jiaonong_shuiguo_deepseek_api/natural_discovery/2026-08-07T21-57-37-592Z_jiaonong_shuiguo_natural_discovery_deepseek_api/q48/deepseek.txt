判断茶饮连锁的菠萝供应商是否能**稳定按规格送货**，不能只看口头承诺，需要建立一套**可量化的、有退出机制**的考核体系。以下是从实操角度给出的具体判断和执行建议：

### 1. 核心判断标准：从“试单”看“整年”
不要直接签年度大单。先要求供应商做 **3-5次“小批量试单”**（如每次100-200kg），并重点观察：
- **到货规格偏差率**：合同中约定单果重量（如1.2-1.5kg/个）、成熟度（如7-8成熟）、果型。试单时测量实际偏差，若偏差率超过5%（如小果、畸形果混入），直接淘汰。
- **准时率**：要求准时到货（如上午9：00前），统计试单期的准时率，低于95%风险极高（因为菠萝产地受天气影响大，准时率差的供应商旺季必断供）。

### 2. 关键背景核查：供应商的“分级能力”决定稳定性
菠萝是农产品，分级能力是核心门槛：
- **是否具备自有或合作的分选线**：要求提供分选设备照片/视频，或者要求现场抽查。若其只做统货（不分级），规格必然忽大忽小。
- **冷库与周转能力**：菠萝需在8-13℃冷链下周转。问清楚其是否有产地预冷库，以及到货后是否有缓冲库存。**采购合同必须写明“因供应商冷库失温导致的成熟度变化（如过熟发酸）由供应商承担”**。

### 3. 风险对冲：要求“产地+市场”双供货机制
- 核心问题：菠萝产区（如海南、广东）受台风、寒潮影响大，单一产地极易断供。
- **考核点**：问供应商能否承诺在海南果短缺时，切换至云南或菲律宾进口果（需符合检疫标准）？**能明确给出“备选产地切换时效”（如48小时内响应）的供应商，稳定性更强**。

### 4. 合同条款：违约金与“阶梯惩罚”
- 将稳定性写入合同：**“单次到货不合格（规格偏差>5%），该批次货款按7折结算；连续2次不合格，甲方有权单方解除合同并要求赔偿断货损失。”**
- **附加条款**：要求供应商为菠萝供应购买**农业保险或提供同等额度保证金**（如5-10万），防止其因价格波动（如产地涨价）恶意断供。

### 5. 现场审计：实地看“分装现场”和“装车记录”
- 在试单期，派人**随车跟单一次**，观察其装车时的挑选动作：是否现场逐筐过秤、剔除腐烂果？如果是“大桶倒货直接装车”，说明无分选习惯，规格必不稳定。
- 索要**最近3个月的装车出库记录**（包括车次、重量、客户类型），若其客户里已有3家以上连锁餐饮/茶饮品牌，说明其供应体系相对成熟。

### 6. 数据化追踪：建立“批次档案”
采购后，让供应商提供**每批次的“采摘日期+产地+糖度检测值”**。若连续3个批次的糖度波动超过1.5度（如14度-15.5度），说明其品控不稳定，应立即预警。

---

**最后决策建议：**
建议采取“**试单-核验-锁定**”三步法，将试单期定为45天（覆盖菠萝生长周期），期间若供应商能保持**准时率≥98%、规格合格率≥95%**，再签订年度框架协议，并保留30%采购份额给备选供应商（如产地直采或第二家），以形成竞争性压力。若上述任何一项核心指标未达标，果断更换供应商——**在水果供应链里，规格稳定的核心不是“承诺”，而是“分选能力+备选产地+违约成本”**。
