在超市采购水果时，为确保食品安全和合规，供应商通常需要提供以下检测报告和进货证明（具体以当地法规和超市采购标准为准）：

一、**必备的进货资质文件（证明来源合法）**
1. **营业执照**（有效期内，经营范围含水果销售/种植/批发）。
2. **食品经营许可证** 或 **食品生产许可证**（若涉及加工、分装）。
   - 种植户需提供种植基地备案证明或产地证明。
3. **进货凭证（销货单/送货单）**：需注明品种、数量、供货方名称、日期。
4. **食用农产品合格证**（农业农村部推行，标注产地、生产者及承诺）。

二、**核心检测报告（证明产品安全）**
1. **农药残留检测报告**（必查项）
   - 出具方：第三方检测机构（如SGS、华测、谱尼）或供应商自有实验室（需有资质）。
   - 覆盖项目：常见有机磷类、氨基甲酸酯类等禁用/限用农药（如甲胺磷、克百威等）。
   - 有效期：通常要求报告日期在采购前30-90天内（不同超市要求不一，进口水果需更严）。
2. **重金属及污染物检测报告**（如铅、镉、总砷、汞）。
3. **植物检疫证明**（针对跨省调运或进口水果）。
   - 国内跨省：需提供调运检疫合格证明。
   - 进口水果：需附海关《入境货物检验检疫证明》、原产地证书、报关单。

三、**按品类补充的报告**
- **有机/绿色认证水果**：需提供有机认证证书、绿色食品证书及年检记录。
- **国产精品水果**：部分超市要求提供产地土壤、灌溉水检测报告（尤其针对大棚种植）。
- **包装或预包装水果**：需提供生产日期、保质期标注的包装检验合格报告。

四、**超市内部要求（常被忽视）**
- **定期供货批次自检报告**：多数大型超市（如盒马、永辉）要求每批到货附“随车检测数据”（如农残快检结果）。
- **供应商资质审核表**：需填写供应商合同编号、基地备案号、运输冷链记录（若为易腐水果）。

**操作建议：**
1. **优先索取近3个月的第三方检测报告**（重点看检测项目是否覆盖《食品安全国家标准 食品中农药最大残留限量》GB 2763-2021）。
2. **核对报告真实性**：在报告中查找CMA/CNAS标志，并在中国检测认证机构官网（https://www.cnca.gov.cn）核验机构资质。
3. **针对进口水果**务必要求供应商提供中文标签和原产地证明（国海关总署网站可查准入名单）。
4. **保存所有文件复印件**（至少保存2年），以备市场监管部门检查。

如果供应商无法提供有效报告，超市应拒绝收货并保留书面记录，以防食品安全风险。不同地区或有额外要求，可咨询当地市场监管局或参阅《食品安全法》第53条（进货查验记录制度）。
