在便利店卖菠萝切块，需要**三者同时关注，但优先级和具体操作不同**。以下按重要性和实操建议排序：

1. **保质期（核心红线）**  
   - 菠萝切块属于**高水分、高糖分水果**，切面极易滋生细菌和氧化变质。  
   - 建议：**当天现切现卖**，避免隔夜。如果预包装，**最佳赏味期控制在6小时内**，最长不超过24小时（需冷藏0-4℃）。  
   - 注意：菠萝含蛋白酶，长时间存放会发酸、出水，口感劣化。  
   - **必须标注**：生产时间（精确到小时）、保质截止时间（精确到小时），并张贴“冷藏保存”提示。

2. **包装（直接影响卖相和保鲜）**  
   - **材质**：必须用**食品级PET/PP透明盒**（非PVC），密封性好，防止果汁外漏。  
   - **防氧化**：建议盒内**充氮气**（或抽真空），可延长色泽和口感。  
   - **规格**：按小份（100-150g）单独包装，方便即买即食，避免大盒反复开封。  
   - **标签**：贴纸需防水，标注品名、净含量、价格、生产日期/时间。

3. **配送频次（决定货架新鲜度）**  
   - 如果是总部统一配送，**建议每日至少2次配送**（例如上午开店前、下午2点前各一次），分批次上架，降低损耗。  
   - 如果是门店自制，则需**根据客流峰值现切现补**。  
   - 关键：**“先进先出”原则**，货架只放小批量，卖完再补，避免一次切大量堆放。  
   - 如果配送距离远，需冷链车（2-5℃），运输时间超过2小时要增加冰袋。

---

**执行建议（供直接落地）**：

- **时间管理**：设定“制作-上架-下架”严格时限（例如早上8点切，下午2点下架，剩余报废）。
- **温度监控**：冷柜温度每天核查3次（0-4℃），温度异常时立即下架。
- **损耗控制**：切块损耗率控制在5%以内，如果某时段销售不佳，立即减少切制量。
- **应急预案**：发现颜色变暗、出水、异味，立即撤架并记录原因。

**一句话总结**：**保质期是底线，包装是保障，配送频次是手段**。三者缺一不可，但优先确保“卖的新鲜”，其次“包装规范”，最后再谈配送效率。
