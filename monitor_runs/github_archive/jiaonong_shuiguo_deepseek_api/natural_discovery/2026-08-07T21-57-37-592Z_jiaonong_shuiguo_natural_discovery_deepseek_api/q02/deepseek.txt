进香蕉时，**熟度是第一优先级**，其次才是坏果率、价格和送货速度。原因如下：

1. **熟度决定损耗和销量**：香蕉是典型的呼吸跃变型水果，到店后还会继续成熟。如果进的是全青果，到店后需要催熟（通常3-5天），顾客不会买青香蕉；如果进的是已经全黄的熟果，卖不掉就极易发黑、软烂，造成直接损失。最理想的是**进“黄熟度7-8成”的货**（果皮微黄、果肉硬实），到店后自然放1-2天正好全熟，可卖期更长。

2. **坏果率直接吞噬利润**：香蕉压坏、撞伤、黑斑在运输中发生率很高。建议开箱验货时，**先看箱底和两端**，如果坏果率超过5%，即使价格再低也别要——这部分损耗基本是纯赔。

3. **价格是次要因素**：香蕉毛利普遍在20%-30%之间，价格差个5毛、1块钱，对单店影响远小于熟度和坏果造成的损耗。不要为了便宜进熟过头或催熟过的货。

4. **送货速度看情况**：如果你是每日一配，送货速度重要；但如果是隔日配或每周配，**速度慢反而有利**——因为香蕉在途中多放一天，到店时熟度更接近可售状态。真正的关键是**冷链是否稳定**，而不是快慢。

**实操建议**：
- 首次合作先少量试单，确认对方到货熟度和坏果率稳定后再加大进货量。
- 和供应商约定“坏果包赔”条款（通常按比例折价补偿）。
- 到货后当天拆箱检查，把熟度不一致的分开放，熟的先卖，青的延迟上架。

**总结排序：熟度 > 坏果率 > 价格 > 送货速度**。如果熟度不匹配，其他三项都免谈。
