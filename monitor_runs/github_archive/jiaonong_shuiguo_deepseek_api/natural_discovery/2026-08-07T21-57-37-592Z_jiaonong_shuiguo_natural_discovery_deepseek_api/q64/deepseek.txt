在批发档口，退货纠纷的核心原因通常是 **“质量/数量问题”** 与 **“双方预期不一致”**。做好收货验货，关键不在于“验得多严”，而在于 **“标准提前说清，过程留痕可查”**。

以下是实操性极强的收货验货执行方案，分三步走：

### 第一步：发货前（比收货更重要）—— 建立“可视”标准
很多纠纷是收货时才发现，但根子在发货时。这一步能降低60%的纠纷。

1.  **“一物一照”留底**：
    *   在打包前，对每一批货或每一个独立包装（特别是爆款、易碎品、颜色多变的款）拍一段**10秒内的小视频**，环绕一圈展示外观、数量、瑕疵点（如有）。
    *   对于混批的货，在单据上写明“已抽检”，并拍照装袋后的状态。
2.  **“开单三写”**：
    *   在送货单/发货单上明确写清三件事：**① 数量（大写+小写）**；**② 对色差/瑕疵的备注**（如“深色面料有轻微色差属正常”）；**③ 退换货时效**（如“签收后48小时内反馈”）。
    *   让收货方在单据上签字，或发货前拍照发给对方确认。**这一步是后续扯皮的底气。**

### 第二步：到货验货 —— 执行“两查两对”
建议形成固定流程，不要凭感觉。

1.  **查外包装（当场）**：
    *   物流卸货时，**先看外箱是否破损、湿水、变形**。若有，**务必当着快递员/司机面拆箱拍照**，并让司机在物流单上签字确认“外包装破损”，这是向物流索赔的依据。
2.  **查内货（按标准）**：
    *   **清点大数**：逐箱核对件数是否与发货单一致。
    *   **抽检与全检结合**：
        *   **单款单色货**：建议**每箱抽3-5件**查看做工、色差、码数标。
        *   **散货/混码**：建议**只验码数准确性和件数**，面料细节问题可反馈，但别指望掉包。
    *   **重点看“敏感部位”**：拉链、刺绣、印花、口袋缝线——这是零售客户最爱退货的地方。
3.  **对码数（最易出错）**：用店内的码数表（或凭经验）核对吊牌码与实际尺码是否一致，混码是批发纠纷最常见的原因。

### 第三步：争议处理 —— 执行“四小时反馈”规则
这是降低纠纷升级的核心操作。

1.  **建立“收货异议期”**：在发货前就告知对方，**“收到货后4小时内（或当天）反馈数量/破损问题，超时视为无误”**。这不是霸王条款，是行业惯例，写在单据上即可。
2.  **“先补后查”原则**：如果客户说少货或破包，**只要拍照清晰、金额不大（如百元内），优先直接补发或退款**，不要先要求对方寄回，否则来回运费和扯皮成本更高。
3.  **瑕疵标准“提前量化”**：在群里或朋友圈发布“验货基准”，例如：
    *   “肉眼在30cm内看不出明显污渍算合格”
    *   “线头、轻微褶皱、里衬小瑕疵不属于退货范围”
    *   “色差以自然光下实物为准，屏幕显示不作为依据”

### 特别关键点（针对档口）：
*   **千万别口头承诺“好的”**。任何关于质量的承诺，**必须落在微信聊天记录或单据上**。比如客户问：“这是纯棉吗？”你回答“是”之前，最好确认面料成分报告，否则容易构成虚假宣传纠纷。
*   **保留“剪版样”**：对于长期返单的款，留一块布样。如果对方说“这批颜色浅了”，你拿出样布对比，一眼就能判定是真问题还是客户找茬。

**执行要点总结**：
1.  发货前拍照拍视频，写清“确认收货后48小时内验货反馈”。
2.  收货时先看外箱，再抽检关键部位，数清件数。
3.  反馈异议必须**有图、有空运单号（如有）、在约定时间内**，否则不予处理。

**最后一句建议**：如果档口生意大，可以考虑**在档口设置一个“验货台”**，提供放大镜和卷尺，让客户当场验货。这既是服务，也是将“验货责任”前置到发货前，能极大减少事后扯皮。
