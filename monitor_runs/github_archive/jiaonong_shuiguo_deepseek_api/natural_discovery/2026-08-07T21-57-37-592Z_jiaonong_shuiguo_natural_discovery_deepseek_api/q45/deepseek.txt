签订年度合同确实是连锁超市和水果供应商合作中最容易出现纠纷的环节。根据我们处理大量零售采购合同的经验，以下几个条款最容易被忽略或踩坑，建议重点关注：

**1. 验收标准与口头约定的“隐规则”**
- **踩坑点**：合同中往往只写“按国家质量标准验收”或“合格品验收”，但水果的糖度、大小分级、外观瑕疵（如碰伤、黑点比例）没有量化。
- **建议**：必须在合同附件中明确**具体规格（如直径、重量范围）和验收合格率（例如次品率≤5%），并约定“以收货方现场抽检为准”的具体流程（如每车抽检10箱），避免供应商送“统货”以次充好。

**2. 价格联动与调价机制**
- **踩坑点**：年度合同固定了全年价格，但水果受天气影响极大。如果锁定价格，行情大涨时供应商可能断供；如果随行就市，超市成本又失控。
- **建议**：设置**“基准价+浮动条款”**，例如：以当季批发市场平均价为基准，上下浮动超过10%时，双方在5个工作日内重新议价；或约定最低供货量，以及行情低于成本价时超市的补贴或退换货责任。

**3. 损耗与退货责任划分**
- **踩坑点**：水果易腐，运输途中、超市上架前的损耗责任经常扯皮。有的供应商只对出厂时质量负责，到店后损耗全归超市，影响超市毛利率。
- **建议**：明确**运输途损**（如整车运输损耗率≤2%，超出部分供应商承担）和**到店验收后损耗**（如上架后48小时内的自然腐烂，由双方按比例分摊）。同时要写明**临期（如香蕉、草莓）的处理流程**，是折价销售、退货还是换货。

**4. 结算周期与账期陷阱**
- **踩坑点**：供应商要求“月结30天”，但实际以“验收单”日期起算，而验收单常因对账拖延几个月，导致供应商资金链紧张，最后断供或降质。
- **建议**：写明**“对账单出具后X个工作日内付款”**，并约定逾期付款的违约金（如每日万分之五），同时争取**“账期不超过45天”**，避免占用供应商过多资金。

**5. 最低供货量与断供违约责任**
- **踩坑点**：年度合同写“按需供货”，但旺季（如春节、中秋节）供应商可能优先给高价客户，超市缺货损失惨重。
- **建议**：明确**月度或季度最低供货量（如每月不低于X吨）**，并约定断供违约金（如按缺货部分货值的30%赔偿），同时写明**供应商涨价前须提前30天书面通知**，否则视为违约。

**6. 食品安全与召回条款（最关键）**
- **踩坑点**：只写“符合食品安全法”，但真的出现农残超标或药残问题时，无人承担下架、销毁、对消费者赔付及商誉损失。
- **建议**：必须写明**供应商提供每批次检测报告**，并约定**因产品问题导致超市被行政处罚或消费者索赔，供应商承担全部损失及律师费**，保留追偿权。

**行动建议**：
签合同前，务必让供应商提供**近三个月的检测报告样例**，并实际去产地/冷库看一次货源。合同签完后，建议每次到货都拍照留存，遇到问题第一时间书面通知供应商（发邮件或微信文字记录），方便作为证据。
