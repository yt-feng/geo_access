针对家庭水果礼盒，既要考虑**营养搭配**，又要考虑**存放耐放**，还要照顾**不同年龄层**（老人、孩子、孕妇等）。基于这四种水果，我给出三个不同侧重的组合方案，你可以根据预算和客户需求任选：

### 方案一：经典实惠型（主打耐放、高性价比）
**组合：苹果（60%） + 橙子（40%）**
- **理由**：这两种是水果礼盒的“压舱石”，价格稳定，磕碰率低，运输损耗小。苹果寓意“平安”，橙子寓意“心想事成”，家庭送礼送这个基本不会出错。
- **适用场景**：走亲访友、单位福利、大众家庭消费。
- **硬性提醒**：**不要放香蕉**，香蕉太娇贵，装箱易压烂，且催熟其他水果，导致苹果和橙子变味。

---

### 方案二：营养丰富型（主打维生素与膳食纤维）
**组合：橙子（40%） + 苹果（30%） + 菠萝（20%） + 香蕉（10%）**
- **理由**：橙子补维C，苹果补果胶，菠萝含有菠萝蛋白酶助消化（对老人肠胃友好），香蕉补钾且含色氨酸助眠。
- **关键操作**：
  - 香蕉**单独用硬纸包住果柄**，装在礼盒顶部隔层里，防止压伤。
  - 未熟的菠萝**不要削皮**，带皮整颗放入，客户回家自己削。
  - **注意**：香蕉和菠萝都会释放乙烯，会加速苹果褐变，所以这个组合建议**只做当日配送或同城闪送**，不适合常温存放超过2天。
- **适用场景**：家庭聚会、探病（需确认对方无糖尿病、无菠萝过敏史）。

---

### 方案三：精致健康型（主打控糖、低GI）
**组合：苹果（50%） + 橙子（30%） + 菠萝（20%）**，**绝不加香蕉**
- **理由**：香蕉升糖指数（GI）较高（约52，但熟透的更高），若有老人高血糖或减重需求，香蕉不适合。菠萝GI约66，但纤维丰富，适量可。苹果和橙子GI较低，全家都能吃。
- **包装建议**：菠萝可切成去皮的菠萝块（盐水浸泡后真空封装），放冰块袋，但价格会高，适合高端家庭客户。

---

### ⚠️ 必须提醒你的几个“坑”（很重要）：
1. **香蕉是“坑王”**：除非你承诺当天必须吃完，否则别进礼盒。家里没人一顿吃3根香蕉，放2天就发黑。
2. **菠萝别放最底部**：菠萝底部有尖刺，会扎破包装纸，且自重压坏下面的苹果，建议**用独立泡沫网套住菠萝底部**，或放在顶层。
3. **苹果必须单独隔开**：苹果释放乙烯会催熟橙子，让橙子变干。最好每个苹果垫一层珍珠棉隔断，否则客户打开盒子全是软塌塌的橙子。
4. **按重量售卖**：如果是线上团购，别写“苹果4个、橙子4个”，要写“净重X斤（约X个）”，因为家庭客户更关心够不够吃，而不是数量。

### 我的最终推荐（最稳妥的“万能公式”）
**推荐方案二（经典+营养混合版）**：
- 3个苹果 + 3个橙子 + 1个大菠萝（去蒂留皮） + 2根香蕉（独立小包装注明“先吃我”）
- 礼盒内附一张手写小卡：**“菠萝和香蕉请尽快食用，苹果橙子可冷藏保存7天。”**
- 这样做既显丰盛，又让客户觉得你专业、贴心，复购率会高。
