做附近小区团购，水果供应商的支持服务直接决定你的利润和口碑。核心原则是：**你要卖得走量、损耗低、配送及时，供应商必须能帮你扛住这些风险。**

根据你的场景，建议优先确认供应商以下6项服务：

---

### 1. 门槛低，支持“小批量、高频次”采购
- **不需要整箱囤货**：水果易损耗，团购单量可能每天只有20-50单，必须能按“份”或“小筐”拿货。
- **支持二次补货**：当天卖爆了，能否当天下午再送一次？或者次日一早送到？这是最基础的要求。

### 2. 可定制“团购装”规格
- 能按你的需求分装成**家庭装（3-5斤）**或**尝鲜装（1-2斤）**，而不是只给大箱。
- 最好能**代贴团购标签**（比如写袋子上“XX小区”），方便你分发时区分。

### 3. 账期和后付费支持
- 如果是新合作，尽量争取**“先货后款”或“压一付一”**（比如本月1号结上月货款），避免你压资金。
- 供应商支持**“临期或轻微磕碰果”退货或换货**，这比降价更实用。

### 4. 送货到小区或附近站点
- 必须支持**免费配送到你门店或指定小区物业/快递柜**，不要只送到批发市场门口。
- 最好固定**每日送货时间**（比如早上6-7点），确保你群内下午开团、晚上到货的节奏。

### 5. 提供“今日价”和行情提醒
- 每天给你**保底价和推荐零售价**，甚至帮你算出毛利率。
- 如果能**提前一天预告次日到货品种和价格**，你就能在群里预告预售。

### 6. 信任背书和品控承诺
- 要有**“坏果包赔”**承诺（比如签收后24小时内，坏果按个数赔钱或补发）。
- 能提供**产地证明或检疫报告**（如果需要向群里宣传“原产地直发”）。
