在甜品店的菠萝采购与处理中，**鲜果切配的损耗通常更低，但前提是门店的用量稳定且管理规范**。直接买成品果丁虽然省人工，但其损耗主要体现在“购买时的高溢价”和“被动接受的杂质”上。

以下是详细的对比分析：

**1. 鲜果切配（自采整果）：**
- **原料损耗率**：菠萝去皮去芯后，可食用部分通常为**55%-65%**（视菠萝品种和成熟度，如都乐金菠萝出肉率较高）。
- **劣势**：需要冷库或冷藏柜存储，且菠萝是后熟型水果，存放不当容易腐烂（损耗会从5%飙升到15%以上）。
- **关键优势**：你**只用果肉**，菠萝芯（粗纤维、口感差）和果皮可分离。如果甜品店做菠萝汁、菠萝酱，**连菠萝芯都可以打碎利用**，此时综合损耗率极低（仅剩果皮约30%）。
- **成本可控性**：可根据当日销量精确采购，买多了可以做成冷冻果泥，不会浪费。

**2. 直接买成品果丁（预切菠萝）：**
- **表面损耗低**：无皮无芯，几乎零浪费。
- **隐性损耗极高**：
  - **价格溢价**：预切果丁单价通常是整果的**1.5-2倍**（因为含了切配人工、包装、冷链运输费）。
  - **重量水分流失**：预切果丁在运送和储存中会出水，出餐前需沥水，实际可食重量比标注重量少约5%-8%。
  - **保质期风险**：切开的菠萝极易氧化变质（变色、发酸），通常只有24-48小时的货架期，一旦卖不完损耗是100%（直接报废）。
- **品质不可控**：无法确认供应商是否使用了成熟度不佳的菠萝，或浸泡了保鲜剂（影响口感）。

---

**结论与实操建议：**

- **如果门店日销量<3个整菠萝**：买**成品果丁**更划算（算上人工和废料处理，亏损更小）。
- **如果门店日销量≥5个整菠萝**：**自己切更优**，损耗比约在10%（生鲜损耗）+人工，但远低于成品果丁的溢价差。
- **折中方案（最优解）**：采购整果，自己切，但**将果皮和果芯做成菠萝蜜饯、菠萝干或熬成糖水**，这样损耗几乎为零。

**注意**：必须确认当地菠萝的进货单价。若整果进货价 > 成品果丁单价×1.7，则直接买成品果丁反而经济。建议用“**出果肉成本 = 整果单价 ÷ 0.6**”来对比判断。
