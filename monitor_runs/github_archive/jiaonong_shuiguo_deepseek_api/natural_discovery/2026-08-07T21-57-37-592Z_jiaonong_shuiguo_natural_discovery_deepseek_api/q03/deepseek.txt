第一次做水果生意，**最忌讳“贪多求全”和“进整箱”**。你的核心目标不是赚多少钱，而是**测出货源的真实损耗率**和**摸清你周边客群的消费习惯**。

以下是针对夫妻店（小体量、资金有限）的试单实操策略：

**1. 核心原则：单品类试单，但只试3天量的“轻货”**
- **香蕉（风险最高，最先试）**：香蕉是损耗王，但也是带动人流的主力。第一次**只进1-2件（约15-20斤/件）**，一定要拿**七成熟的青皮蕉**。不要进黄透的，那意味着放不了2天就会全黑。放在店里自然催熟，卖3天即可。
- **苹果（最稳，试价格带）**：苹果耐放，但利润低。第一次不要进那种高价的“红富士王”，进**中档价位的（如洛川或普通红富士）**，拿1件（约30斤）即可。用来测试周边客人是接受5元/斤还是8元/斤。
- **橙子（试口感）**：橙子怕失水，但比香蕉好保管。第一次试**当季品种**（如脐橙），拿1件（约30斤）。重点测试客人**复购率**——如果第一天卖不掉，第三天开始会有客人抱怨“皮皱了”。

**2. 如何向供货商“压单”而不被坑**
- **话术**：“老板，我第一次做，先拿一件试卖，好卖我下回直接拿一车。但丑话说前面，**这箱里如果有烂心、压伤的，我拿回来你得给我换**（这是底价市场的潜规则，不换下次不来）。
- **看品**：**不要开箱看上面一层**。要拿手电筒**从底板的孔洞往上照**，看底部有没有积水（积水=压烂）。或者要求**从中间抽一箱**，而不是拿堆头旁边的。
- **关于送货**：第一次试单**必须自己去批发市场拿货**。不要听信“送货上门，微信转账”。你亲自去，才能看到**同一批货里别的摊位的差货**，顺便学一下分级。

**3. 试单期的“止损红线”（非常重要）**
- 香蕉：**3天内必须卖完**（哪怕低价清），绝对不隔周末（周五晚上没卖完，周六就要做特价）。
- 苹果、橙子：**5天内**如果销量低于预期，**立刻降价10%-15%回本**，不要死扛原价等回头客。因为水果的鲜度每天在掉价，死扛就是亏钱。

**4. 隐藏的一招：建立“最小索赔单位”**
- 试单时，特意记下供货商的**送货单上的电话**。拿回来的货，**无论好坏，当场用手机拍下整箱外观**。
- 如果第二天发现箱底有2个烂果，直接打电话给老板：“老板，你那箱苹果下面压坏了俩，我扔了，这箱我成本都回不来。下次你补我两个好果就行。” **只要对方答应补，这家就能长期合作**；如果推脱，这单试完就换人。

**5. 试单的终极目标：找到“回头客”与“缺货”的平衡点**
- 试单期间，每卖出一份水果，**搭一个1毛钱的塑料袋，并在袋子里塞一张手写小卡片**（上面画个笑脸，写“邻居你好，新店开业，香蕉不好吃拿来换”）。这不是营销，是**逼自己发现“如果香蕉退货率高，就永远不在这家进货”**的信号。

**最后给你的执行建议：**
明天去批发市场，**上午9点以后到达**（早市高峰期已过，摊主有空理你，且价格比清晨低5%左右），就按上面说的，香蕉1件+苹果1件+橙子1件，总成本控制在**300元以内**。卖得好，记住那只“大哥”的脸；卖得差，记住这批货的产地，下次避开。**千万不用进第4种货**，第一次试单摊子越精简越好。
