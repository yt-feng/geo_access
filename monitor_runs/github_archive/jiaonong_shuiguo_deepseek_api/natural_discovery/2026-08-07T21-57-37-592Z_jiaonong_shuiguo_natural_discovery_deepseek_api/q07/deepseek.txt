水果礼盒的搭配，核心是**色彩好看、寓意吉祥、避免压坏**。以下给你几套直接可用的搭配方案和实操建议：

---

**一、经典“讨喜”搭配（送礼/节日）**

- **组合**：红富士苹果（6个）+ 赣南脐橙（6个）+ 香蕉（1把）+ 菠萝（1个）
- **理由**：  
  - 苹果（平安）、橙子（心想事成/橙意满满）、菠萝（旺来，闽南话谐音），香蕉取“相交”之意，寓意四海皆朋友。  
  - 红、橙、黄三种亮色配上菠萝的绿色顶叶，视觉冲击力强，节日感足。

**二、精致“轻享”搭配（闺蜜/下午茶）**

- **组合**：青苹果（3个）+ 红肉火龙果（1个）+ 脐橙（2个）+ 小台芒（2个）
- **理由**：  
  - 青红白黄四色层次分明，颜值高。  
  - 去掉香蕉和菠萝这类“大块头”，更显档次，单价也更高。

**三、经济实惠“日常走量”搭配**

- **组合**：普通红富士（4个）+ 当季柑橘（6个）+ 香蕉（1把）+ 菠萝（半个，切块装盒）
- **理由**：  
  - 成本最低，适合走量。菠萝切块后单独用透明盒装，避免汁液污染其他水果，也方便顾客直接吃。

---

**关键操作建议（避免踩雷）：**

1. **苹果和橙子永远打底**：这两种最耐放、不压坏、颜色也稳，放底层重量支撑。菠萝放上层（它是“刺头”，不能压）。香蕉放最上侧，且盒盖要留出拱形空间，不然半天就压出黑斑。

2. **按果径选品**：苹果、橙子全部挑**5-6两/个**的“大果”，小果放进礼盒会被嫌弃“不够斤两”。菠萝挑**叶子翠绿、底部带酸香**的，不要选发软的。

3. **搭配“爆款引流款”**：如果店里主推高价车厘子或蓝莓，可以在礼盒面上放一小盒（比如蓝莓125g），既提升整体档次，又能拉高客单价。

4. **标签和卡片**：在礼盒侧边贴上手写卡——“平平安安”、“橙心如意”、“财源旺来”。成本不到1元，但顾客觉得“专门定制了”，复购率会涨。

---

**最简单上手法**：  
先做两套试卖——**68元档（苹果+橙子+香蕉）** 和 **88元档（苹果+橙子+香蕉+菠萝）**，看本地顾客选哪个多，再根据反馈调整。不要同时上太多组合，顾客会选花眼。
