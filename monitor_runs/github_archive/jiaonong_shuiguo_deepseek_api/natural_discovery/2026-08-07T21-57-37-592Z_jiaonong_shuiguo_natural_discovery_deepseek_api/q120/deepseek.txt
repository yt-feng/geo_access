当供应商面对只熟悉大品类的普通商家时，核心原则是**“把专业术语翻译成生意语言”**，围绕商家的**利润、周转、损耗和客户口碑**来介绍。

以下是具体的沟通话术和策略，按“开场-展示-算账-促单”四个步骤展开：

### 1. 开场：用“你熟悉的 + 一个差异点”破冰
不要上来就报产地和品种编号，而是先建立关联。
- **错误示范**：“这是我们基地的A级金枕榴莲，干尧嫁接苗，树龄15年，甜度36%。”
- **正确示范**：“老板，您平时卖得最好的香蕉是什么？我们这款是‘香蕉里的爱马仕’，卖相好、耐放，摆店里特别吸引回头客。”

**要点**：先承认他懂的大品类，把自己的产品定位成“大品类里升级款”或“大品类里性价比款”。

### 2. 展示：用“生活化比喻”替代专业名词
供应商常犯的错误是讲“果径”“糖度仪数值”“冷库预冷时间”，商家听不懂。
- **要说**：“这个果子**拿在手里沉甸甸的**，说明水分足。”
- **要说**：“这个菠萝**削皮后芯很小**，客人买回去切盘，满满一盘都是肉，不会骂你坑人。”
- **要说**：“这个香蕉**在店里能多放3-4天不黑**，意味着你损耗少，卖不完也能慢慢卖。”

**核心比喻表**：

| 专业术语 | 商家听得懂的翻译 |
| :--- | :--- |
| 果径/单果重 | “**一箱大概多少个**，单个拿手里有多大**（用手机或拳头比划）**” |
| 糖度（Brix） | “**甜得跟喝糖水一样**，还是那种**带着果香的清甜**” |
| 冷链运输 | “**到货是冰的**，你放常温半天就能卖，**不容易烂**” |
| 品种编号（如MD2） | “这是**全球都在卖的网红款**，就像手机里的苹果手机，**顾客指名要这个**” |

### 3. 算账：帮他把“进货价”算成“赚多少钱”
普通商家最关心的是**综合利润**，而不是单品价格。你要给他算三笔账：
- **损耗账**：拿香蕉举例。
  - “我家香蕉虽然贵5毛一斤，但**损耗率只有3%**。你在批发市场拿的普通蕉，到家可能断两把、黑几个，损耗就到8%了。**算上扔掉的，其实我比你便宜。**”
- **周转账**：拿菠萝举例。
  - “这个菠萝**表皮金黄，拿到手就能直接卖**，不用像青皮那样放几天催熟。**你今天拿货，今天就能卖钱**，资金回笼快。”
- **复购账**：
  - “这果子的**香味特别冲**，你切开试吃，客人在店门口都能闻到。**他吃完这次，下次还会来问你这个**，你就不用担心压货。”

### 4. 促单：用“风险逆转”降低下单门槛
商家怕进错货，所以你要给**尝试的台阶**。
- **给最小起订量**：“您先拿一件试试，就一件货，卖不动算我的，卖得动咱们再谈长期价。”
- **给售后承诺**：“我跟您说清楚，**如果出现黑心、烂心，拍照给我，我直接补货**，不让您亏一分钱。”
- **给对比方案**：“您可以先别买我的，去隔壁拿货，然后**两边各放一根在店里**，明天你摸摸谁软得快、看看谁颜色亮。您自己做决定。”

---

### 一句话总结（给供应商的万能公式）
**先用他懂的（香蕉/菠萝）打招呼，再用他痛的（损耗/卖相）说效果，最后用他赚的（利润/复购）算账，结尾给他退路（试单/包赔）。**

例如：
> “老板，你看这个菠萝，**比你那个青皮的要黄**（视觉对比），你**拿货回去不用等**，直接上架就能卖（省时间）。关键**我算过你卖这个，每箱能比普通的多赚20块**，因为客人觉得这个品相高级愿意多花钱（算利润）。**你先拿半箱试试，坏了我包赔**（给台阶）。”
