社区超市进水果，控制新鲜度和库存的核心在于**“小批量、多频次”**和**“动态分级管理”**。以下是具体可落地的执行方案：

### 一、 进货端：源头控鲜

1.  **按需定品，少而全**：不要贪多。选择**3-4种走量快的常规款**（如苹果、香蕉、梨）+ **2-3种应季款** + **1种引流款**（特价高损耗品）。
2.  **根据天气和周边人流定货**：周一人少，周三/周末人多；下雨天减少绿叶菜和草莓等娇贵品。
3.  **签“保底”协议**：与供应商约定，如果部分水果因品质问题滞销，可协商**退货或换货**，尤其是大件（整箱）。
4.  **少拿货，多续货**：如果距离批发市场近，最好**一天一进**或**两天一进**。如果偏远，建议只进平时销量的70%。

### 二、 店内端：货架寿命管理

1.  **“先进先出”双堆法**：新货上架，旧货必须**摆在最前面**，醒目标注“今日特价/当天必清”。
2.  **分级销售策略**：
    -   **卖相极好**：正常价，摆陈列中央。
    -   **略有瑕疵**：放最外层，贴“特价处理/现切果盒”，**在当天下午4点前必须出清**。
    -   **熟透/软塌**：立即做成果切或榨汁，或封在保鲜盒里买一送一。
3.  **按“生命周期”摆放**：香蕉、芒果等释放乙烯的（会催熟其他水果），尽量**单独放置**，不要和绿叶菜或草莓堆一起。

### 三、 库存端：数据盯防

1.  **建立“日盯”台账**：每天打烊前，记录三类数据：
    -   今日进货量
    -   今日销量
    -   盘点损耗（坏掉扔了多少）
2.  **设定“红线警戒”**：
    -   当某品销量连续2天下降10%，立即**停止补货**。
    -   当库存可售天数**超过2天**（如苹果能放7天，若积压3天库存），自动转为**促销品**。
3.  **“三三制”库存法**：货架区（显眼位置）放1/3，冷藏保鲜柜放1/3（随时补货），后台周转区（库房）**坚决不压货**，只留当日进明日销的量。

### 四、 促销端：快进快出

1.  **“每日一鲜”**：每天选一种临期水果，早上开门就挂“今日特价”，制造抢购氛围。
2.  **“组合打包”**：把卖相不好的跟卖相好的打包成“家庭装”（如5元一袋），减少零散损耗。
3.  **“下午5点清仓法则”**：下班高峰期前，对当日未售完的易腐水果（草莓、杨梅、车厘子）直接**降价30%-50%**，宁可亏本卖，不可存过夜。

### 五、 核心公式（防压货）

**单品种进货量 = （昨日销量 × 1.1浮动力） - （昨日剩余库存）**

-   如果今日卖10斤，剩5斤，明天只进 11 - 5 = 6斤。
-   **宁缺毋滥**：缺货只损失利润，积货则损失本金。卖断货叫机会损失，剩一筐烂果叫直接亏损。

**最后关键提醒**：水果生意的利润=**销售价 - 进货价 - 损耗成本**。控制损耗比提高售价更重要。如果连续3天某种水果损耗超过20%，果断砍掉该品种，不要再抱侥幸心理。

如果条件允许，建议配置一个小型**保鲜柜**，并保持温度在4-8℃，这是降低损耗最有效的物理手段。
