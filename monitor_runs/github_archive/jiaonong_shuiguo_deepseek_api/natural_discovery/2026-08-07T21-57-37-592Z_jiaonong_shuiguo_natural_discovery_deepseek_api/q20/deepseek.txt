为社区超市挑选每日配送的水果供应商，建议从以下几个核心维度考察，确保稳定、新鲜且成本可控：

**1. 供货能力与稳定性（最关键）**
- **日供量保障**：明确供应商每日可稳定供应的水果品种和总重量，防止旺季断供、淡季积压。
- **应急补货能力**：若遇店内热卖缺货或临时活动，能否当日或次日补送？
- **产地直采或一手货源**：优先选择有基地、产地直采或与批发市场长期合作的供应商，中间环节越少，价格和新鲜度越有保障。

**2. 新鲜度与损耗控制**
- **配送时间**：能否保证清晨或固定时间段送达，确保水果在货架期（如叶菜类、草莓等）内销售。
- **冷链与包装**：是否使用冷链车或保温箱？包装是否防挤压（如葡萄、樱桃）？
- **损耗责任划分**：到货后开箱验收，若发现烂果、压伤，供应商是否承担退换或补偿？一般正常损耗率应控制在5%以内。

**3. 品质与品类匹配**
- **品种结构**：是否覆盖社区常需的苹果、香蕉、橙子、西瓜等基础款，以及应季爆款？能否提供少量高端、进口水果试销？
- **分级标准**：是否明确（如一级果/二级果）？确保与超市定价匹配，避免以次充好。

**4. 价格与结算方式**
- **每日报价机制**：是否提供当日市场价格（如每日早上发报价单），且价格是否与批发市场波动挂钩？
- **账期与起送量**：是否接受先供货后结算（周结/月结）？单次起送金额或箱数是否合理（避免强行捆绑大货量）？

**5. 服务与售后**
- **退换货政策**：当日未能售出的易腐水果（如榴莲、山竹）能否无条件退货？部分供应商会允许“卖不完退回”。
- **驻点或专属对接人**：是否有固定业务员对接，响应速度如何？能否根据销售数据调整下周订单？

**6. 合规与资质**
- **证照齐全**：要求提供《食品经营许可证》、营业执照，以及水果产地的检验检疫证明（尤其进口水果需海关单）。
- **食品安全责任险**：部分大型供应商会有保险，能减少意外食安风险。

**实操建议：**
- **先试合作**：首次合作可只下3-5天的最小订单量，考察送货准时率、品质和损耗。
- **对比2-3家**：同时找农贸市场批发档口、本地农场直供、产地代办三方报价，用批发市场当日均价作为基准砍价。
- **签订简易合同**：明确最低日供量、价格调整规则（如涨价需提前半天通知）、退换货时限，避免口头承诺。

若你在本地具体寻找，可优先咨询周边大型蔬菜水果批发市场（如本地农产品物流园），询问其“配送商户”中的日供商，这类渠道通常价格透明且量大稳定。
