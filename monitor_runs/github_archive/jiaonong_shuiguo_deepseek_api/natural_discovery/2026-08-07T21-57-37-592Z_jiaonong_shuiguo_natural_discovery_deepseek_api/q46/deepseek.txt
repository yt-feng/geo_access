针对茶饮店做果茶的需求，**建议优先考虑果丁，其次果泥，鲜果作为补充或门店形象展示**。原因如下：

**1. 果丁（罐头果丁/冷冻果丁）—— 最推荐**
- **优势**：出杯快、稳定。果丁颗粒感强，能明显提升果茶的“料感”，拍照好看；成本可控，损耗极低（无需清洗、去皮、去芯），且保质期长。
- **适用场景**：做经典菠萝果茶、水果茶基底、加料杯。
- **注意**：优先选**冷冻果丁**（水分保留好），尽量避开糖水浸泡的罐头（甜度过高、有罐头味）；如果选糖水罐头，需注意洗去糖水或调整糖浆比例。

**2. 果泥（冷冻果泥/浓缩果浆）—— 做风味底**
- **优势**：出味快、风味统一，特别适合做**菠萝气泡水、菠萝冰沙、或与茶底融合度高的奶盖果茶**。省去鲜果预处理时间，适合高峰期出餐。
- **劣势**：如果只用果泥，果肉感不足，消费者会觉得“添加剂味重”。
- **建议**：**果泥+果丁**组合使用，用果泥打底提供酸甜感，用果丁增加咀嚼感——这是目前连锁茶饮店的常见做法。

**3. 鲜果（鲜菠萝）—— 补充与溢价**
- **优势**：新鲜度高，可做“现切鲜果”展示，提升门店品质感和客单价值；果香更自然。
- **劣势**：损耗大（去皮、去芯损耗约40%-50%），切配耗时，且菠萝的**酶和氧化**问题容易导致成品分层或苦涩，需要严格的盐水浸泡和当日现用。
- **建议**：如果门店客流量大且人手充足，可在**高峰前批量预加工**，但仅建议用于招牌款，不要全菜单覆盖，否则后台负担过重。

**最终采购决策参考（按你的门店情况）：**

| 你的情况 | 推荐方案 |
|---------|---------|
| 门店注重出杯速度、想控制人力 | 冷冻果丁+风味果泥（组合） |
| 预算有限、想突出果肉感 | 糖水菠萝丁（需降糖）+平价果肉 |
| 主打高端现切、走体验感 | 鲜果（仅做1-2款明星单品）+果丁兜底 |

**额外提醒：**
- 选供应商时，要问清**“果肉占比”**（果丁的果肉含量通常≥70%为佳）和**“甜度Brix值”**（果泥一般25-30°Brix适合配茶）。
- 如果店里有**制冰机和SOP体系**，推荐每年**夏季前囤货冷冻果丁**，价格更低且稳定。
