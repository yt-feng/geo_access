判断水果批发商（尤其是香蕉这类易腐品）的供应商能否按时到车，不能只听口头承诺，必须设定**可视化、可验证**的履约标准。以下是具体、可执行的核心判断维度：

### 第一步：合同与信息前置（书面约束）
在合同或订单备注中，**必须写明**以下三条，做不到的直接排除：
1.  **时间弹性**：明确“到车时间”是指**车停靠档口时间**，而非“发车时间”或“装货时间”（防止供应商把“装车中”算成“已出发”）。
2.  **违约条款**：写明“延迟超过X小时（建议6小时），每吨扣XX元，或有权拒收”。如果对方对扣款条款含糊其辞，合作风险高。
3.  **实时定位共享**：要求装货完成后，**必填**GPS定位共享（货拉拉、运满满、地图实时位置均可），口头报“在路上”无效。

### 第二步：用“装货进度”代替“发车时间”判断
香蕉产地（如老挝、云南、广西）装货常会因采摘、催熟、打包耽误。**不要问“几点能到”**，而要问：
- **现在几点能装满？**（问具体库位和装了一半没）
- **车是17米还是9.6米？装了几吨了？**（如果傍晚说“马上装完”，第二天早上还没到，基本就有问题）
- 要求对方**拍下驾驶室里程表的照片**（显示当前公里数），并记录发车前的公里数，以此计算预计用时。

### 第三步：关注“车辆状态”而非“货源状态”
按时到车的关键不在香蕉，在于**车有没有着落**。
- 明确问：**“车是你们自己的长期合作车队，还是今天临时叫的？”**
  - 长期车队：通常有固定调度，违约成本高，相对可靠。
  - 临时叫车：如果对方说不清车牌号、司机电话，或司机电话打不通，**大概率要晚点**。
- 如果是产地直发，问**“司机熟不熟路”**。熟路司机对采摘点和催熟房位置熟悉，能省1-2小时卸货装车时间。

### 第四步：反向测试（重要技巧）
- 在预计到货前**4小时**，打电话要求**“今晚必须到，如果到不了我这边就换货了”**。
- **观察反应**：
  - 靠谱供应商会立刻说“我在催司机，刚才到XX服务区了，拍给你看”，并给出具体位置信息。
  - 不靠谱的会说“在路上了在路上了”，但**无法提供任何定位截图或服务区名称**，这类要立刻启动备选方案。

### 第五步：建立“备胎机制”（应对突发）
- 如果该供应商**连续两次**出现“到车时间误差超过4小时”，视为不稳定，应并行联系**1-2家备选供应商**（哪怕价格贵1毛/斤），并把“备胎”安排在下一次订单的同一时段，作为保险。

---

**特别提醒（香蕉属性）**：香蕉是呼吸跃变型水果，如果车在路上因堵车或故障耽误超过8小时，到货后果皮可能提前出现梅花点或青熟不均，**按时到车比价格重要得多**。如果条件允许，优先选择**离你市场半径300公里以内**的产地供应商，因为距离越短，不可控变量越少。

**如果对方始终只回复“没问题”“放心”却不提供任何事实依据（车牌、装车视频、定位），无论跟您关系多熟，建议视为不能按时到车，立即启动备用采购。** 在生鲜行业，**看得见的数据**比承诺可靠得多。
