生鲜平台做一件代发（即平台接单后，由供应商直接按订单分拣、打包并发给消费者）时，对供应商的仓配能力要求远高于传统的批发供货。这不仅仅是“有货”的问题，而是“接得住订单、发得出好货、扛得起售后”的综合能力。

以下是供应商必须具备的**核心仓配能力清单**，按重要性排序：

### 1. 精准的分拣与打包能力（决定退货率）
-   **按单拣货（拆零）能力**：必须能脱离整箱包装，按平台SKU（单品）进行拆零分拣。系统需支持扫描枪或PDA操作，确保**单货相符**，避免发错货。
-   **专业水果打包工艺**：
    -   **缓冲材料**：必须配备珍珠棉、气泡柱、网套、吸塑托盒等，针对不同水果（如桃子怕压、葡萄怕掉粒、芒果怕碰伤）定制不同包装。
    -   **分级定重**：必须建立严格的重量/规格标准（如单果重、果径），打包时复秤，避免“大果小果混发”导致客诉。
    -   **保鲜耗材**：需备有吸水纸、冰袋（针对草莓、蓝莓）、气调保鲜袋（针对荔枝）等。

### 2. 高效的仓储调度能力（决定履约时效）
-   **合理库位规划**：按水果成熟度、发货批次区分库区，设立“待采区”“冷藏区”“打包区”“待发货区”，防止串货和积压损耗。
-   **日处理峰值处理能力**：必须清楚自己的**最大日发货量**（单日可打包多少单）。平台大促或爆单时，要有应急召集临时工或外包团队的能力，确保**当天17：00前订单当天发出**（大多数平台的时效红线）。
-   **库存实时同步**：库存必须与平台系统打通（API或手动及时更新），避免超卖（接了单却无货发）。

### 3. 温控与冷链供应链能力（决定损耗率）
-   **全链路预冷**：水果采收后需快速预冷（冷库/真空预冷），发货时包装内需有**保鲜介质**（冰袋+保温箱）以维持控温运输。
-   **常温/冷链分仓**：如果是香蕉、木瓜等热带水果，需有催熟库；如果是车厘子、草莓，必须配备3-5℃冷库，且打包区最好也在恒温环境操作，否则冰袋融化快。

### 4. 快递网络与转运能力（决定物流评分）
-   **快递资源对接**：必须与顺丰、京东、中通冷链等合作，签订**生鲜专项协议**（含顺丰优先中转、丢损理赔绿色通道）。最好有固定的揽收时间点（如下午2点和5点两班），确保打包完即走。
-   **异常件拦截能力**：具备在发运途中拦截订单（如买家突然退款、地址错误）的能力，这需要和快递网点有即时协同机制。

### 5. 售后赔付与补发能力（决定店铺评分）
-   **“坏果包赔”兜底机制**：必须建立独立售后库存（预留5%-10%的货作为补发备用仓）。遇到坏果，能快速判定责任并**秒退款**或**立即补发**，不能等客户拍照逐一扯皮。
-   **快速响应时效**：需承诺“签收12小时内反馈坏果率”，并立即处理，因为水果时效性极强，拖延会造成严重客诉。

---

### 特别提醒（规避踩坑）：

1.  **不要试图用“没拆箱”来做一件代发**：很多供应商有整箱货，直接贴面单发出去，导致平台大量“货不对板”“缩水”差评，这是做不好的根本原因。
2.  **成本账要算清楚**：一件代发的打包耗材成本+快递生鲜运费+坏果赔付率，通常占售价的25%-40%。如果毛利低于这个水平，建议只对平台供应整箱，不要做代发。
3.  **建议先做“代发测试”**：供应商可以先向平台申请 **“样品试发”** ，寄几个样品到不同省份（如海南发北京、发哈尔滨），观察3-5天到货状态和果损情况，再决定是否正式开仓代发。
