在水果店采购菠萝时，判断成熟度主要看**外观、质地和气味**，三者结合最可靠：

1. **看颜色**：成熟菠萝表皮呈**橙黄色或金黄色**，颜色越深通常越熟（但全绿的菠萝多半未熟）。注意：**不要选有黑斑或软烂处**的，说明已过熟或内部变质。
2. **捏硬度**：用手轻按菠萝，**果肉有轻微弹性但不塌陷**为最佳。太硬说明未熟（酸涩），太软说明过熟（易腐烂，损耗会高）。
3. **闻气味**：靠近菠萝底部闻，成熟菠萝有**浓郁香甜味**；无味或青草味说明未熟，有酸味或酒味说明已变质。
4. **看底部和叶子**：底部切口干燥且无异味；叶子翠绿、挺立的新鲜。叶子发黄干枯说明存放过久。

**采购建议（针对损耗控制）**：
- 门店销售周期短（如1-2天），买**七八成熟**（表皮黄中带绿、微硬）的，到店可继续催熟，不易当天烂。
- 若按周备货，优先选**全黄但硬实**的（当天可卖），再备少量未熟用于后续。
- **避开**雨天采的菠萝或表皮发粘的，易快速腐坏。

**额外提醒**：菠萝损耗常源于**削皮后氧化变黑**，建议到店后再削，现切现卖，并控制单次削皮数量。
